# 原生宿主与界面

沿用仓库根目录的权限、测试隔离、日志和提交规则。前端仅使用 GPUI 与应用数据，窗口和操作系统集成放在 platform 及宿主模块。

- UI 文案用 locales，主题与应用元数据用 resources；硬件信息必须来自实际快照，缺失数据保持未知。
- 菜单、下拉列表、悬浮提示与通知使用背景和边框区分，显式关闭组件库默认投影；对话框保留遮罩与投影。RTX 4080 SUPER、4K、150% 缩放、HDR 关闭时曾出现随截图工具启动而消失的亮色光晕，历史修复见 `904bc43`、`77251a2`；重构与组件升级时需保留此处理。
- 测试只启动自身的 --hidden --test --identifier 实例，通过窗口探针不激活显示和捕获，禁止调用会抢占用户桌面的激活路径。
- 曲线时间来自采集时间戳，保留未知区间与暂停语义；避免在每帧复制快照或重建表格。渲染变化需检查真实呈现与隐藏开销。
- 更新公钥和版本签名约束不可改变，安装前二次验签。耗时命令不运行在 UI 线程。
- 平台能力与前端分离；macOS 不可用的采集或操作不能返回模拟成功。

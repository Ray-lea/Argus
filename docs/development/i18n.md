# 多语言

界面、托盘与原生错误共用 locales。zh-CN 为源文案，en-US 在相同命名空间提供译文。完整界面键包含文件名前缀，例如 settings.update.check；native.json 的键直接使用，例如 tray.quit。

GPUI 宿主注册界面目录后，统一通过 argus_core::tr! 格式化带占位符的文案；不带占位符的标签使用 frontend::theme::label。动态键保留为语义字段，在渲染时按当前语言查找。日期、字节数和单位使用原生格式化辅助函数。

语言切换重新构建表头、菜单与主题相关标签，不在模块级缓存译文。复数采用 one/other 目录，数字 count 决定形式。辅助进程通过 ARGUS_LOCALE 继承语言；服务使用所在系统账户的显示语言。Rust 测试不得调用 set_locale 或断言具体译文。

用户可见文字必须写入两份目录；日志、panic 与注释不翻译。node scripts/i18n.mjs 检查键、占位符、富文本标签和代码中直接写入的中文。安装器使用 NSIS LangString 与 ARGUS_TEXT，不能读取应用 JSON。

增加语言时需补齐所有目录，在 argus-core 的 Locale 和原生设置选项中注册，并使用模拟快照检查所有页面排版。

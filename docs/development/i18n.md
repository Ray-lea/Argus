# 多语言

界面、托盘和原生错误共用 [`locales`](../../locales)。`zh-CN` 为源文案，`zh-TW` 與 `en-US` 在同一命名空间提供译文。界面键带文件名前缀，如 `settings.update.check`；`native.json` 中的键直接写作 `tray.quit`。

GPUI 宿主注册文案目录后，用 `argus_core::tr!` 格式化带占位符的文字，用 `frontend::theme::label` 读取静态标签。动态键在绘制时按当前语言解析，日期、字节数和单位由原生格式化函数处理。

切换语言时重新构建表头、菜单及主题标签。复数按 `count` 选择 `one` 或 `other`。辅助进程可通过 `ARGUS_LOCALE` 继承语言，服务使用所在系统账户的显示语言。Rust 测试应核对键与数据，避免修改进程级语言或依赖具体译文。

用户可见的文字在两份目录中维护。日志、panic 和注释使用英文。`node scripts/i18n.mjs` 检查文案键、占位符、富文本标签和代码中直接写入的中文。安装程序通过 NSIS `LangString` 与 `ARGUS_TEXT` 提供双语文字。

增加语言时需补齐所有目录，在 argus-core 的 Locale 和原生设置选项中注册，并使用模拟快照检查所有页面排版。

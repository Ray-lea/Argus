# 多语言

界面、托盘、原生错误和安装程序共用 [`locales`](../../locales)。`zh-CN` 为源文案；`zh-TW`、`en-US`、`es-ES`、`de-DE`、`ja-JP`、`fr-FR`、`ru-RU` 在同一命名空间提供译文。界面键带文件名前缀，如 `settings.update.check`；`native.json` 中的键直接写作 `tray.quit`。语言选项使用各语言的原生名称，方便在任意界面语言下识别。

GPUI 宿主注册文案目录后，用 `argus_core::tr!` 格式化带占位符的文字，用 `frontend::theme::label` 读取静态标签。动态键在绘制时按当前语言解析，日期、字节数和单位由原生格式化函数处理。

组件库 `gpui-component` 另有自己的文案目录，仅含英文、简体中文、繁体中文和意大利文。`catalog::set_locale` 在设置界面语言时把同一语言标签传给组件库，其余语言回退到英文；这份目录用于组件库自行绘制的文字，即触摸长按文本框时的编辑菜单和无障碍标签。文本框的右键菜单由 `widgets::input` 用 `common.edit` 的文案构建，覆盖全部语言。使用带内置文字的组件时，同样从 `locales` 传入文案。

切换语言时重新构建表头、菜单及主题标签，字体回退按语言分别缓存，日语优先使用 Yu Gothic UI / Meiryo，繁体中文优先使用 Microsoft JhengHei UI / Microsoft JhengHei。系统语言按 Windows 显示语言选择，未支持时查找用户首选语言列表，最后使用英文；同一语言的区域变体共用目录，如 `es-MX` 使用 `es-ES`、`fr-CA` 使用 `fr-FR`。中文按脚本区分：`Hant` 使用 `zh-TW`，`Hans` 使用 `zh-CN`；未指定脚本时，中国台湾、中国香港、中国澳门使用 `zh-TW`，其他地区使用 `zh-CN`。显式脚本优先于地区，旧式 `zh-CHT` / `zh-CHS` 也分别对应繁体 / 简体中文。辅助进程可通过 `ARGUS_LOCALE` 继承语言，服务使用所在系统账户的显示语言。

复数按原始数值参数 `count` 和 CLDR 基数规则选择：中日文使用 `other`，英文和德文使用 `one/other`，西班牙文和法文使用 `one/many/other`，俄文使用 `one/few/many/other`。`many` 覆盖法文和西班牙文的整数百万倍数；俄文区分 1、2–4、5–20 及 21、22 等尾数，有小数部分时使用 `other`。需要分组显示整数时使用 `theme::counted`，小数数量使用 `theme::quantity`：原始数值交给 `i18n::format_count` 选择复数，区域格式化结果替换 `{count}`，避免把分组符当作小数点。刷新间隔等小数也通过区域格式化函数显示。原生层和界面共用选择逻辑；缺失条目先回退英文，再回退源文案。测试使用显式语言参数，避免修改进程级语言或断言具体译文。

数字与完整日期遵循 Windows 区域设置，独立于界面语言：小数点、分组符及分组位数在启动时读取，日期使用系统的短日期和时间格式。时间戳按该时刻的本地时区偏移转换；历史曲线的紧凑日期标签使用界面语言，时间轴保持 24 小时制。数字输入保留输入法组字，提交时识别区域小数符、点号及全角数字；不解析分组符。版本、PID、端口、路径、设置文件和协议数据保持原格式。

用户可见的文字在所有语言目录中维护。日志、panic 和注释使用英文。`node scripts/i18n.mjs` 检查文案键、占位符、各语言所需的复数形式、富文本嵌套、空译文、隐藏控制字符、月份数量，以及原生层、桌面和安装程序的语言注册是否一致。法文和俄文的 `one` 覆盖多个数值，译文必须保留 `{count}`。日语允许汉字，语言名称保持原生文字。路径、文件名、命令行参数、`Debugger`、`UseFilter` 和 JSON 的 `null` 等技术标识保留原文。安装文案在 `installer.json`，打包时由 `scripts/lib/installer-locales.mjs` 转成 NSIS `LangString`；钩子通过 `ARGUS_TEXT` 引用键。安装帮助进程接受各语言的 Windows LANGID，静态文本按字面显示路径中的 `&`。

更新日志保留简体中文和英文两份；繁体中文优先使用对应译文，缺少时显示简体中文。其他界面语言优先显示该版本提供的对应译文，缺少时显示英文，英文也缺少时显示中文。官网与仓库说明文件的语言独立维护。

增加语言时需补齐所有目录，在 argus-core 的 Locale 和原生设置选项中注册，并使用模拟快照检查所有页面排版。

窗口复核可运行 `node scripts/ui-shots.mjs l10n-ja tools/window-probe/steps/localization.json --language ja-JP`，更换标签和语言后复用同一步骤。该步骤覆盖所有页面、首次启动引导、最小窗口与 20 px 字号、150% 界面缩放。安装向导文字需同时考虑 NSIS 控件高度和各语言字体的实际行高。

历史刻度按本地时间边界计算，跨夏令时跳过不存在的时刻并保留回拨后的重复时刻；选中时刻附加 UTC 偏移，标签宽度使用实际字体测量。区域格式测试直接对照 Windows 的区域 API，时区测试读取 Windows 时区数据库，均不改变系统设置。快捷键录制从主窗口当前的原生消息获取虚拟键与修饰键，松开修饰键或字形变化后仍以同一虚拟键结束录制；测试输入保留字符映射回退。

# 性能测量

测量使用发行构建、独立应用标识与相同数据源，记录窗口客户区物理尺寸、DPI、刷新间隔、曲线模式、设备、主题和实际呈现帧率。CPU 与 GPU 比较需要相同的实际画面和节拍；设置的 FPS 不等于实际 FPS。

tools/window-probe 通过 Job 跟踪测试进程，采样累计 CPU 时间、内存及 GPU 引擎时间，通过 Windows.Graphics.Capture 观察目标窗口的呈现间隔。DWM 服务整个桌面，其消耗不能全部归因于 Argus。忙碌开发机上的进程占用结果需要多轮交替与稳定性判断。

应用以 --hidden --test --identifier <独立标识> 启动；工具使用 HWND_BOTTOM 和 NOACTIVATE 显示，并每 50 ms 监视前台。截图与帧统计只捕获该窗口，隐藏窗口的回调不能替代实际呈现统计。测试完退出实例并清理自身测试数据。

渲染变更关注长帧分布、连续更新时的路径构建次数、可见和隐藏状态开销。静态文字或布局修正不需要重复完整性能对照。详细原始结果留在 target，不作为跨技术栈通用基线。

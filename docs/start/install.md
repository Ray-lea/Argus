# 安装与更新

本页说明 Argus 的系统要求、安装版与免安装版的区别，以及下载、安装、更新与卸载的方法和数据的保存位置。

## 系统要求

Argus 对系统与硬件的要求如下：

- 操作系统：Windows 10 22H2（内部版本 19045）及以上版本，包括 Windows 11；支持 x64 与 ARM64 架构。
- 图形：支持 DirectX 11 的图形设备与驱动。

各系统版本的功能差异与权限要求见[系统兼容范围](../guide/hardware-data.md#系统兼容范围)。

## 选择版本

每个版本提供安装版与免安装版，各有 x64 与 ARM64 两种架构：

| 版本 | 文件 | 特点 |
| --- | --- | --- |
| 安装版（推荐） | `Argus_<版本>_x64-setup.exe`、`Argus_<版本>_arm64-setup.exe` | 为所有用户安装到 Program Files，支持应用内更新 |
| 免安装版 | `Argus_<版本>_x64.exe`、`Argus_<版本>_arm64.exe` | 单个程序文件，直接运行 |

两种版本共用设置与历史数据，从免安装版改用安装版后无需重新配置。与安装版相比，免安装版缺少以下功能：

- 应用内更新
- 开始菜单快捷方式与卸载入口
- 特权服务与任务管理器替换随版本自动更新

> [!WARNING]
> 免安装版放在标准用户可写的文件夹中时，安装特权服务存在被替换提权的风险。需要特权服务时使用安装版，原因见[权限](../guide/settings.md#权限)。

## 下载与校验

最新稳定版在[官网下载页](https://argustask.com/download/)下载，全部版本在 [GitHub Releases](https://github.com/Ray-lea/Argus/releases) 下载。每个版本附带 `SHA256SUMS.txt`，列出各发布文件的 SHA-256 校验值。

在 PowerShell 中计算下载文件的 SHA-256，再与 `SHA256SUMS.txt` 中的值比较：

```powershell
Get-FileHash .\Argus_<版本>_x64-setup.exe -Algorithm SHA256
```

## 安装

安装与升级需要管理员授权。按以下步骤安装：

1. 运行安装程序，在 Windows 的管理员授权提示中允许。
2. 在安装页确认安装位置，单击**立即安装**。
3. 安装完成后，单击**启动 Argus**，或稍后从开始菜单打开。

已安装旧版本时，安装页显示将从哪个版本升级到哪个版本，按钮为**立即升级**，覆盖安装而不先卸载。已安装更新的版本时无法直接安装较旧的版本，需要先卸载。

新安装时，若所选位置不在本机固定磁盘上，或所在文件夹的权限不安全，安装程序会说明原因，并提供仍然安装或更改位置两种选择。判定规则见[安装位置的权限](../development/release.md#安装位置的权限)。

## 更新

安装版通过应用内更新升级到新版本：

- 自动检查在启动约 1 分钟后进行一次，此后每天一次，也可在**设置 → 更新**中手动检查。
- 更新通道分为稳定版与测试版。下载线路为**自动**时，依次尝试 GitHub、Argus 官方镜像与加速代理。
- 安装包与更新内容都经过签名校验，校验不通过的安装包不会安装。

更新的设置与下载线路见[更新](../guide/settings.md#更新)，从 0.x 版本升级时的数据处理见[旧版升级与数据](../guide/settings.md#旧版升级与数据)。

免安装版不能应用内更新，需要从官网或 GitHub 下载新版本，替换原来的程序文件。

## 卸载

安装版通过 Windows 的应用列表卸载。卸载程序的确认页可以选择同时删除应用数据。

> [!CAUTION]
> 删除应用数据后无法恢复。需要保留历史记录时，先备份历史文件夹。

按以下步骤卸载：

1. 在 Windows 11 的**设置 → 应用 → 已安装的应用**中，或 Windows 10 的**设置 → 应用 → 应用和功能**中，找到 Argus 并卸载。
2. 在卸载程序的确认页选择是否同时删除应用数据，然后确认卸载。

安装了特权服务时，卸载程序还会询问是否一并卸载特权服务；一并卸载时，先恢复系统任务管理器。

免安装版没有卸载入口，删除程序文件即可。设置与历史数据仍保留在下文所列的位置，可手动删除。

## 数据的位置

安装版与免安装版的数据保存在同一组文件夹中：

| 内容 | 位置 |
| --- | --- |
| 设置与界面偏好 | `%APPDATA%\dev.argus.taskmanager` |
| 历史记录 | `%LOCALAPPDATA%\dev.argus.taskmanager\history`，可在设置中更改 |
| 诊断日志 | `%LOCALAPPDATA%\dev.argus.taskmanager\logs\diagnostics` |

诊断日志可在**关于**页打开所在的文件夹，报告问题时附上相关的日志。

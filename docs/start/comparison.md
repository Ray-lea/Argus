# 与系统任务管理器对比

本页比较 Argus 与 Windows 自带的任务管理器，列出两者的共同功能、响应速度与功能差异，并说明各自适合的场合。

## 共同的功能

两者都提供日常管理进程与查看性能所需的基本功能：

- 按应用查看进程的资源占用，结束进程或进程树。
- 查看 CPU、内存、磁盘、网络与 GPU 的实时曲线。
- 启动、停止服务；启用、禁用登录时启动的程序。
- 设置优先级、开启效率模式、创建内存转储文件。
- 运行新任务、重新启动 Windows 资源管理器。

Argus 中的同类操作与系统任务管理器保持一致。例如效率模式同样把进程安排到能效核并降低优先级，启动项的开关与系统任务管理器共用同一个状态。

## 响应速度

同样的操作，Argus 的响应比系统任务管理器快得多。下表是同一台电脑上从单击到目标画面出现的耗时中位数：

| 操作 | Argus | 系统任务管理器 |
| --- | --- | --- |
| 进程 → CPU 性能 | 139 ms | 567 ms |
| CPU 性能 → 进程 | 92 ms | 1405 ms |
| 服务 → 进程 | 232 ms | 1475 ms |
| 进程 → 服务 | 231 ms | 269 ms |
| 按 PID 排序 | 41 ms | 458 ms |
| 选中另一行 | 37 ms | 45 ms |

进程页与 CPU 性能页之间的切换、从服务页回到进程页以及排序，Argus 的耗时只有系统任务管理器的 1/15–1/4。从进程页切到服务页、选中另一行两项相差不大。

测量在一台物理机上进行（Intel Core i5-13500HX，Windows 11 26H2，窗口客户区 960×620），对象为 Argus 0.3.4 的 GPUI 开发构建与系统任务管理器 10.0.26100.9549，两者均以管理员身份运行。每项操作交替测量 12–16 次，计时从鼠标单击开始，到窗口中首次出现目标画面为止。测量方法与原始数据见[首页实测数据的说明](../../website/src/data/README.md)。

## 功能对比

下表列出两者在信息与操作上的差异：

| 功能 | Argus | 系统任务管理器 |
| --- | --- | --- |
| 资源占用的历史 | 默认保留 30 天，可回看任一时刻占用最高的进程 | 性能页的曲线显示最近 60 秒 |
| CPU 温度与功耗 | 显示；部分处理器的读数需要开启内核传感器 | 不显示 CPU 温度 |
| 磁盘健康 | 显示健康状况、剩余寿命与 SMART 属性 | 无 |
| 网络连接 | 列出 TCP、UDP 端点及所属进程，可断开 IPv4 TCP 连接 | 无，资源监视器可查看 |
| 文件占用 | 拖入文件或文件夹，列出占用它的进程 | 无，资源监视器可搜索关联的句柄 |
| 服务 | 启动、停止、重新启动，修改启动类型，删除服务 | 启动、停止、重新启动 |
| 启动项 | 启用、禁用、删除，标出已失效的项目 | 启用、禁用 |
| 资源泄漏 | 标出可能泄漏句柄或残留进程的程序 | 无 |
| 常驻显示 | 托盘图标、悬停卡片、桌面监控与任务栏监控 | 无桌面与任务栏监控 |
| 自动规则 | 程序每次启动时自动套用优先级等设置 | 无 |
| 界面语言 | 9 种，可独立于 Windows 的显示语言选择 | 跟随 Windows 的显示语言 |
| 获取方式 | 下载安装版或免安装版 | 随 Windows 提供 |

各功能的用法见[使用指南](../guide/README.md)，读数的来源与限制见[硬件数据的来源与限制](../guide/hardware-data.md)。

## 适合的场合

系统任务管理器随 Windows 提供，无需下载，适合在任何一台电脑上临时查看或结束进程。

Argus 适合以下场合：

- 经常切换页面或排序，希望常用操作更快响应。
- 需要回看过去某一时刻是哪个程序占用了资源。
- 需要查看 CPU 温度、功耗或磁盘的健康状况。
- 需要管理服务的启动类型、删除服务或启动项。
- 需要排查网络连接、文件占用或资源泄漏。
- 希望在桌面或任务栏上常驻显示读数。

## 替换系统任务管理器

Argus 可以替换系统任务管理器：开启后，按 Ctrl+Shift+Esc 或从任务栏菜单打开任务管理器时，打开的是 Argus。替换需要特权服务，开启与恢复的方法见[替换系统任务管理器](../guide/settings/task-manager.md)。

替换后仍可临时打开系统任务管理器，也可随时恢复。替换的实现与卸载时的处理见[系统任务管理器替换](../architecture/task-manager.md)。

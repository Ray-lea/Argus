# 快速入门

本页带领新用户完成 Argus 的下载、安装与首次启动，再依次使用进程、性能与历史三个常用页面，最后让 Argus 在后台常驻。

## 1. 下载并安装

安装版支持应用内更新，推荐大多数用户使用。按以下步骤安装：

1. 打开[官网下载页](https://argustask.com/download/)，下载与电脑架构对应的安装程序：x64 电脑选 `Argus_<版本>_x64-setup.exe`，ARM64 电脑选 `Argus_<版本>_arm64-setup.exe`。
2. 运行安装程序，在 Windows 的管理员授权提示中允许。
3. 在安装页单击**立即安装**。
4. 安装完成后，单击**启动 Argus**。

不安装也能使用：免安装版是单个程序文件，两种版本的区别见[安装与更新](install.md#选择版本)。

## 2. 完成首次启动的引导

第一次启动时，Argus 显示引导，依次设置以下内容：

1. 界面语言。
2. 导航栏的位置、界面动画、曲线动画与刷新频率。
3. 登录 Windows 时启动、关闭窗口时保留在托盘、后台的刷新间隔，以及显示或隐藏窗口的快捷键。
4. 自动检查更新、更新通道与下载线路。
5. 可选的管理员运行、特权服务与内核传感器。
6. 是否用 Argus 替换系统任务管理器。
7. 常用操作的提示。

每一步的修改立即保存。任何一步都可以单击**跳过**或按 Esc 结束引导，之后可在**关于**页重新打开。

> [!TIP]
> 暂时不确定是否需要特权服务、内核传感器或替换任务管理器时，可先跳过，之后在**设置**中开启。

## 3. 认识窗口

窗口由上到下分为四个区域：

| 区域 | 内容 |
| --- | --- |
| 标题栏 | 当前页面的搜索框，以及置顶显示、最小化、最大化与关闭按钮 |
| 导航栏 | 各页面的标签；也可在设置中改到窗口左侧 |
| 页面 | 当前页面的内容；页面栏放当前页面的控件与**更多操作**菜单 |
| 状态栏 | 版本号、系统计数、刷新控件与权限标记 |

按 Ctrl+1 至 Ctrl+9 切换到对应的页面，按 Ctrl+Tab 或 Ctrl+Shift+Tab 切换到下一个或上一个页面。各区域的说明见[窗口布局](../guide/README.md#窗口布局)。

## 4. 查看与结束进程

进程页列出正在运行的程序及其资源占用。

> [!CAUTION]
> 结束进程后，该程序中未保存的数据会丢失。按 Shift+Delete 结束进程时不再确认。

按以下步骤找到并结束一个进程：

1. 按 Ctrl+1 打开**进程**页。
2. 按 Ctrl+F，输入程序的名称进行搜索。
3. 选中目标进程，按 Enter 查看它的详细信息。
4. 按 Delete 或 Alt+E 结束进程，在确认框中确认。

在进程上单击右键，还可以设置优先级、开启效率模式，或添加在程序每次启动时套用的规则。

## 5. 查看性能

按 Ctrl+2 打开**性能**页，在左侧的设备列表中选择 CPU、内存、磁盘、网络或 GPU 等设备。在 CPU 图表上单击右键，可以在**整体视图**与**多核视图**之间切换。

按住 Ctrl 时，进程页与性能页暂停刷新，曲线停在按下的瞬间，松开后恢复。

## 6. 回看历史

Argus 运行时每 5 秒记录一帧读数，默认保留 30 天。按以下步骤查看过去某一时刻的情况：

1. 按 Ctrl+6 打开**历史**页。
2. 单击导航条左侧的时间范围按钮，选择 5 分钟、3 小时、1 天、3 天或自定义范围。
3. 单击曲线上的任一时刻，查看当时占用最高的进程。

## 7. 在后台常驻

默认情况下，关闭窗口后 Argus 留在通知区域（托盘），采样、历史记录与规则继续运行，托盘图标实时显示 CPU 占用。按 Ctrl+Alt+Esc 可随时显示或隐藏窗口。

## 常见问题

以下是初次使用时常见的几个问题。

<details>
<summary>为什么看不到 CPU 温度？</summary>

CPU 温度优先取自处理器的内部传感器，这需要开启**内核传感器**，它依赖特权服务与 PawnIO 驱动。未开启时回退到 ACPI 热区，部分主板没有这一接口。

</details>

<details>
<summary>关闭窗口后，Argus 还在运行吗？</summary>

默认仍在运行，窗口隐藏到托盘。完全退出时，在托盘图标上单击右键打开快捷面板，再单击**退出 Argus**。关闭**关闭窗口时保留在托盘**后，关闭窗口即退出 Argus。

</details>

<details>
<summary>如何恢复系统任务管理器？</summary>

在**设置 → 权限**的**替换系统任务管理器**卡片中，单击**恢复 Windows 任务管理器**。只想临时使用时，单击**临时打开系统任务管理器**，替换设置保持不变。

</details>

<details>
<summary>设置与历史记录保存在哪里？</summary>

设置保存在 `%APPDATA%\dev.argus.taskmanager`，历史记录与诊断日志保存在 `%LOCALAPPDATA%\dev.argus.taskmanager`。安装版与免安装版共用这些数据，换用另一种版本后无需重新配置。

</details>

使用中遇到其他问题，可在 [GitHub 讨论区](https://github.com/Ray-lea/Argus/discussions/categories/q-a)提问，或按[参与贡献](../../.github/CONTRIBUTING.md)中的说明报告缺陷。

# 界面与操作

Argus 的窗口顶部是工具栏，下方是导航栏、当前页面和状态栏。导航栏默认位于工具栏下方，也可以改为位于窗口左侧；进程页可在列表上方显示系统概况带。

“设置 → 语言与外观 → 进程概况带”提供“自动”（默认）、“始终显示”和“隐藏”。自动模式仅按固定高度预算预留概况带、表头、滚动条与虚拟的 10 行进程；窗口空间不足时收起。计算使用完整页面高度，与实际进程数量、分组折叠、搜索筛选、滚动位置及概况带当前是否显示无关，避免收起后空间增大又反复展开。展开和收起以高度过渡带动列表移动；关闭界面动画时直接切换。隐藏期间仍继续采集数据和维护曲线历史。

## 首次启动

第一次启动时显示引导，依次完成常用设置：界面语言；导航栏的位置、界面动画、曲线动画与刷新频率；登录 Windows 时启动、关闭窗口时保留在托盘、最小化与后台常驻时的刷新间隔，以及显示或隐藏窗口的快捷键；自动检查更新、更新通道与下载线路；可选的管理员运行，授权后在完成引导时切换权限；可选的特权服务及其授权范围，可以在引导中直接安装（需要管理员授权），也可以跳过、之后在“设置 → 权限”中安装；可选的内核传感器（依赖特权服务，开启时自动准备 PawnIO 驱动，需要管理员授权）；是否用 Argus 替换系统任务管理器（依赖特权服务，同样需要管理员授权）；最后是常用操作的提示。每一步的修改立即保存，任何一步都可以单击“跳过”或按 Esc 结束，之后随时可以在[关于](#关于)页重新打开引导。

免安装版在引导第一步的“界面语言”下方说明与安装版相比缺少的功能：应用内更新、开始菜单快捷方式与卸载入口，以及特权服务与任务管理器替换随版本自动更新；“前往官网下载”打开官网下载页，“前往 GitHub 下载”打开 GitHub 上的最新版本。首次启动的引导结束后，右下角再提示一次相同的内容和两个下载入口，约 30 秒后自动收起，指针停留时保持显示；此前已完成引导的账户，在下一次以免安装版启动并显示窗口时提示。该提示在每个 Windows 账户下仅出现一次，从关于页重新打开引导时不再出现，出现提示的那一次运行不再显示 Star 提醒；由任务管理器替换入口启动的那一次运行不提示，留到之后的正常启动。安装版与免安装版共用设置和历史数据，改用安装版后无需重新配置。

## 页面

进程页的视图切换右侧、连接页的状态筛选右侧均提供“隐藏系统进程”按钮，默认关闭，开启时以强调色标记。两个页面分别保存开关；进程页的按应用、进程树和列表均适用。隐藏仅影响列表，系统概况、采集、历史记录与规则继续保留完整数据；隐藏父进程后，其余子进程仍可显示。从服务或连接等入口定位被隐藏的进程时，会自动关闭进程页的隐藏开关以显示目标。

工具栏仅显示图标，悬停可查看操作说明；规则位于“设置 → 语言与外观 → 系统进程隐藏规则”。默认识别 Windows 系统组件，同时保留资源管理器、命令提示符、控制台与 PowerShell（`explorer.exe`、`cmd.exe`、`conhost.exe`、`openconsole.exe`、`powershell.exe`、`pwsh.exe`）。可编辑“始终显示”和“额外隐藏”名单，按程序文件名匹配、不区分大小写，两页共用；单击“保存”后生效并持久保存。“始终显示”优先，恢复默认规则后需保存。

进程页可在最外层按登录用户分组，由“设置 → 语言与外观 → 按用户分组进程”控制：“自动”（默认）仅在多个用户同时登录时分组，已断开连接但未注销的会话计入；“始终分组”与“不分组”固定为所选状态。有用户登录或注销后，列表随下一次采样更新，无需重启。

每个用户一组，当前会话的用户在前，其余用户按名称排列，最后是“系统”；各组的先后不随列排序变化。进程归入其所在会话的登录用户，同一用户的多个会话合为一组，两个用户名称相同时显示为“域\用户名”。无用户登录的会话归入“系统”，包括系统服务所在的会话 0 和停在登录界面的会话。分组行显示用户名、进程数与各列的资源合计，用户的全部会话均已断开时标注“已断开连接”；单击可折叠或展开，折叠状态随配置保存。

组内的显示与不分组时相同：三种视图、按名称排序时的三类分组、列排序、搜索和“隐藏系统进程”都在各组内部生效。进程树只连接同一组内的父子进程，父进程属于其他组的进程列在本组的顶层。同一程序由两个用户运行时，按应用视图在各自组内各占一行，详细信息面板的进程数、资源与曲线只统计该用户的进程。折叠某一类（如“Windows 进程”）对所有用户组同时生效；搜索时显示全部匹配项，没有匹配项的用户组不显示。

在用户的分组行上单击右键，除折叠或展开外还有两项，与任务管理器“用户”页相同：“管理用户账户”打开控制面板的用户账户页面；“注销”在确认后结束该用户的全部会话，其中运行的程序随之关闭，未保存的数据可能丢失。注销当前用户与从“开始”菜单注销相同，程序仍可提示保存，Argus 随会话一同退出。注销其他用户需要管理员权限，仅在以管理员身份运行的 Argus 中可用，否则该项不可选并标注“需要管理员权限”。“系统”分组只能折叠或展开。

连接页开启隐藏时，还会过滤 PID 为 0 的“无所属进程”记录。这类记录常见于 TCP 关闭后的 `TimeWait` 阶段，等待协议回收；UDP 的 PID 为 0 表示系统未提供归属。它们没有可供定位或结束的用户进程。其他 PID 暂时缺少身份信息时保留显示。

## 选择进程列

在进程列表的表头右键打开列菜单。指针所在的列可直接升序或降序排序、隐藏该列（名称列除外），或“自动调整此列宽度”。“基本信息”“CPU”“内存”“磁盘与 I/O”“网络”“GPU”六个子菜单列出全部 44 项属性并显示已选数量，单击即显示或隐藏对应的列，子菜单保持打开，可连续调整。菜单下方是“选择列…”“自动宽度”“全宽”和“恢复默认列”。

“选择列”对话框左侧按分类分组列出属性及说明，可按分类筛选、按列名或说明搜索，分类标题旁的“全选”“清空”作用于该分类当前列出的属性。右侧“显示顺序”按表格顺序列出已选的列：拖动时该项浮起并跟随指针，其余项实时让位；指针悬停时可上移、下移或移除。修改在单击“确定”后应用并保存；“取消”或 Esc 保留原设置。名称列固定显示在最前，所选列在按应用、进程树、列表三种视图间共享，并在重启后保留。

拖动表头可调整列顺序，名称列固定在最左侧。拖动时整列跟随指针，越过相邻列的中线即与之交换位置，其余列平滑让位；松开后该列滑入新位置。顺序会保存；暂时隐藏后重新选中的列回到原位置。动画遵循“界面动画”设置，关闭时直接换位。

“自动宽度”默认开启，根据列标题、汇总数值、各行内容和字号分配宽度，各列仅取内容所需的宽度，剩余空间留在表格右侧。百分比、内存、速率等数值列及其汇总值按该格式常见的最大值预留宽度，首次显示即接近最终宽度，读数变化不改变列宽；这些列只增不减，按 8 px 递增。名称、路径、描述等文本列按全部进程测量，滚动到其他行时无需再加宽：表格宽度不足时，文本列取多数进程完整显示所需的宽度（至少 95% 的行），明显过长的少数内容以省略号截断，悬停可查看全文；宽度充裕时逐步加宽至完整显示全部内容。名称列中映像名称先于进程名称截断，效率模式、已暂停与固定标记紧随文字显示。文本列在内容变短超过一档时才收窄，避免列宽反复变化。列宽变化时平滑过渡，遵循界面动画设置；调整窗口大小时直接跟随，更改字号或界面语言时重新计算。

指针移到表头的列边界上时显示强调色竖线，停留片刻后提示“拖动调整宽度，双击自动调整”；拖动时竖线延伸到列表底部，经过的表头不显示悬停效果与说明。自动宽度开启时也可拖动列边界调整单列宽度：该列保持手动宽度，其余列宽度不变，其右侧各列随之移动，其余列继续按内容调整；双击列边界或在表头菜单中选择“自动调整此列宽度”，该列恢复自动宽度，恢复时整列以强调色标出并随宽度过渡淡出。重新开启“自动宽度”时，所有列恢复自动宽度。关闭“自动宽度”后各列保持保存的手动宽度，双击列边界使该列适应全部内容；再次关闭自动宽度时恢复已保存的手动宽度。“全宽”默认关闭，在自动宽度开启时可用：名称列延伸至表格右侧，不留空白；名称列被拖动过宽度时保持该宽度。空间不足时可横向滚动查看所选列，名称列保持固定。横向滚轮、Shift+滚轮和单击滚动条轨道均支持滚动动画，遵循界面动画设置。“恢复默认列”同时恢复初始选择、顺序、自动宽度与全宽。

三种视图的“名称”均优先显示应用名称或文件描述，可执行文件名放在次级文字；“映像名称”列始终显示可执行文件名。应用分组展开后的子进程保留可执行文件名，便于区分成员。

进程树默认折叠全部分支。可通过父进程左侧箭头、双击、左右方向键或右键菜单中的“展开”“折叠”调整单个分支；在进程表列标题（名称、CPU 等）上右键，可选择“展开所有”“折叠所有”。展开状态在当前运行期间保留，重启后重新折叠，新出现的分支默认折叠。搜索时自动展开匹配进程的父级，并暂时停用折叠操作；清除搜索后恢复原来的展开状态。

可选列包含父进程 ID、映像名称与路径、描述、公司、文件版本、架构、是否已提升、命令行、会话、启动时间、进程状态、CPU 累计时间、优先级、工作集及峰值、提交大小、虚拟地址空间、缺页次数、I/O 累计字节、网络收发、GPU 引擎及显存用量。

应用分组汇总当前资源计数及累计时间、I/O 字节。虚拟地址空间与工作集峰值按单进程显示，可展开应用分组查看。虚拟地址空间包含预留和已提交的地址范围，浏览器等程序可能预留数 TB；当前私有提交用量见“提交大小”。峰值、地址范围和累计计数使用普通底色。PID、启动时间、优先级和状态等实例属性只在单进程行显示；路径、公司等文字在成员一致时显示共同值。网络采集暂不可用时隐藏网络列，并保留选择以便恢复。取消当前排序列后按名称升序排列。

## 导航栏、工具栏、概况带与状态栏

- **概况带**：CPU、内存、最忙的磁盘、网络和 GPU。大号数字下方是辅助读数：CPU 为频率、温度与功耗，GPU 为温度与功耗（取自当前最忙的显卡），内存为占用比例，磁盘为活动时间，网络为接收与发送速率。缺失的读数不显示；卡片较窄时，数字与辅助读数随之缩小字号。曲线铺满卡片，在文字下方渐隐；顶部细线标出量程上限，右上角注明上限数值（使用率为 100%，内存为总容量，磁盘与网络为当前档位）。CPU 温度与功耗的来源可悬停查看；GPU 功耗优先显示瓦数，仅有相对读数时显示 `% TDP`。单击卡片转到“性能”页的对应设备。
- **导航栏**：默认以标签形式排列在工具栏下方。在“设置 → 语言与外观”或首次启动引导中可改为侧边导航栏：位于窗口左侧，“设置”与“关于”位于底部；默认仅显示图标（指针悬停可看到页面名称与快捷键），单击顶部的 ☰ 按钮展开显示页面名称，再次单击收起。展开后可拖动侧边栏的右边缘调整宽度（150–320 px），双击右边缘恢复默认宽度。位置、展开状态与宽度在重启后保留。
- **工具栏**：兼作窗口的标题栏，空白处可拖动窗口、双击最大化，最右端是最小化、最大化与关闭按钮（指针停在最大化按钮上时，Windows 11 显示贴靠布局）。左侧是 Argus 的图标与名称，以及页面的视图与筛选控件（例如进程页的视图切换、服务页的状态筛选、历史页的时间范围）；中间是当前页面的搜索框；右侧是针对所选项目的操作（例如服务页的启动、停止、重新启动）、刷新频率、暂停 / 继续刷新、查找占用文件的进程、详细信息面板按钮；面板默认始终显示，单击按钮在“始终显示”“选中进程时显示”“隐藏”之间切换，右键可直接选择。有待安装的更新时，最右侧另有强调色的圆形更新按钮，见[设置 → 更新](settings.md#更新)。两侧空间足够时搜索框位于窗口正中，否则紧随左侧的控件。窗口较窄时，按钮只保留图标，进程页的视图切换隐藏文字，仍放不下时左侧的页面控件移到第二行，字号或界面缩放较大时搜索框也移到单独一行；指针悬停仍可看到名称。
- **状态栏**：最左端是版本号，测试构建在版本号后附带提交数（悬停可看到完整版本与更新通道），单击打开本版本的更新内容，右键复制版本号；其后是线程数、句柄数、缓存、分页缓冲池与系统已运行时间，窗口较窄时从最后一项起依次隐藏；右端是刷新状态（例如“每 1 秒刷新”“已暂停刷新”）和权限标记。权限标记显示“管理员”时，Argus 以管理员身份运行；显示“特权服务”时，Argus 以标准权限运行，需要管理员权限的操作由已连接的特权服务执行；显示“标准权限”时两者都不具备。指针悬停可看到说明。

暂停刷新只冻结界面上的数据，历史记录和规则照常进行（这期间每 5 秒采样一次）。

内存页的组成条区分“使用中”“已修改”“备用”和“空闲”。已修改的内容须先写入磁盘才能重新使用；备用内存包含未在使用的缓存数据与代码，空闲内存可直接分配。“已缓存”包含备用与已修改内存，“可用”包含备用与空闲内存。四项说明仅在下方色块图标上悬停时显示，说明文字不随采样数值变化，悬停期间图标位置保持稳定；没有组成明细时显示“—”。进程合计与整机占用的区别见[内存统计口径](#内存统计口径)。

在进程页或性能页按住 Ctrl 可临时暂停刷新，工具栏的暂停按钮同步亮起，曲线保持暂停瞬间的位置；松开 Ctrl、切换到其他窗口或隐藏窗口后解除临时暂停。手动暂停的状态保留；按住 Ctrl 时单击暂停按钮，可选择在松开后保持暂停或继续刷新。

指针停在进程列表上，或右键菜单、确认框打开时，行位置保持固定，资源读数继续刷新。移开指针或关闭菜单、确认框后恢复排序。状态栏会提示由指针悬停引起的排序暂停。

进程查询耗时较长时，表格保留最近一次有效读数，悬停可查看更新状态；超过 10 秒的读数淡化显示。新读数到达后自动更新，等待期间保留的数值不重复计入曲线和历史统计。整机和设备读数继续独立更新。

支持轻量进程枚举的系统会独立更新进程名单。完整计数查询较慢时，新进程仍可出现、已退出进程仍会移除；新进程的计数取得前显示“—”，取得后补齐并保留选择。进程身份尚未确认时，结束进程、优先级及效率模式操作暂不可用。其他系统自动使用完整快照更新名单。

“磁盘读取”和“磁盘写入”分别统计磁盘读写速率，I/O 列还计入网络及设备访问。Windows 11 24H2 及以上优先使用普通进程查询，其他系统可使用特权服务或管理员权限采集。空闲时显示“0”，暂缺读数时显示“—”，悬停可查看原因。表头及应用分组汇总已有读数，全部缺测时显示“—”。

进程表的 GPU 列是该进程在最忙的那个 GPU 引擎上占用的时间比例，悬停可以看到是哪个引擎（例如“GPU 0 - 3D”）；应用分组显示汇总后最忙的引擎。专用和共享 GPU 内存使用 Windows 报告的进程驻留用量，缺失读数显示“—”。共享资源可归属于多个进程；整张显卡的物理用量见性能页。以管理员身份运行 Argus 或启用特权服务且 ETW 可用时，进程表还会多出网络列：每个进程每秒发送和接收的数据量，悬停可以分别看到发送和接收；采集不可用时隐藏这一列。表格放不下时可横向滚动，名称列固定在左侧。

按应用视图按可执行文件路径合并进程，不同安装位置的同名程序分别显示。其他应用启动的 WebView2 子进程按宿主和运行时实例分组，展开可查看渲染、GPU、网络等角色，也可按宿主名称搜索。服务主机显示承载的服务，其他未识别宿主的进程可在进程树中查看父子关系。

应用包（MSIX）程序与系统任务管理器一样显示应用名称，例如“终端”，名称使用 Windows 显示语言；应用包启动的辅助进程（如控制台主机、后台任务宿主）仍显示各自的描述。按名称排序时，中文界面将汉字名称按拼音排在拉丁字母之前，英文界面拉丁字母在前；名称中的数字按数值比较，不区分大小写与重音。服务、启动与连接页的文字列按同样的规则排序。

拥有任务栏窗口的程序归入“应用”，其余进程中，系统目录内具有 Windows 组件版本信息的程序及系统内核进程归入“Windows 进程”，其他程序归入“后台进程”。分组便于浏览，结束进程前仍需确认其用途。标题数量统计当前筛选下的顶层条目，展开子进程不增加数量；没有匹配项的分组不显示。按 CPU、内存等数值排序时保持全局排序，便于查找占用最高的进程。

单击列表中的应用或进程即可选中，再次单击取消选中；双击仅用于展开或折叠含有子项的行（应用组、进程树中的父进程）。详细信息面板默认常驻在列表右侧：选中某一行时显示其详细信息，未选中时显示本机配置（处理器、内存、存储、网络、显卡与电池，单击某一项可转到“性能”页的对应设备）。工具栏右上角的面板按钮有三种状态，单击依次切换，右键可直接选择：

| 状态 | 按钮 | 面板 |
|---|---|---|
| 始终显示 | 面板图标，强调色 | 常驻列表右侧，未选中时显示本机配置 |
| 选中进程时显示 | 右栏带箭头的面板图标，强调色 | 单击进程即滑出；再次单击该行或单击面板右上角的关闭按钮取消选中后滑回隐藏 |
| 隐藏 | 面板图标 | 不显示；按 Enter 或从其他位置查看某个进程的详细信息时，切换为“始终显示” |

所选状态在重启后保留。拖动面板左缘可调整宽度，双击左缘恢复默认宽度。

“本机配置”标题右侧的显示／隐藏按钮仅隐藏硬件列表，保留面板的操作提示，并记住显示状态；不影响选中进程后查看详细信息。单击“操作提示”标题可收起或展开提示内容，收起后仅保留标题行，展开状态同样在重启后保留。单击“复制配置为文字”可复制当前硬件配置，列表隐藏时仍可复制。提交 GitHub 缺陷报告时，可将相关配置粘贴到“相关环境与对照”栏目；功能建议中的对应栏目为“当前替代办法与相关环境”。

选中应用组时，详情面板显示该组的 CPU 与内存曲线、资源合计、最早启动时间、文件位置，以及按 CPU 排序的成员。单击成员可查看单进程详情。结束、优先级和效率模式操作仅作用于选中组。

网络速率默认以字节每秒显示（KB/s、MB/s，与磁盘一致），可以在“设置 → 数据与历史”里改为比特每秒（Kbps、Mbps，与网卡的链路速度、宽带套餐一致），概况带、进程表、详细信息面板和历史页随之切换；性能页的网络视图总是同时显示两种。

## GPU 统计口径

进程 GPU 占用取最忙的单个引擎。应用组及分类标题先按适配器、物理 GPU 和引擎节点的完整身份汇总进程贡献，再取最忙节点。不同显卡或引擎节点分别计算，同名引擎按各自节点区分。

整体占用以 Windows 引擎计时为基础，不低于有效的进程引擎读数；NVIDIA 显卡另用 NVML 核心利用率补充计算负载。性能页显示本次来源，概况带的 GPU 数字也可悬停查看来源。NVML 补充不改写原生引擎曲线。比较其他工具时，须同时核对适配器、引擎和采样窗口，分别对照视频、3D 与计算负载的对应指标。

## 内存统计口径

概况带、进程表头与进程行的“内存”采用不同口径。在概况带的内存数值、进程表头的“内存”和分类标题的内存合计上悬停，可看到对应口径的说明：

| 位置 | 统计含义 |
|---|---|
| 概况带的已用内存 | 整机总物理内存减去可用内存，包含使用中与已修改的部分 |
| 进程表头的内存百分比 | 上述整机占用占总物理内存的比例 |
| 进程行、应用组及分类标题的内存数值 | 专用工作集，即进程独占且驻留在物理内存中的部分；组与分类按该口径合计 |

分类标题合计各进程的专用工作集；整机占用还涉及共享驻留页、内核与驱动、页表、使用中的系统缓存和已修改页等。“Windows 进程”统计该分类内的进程专用工作集。完整工作集包含共享页，直接累加会重复计算进程间共享的部分。

备用内存计入“可用”；查看系统各类内存的占用，应使用“性能 → 内存”中的组成数据。

各类内存的采集来源见[硬件数据](hardware-data.md)。

## 磁盘详情

磁盘标题旁的“概览 / 详情”切换两页，所选页面在重启后保留。详情页每次打开时读取一次磁盘信息；单击切换按钮旁的“重新读取”可再次读取，健康状况卡片右上方显示读取时间。温度显示实时读数，其余数值保持读取时的状态。

- **健康状况**：状态、剩余寿命、温度与可用备用空间，下方列出读取总量、写入总量、通电时间、通电次数、不安全关机与介质错误。已适配的 SATA SSD 按型号显示对应的寿命、累计主机读写、通电统计、异常断电及不可校正错误，提供备用空间比例的型号还显示其比例和阈值。SATA/ATA HDD 显示可读取的通电、启停、磁头加载、重映射／待映射／离线不可校正扇区及接口 CRC 计数，已适配的读写总量也会列出。NVMe 温度条以硬盘报告的严重温度为满刻度，刻线标出警告温度；备用空间条的刻线标出阈值。
- **设备信息**：型号、固件版本、序列号、容量、卷、接口、PCIe、SATA 或 PATA UDMA 传输模式（当前链路与设备支持的最高链路不同时同时列出）、NVMe 或 ATA 标准版本、扇区大小与支持的功能，包含设备报告的 SMART、TRIM、写入缓存及 NCQ。序列号默认隐藏，单击“显示”查看。
- **SMART 属性**：NVMe 健康日志按健康、使用情况和温度分组，读写量按每单位 512,000 字节换算；温度原始值单位为开尔文，未报告的传感器不列出。ATA／SATA 和支持 SAT 的桥接设备显示属性编号、名称、当前值、最差值、阈值及十六进制原始值，已识别的 SSD 字段按型号命名。SCSI／SAS 显示设备提供的健康状态、温度与读写错误统计。异常的数值以红色显示。

SMART 属性的表格随窗口宽度调整。各列按其中最宽的文字定宽，名称与数值相邻，多出的宽度平均分给各数值列。NVMe 的健康、使用情况与温度三组在各栏高度相近时并排，否则上下排列，每组的行再分栏；ATA／SATA 属性在放得下时拆成至多 3 张并排的表，每张不少于 5 行。不再分栏后，每张表的宽度以文字所需宽度的 2 倍为限，其余宽度留在表格之间。窗口较窄时名称换行，仍放不下时数值移到名称下方。指针所在的行以底色标出。

健康状态按以下规则判定：

| 状态 | 条件 |
|---|---|
| 异常 | 严重警告中的备用空间低于阈值、可靠性下降、介质转为只读、易失性存储备份设备故障或持久性内存区域转为只读，或可用备用空间低于阈值 |
| 注意 | 严重警告中的温度超出阈值或尚未定义的警告位，存在介质与数据完整性错误，剩余寿命不高于 10%，或 HDD 存在重映射、待映射、离线不可校正扇区 |
| 良好 | 以上情况均未出现 |

NVMe 剩余寿命为 `100 − 已用寿命`，已用寿命是厂商对耐久度的估计，可超过 100%。严重警告与剩余寿命分别判定。ATA／SATA、USB-SAT 和 SCSI／SAS 的扩展数据经已运行的特权服务读取，可在“设置 → 权限”中安装、启动或更新服务。缺失的阈值与读数显示“—”，未取得设备故障预测时健康状态显示“未知”。读取保留设备的 SMART 启用状态。厂商专用 USB／RAID 通道的覆盖情况见路线图。

序列号优先采用 NVMe／ATA 厂商 SN，缺失时回退至 SCSI 单元序列号及 Windows 通用存储描述符；转速按 ATA 设备报告值显示。

## 运行新任务与重新启动资源管理器

窗口右上角的“运行新任务”可在任意页面使用。输入程序名称、文件或文件夹路径，也可附加启动参数；“浏览”可选择文件。勾选“以管理员身份运行”时，由 Windows 处理授权。取消授权或启动失败后保留输入，可修改后重试。未勾选时以普通权限启动，即使 Argus 本身以管理员身份运行。

右键当前桌面的 Windows 资源管理器，选择“重新启动”并确认，可恢复桌面和任务栏。支持普通权限和高权限资源管理器，重启后保持原账户与权限；重启高权限实例时，Argus 需以管理员权限运行。此操作可能影响资源管理器窗口及正在进行的文件操作；仅作用于承载当前桌面的实例。该实例提供“重新启动”操作，“结束”和“结束进程树”均禁用。资源管理器已经退出时，可在“运行新任务”中输入 `explorer.exe` 重新打开。

重启前会检查权限并准备替代进程。旧资源管理器在退出清理或错误报告阶段卡住时，会在超时后结束已确认的旧实例，确认退出再恢复桌面；Windows 已恢复桌面时使用现有实例。桌面和任务栏均能够响应后才提示重启完成。

## 优先级、效率模式与暂停

右键一个进程（或按应用视图中的一组进程）：

- **设置优先级**：实时、高、高于正常、正常、低于正常、低。设为实时前会先确认；以标准权限运行时，Windows 会把实时降为高，Argus 会提示。
- **效率模式**：与系统任务管理器相同，让 Windows 优先把它安排到能效核和低频率上运行，并把优先级降为低；关闭后恢复正常优先级。处于效率模式的进程名称后面有一个叶子标记。
- **暂停进程 / 恢复进程**：暂停进程的全部线程，直到恢复，适合临时让出长时间运行的渲染、编码或编译任务。暂停前会先确认：被暂停程序的窗口会停止响应，网络连接可能超时，带反作弊或自我保护的程序可能出错。系统关键进程、桌面窗口管理器（dwm.exe）、Argus 自身及其特权服务不能暂停。暂停只作用于仍在运行的进程，“恢复进程”只作用于已暂停的进程；应用在暂停后又启动了新进程时，菜单同时提供两项。Windows 在后台挂起的应用包（例如最小化的“计算器”）同样显示为“已暂停”，由 Windows 自行恢复，菜单不提供这两项。执行时按进程当前的线程状态处理：已暂停的进程不会再次暂停；恢复撤销一次暂停，程序或调试器自行暂停的线程保持暂停。其他工具多次叠加暂停的进程，恢复后仍可能处于暂停状态，可再次恢复。
- **添加规则**：为该程序建立一条规则，以后它每次启动都会自动套用，见[设置](settings.md#规则)。

系统进程和其他用户的进程需要启用[特权服务](settings.md#权限)，或以管理员身份运行 Argus 才能更改。

## 启动项

启动页列出注册表 Run 项、启动文件夹中的项目，以及当前账户安装的应用包启动任务。同一应用的多个启动任务分别显示；名称优先采用程序描述或应用包的本地化名称，原始项目名仍可搜索，并显示在名称的悬停提示中。

单击开关或使用右键菜单可启用、禁用下次登录时启动的项目，与系统任务管理器共用状态。应用包启动任务可在标准权限下更改；“所有用户”的传统启动项仍需要管理员权限。应用不允许手动更改或暂时无法读取状态时，会禁用开关并说明原因。页面可见时每 10 秒刷新，切回页面后重新读取。

启用应用包启动任务后，下次登录时即可启动。系统任务管理器若仍显示旧状态，可重新打开核对。

## 备注与置顶

服务、启动和连接页可为条目添加备注或将其置顶：右键条目，选择“置顶”“取消置顶”，或“添加备注”“编辑备注”“删除备注”。备注显示在名称之后，以带图标的浅色标签与名称区分；名称始终完整显示，空间不足时备注先收窄，指针悬停可看到全文。搜索框同时匹配备注。置顶的条目排在列表最前，名称列末端显示图钉，下方以分隔线与其余条目隔开；置顶条目之间按当前排序排列。

备注与置顶随界面偏好保存在本机，重启后保留。服务按服务名称记忆，启动项按所在位置与项目名称记忆。连接按程序与端口记忆：监听端口、UDP 端口及经监听端口接受的连接按本地端口，程序主动发起的连接按远程地址和端口；同一程序在同一端口上的多个连接共用备注与置顶，程序重启、PID 变化后仍然有效。

## 历史

Argus 运行时每 5 秒记录一帧：整机的 CPU（这 5 秒内各次采样的平均值和最高值）、内存、磁盘与网络吞吐量、GPU，有电池的设备还有电池电量与充放电功率（电量为各块电池的平均值，功率为各块之和），以及当时 CPU、内存、I/O、GPU 和网络占用最高的几个进程。窗口最小化、隐藏在托盘或暂停刷新时照常记录；最小化或后台常驻时的刷新间隔长于 5 秒时，按该间隔记录，曲线随之变稀，仍连成线。Argus 没有运行的时段，曲线留空；紧邻按较长间隔记录的时段时，一分钟左右的中断不留空。

历史中的磁盘吞吐量汇总读写计数均可用的磁盘；全部缺测时记录为 0。实时概况带在任一磁盘计数缺测时显示“—”，与历史记录的汇总口径不同。

- **时间范围**：在工具栏选择 1 小时、6 小时、24 小时或 7 天，图表显示截至当前的这段时间，并随时间定期前移（1 小时的范围每 10 秒，7 天的范围每 5 分钟）。CPU 曲线上方较淡的线是每段时间里采样的最高值。
- **查看某一时刻**：指针移到曲线上，左侧显示那一刻的数值；单击选中这一时刻，下方列出当时最忙的进程。选中后在曲线上按 ← →（加 Shift 一次移动更多）前后移动，按 Esc 或工具栏上的“回到最新”取消选中。选中时刻后图表仍随时间前移，该时刻移出图表时自动取消选中。
- **切换范围**：切换后总是显示新范围截至当前的时间段。选中的时刻仍在新范围内时保持选中，下方的进程列表不变；否则取消选中，读数与进程列表回到最新数据。查看更早的时段需选择更长的范围。
- **电池数据缺失**：设备暂未上报电池电量的时段，电池曲线留空，读数显示“无记录”；实际电量为 0% 时仍显示为 0%。
- **转到进程**：双击列表中的进程，如果它仍在运行，就转到进程页并选中它。

每进程网络流量会在本地采集或特权服务采集可用时记录。记录保存在 `%LOCALAPPDATA%\dev.argus.taskmanager\history`，每天一个文件，保留 7 天，连续运行一天约 8 MB。在“设置 → 数据与历史”里可以关闭记录、查看占用的空间或清除全部历史，见[设置](settings.md#数据与历史)。

从 0.2.0 升级且需要保留旧历史时，请先退出 Argus 并备份 `history` 目录，旧版可读取备份。新版从新的记录格式开始显示历史。

## 文件占用

单击工具栏上的“查找占用文件的进程”，或者直接把文件、文件夹拖到窗口上，即可查询占用。结果合并两种来源：Restart Manager 查找文件引用和已加载的模块，句柄扫描补充打开的文件、目录及后代，包括把所选文件夹当作当前目录的命令行进程。文件 ID 可识别通过硬链接打开同一文件的情况。

对话框打开后，可继续将文件或文件夹拖入对话框，以更新查询目标。管理员窗口也支持从普通权限的文件管理器拖入文件。

占用进程是当前桌面的资源管理器时，操作按钮显示“重新启动”；确认后恢复桌面与任务栏，再重新检查文件占用。其他进程仍可通过“结束”释放占用。

有可用且已授权的特权服务时，句柄查询交给服务；否则以当前账户的权限查询，普通权限也能发现许多自有进程。每个结果显示匹配路径和句柄数量，重复来源按 PID 与启动时间合并。“结束”仍会确认，并核对同一进程实例，避免 PID 复用后结束其他进程。

结果会列出无法访问的进程、跳过的句柄和超时情况。“未发现”表示本次查询范围内没有匹配。查询卡住时保留已找到的结果；达到时间或数量上限时返回部分结果。允许共享删除的句柄也可能列出。

句柄扫描使用本地磁盘绝对路径。符号链接、目录联接、网络驱动器与 SUBST 路径保留 Restart Manager 的查询结果，指定实际目标可补查句柄。受保护进程和已关闭句柄的映射可能漏检。见[已知问题](../known-issues.md)。

## 关于

关于页位于导航栏中“设置”之后，显示版本、当前权限和许可证，提供更新内容、退出及重新打开首次引导的入口。版本号与发行版相同；从未发布的提交构建的测试版本在后面附加提交数与提交的短哈希，例如 `0.3.4+583.g4c638d7`，便于确认所用的构建。版本信息下方的两张卡片分别打开 [Argus 官网](https://argustask.com/)（下载、使用文档与更新日志）和 [GitHub 仓库](https://github.com/Ray-lea/Argus)（源代码、问题反馈与各版本安装包），单击整张卡片即可。“交流与反馈”可打开 QQ 群邀请或复制群号（453803497）；“Telegram 频道”可打开频道页面或复制频道链接（[t.me/argustask](https://t.me/argustask)）。“第三方组件”列出开源组件及许可证。

单击“打开日志文件夹”可查看 `%LOCALAPPDATA%\dev.argus.taskmanager\logs\diagnostics`。`argus.log` 记录系统版本、渲染器、传感器和特权功能状态，以及运行程序的 SHA-256，可用来区分同版本号的不同构建。失败记录包含具体步骤、系统错误码及相关路径。公开提交日志前，请检查这些路径中的用户目录名称。

时间戳包含本地日期、毫秒及 UTC 偏移，时区查询失败时使用 `+00:00`。`argus.log` 超过 1 MiB 时轮换，保留最近三份归档。任务管理器替换启动器另写 `taskmgr.log`。

## 键盘操作

| 操作 | 按键 |
|---|---|
| 切换页面 | Ctrl+1 … Ctrl+8 |
| 搜索进程 | Ctrl+F 或 /；进程页直接键入字母或数字 |
| 临时暂停刷新 | 进程页、性能页按住 Ctrl，松开后恢复；手动暂停的状态保留 |
| 选择 | ↑ ↓ |
| 折叠 / 展开 | ← →；分组标题上也可按 Enter 或空格 |
| 打开详细信息 | Enter |
| 结束进程 | 进程页 Alt+E；列表获得焦点时也可按 Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

分组标题的折叠状态在重启后保留；在进程列表中按 ← 可从顶层的条目移到所属分组的标题。搜索时各组显示全部匹配项，暂不能折叠，清除搜索后恢复原来的折叠状态。列表处于筛选状态时，外框、表头与搜索框以强调色标示，名称列表头的计数前显示漏斗图标（指针悬停时显示说明）；开始筛选时外框以一次光圈提示，随“界面动画”设置。转到某个进程时（例如从服务页或连接页），其所在的分组随之展开。

进程页的列表、按钮或空白区域获得焦点时，直接键入字母或数字会将文字追加到搜索框。按 ↓ 回到列表，按 Esc 清除搜索并回到原位置。使用中文输入法时，从第一个按键开始组字，选定文字后才筛选列表；组字期间的 Enter、方向键和 Esc 由输入法处理。

Alt+E 使用与右键菜单相同的确认和权限处理，选中应用组时作用于该组；输入框、弹窗或菜单打开时不触发。完整按键说明见“设置 → 快捷键 → 查看快捷键”。

## 权限

在[设置 → 权限](settings.md#权限)或首次启动引导中可开启“管理员运行”。完成一次授权后，各启动入口遵循相同策略；登录启动保持隐藏，常驻快捷键显示当前管理员实例。该模式默认关闭，与特权服务分别管理。

使用其他管理员账户启动时，设置、历史和日志保存在该管理员账户中，进程视图、列宽等界面偏好单独保存。

以管理员身份启动时，若 Windows 资源管理器已经退出，Argus 会询问是否先恢复桌面。确认后以原桌面账户的普通权限打开资源管理器，再继续启动界面；选择“否”则取消本次启动。

标准权限可读取一般进程的路径和资源用量，受保护进程的部分信息可能缺失。服务可协助执行的操作见[设置 → 权限](settings.md#权限)。进程详情和所有用户启动项的修改使用界面进程自身的权限。状态栏显示“管理员”“特权服务”或“标准权限”。

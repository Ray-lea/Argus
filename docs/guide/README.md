# 界面与操作

Argus 的窗口顶部是工具栏，下方左侧是导航栏，右侧是当前页面和状态栏；进程页的上方是系统概况带。

- [常驻、托盘与快捷键](resident-mode.md)
- [设置](settings.md)
- [硬件数据的来源与限制](hardware-data.md)

## 首次启动

第一次启动时显示引导，依次完成常用设置：界面语言；登录 Windows 时启动、关闭窗口时保留在托盘，以及显示或隐藏窗口的快捷键；自动检查更新、更新通道与下载线路；可选的特权服务及其授权范围，可以在引导中直接安装（需要管理员授权），也可以跳过、之后在“设置 → 权限”中安装；是否用 Argus 替换系统任务管理器（依赖特权服务，同样需要管理员授权）；最后是常用操作的提示。每一步的修改立即保存，任何一步都可以单击“跳过”或按 Esc 结束，之后随时可以在“设置 → 关于”中重新打开引导。

## 页面

| 页面 | 快捷键 | 内容 |
|---|---|---|
| 进程 | Ctrl+1 | 三种视图：按应用（同一程序的多个进程合并为一行）、进程树（按父子关系）、列表（全部平铺）。CPU、内存、I/O、GPU 等列可排序，支持搜索；按名称排序时，按应用与列表视图参照 Windows 任务管理器分为“应用”（拥有任务栏窗口的程序）和“后台进程”两段；结束进程或整个进程树、设置优先级与效率模式、详细信息面板、右键菜单 |
| 性能 | Ctrl+2 | CPU（整体或逻辑处理器视图，可按性能核 / 能效核筛选；频率、温度、功耗）、内存、各个磁盘、网络适配器、GPU（NVIDIA 显卡另有功耗瓦数）、电池。拖动设备列表右侧的分隔条可调整列表宽度，双击恢复默认 |
| 服务 | Ctrl+3 | 启动、停止服务，修改启动类型；进程页里的 svchost 会显示它承载的服务 |
| 启动 | Ctrl+4 | 启用、禁用登录时启动的程序，标出已失效的项目；与系统任务管理器使用同一个开关 |
| 连接 | Ctrl+5 | TCP / UDP 端点及所属进程，可按端口精确搜索，可断开 IPv4 TCP 连接 |
| 历史 | Ctrl+6 | 最近 7 天的 CPU、内存、磁盘、网络和 GPU 曲线，以及任一时刻最忙的进程，见[历史](#历史) |
| 设置 | Ctrl+7 | 见[设置](settings.md) |

## 导航栏、工具栏、概况带与状态栏

- **概况带**：CPU（含每个逻辑处理器的使用率小条）、内存、最忙的磁盘、网络和 GPU。单击其中一项，转到“性能”页的对应设备。
- **导航栏**：位于窗口左侧，列出各个页面，“设置”在最下方。单击顶部的 ☰ 按钮收起为仅显示图标（指针悬停可看到页面名称与快捷键），再次单击展开；展开与否在重启后保留。
- **工具栏**：兼作窗口的标题栏，空白处可拖动窗口、双击最大化，最右端是最小化、最大化与关闭按钮（指针停在最大化按钮上时，Windows 11 显示贴靠布局）。依次是 Argus 的图标与名称；各页面自己的控件（例如进程页的视图切换、历史页的时间范围）；刷新频率、暂停 / 继续刷新、查找占用文件的进程、详细信息面板开关。窗口较窄时，按钮只保留图标，进程页的视图切换隐藏文字，仍放不下时页面控件移到第二行，再放不下时右侧的控件也移到第二行；指针悬停仍可看到名称。
- **状态栏**：左侧是线程数、句柄数、缓存、分页缓冲池与系统已运行时间，窗口较窄时从最后一项起依次隐藏；右端是刷新状态（例如“每 1 秒刷新”“已暂停刷新”）和权限标记。权限标记显示“管理员”时，Argus 以管理员身份运行；显示“特权服务”时，Argus 以标准权限运行，需要管理员权限的操作由已连接的特权服务执行；显示“标准权限”时两者都不具备。指针悬停可看到说明。

暂停刷新只冻结界面上的数据，历史记录和规则照常进行（这期间每 5 秒采样一次）。

指针停在进程列表上时，刷新只更新数值、不重新排序，状态栏会提示“指针在列表上，暂不重新排序”；移开后按当前排序重新排列。

进程表的 GPU 列是该进程在最忙的那个 GPU 引擎上占用的时间比例，悬停可以看到是哪个引擎（例如“GPU 0 - 3D”）；详细信息面板还显示它占用的专用和共享 GPU 内存。以管理员身份运行 Argus 或启用特权服务且 ETW 可用时，进程表还会多出网络列：每个进程每秒发送和接收的数据量，悬停可以分别看到发送和接收；采集不可用时隐藏这一列。窗口较窄、表格放不下时，先隐藏线程和句柄列，再隐藏 PID 和 I/O 列。

在按应用视图中选中一组进程时，详细信息面板显示整个应用的情况：合计的 CPU 与内存曲线、各项资源的总和、最早的启动时间、组内各进程（按 CPU 占用排序，单击可查看单个进程）以及文件位置。

网络速率默认以字节每秒显示（KB/s、MB/s，与磁盘一致），可以在“设置 > 数据与历史”里改为比特每秒（Kbps、Mbps，与网卡的链路速度、宽带套餐一致），概况带、进程表、详细信息面板和历史页随之切换；性能页的网络视图总是同时显示两种。

## 优先级与效率模式

右键一个进程（或按应用视图中的一组进程）：

- **设置优先级**：实时、高、高于正常、正常、低于正常、低。设为实时前会先确认；以标准权限运行时，Windows 会把实时降为高，Argus 会提示。
- **效率模式**：与系统任务管理器相同，让 Windows 优先把它安排到能效核和低频率上运行，并把优先级降为低；关闭后恢复正常优先级。处于效率模式的进程名称后面有一个叶子标记。
- **添加规则**：为这个程序建立一条规则，以后它每次启动都会自动套用，见[设置](settings.md#规则)。

系统进程和其他用户的进程需要启用[特权服务](settings.md#权限)，或以管理员身份运行 Argus 才能更改。

## 历史

Argus 运行时每 5 秒记录一帧：整机的 CPU（这 5 秒的平均值和其中最高的一秒）、内存、磁盘与网络吞吐量、GPU，以及当时 CPU、内存、I/O、GPU 和网络占用最高的几个进程。窗口隐藏在托盘或暂停刷新时照常记录；Argus 没有运行的时段，曲线留空。

- **时间范围**：在工具栏选择 1 小时、6 小时、24 小时或 7 天。CPU 曲线上方较淡的线是每段时间里最高的一秒。
- **查看某一时刻**：指针移到曲线上，左侧显示那一刻的数值；单击选中这一时刻，下方列出当时最忙的进程。选中后在曲线上按 ← →（加 Shift 一次移动更多）前后移动，按 Esc 或工具栏上的“回到最新”返回。
- **放大**：选中一个时刻后切换到更短的范围，会以这个时刻为中心显示。
- **转到进程**：双击列表中的进程，如果它仍在运行，就转到进程页并选中它。

每进程网络流量会在本地采集或特权服务采集可用时记录。记录保存在 `%LOCALAPPDATA%\dev.argus.taskmanager\history`，每天一个文件，保留 7 天，连续运行一天约 8 MB。在“设置 > 数据与历史”里可以关闭记录、查看占用的空间或清除全部历史，见[设置](settings.md#数据与历史)。

## 文件占用

单击工具栏上的“查找占用文件的进程”，或者直接把文件、文件夹拖到窗口上，即可查询占用。结果合并两种来源：Restart Manager 查找文件引用和已加载的模块，句柄扫描补充打开的文件、目录及后代，包括把所选文件夹当作当前目录的命令行进程。文件 ID 可识别通过硬链接打开同一文件的情况。

有可用且已授权的特权服务时，句柄查询交给服务；否则以当前账户的权限查询，普通权限也能发现许多自有进程。每个结果显示匹配路径和句柄数量，重复来源按 PID 与启动时间合并。“结束”仍会确认，并核对同一进程实例，避免 PID 复用后结束其他进程。

扫描无法访问的进程、跳过的句柄或超时都会单独提示；“未发现”不等于绝对没有占用。辅助进程遇到阻塞会被终止，保留已找到的结果并继续；达到总时间或数量上限时返回部分结果。句柄表示引用，允许共享删除的句柄也可能列出。

当前句柄扫描只支持本地磁盘的绝对路径，不跟随符号链接、目录联接或网络/SUBST 驱动器；这些目标仍保留 Restart Manager 的查询结果，可改选链接的实际目标。保护进程和已经关闭文件句柄的内存映射仍可能无法检出，见[已知问题](../known-issues.md)。

## 键盘操作

| 操作 | 按键 |
|---|---|
| 切换页面 | Ctrl+1 … Ctrl+7 |
| 搜索进程 | Ctrl+F 或 / |
| 选择 | ↑ ↓ |
| 折叠 / 展开 | ← → |
| 打开详细信息 | Enter |
| 结束进程 | Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

## 权限

以标准用户身份运行就能看到全部进程的路径与资源占用。在[设置 > 权限](settings.md#权限)安装可选的特权服务后，手动进程操作、自动规则、每进程网络采集、句柄查询、服务控制和断开连接可以使用后台服务。详细信息与所有用户启动项的修改仍使用界面进程自身的权限；没有权限时界面会明确提示。状态栏右下角的权限标记显示当前状态：以管理员身份运行时为“管理员”，特权服务已连接时为“特权服务”，否则为“标准权限”。

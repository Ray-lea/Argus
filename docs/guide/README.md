# 界面与操作

Argus 的窗口顶部是工具栏，下方是导航栏、当前页面和状态栏。导航栏默认位于工具栏下方，也可以改为位于窗口左侧；进程页的上方是系统概况带。

- [设置](settings.md)
- [硬件数据的来源与限制](hardware-data.md)

## 首次启动

第一次启动时显示引导，依次完成常用设置：界面语言；导航栏的位置、界面动画、曲线动画与刷新频率；登录 Windows 时启动、关闭窗口时保留在托盘、最小化与后台常驻时的刷新间隔，以及显示或隐藏窗口的快捷键；自动检查更新、更新通道与下载线路；可选的特权服务及其授权范围，可以在引导中直接安装（需要管理员授权），也可以跳过、之后在“设置 → 权限”中安装；可选的内核传感器（依赖特权服务，开启时自动准备 PawnIO 驱动，需要管理员授权）；是否用 Argus 替换系统任务管理器（依赖特权服务，同样需要管理员授权）；最后是常用操作的提示。每一步的修改立即保存，任何一步都可以单击“跳过”或按 Esc 结束，之后随时可以在“设置 → 关于”中重新打开引导。

## 页面

| 页面 | 快捷键 | 内容 |
|---|---|---|
| 进程 | Ctrl+1 | 三种视图：按应用（同一程序的多个进程合并为一行）、进程树（按父子关系）、列表（全部平铺）。CPU、内存、I/O、GPU 等列可排序，支持搜索；按名称排序时，按应用与列表视图分为“应用”“后台进程”“Windows 进程”三组，标题显示数量和该组的资源合计，单击标题可折叠或展开该组；结束进程或整个进程树、设置优先级与效率模式、详细信息面板、右键菜单 |
| 性能 | Ctrl+2 | CPU（整体或逻辑处理器视图，可按性能核 / 能效核筛选；频率、温度、功耗）、内存、各个磁盘、网络适配器、GPU（引擎利用率可选择显示几张小图、每张显示哪个引擎，按显卡型号保存；NVIDIA 显卡另有功耗瓦数）、电池。曲线随窗口大小伸缩，填满实时数字以外的空间，窗口较矮时压扁曲线以显示实时数字。CPU 的温度与功耗曲线、内部传感器、每核读数、空闲状态、处理器信息等收在首屏下方的展开卡片中，默认收起，标题行显示摘要，单击展开，展开状态在重启后保留。磁盘、网络、功耗等不固定上限的曲线以峰值向上取整为上限：不超过 10 时取整数，超过 10 时取整十数（如 8 MB/s、150 Mbps）；上限变化时曲线平滑过渡、上限标签淡入，随“曲线动画”设置，关闭时直接切换。网络适配器的 IPv4、IPv6 地址超过 3 个时，单击“展开全部”查看其余地址。拖动设备列表右侧的分隔条可调整列表宽度，双击恢复默认 |
| 服务 | Ctrl+3 | 启动、停止服务，修改启动类型；进程页里的 svchost 会显示它承载的服务；可[添加备注与置顶](#备注与置顶) |
| 启动 | Ctrl+4 | 启用、禁用登录时启动的程序，标出已失效的项目；与系统任务管理器使用同一个开关；可[添加备注与置顶](#备注与置顶) |
| 连接 | Ctrl+5 | TCP / UDP 端点及所属进程，可按端口精确搜索，可断开 IPv4 TCP 连接；可[添加备注与置顶](#备注与置顶) |
| 历史 | Ctrl+6 | 最近 7 天的 CPU、内存、磁盘、网络和 GPU 曲线（有电池的设备另有电池电量与充放电功率），以及任一时刻最忙的进程，见[历史](#历史) |
| 设置 | Ctrl+7 | 见[设置](settings.md) |

## 导航栏、工具栏、概况带与状态栏

- **概况带**：CPU（含每个逻辑处理器的使用率小条）、内存、最忙的磁盘、网络和 GPU。单击其中一项，转到“性能”页的对应设备。
- **导航栏**：默认以标签形式排列在工具栏下方。在“设置 → 语言与外观”或首次启动引导中可改为侧边导航栏：位于窗口左侧，“设置”在最下方；默认仅显示图标（指针悬停可看到页面名称与快捷键），单击顶部的 ☰ 按钮展开显示页面名称，再次单击收起。位置与展开状态在重启后保留。
- **工具栏**：兼作窗口的标题栏，空白处可拖动窗口、双击最大化，最右端是最小化、最大化与关闭按钮（指针停在最大化按钮上时，Windows 11 显示贴靠布局）。左侧是 Argus 的图标与名称，以及页面的视图与筛选控件（例如进程页的视图切换、服务页的状态筛选、历史页的时间范围）；中间是当前页面的搜索框；右侧是针对所选项目的操作（例如服务页的启动、停止、重新启动）、刷新频率、暂停 / 继续刷新、查找占用文件的进程、详细信息面板开关（未选中应用或进程时单击会提示先在列表中选中一项，选中后面板随即显示）；有待安装的更新时，最右侧另有强调色的圆形更新按钮，见[设置 → 更新](settings.md#更新)。两侧空间足够时搜索框位于窗口正中，否则紧随左侧的控件。窗口较窄时，按钮只保留图标，进程页的视图切换隐藏文字，仍放不下时左侧的页面控件移到第二行；指针悬停仍可看到名称。
- **状态栏**：左侧是线程数、句柄数、缓存、分页缓冲池与系统已运行时间，窗口较窄时从最后一项起依次隐藏；右端是刷新状态（例如“每 1 秒刷新”“已暂停刷新”）和权限标记。权限标记显示“管理员”时，Argus 以管理员身份运行；显示“特权服务”时，Argus 以标准权限运行，需要管理员权限的操作由已连接的特权服务执行；显示“标准权限”时两者都不具备。指针悬停可看到说明。

暂停刷新只冻结界面上的数据，历史记录和规则照常进行（这期间每 5 秒采样一次）。

内存页的组成条区分“使用中”“已修改”“备用”和“空闲”。已修改的内容须先写入磁盘才能重新使用；备用内存包含未在使用的缓存数据与代码，空闲内存可直接分配。“已缓存”包含备用与已修改内存，“可用”包含备用与空闲内存。四项说明仅在下方色块图标上悬停时显示，说明文字不随采样数值变化，悬停期间图标位置保持稳定；没有组成明细时显示“—”。

在进程页或性能页按住 Ctrl 可临时暂停刷新，工具栏的暂停按钮同步亮起，曲线保持暂停瞬间的位置；松开 Ctrl、切换到其他窗口或隐藏窗口后解除临时暂停。手动暂停的状态保留；按住 Ctrl 时单击暂停按钮，可选择在松开后保持暂停或继续刷新。

指针停在进程列表上，或右键菜单、确认框打开时，刷新只更新数值、不重新排序；指针移开、菜单或确认框关闭后按当前排序重新排列。仅因指针停在列表上而暂停时，状态栏提示“指针位于列表上，暂停重新排序”。

进程表的“磁盘读取”“磁盘写入”列分别显示每秒磁盘读写字节数，按应用视图会汇总组内进程，单击列标题可排序；详细信息面板也显示这两项。Windows 11 24H2 及以上优先从普通进程查询读取；系统未提供这些计数时，通过已启用的特权服务或管理员权限读取，无需内核驱动；特权服务版本过旧时需先在设置中更新服务。暂无读数时显示“—”，指针悬停可看到原因：其他进程已有读数时，只是新出现的进程尚待下一次刷新；所有进程都暂无读数时，按特权服务的状态提示在设置中启用、启动或更新服务。已采到的空闲值显示“0”。在 Windows 11 24H2 及以上，新启动的进程第一次刷新即有读数；通过特权服务或管理员权限读取时，要到下一次刷新才有读数。表头和按应用视图的合计只累加已有读数的进程，全部暂无读数时才显示“—”。I/O 列保留进程的通用 I/O 合计，包含文件、网络和设备访问，与磁盘列的统计口径不同。

进程表的 GPU 列是该进程在最忙的那个 GPU 引擎上占用的时间比例，悬停可以看到是哪个引擎（例如“GPU 0 - 3D”）；详细信息面板还显示它占用的专用和共享 GPU 内存。以管理员身份运行 Argus 或启用特权服务且 ETW 可用时，进程表还会多出网络列：每个进程每秒发送和接收的数据量，悬停可以分别看到发送和接收；采集不可用时隐藏这一列。窗口较窄、表格放不下时，先隐藏线程和句柄列，再隐藏 PID 和 I/O 合计列；磁盘读写列始终保留，剩余空间不足时可横向滚动，名称列固定在左侧。

按应用视图按可执行文件路径合并进程，不同安装位置的同名程序分别显示。WebView2 显示启动它的应用名称，并按各自的运行时进程组归类；展开后可区分浏览器、渲染、GPU、网络等进程，搜索宿主名称也能找到它们。服务主机显示承载的服务；无法可靠确定所属应用的通用宿主和解释器进程分别显示，可通过进程树查看父子关系。

拥有任务栏窗口的程序归入“应用”，其余进程中，系统目录内具有 Windows 组件版本信息的程序及系统内核进程归入“Windows 进程”，其他程序归入“后台进程”。分组只用于浏览，不代表进程可以安全结束。标题数量统计当前筛选下的顶层条目，展开子进程不增加数量；没有匹配项的分组不显示。按 CPU、内存等数值排序时保持全局排序，便于查找占用最高的进程。

在按应用视图中选中一组进程时，详细信息面板显示该组的情况：合计的 CPU 与内存曲线、各项资源的总和、最早的启动时间、组内各进程（按 CPU 占用排序，单击可查看单个进程）以及文件位置。结束、优先级和效率模式操作仅作用于该组；同名的其他应用或 WebView2 运行时组不受影响。

网络速率默认以字节每秒显示（KB/s、MB/s，与磁盘一致），可以在“设置 → 数据与历史”里改为比特每秒（Kbps、Mbps，与网卡的链路速度、宽带套餐一致），概况带、进程表、详细信息面板和历史页随之切换；性能页的网络视图总是同时显示两种。

## 运行新任务与重新启动资源管理器

窗口右上角的“运行新任务”可在任意页面使用。输入程序名称、文件或文件夹路径，也可附加启动参数；“浏览”可选择文件。勾选“以管理员身份运行”时，由 Windows 处理授权。取消授权或启动失败后保留输入，可修改后重试。未勾选时以普通权限启动，即使 Argus 本身以管理员身份运行。

右键当前桌面的 Windows 资源管理器，选择“重新启动”并确认，可恢复桌面和任务栏。此操作可能影响资源管理器窗口及正在进行的文件操作；仅作用于承载当前桌面的实例，不会批量结束同名进程。资源管理器已经退出时，可在“运行新任务”中输入 `explorer.exe` 重新打开。

## 优先级与效率模式

右键一个进程（或按应用视图中的一组进程）：

- **设置优先级**：实时、高、高于正常、正常、低于正常、低。设为实时前会先确认；以标准权限运行时，Windows 会把实时降为高，Argus 会提示。
- **效率模式**：与系统任务管理器相同，让 Windows 优先把它安排到能效核和低频率上运行，并把优先级降为低；关闭后恢复正常优先级。处于效率模式的进程名称后面有一个叶子标记。
- **添加规则**：为该程序建立一条规则，以后它每次启动都会自动套用，见[设置](settings.md#规则)。

系统进程和其他用户的进程需要启用[特权服务](settings.md#权限)，或以管理员身份运行 Argus 才能更改。

## 启动项

启动页列出注册表 Run 项、启动文件夹中的项目，以及当前账户安装的应用包启动任务。同一应用的多个启动任务分别显示；名称优先采用程序描述或应用包的本地化名称，原始项目名仍可搜索，并显示在名称的悬停提示中。

单击开关或使用右键菜单可启用、禁用下次登录时启动的项目，与系统任务管理器共用状态。应用包启动任务可在标准权限下更改；“所有用户”的传统启动项仍需要管理员权限。应用不允许手动更改或暂时无法读取状态时，会禁用开关并说明原因。页面可见时每 10 秒刷新，切回页面后重新读取。

手动启用应用包启动任务后，无需先打开应用即可在下次登录时启动。系统任务管理器已打开时可能保留旧状态，可关闭后重新打开进行核对。

## 备注与置顶

服务、启动和连接页可为条目添加备注或将其置顶：右键条目，选择“置顶”“取消置顶”，或“添加备注”“编辑备注”“删除备注”。备注显示在名称之后，以带图标的浅色标签与名称区分；名称始终完整显示，空间不足时备注先收窄，指针悬停可看到全文。搜索框同时匹配备注。置顶的条目排在列表最前，名称列末端显示图钉，下方以分隔线与其余条目隔开；置顶条目之间按当前排序排列。

备注与置顶随界面偏好保存在本机，重启后保留。服务按服务名称记忆，启动项按所在位置与项目名称记忆。连接按程序与端口记忆：监听端口、UDP 端口及经监听端口接受的连接按本地端口，程序主动发起的连接按远程地址和端口；同一程序在同一端口上的多个连接共用备注与置顶，程序重启、PID 变化后仍然有效。

## 历史

Argus 运行时每 5 秒记录一帧：整机的 CPU（这 5 秒内各次采样的平均值和最高值）、内存、磁盘与网络吞吐量、GPU，有电池的设备还有电池电量与充放电功率（电量为各块电池的平均值，功率为各块之和），以及当时 CPU、内存、I/O、GPU 和网络占用最高的几个进程。窗口最小化、隐藏在托盘或暂停刷新时照常记录；最小化或后台常驻时的刷新间隔长于 5 秒时，按该间隔记录，曲线随之变稀，仍连成线。Argus 没有运行的时段，曲线留空；紧邻按较长间隔记录的时段时，一分钟左右的中断不留空。

- **时间范围**：在工具栏选择 1 小时、6 小时、24 小时或 7 天。CPU 曲线上方较淡的线是每段时间里采样的最高值。
- **查看某一时刻**：指针移到曲线上，左侧显示那一刻的数值；单击选中这一时刻，下方列出当时最忙的进程。选中后在曲线上按 ← →（加 Shift 一次移动更多）前后移动，按 Esc 或工具栏上的“回到最新”返回。
- **电池数据缺失**：设备暂未上报电池电量的时段，电池曲线留空，读数显示“无记录”；实际电量为 0% 时仍显示为 0%。
- **放大**：选中一个时刻后切换到更短的范围，会以该时刻为中心显示。
- **转到进程**：双击列表中的进程，如果它仍在运行，就转到进程页并选中它。

每进程网络流量会在本地采集或特权服务采集可用时记录。记录保存在 `%LOCALAPPDATA%\dev.argus.taskmanager\history`，每天一个文件，保留 7 天，连续运行一天约 8 MB。在“设置 → 数据与历史”里可以关闭记录、查看占用的空间或清除全部历史，见[设置](settings.md#数据与历史)。

## 文件占用

单击工具栏上的“查找占用文件的进程”，或者直接把文件、文件夹拖到窗口上，即可查询占用。结果合并两种来源：Restart Manager 查找文件引用和已加载的模块，句柄扫描补充打开的文件、目录及后代，包括把所选文件夹当作当前目录的命令行进程。文件 ID 可识别通过硬链接打开同一文件的情况。

有可用且已授权的特权服务时，句柄查询交给服务；否则以当前账户的权限查询，普通权限也能发现许多自有进程。每个结果显示匹配路径和句柄数量，重复来源按 PID 与启动时间合并。“结束”仍会确认，并核对同一进程实例，避免 PID 复用后结束其他进程。

扫描无法访问的进程、跳过的句柄或超时都会单独提示；“未发现”不等于绝对没有占用。辅助进程遇到阻塞会被终止，保留已找到的结果并继续；达到总时间或数量上限时返回部分结果。句柄表示引用，允许共享删除的句柄也可能列出。

当前句柄扫描只支持本地磁盘的绝对路径，不跟随符号链接、目录联接或网络/SUBST 驱动器；这些目标仍保留 Restart Manager 的查询结果，可改选链接的实际目标。保护进程和已经关闭文件句柄的内存映射仍可能无法检出，见[已知问题](../known-issues.md)。

| 结束进程 | 进程页 Alt+E；列表获得焦点时也可按 Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

分组标题的折叠状态在重启后保留；在进程列表中按 ← 可从顶层的条目移到所属分组的标题。搜索时各组显示全部匹配项，暂不能折叠，清除搜索后恢复原来的折叠状态。转到某个进程时（例如从服务页或连接页），其所在的分组随之展开。

在进程页，焦点不在输入框、且没有弹窗或菜单打开时，直接键入字母或数字即开始搜索：文字追加在搜索框原有内容之后，不会清除已有的筛选；按 ↓ 回到列表，按 Esc 清除搜索并回到原来的位置。也可直接用中文等输入法输入：组字过程显示在搜索框中、候选窗口出现在搜索框下方，此时列表暂不筛选；选定文字后填入搜索框，可继续在其中输入；组字中途单击别处时，已显示的文字保留在搜索框中。为此，进程页上没有其他控件需要焦点时，键盘焦点停在进程列表上：打开页面、窗口回到前台、单击空白处或工具栏按钮、关闭菜单之后，焦点回到列表，不显示焦点框；输入框、弹窗、菜单、正在选择的文字，以及用 Tab 移到按钮上的焦点不受影响。带 Ctrl、Alt（含 AltGr）或 Win 的组合键、空格和标点（包括输入法在组字之外送出的标点）以及按住不放的按键都不会开始搜索；组字期间按 Enter、方向键或 Esc 由输入法处理，不会操作列表。

Alt+E 使用与右键菜单相同的确认和权限处理，选中应用组时作用于该组；输入框、弹窗或菜单打开时不触发。完整按键说明见“设置 → 快捷键 → 查看快捷键”。

## 权限

使用其他管理员账户启动时，设置、历史和日志保存在该管理员账户中，进程视图、列宽等界面偏好单独保存。

以管理员身份启动时，若 Windows 资源管理器已经退出，Argus 会询问是否先恢复桌面。确认后以原桌面账户的普通权限打开资源管理器，再继续启动界面；选择“否”则取消本次启动。

以标准用户身份运行就能看到全部进程的路径与资源占用。在[设置 → 权限](settings.md#权限)安装可选的特权服务后，手动进程操作、自动规则、每进程网络与磁盘读写采集、句柄查询、服务控制和断开连接可以使用后台服务。详细信息与所有用户启动项的修改仍使用界面进程自身的权限；没有权限时界面会明确提示。状态栏右下角的权限标记显示当前状态：以管理员身份运行时为“管理员”，特权服务已连接时为“特权服务”，否则为“标准权限”。

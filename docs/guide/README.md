# 界面与操作

Argus 的窗口从上到下依次是工具栏、系统概况带、当前页面和状态栏。

- [常驻、托盘与快捷键](resident-mode.md)
- [设置](settings.md)
- [硬件数据的来源与限制](hardware-data.md)

## 页面

| 页面 | 快捷键 | 内容 |
|---|---|---|
| 进程 | Ctrl+1 | 三种视图：按应用（同一程序的多个进程合并为一行）、进程树（按父子关系）、列表（全部平铺）。排序、搜索、结束进程或整个进程树、详细信息面板、右键菜单 |
| 性能 | Ctrl+2 | CPU（整体或逻辑处理器视图，可按性能核 / 能效核筛选；频率、温度、功耗）、内存、各个磁盘、网络适配器、GPU、电池 |
| 服务 | Ctrl+3 | 启动、停止服务，修改启动类型；进程页里的 svchost 会显示它承载的服务 |
| 启动 | Ctrl+4 | 启用、禁用登录时启动的程序，标出已失效的项目；与系统任务管理器使用同一个开关 |
| 连接 | Ctrl+5 | TCP / UDP 端点及所属进程，可按端口精确搜索，可断开 IPv4 TCP 连接 |
| 设置 | Ctrl+6 | 见[设置](settings.md) |

## 概况带、工具栏与状态栏

- **概况带**：CPU（含每个逻辑处理器的使用率小条）、内存、最忙的磁盘、网络和 GPU。单击其中一项，转到“性能”页的对应设备。
- **工具栏**：页面标签；进程页的视图切换；右侧依次是权限标记（标准权限 / 管理员）、刷新频率、暂停 / 继续刷新、查找占用文件的进程、详细信息面板开关。
- **状态栏**：线程数、句柄数、缓存、内核分页池、系统已运行时间，以及刷新状态（例如“已暂停刷新”）。

指针停在进程列表上时，刷新只更新数值、不重新排序，状态栏会提示“指针在列表上，暂不重新排序”；移开后按当前排序重新排列。

## 文件占用

单击工具栏上的“查找占用文件的进程”，或者直接把文件拖到窗口上，即可列出正在使用这个文件（或加载了这个 DLL）的进程。不需要管理员权限，限制见[已知问题](../known-issues.md)。

## 键盘操作

| 操作 | 按键 |
|---|---|
| 切换页面 | Ctrl+1 … Ctrl+6 |
| 搜索进程 | Ctrl+F 或 / |
| 选择 | ↑ ↓ |
| 折叠 / 展开 | ← → |
| 打开详细信息 | Enter |
| 结束进程 | Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

## 权限

以标准用户身份运行就能看到全部进程的路径与资源占用。部分系统进程的详细信息与结束操作、多数服务的启停、所有用户启动项的修改需要管理员权限；没有权限时界面会明确提示。以管理员身份运行时，工具栏的权限标记显示“管理员”。

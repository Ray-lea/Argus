# 界面与操作

Argus 的窗口顶部是标题栏，下方是导航栏、当前页面和状态栏。导航栏默认位于标题栏下方，也可以改为位于窗口左侧；进程页可在列表上方显示系统概况带。

“设置 → 语言与外观 → 进程概况带”提供“自动”（默认）、“始终显示”和“隐藏”。自动模式仅按固定高度预算预留概况带、表头、滚动条与虚拟的 10 行进程；窗口空间不足时收起。计算使用完整页面高度，与实际进程数量、分组折叠、搜索筛选、滚动位置及概况带当前是否显示无关，避免收起后空间增大又反复展开。展开和收起以高度过渡带动列表移动；关闭界面动画时直接切换。隐藏期间仍继续采集数据和维护曲线历史。

## 首次启动

第一次启动时显示引导，依次完成常用设置：界面语言；导航栏的位置、界面动画、曲线动画与刷新频率；登录 Windows 时启动、关闭窗口时保留在托盘、最小化与后台常驻时的刷新间隔，以及显示或隐藏窗口的快捷键；自动检查更新、更新通道与下载线路；可选的管理员运行，授权后在完成引导时切换权限；可选的特权服务及其授权范围，可以在引导中直接安装（需要管理员授权），也可以跳过、之后在“设置 → 权限”中安装；可选的内核传感器（依赖特权服务，开启时自动准备 PawnIO 驱动，需要管理员授权）；是否用 Argus 替换系统任务管理器（依赖特权服务，同样需要管理员授权）；最后是常用操作的提示。每一步的修改立即保存，任何一步都可以单击“跳过”或按 Esc 结束，之后随时可以在[关于](#关于)页重新打开引导。

免安装版在引导第一步的“界面语言”下方说明与安装版相比缺少的功能：应用内更新、开始菜单快捷方式与卸载入口，以及特权服务与任务管理器替换随版本自动更新；“前往官网下载”打开官网下载页，“前往 GitHub 下载”打开 GitHub 上的最新版本。首次启动的引导结束后，右下角再提示一次相同的内容和两个下载入口，约 30 秒后自动收起，指针停留时保持显示；此前已完成引导的账户，在下一次以免安装版启动并显示窗口时提示。该提示在每个 Windows 账户下仅出现一次，从关于页重新打开引导时不再出现，出现提示的那一次运行不再显示 Star 提醒；由任务管理器替换入口启动的那一次运行不提示，留到之后的正常启动。安装版与免安装版共用设置和历史数据，改用安装版后无需重新配置。

## 页面

进程页与连接页的页面栏均提供“隐藏系统进程”按钮，默认关闭，开启时以强调色标记。两个页面分别保存开关；进程页的按应用、进程树和列表均适用。隐藏仅影响列表，系统概况、采集、历史记录与规则继续保留完整数据；进程页开启隐藏后，名称列上方的统计显示为“607 个进程 (27 个隐藏)”的形式，前者为全部进程数，括号内为被隐藏的进程数；隐藏父进程后，其余子进程仍可显示。从服务或连接等入口定位被隐藏的进程时，会自动关闭进程页的隐藏开关以显示目标。

按钮仅显示图标，悬停可查看操作说明；规则位于“设置 → 语言与外观 → 系统进程隐藏规则”。默认识别 Windows 系统组件，同时保留资源管理器、命令提示符、控制台与 PowerShell（`explorer.exe`、`cmd.exe`、`conhost.exe`、`openconsole.exe`、`powershell.exe`、`pwsh.exe`）。可编辑“始终显示”和“额外隐藏”名单，按程序文件名匹配、不区分大小写，两页共用；单击“保存”后生效并持久保存。“始终显示”优先，恢复默认规则后需保存。

进程页可在最外层按登录用户分组，由“设置 → 语言与外观 → 按用户分组进程”控制：“自动”（默认）仅在多个用户同时登录时分组，已断开连接但未注销的会话计入；“始终分组”与“不分组”固定为所选状态。有用户登录或注销后，列表随下一次采样更新，无需重启。

每个用户一组，当前会话的用户在前，其余用户按名称排列，最后是“系统”；各组的先后不随列排序变化。进程归入其所在会话的登录用户，同一用户的多个会话合为一组，两个用户名称相同时显示为“域\用户名”。无用户登录的会话归入“系统”，包括系统服务所在的会话 0 和停在登录界面的会话。分组行显示用户名、进程数与各列的资源合计，用户的全部会话均已断开时标注“已断开连接”；单击可折叠或展开，折叠状态随配置保存。

组内的显示与不分组时相同：三种视图、按名称排序时的三类分组、列排序、搜索和“隐藏系统进程”都在各组内部生效。进程树只连接同一组内的父子进程，父进程属于其他组的进程列在本组的顶层。同一程序由两个用户运行时，按应用视图在各自组内各占一行，详细信息面板的进程数、资源与曲线只统计该用户的进程。折叠某一类（如“Windows 进程”）对所有用户组同时生效；搜索时显示全部匹配项，没有匹配项的用户组不显示。

在用户的分组行上单击右键，除折叠或展开外还有两项，与任务管理器“用户”页相同：“管理用户账户”打开控制面板的用户账户页面；“注销”在确认后结束该用户的全部会话，其中运行的程序随之关闭，未保存的数据可能丢失。注销当前用户与从“开始”菜单注销相同，程序仍可提示保存，Argus 随会话一同退出。注销其他用户需要管理员权限，仅在以管理员身份运行的 Argus 中可用，否则该项不可选并标注“需要管理员权限”。“系统”分组只能折叠或展开。

连接页开启隐藏时，还会过滤 PID 为 0 的“无所属进程”记录。这类记录常见于 TCP 关闭后的 `TimeWait` 阶段，等待协议回收；UDP 的 PID 为 0 表示系统未提供归属。它们没有可供定位或结束的用户进程。其他 PID 暂时缺少身份信息时保留显示。

### 连接按应用分组

连接页默认显示“列表”。切换到“按应用”后，同一可执行文件路径的连接归入一组。路径缺失时按文件名分组。无所属进程和所属进程已退出的连接分别归组。

分组行显示应用名称与连接数。单击箭头、双击分组行或按 Enter 可展开或折叠，也可用左右方向键操作。只有一条连接时直接显示该连接。筛选和排序先于分组生效，搜索时自动展开匹配结果。视图与手动展开的分组在重启后保留。

分组内的连接由同一进程持有时，可从分组行的右键菜单转到或结束该进程。备注与置顶作用于单条连接。

## 导出当前页为 CSV

在进程、服务、启动或连接页，单击右上角“更多操作”（…），选择“导出当前页为 CSV…”，再选择保存位置。文件保留单击导出时的筛选、排序、列顺序、显示单位和分组展开状态，包含滚动区域外的行。筛选结果为空时，文件仅含表头。

默认文件名包含页名、导出时的本地日期和时间，以及表头以外的行数。进程页还包含视图名称，例如 `Argus-进程-列表-2026-11-21_13-35-42-128行.csv`。保存时可修改文件名。

CSV 使用带 BOM 的 UTF-8 编码，可在 Excel 中打开。名称、描述或命令行等文本若以公式符号开头，会添加前导单引号，使电子表格按文本读取。

## 选择进程列

在进程列表的表头右键打开列菜单。指针所在的列可直接升序或降序排序、隐藏该列（名称列除外），或“自动调整此列宽度”。“基本信息”“CPU”“内存”“磁盘与 I/O”“网络”“GPU”六个子菜单列出全部 48 项属性并显示已选数量，单击即显示或隐藏对应的列，子菜单保持打开，可连续调整。菜单下方是“选择列…”“自动宽度”“全宽”和“恢复默认列”。

“选择列”对话框左侧按分类分组列出属性及说明，可按分类筛选、按列名或说明搜索，分类标题旁的“全选”“清空”作用于该分类当前列出的属性。右侧“显示顺序”按表格顺序列出已选的列：拖动时该项浮起并跟随指针，其余项实时让位；指针悬停时可上移、下移或移除。修改在单击“确定”后应用并保存；“取消”或 Esc 保留原设置。名称列固定显示在最前，所选列在按应用、进程树、列表三种视图间共享，并在重启后保留。

拖动表头可调整列顺序，名称列固定在最左侧。拖动时整列跟随指针，越过相邻列的中线即与之交换位置，其余列平滑让位；松开后该列滑入新位置。顺序会保存；暂时隐藏后重新选中的列回到原位置。动画遵循“界面动画”设置，关闭时直接换位。

“自动宽度”默认开启，根据列标题、汇总数值、各行内容和字号分配宽度，各列仅取内容所需的宽度，剩余空间留在表格右侧。百分比、内存、速率等数值列及其汇总值按该格式常见的最大值预留宽度，首次显示即接近最终宽度，读数变化不改变列宽；这些列只增不减，按 8 px 递增。名称、路径、描述等文本列按全部进程测量，折叠的分组与搜索未显示的进程同样计入，滚动到其他行、展开或折叠分组以及搜索时列宽不变：表格宽度不足时，文本列取多数进程完整显示所需的宽度（至少 95% 的行），明显过长的少数内容以省略号截断，悬停可查看全文；宽度充裕时逐步加宽至完整显示全部内容。名称列中映像名称先于进程名称截断，效率模式、已暂停、资源泄漏与固定标记紧随文字显示。文本列在内容变短超过一档时才收窄，避免列宽反复变化。列宽变化时平滑过渡，遵循界面动画设置；调整窗口大小时直接跟随，更改字号或界面语言时重新计算。

指针移到表头的列边界上时显示强调色竖线，停留片刻后提示“拖动调整宽度，双击自动调整”；拖动时竖线延伸到列表底部，经过的表头不显示悬停效果与说明。自动宽度开启时也可拖动列边界调整单列宽度：该列保持手动宽度，其余列宽度不变，其右侧各列随之移动，其余列继续按内容调整；双击列边界或在表头菜单中选择“自动调整此列宽度”，该列恢复自动宽度，恢复时整列以强调色标出并随宽度过渡淡出。重新开启“自动宽度”时，所有列恢复自动宽度。关闭“自动宽度”后各列保持保存的手动宽度，双击列边界使该列适应全部内容；再次关闭自动宽度时恢复已保存的手动宽度。“全宽”默认关闭，在自动宽度开启时可用：名称列延伸至表格右侧，不留空白；名称列被拖动过宽度时保持该宽度。空间不足时可横向滚动查看所选列，名称列保持固定。横向滚轮、Shift+滚轮和单击滚动条轨道均支持滚动动画，遵循界面动画设置。“恢复默认列”同时恢复初始选择、顺序、自动宽度与全宽。

三种视图的“名称”均优先显示应用名称或文件描述，可执行文件名放在次级文字；“映像名称”列始终显示可执行文件名。应用分组展开后的子进程保留可执行文件名，便于区分成员。

进程树默认折叠全部分支。可通过父进程左侧箭头、双击、左右方向键或右键菜单中的“展开”“折叠”调整单个分支；在进程表列标题（名称、CPU 等）上右键，可选择“展开所有”“折叠所有”。展开状态在当前运行期间保留，重启后重新折叠，新出现的分支默认折叠。搜索时自动展开匹配进程的父级，并暂时停用折叠操作；清除搜索后恢复原来的展开状态。

可选列包含父进程 ID、映像名称与路径、描述、公司、文件版本、架构、是否已提升、命令行、会话、启动时间、进程状态、电源使用情况及其趋势、CPU 累计时间、优先级、工作集及峰值、提交大小、虚拟地址空间、缺页次数、内存优先级、I/O 累计字节、I/O 优先级、网络收发、GPU 引擎及显存用量。

应用分组汇总当前资源计数及累计时间、I/O 字节。虚拟地址空间与工作集峰值按单进程显示，可展开应用分组查看。虚拟地址空间包含预留和已提交的地址范围，浏览器等程序可能预留数 TB；当前私有提交用量见“提交大小”。峰值、地址范围和累计计数使用普通底色。PID、启动时间、优先级和状态等实例属性只在单进程行显示；路径、公司等文字在成员一致时显示共同值。网络采集暂不可用时隐藏网络列，并保留选择以便恢复。取消当前排序列后按名称升序排列。

“基本信息”中的“电源使用情况”与“电源使用情况趋势”对应系统任务管理器的同名列，按进程的 CPU、GPU 与磁盘活动估算耗电水平，分为非常低、低、中、高、非常高五级，单元格底色随等级加深。前者为当前采样间隔的水平，后者为最近约两分钟的平均水平，进程出现或 Argus 启动约 10 秒后显示。应用分组按成员估算值之和分级，排序按显示的等级进行，同级按名称排列。Windows 未公开这两列的计算方法，Argus 自行估算（权重与分级见[采集层](../architecture/core.md)的 `power.rs`），等级表示相对水平而非实际功耗，可能与系统任务管理器的显示不同。

## 标题栏、导航栏、概况带与状态栏

- **概况带**：CPU、内存、最忙的磁盘、网络和 GPU。大号数字下方是辅助读数：CPU 为频率、温度与功耗，GPU 为温度与功耗（取自当前最忙的显卡），内存为占用比例，磁盘为活动时间，网络为接收与发送速率。缺失的读数不显示；卡片较窄时，数字与辅助读数随之缩小字号。曲线铺满卡片，在文字下方渐隐；顶部细线标出量程上限，右上角注明上限数值（使用率为 100%，内存为总容量，磁盘与网络为当前档位）。CPU 温度与功耗的来源可悬停查看；GPU 功耗优先显示瓦数，仅有相对读数时显示 `% TDP`。单击卡片转到“性能”页的对应设备。
- **导航栏**：默认以标签形式排列在标题栏下方，标签右侧是页面栏。在“设置 → 语言与外观”或首次启动引导中可改为侧边导航栏：位于窗口左侧，“设置”与“关于”位于底部；默认仅显示图标（指针悬停可看到页面名称与快捷键），单击顶部的 ☰ 按钮展开显示页面名称，再次单击收起。展开后可拖动侧边栏的右边缘调整宽度（150–320 px），双击右边缘恢复默认宽度。位置、展开状态与宽度在重启后保留。
- **标题栏**：空白处可拖动窗口、双击最大化，最右端是最小化、最大化与关闭按钮（指针停在最大化按钮上时，Windows 11 显示贴靠布局）。最小化按钮左侧的图钉按钮切换“置顶显示”：开启后窗口始终显示在其他窗口之上，图钉以强调色填充，再次单击恢复；该状态在重启后保留。左侧是 Argus 的图标与名称，中间是当前页面的搜索框，宽度约为窗口宽度的 30%（不窄于占位文字，不超过 480 px），空间足够且未输入时右端显示快捷键 Ctrl+F。两侧空间足够时搜索框位于窗口正中，否则紧随左侧的名称。
- **页面栏**：顶部导航时位于标签右侧；侧边导航时位于页面顶部，左侧显示页面名称。依次是当前页面的控件和“更多”按钮：进程页为视图切换（按应用、进程树、列表，仅显示图标）、隐藏系统进程与详细信息面板按钮，服务页为针对所选服务的启动、停止、重新启动，连接页为视图切换（按应用、列表，仅显示图标）与隐藏系统进程，历史页为“实时”或“回到最新”。服务页与连接页的筛选位于列表“状态”列的表头：单击表头右端的 ⌄ 选择全部、正在运行、已停止（连接页为全部、监听、已连接）；连接页的“协议”列另有协议筛选，可选全部、TCP、TCPv6、UDP、UDPv6，与状态筛选同时生效。筛选生效时该按钮显示为强调色的漏斗图标；单击表头其余部分仍按该列排序。“更多”在每个页面都位于最右端，其中有“运行新任务”（Ctrl+N）、“查找占用文件的进程”、服务页的“打开 Windows 服务管理器”和快捷键说明。标签（或页面名称）与控件之间的空白同样可拖动窗口、双击最大化。窗口较窄时，页面控件移到下方单独一行；指针悬停仍可看到按钮名称。
- **状态栏**：最左端是版本号，测试构建在版本号后附带提交数（悬停可看到完整版本与更新通道），单击打开本版本的更新内容，右键复制版本号，有新版本时改为更新标记（见[设置 → 更新](settings.md#更新)）；其后是线程数、句柄数、缓存、分页缓冲池与系统已运行时间，窗口较窄时从最后一项起依次隐藏；右端是刷新控件和权限标记。刷新控件左侧显示刷新状态（例如“每 1 秒刷新”“已暂停刷新”），单击可选择刷新频率，再次单击收起；右端的按钮单击暂停或继续刷新，对所有页面生效，位置不随状态文字变化。权限标记显示“管理员”时，Argus 以管理员身份运行；显示“特权服务”时，Argus 以标准权限运行，需要管理员权限的操作由已连接的特权服务执行；显示“标准权限”时两者都不具备。指针悬停可看到说明。

暂停刷新只冻结界面上的数据，历史记录和规则照常进行（这期间每 5 秒采样一次）。

内存页的组成条区分“使用中”“已修改”“备用”和“空闲”。已修改的内容须先写入磁盘才能重新使用；备用内存包含未在使用的缓存数据与代码，空闲内存可直接分配。“已缓存”包含备用与已修改内存，“可用”包含备用与空闲内存。各项说明仅在下方色块图标上悬停时显示，说明文字不随采样数值变化，悬停期间图标位置保持稳定；没有组成明细时显示“—”。已压缩内存是使用中内存的一部分，即内存压缩进程（Memory Compression）占用的物理内存，在组成条上以斜纹显示在“使用中”的末端，图例另列“已压缩”；“使用中（已压缩）”的括号内为其数值，悬停可查看压缩内存估计存储的数据量与为系统节省的内存。系统未报告压缩存储时，组成条与图例不显示已压缩部分，该项仅显示“使用中”。进程合计与整机占用的区别见[内存统计口径](#内存统计口径)。

在进程页或性能页按住 Ctrl 可临时暂停刷新，曲线保持暂停瞬间的位置；松开 Ctrl、切换到其他窗口或隐藏窗口后解除临时暂停。手动暂停的状态保留；按住 Ctrl 时单击状态栏的暂停按钮，可选择在松开后保持暂停或继续刷新。

指针停在进程列表上，或右键菜单、确认框打开时，行位置保持固定，资源读数继续刷新；此时展开或折叠分组与子进程，展开的行显示在所属条目之下，其余行位置不变。移开指针或关闭菜单、确认框后恢复排序。行序因此与当前排序不同时，排序列表头的箭头变为强调色的暂停图标；由指针悬停引起时，状态栏另显示“排序已暂停”，悬停可查看说明。在“设置 → 语言与外观”中关闭“指针悬停时暂停排序”后，列表随读数实时排序，右键菜单或确认框打开时仍保持行位置。

进程查询耗时较长时，表格保留最近一次有效读数，悬停可查看更新状态；超过 10 秒的读数淡化显示。新读数到达后自动更新，等待期间保留的数值不重复计入曲线和历史统计。整机和设备读数继续独立更新。

支持轻量进程枚举的系统会独立更新进程名单。完整计数查询较慢时，新进程仍可出现、已退出进程仍会移除；新进程的计数取得前显示“—”，取得后补齐并保留选择。进程身份尚未确认时，结束进程、优先级及效率模式操作暂不可用。其他系统自动使用完整快照更新名单。

“磁盘读取”和“磁盘写入”分别统计磁盘读写速率，I/O 列还计入网络及设备访问。两列取自 Windows 为每个进程累计的磁盘字节数：由文件缓存直接提供的读取不计入；经缓存的写入在程序写入时即计入，由系统稍后写到磁盘，因此进程的写入速率可在短时间内高于磁盘的实际速率。Windows 记录的读取字节数也可能集中在一次采样内增加，大量读取的进程可在个别采样中显示超过磁盘性能上限的速率；采样间隔越短越明显，启动后最初几次采样的间隔可短至约 0.3 秒。Windows 11 24H2 及以上优先使用普通进程查询，其他系统可使用特权服务或管理员权限采集。空闲时显示“0”，暂缺读数时显示“—”，悬停可查看原因。表头及应用分组汇总已有读数，全部缺测时显示“—”。

进程表的 GPU 列是该进程在最忙的那个 GPU 引擎上占用的时间比例，悬停可以看到是哪个引擎（例如“GPU 0 - 3D”）；应用分组显示汇总后最忙的引擎。专用和共享 GPU 内存使用 Windows 报告的进程驻留用量，缺失读数显示“—”；集成显卡使用的系统内存计入共享 GPU 内存，仅固件预留给显卡的部分计入专用 GPU 内存。共享资源可归属于多个进程；整张显卡的物理用量见性能页。GPU 列只统计性能页列出的显卡；未检测到显卡时（例如仅有 Microsoft 基本呈现驱动程序的虚拟机）隐藏 GPU 列，并保留选择以便恢复。以管理员身份运行 Argus 或启用特权服务且 ETW 可用时，进程表还会多出网络列：每个进程每秒发送和接收的数据量，悬停可以分别看到发送和接收；采集不可用时隐藏这一列。表格放不下时可横向滚动，名称列固定在左侧。

按应用视图按可执行文件路径合并进程，不同安装位置的同名程序分别显示。其他应用启动的 WebView2 子进程按宿主和运行时实例分组，展开可查看渲染、GPU、网络等角色，也可按宿主名称搜索。服务主机显示承载的服务，其他未识别宿主的进程可在进程树中查看父子关系。

应用包（MSIX）程序与系统任务管理器一样显示应用名称，例如“终端”，名称使用 Windows 显示语言；应用包启动的辅助进程（如控制台主机、后台任务宿主）仍显示各自的描述。按名称排序时，中文界面将汉字名称按拼音排在拉丁字母之前，英文界面拉丁字母在前；名称中的数字按数值比较，不区分大小写与重音。服务、启动与连接页的文字列按同样的规则排序。

拥有任务栏窗口的程序归入“应用”，其余进程中，系统目录内具有 Windows 组件版本信息的程序及系统内核进程归入“Windows 进程”，其他程序归入“后台进程”。分组便于浏览，结束进程前仍需确认其用途。标题数量统计当前筛选下的顶层条目，展开子进程不增加数量；没有匹配项的分组不显示。按 CPU、内存等数值排序时保持全局排序，便于查找占用最高的进程。

单击列表中的应用或进程即可选中，再次单击取消选中；双击仅用于展开或折叠含有子项的行（应用组、进程树中的父进程）。在已选中的这类行上单击时，Argus 等待系统的双击间隔过后再取消选中，双击展开或折叠期间保持选中，详细信息面板不收起，也不切换为本机配置。详细信息面板默认常驻在列表右侧：选中某一行时显示其详细信息，未选中时显示本机配置（处理器、内存、存储、网络、显卡与电池，单击某一项可转到“性能”页的对应设备）。页面栏中的面板按钮有三种状态，单击依次切换，右键可直接选择：

| 状态 | 按钮 | 面板 |
|---|---|---|
| 始终显示 | 面板图标，强调色 | 常驻列表右侧，未选中时显示本机配置 |
| 选中进程时显示 | 右栏带箭头的面板图标，强调色 | 单击进程即滑出；再次单击该行或单击面板右上角的关闭按钮取消选中后滑回隐藏 |
| 隐藏 | 面板图标 | 不显示；按 Enter 或从其他位置查看某个进程的详细信息时，切换为“始终显示” |

所选状态在重启后保留。拖动面板左缘可调整宽度，双击左缘恢复默认宽度。

“本机配置”标题右侧的显示／隐藏按钮仅隐藏硬件列表，保留面板的操作提示，并记住显示状态；不影响选中进程后查看详细信息。单击“操作提示”标题可收起或展开提示内容，收起后仅保留标题行，展开状态同样在重启后保留。单击“复制配置为文字”可复制当前硬件配置，列表隐藏时仍可复制。提交 GitHub 读数异常报告时，可将相关配置粘贴到“相关硬件”栏目；功能建议中的对应栏目为“参考与补充”。

选中单个进程时，详细信息面板依次列出：进程（PID、父进程、启动时间、用户、完整性、架构、优先级、I/O 与内存优先级、效率模式、是否已暂停、会话）、资源（专用工作集、工作集与其峰值、提交大小、虚拟地址空间、磁盘读写、I/O、GPU 与显存、网络、电源使用情况及其趋势、线程与句柄）、累计（CPU 时间及其用户态与内核态部分、I/O 读取、写入与其他 I/O 的累计字节、缺页次数）、文件位置、命令行与文件版本。用户、完整性与产品名称来自选中时的单独查询，以右键菜单选中进程时同样查询。

选中应用组时，详情面板显示该组的 CPU 与内存曲线、资源合计、最早启动时间、累计读数之和、按 CPU 排序的成员与文件位置。单击成员可查看单进程详情。结束、优先级和效率模式操作仅作用于选中组。

面板右上角的复制按钮（Ctrl+Shift+C）将面板所列内容复制为文字，按“【进程】”“【资源】”等小节分段，暂无读数的项目不复制；进程页的列表获得焦点时按 Ctrl+C 复制选中项的名称（与名称列显示的一致），面板或其他位置有选中的文字时，两组快捷键都改为复制所选文字。进程的右键菜单中，“复制”子菜单可复制名称、映像名称、PID、映像路径、命令行或详细信息；在某一列上单击右键时，菜单另有“复制“列名””，复制该行在这一列显示的内容，例如在 CPU 列上为“复制“CPU””。服务、启动与连接页的列表同样支持：Ctrl+C 复制名称列显示的名称，Ctrl+Shift+C 或右键菜单的“复制详细信息”以“列名: 内容”逐行复制该行显示的各列（空白与暂无读数的列除外），在某一列上单击右键时同样可“复制“列名””。

网络速率默认以字节每秒显示（KB/s、MB/s，与磁盘一致），可以在“设置 → 数据与历史”里改为比特每秒（Kbps、Mbps，与网卡的链路速度、宽带套餐一致），概况带、进程表、详细信息面板和历史页随之切换；性能页的网络视图总是同时显示两种。

## GPU 统计口径

进程 GPU 占用取最忙的单个引擎。应用组及分类标题先按适配器、物理 GPU 和引擎节点的完整身份汇总进程贡献，再取最忙节点。不同显卡或引擎节点分别计算，同名引擎按各自节点区分。

整体占用以 Windows 引擎计时为基础，不低于有效的进程引擎读数；NVIDIA 显卡另用 NVML 核心利用率补充计算负载。性能页显示本次来源，概况带的 GPU 数字也可悬停查看来源。NVML 补充不改写原生引擎曲线。比较其他工具时，须同时核对适配器、引擎和采样窗口，分别对照视频、3D 与计算负载的对应指标。

空闲时由 Windows 断电的显卡（如混合显卡笔记本的独立显卡）进入低功耗状态后，性能页的“电源状态”一行显示“已休眠”，悬停可查看说明。此时不读取温度、风扇、频率、电压与功耗，以免将其唤醒；利用率与显存照常显示。显卡恢复工作后，该行消失，读数继续更新。

## 内存统计口径

概况带、进程表头与进程行的“内存”采用不同口径。在概况带的内存数值、进程表头的“内存”和分类标题的内存合计上悬停，可看到对应口径的说明：

| 位置 | 统计含义 |
|---|---|
| 概况带的已用内存 | 整机总物理内存减去可用内存，包含使用中与已修改的部分 |
| 进程表头的内存百分比 | 上述整机占用占总物理内存的比例 |
| 进程行、应用组及分类标题的内存数值 | 专用工作集，即进程独占且驻留在物理内存中的部分；组与分类按该口径合计 |

分类标题合计各进程的专用工作集；整机占用还涉及共享驻留页、内核与驱动、页表、使用中的系统缓存和已修改页等。“Windows 进程”统计该分类内的进程专用工作集。完整工作集包含共享页，直接累加会重复计算进程间共享的部分。

备用内存计入“可用”；查看系统各类内存的占用，应使用“性能 → 内存”中的组成数据。

各类内存的采集来源见[硬件数据](hardware-data.md)。

## 磁盘详情

磁盘标题旁的“概览 / 详情”切换两页，所选页面在重启后保留。详情页每次打开时读取一次磁盘信息；单击切换按钮旁的“重新读取”可再次读取，健康状况卡片右上方显示读取时间。温度显示实时读数，其余数值保持读取时的状态。

读取会向磁盘的存储驱动发送只读查询。读取期间或读取返回后的 2 分钟内，Argus 未正常退出（系统崩溃、断电、整机无响应后重启，或进程被强制结束）时，此后启动不再自动读取，详情页显示“已暂停自动读取”及原因。单击其中的“仍要读取”或标题旁的“重新读取”照常读取；所选页面与磁盘保持不变。读取返回后 Argus 继续运行满 2 分钟，自动读取恢复；在此之前退出，下次启动仍显示该说明。

- **健康状况**：状态、剩余寿命、温度与可用备用空间，下方列出读取总量、写入总量、通电时间、通电次数、不安全关机与介质错误。已适配的 SATA SSD 按型号显示对应的寿命、累计主机读写、通电统计、异常断电及不可校正错误，提供备用空间比例的型号还显示其比例和阈值。SATA/ATA HDD 显示可读取的通电、启停、磁头加载、重映射／待映射／离线不可校正扇区及接口 CRC 计数，已适配的读写总量也会列出。NVMe 温度条以硬盘报告的严重温度为满刻度，刻线标出警告温度；备用空间条的刻线标出阈值。
- **设备信息**：型号、固件版本、序列号、容量、卷、接口、PCIe、SATA 或 PATA UDMA 传输模式（当前链路与设备支持的最高链路不同时同时列出）、NVMe 或 ATA 标准版本、扇区大小与支持的功能，包含设备报告的 SMART、TRIM、写入缓存及 NCQ。序列号默认隐藏，单击“显示”查看。
- **SMART 属性**：NVMe 健康日志按健康、使用情况和温度分组，读写量按每单位 512,000 字节换算；温度原始值单位为开尔文，未报告的传感器不列出。ATA／SATA 和支持 SAT 的桥接设备显示属性编号、名称、当前值、最差值、阈值及原始值，原始值的 6 个字节合为一个数，已识别的 SSD 字段按型号命名。SCSI／SAS 显示设备提供的健康状态、温度与读写错误统计。异常的数值以红色显示。卡片右上方的“十进制 / 十六进制”切换原始值的进制，默认为十进制，所选进制对所有磁盘生效，重启后保留。

SMART 属性的表格随窗口宽度调整。各列按其中最宽的文字定宽，名称与数值相邻，多出的宽度平均分给各数值列。NVMe 的健康、使用情况与温度三组在各栏高度相近时并排，否则上下排列，每组的行再分栏；ATA／SATA 属性在放得下时拆成至多 3 张并排的表，每张不少于 5 行。不再分栏后，每张表的宽度以文字所需宽度的 2 倍为限，其余宽度留在表格之间。窗口较窄时名称换行，仍放不下时数值移到名称下方。指针所在的行以底色标出。

健康状态按以下规则判定：

| 状态 | 条件 |
|---|---|
| 异常 | 严重警告中的备用空间低于阈值、可靠性下降、介质转为只读、易失性存储备份设备故障或持久性内存区域转为只读，或可用备用空间低于阈值 |
| 注意 | 严重警告中的温度超出阈值或尚未定义的警告位，存在介质与数据完整性错误，剩余寿命不高于 10%，或 HDD 存在重映射、待映射、离线不可校正扇区 |
| 良好 | 以上情况均未出现 |

NVMe 剩余寿命为 `100 − 已用寿命`，已用寿命是厂商对耐久度的估计，可超过 100%。严重警告与剩余寿命分别判定。ATA／SATA、USB-SAT 和 SCSI／SAS 的扩展数据经已运行的特权服务读取，可在“设置 → 权限”中安装、启动或更新服务。缺失的阈值与读数显示“—”。USB 桥接设备常不回传 SMART 状态，未取得设备故障预测时按属性与阈值判定：有预故障属性达到阈值为“异常”，均未达到时按上表判定；阈值也未取得时健康状态显示“未知”。读取保留设备的 SMART 启用状态。厂商专用 USB／RAID 通道的覆盖情况见路线图。

序列号优先采用 NVMe／ATA 厂商 SN，缺失时回退至 SCSI 单元序列号及 Windows 通用存储描述符；转速按 ATA 设备报告值显示。

## 运行新任务与重新启动资源管理器

“运行新任务”位于页面栏最右端的“更多”菜单中，可在任意页面使用，也可按 Ctrl+N 打开。输入程序名称、文件或文件夹路径，也可附加启动参数；“浏览”可选择文件。勾选“以管理员身份运行”时，由 Windows 处理授权。取消授权或启动失败后保留输入，可修改后重试。未勾选时以普通权限启动，即使 Argus 本身以管理员身份运行。

右键当前桌面的 Windows 资源管理器，选择“重新启动”并确认，可恢复桌面和任务栏。支持普通权限和高权限资源管理器，重启后保持原账户与权限；重启高权限实例时，Argus 需以管理员权限运行。此操作可能影响资源管理器窗口及正在进行的文件操作；仅作用于承载当前桌面的实例。该实例提供“重新启动”操作，“结束”和“结束进程树”均禁用。资源管理器已经退出时，可在“运行新任务”中输入 `explorer.exe` 重新打开。

重启前会检查权限并准备替代进程。旧资源管理器在退出清理或错误报告阶段卡住时，会在超时后结束已确认的旧实例，确认退出再恢复桌面；Windows 已恢复桌面时使用现有实例。桌面和任务栏均能够响应后才提示重启完成。

## 优先级、效率模式与暂停

右键一个进程（或按应用视图中的一组进程）：

- **设置优先级**：实时、高、高于正常、正常、低于正常、低。设为实时前会先确认；以标准权限运行时，Windows 会把实时降为高，Argus 会提示。
- **I/O 优先级**：非常低、低、正常。降低后，该进程的磁盘读写排在其他进程之后，适合后台压缩、索引、同步或下载占满磁盘时让前台程序保持流畅。高与关键两档由 Windows 保留，不能设置。当前取值也可在“I/O 优先级”“内存优先级”两列中查看，按级别排序。
- **内存优先级**：非常低、低、中、低于正常、正常。内存紧张时，Windows 先回收优先级低的进程的内存页，适合不常用的后台程序。
- **效率模式**：与系统任务管理器相同，让 Windows 优先把它安排到能效核和低频率上运行，并把优先级降为低；关闭后恢复正常优先级。处于效率模式的进程名称后面有一个叶子标记。
- **暂停进程 / 恢复进程**：暂停进程的全部线程，直到恢复，适合临时让出长时间运行的渲染、编码或编译任务。暂停前会先确认：被暂停程序的窗口会停止响应，网络连接可能超时，带反作弊或自我保护的程序可能出错。系统关键进程、桌面窗口管理器（dwm.exe）、Argus 自身及其特权服务不能暂停。暂停只作用于仍在运行的进程，“恢复进程”只作用于已暂停的进程；应用在暂停后又启动了新进程时，菜单同时提供两项。Windows 在后台挂起的应用包（例如最小化的“计算器”）同样显示为“已暂停”，由 Windows 自行恢复，菜单不提供这两项。执行时按进程当前的线程状态处理：已暂停的进程不会再次暂停；恢复撤销一次暂停，程序或调试器自行暂停的线程保持暂停。其他工具多次叠加暂停的进程，恢复后仍可能处于暂停状态，可再次恢复。
- **添加规则**：为该程序建立一条规则，以后它每次启动都会自动套用，见[设置](settings.md#规则)。

系统进程和其他用户的进程需要启用[特权服务](settings.md#权限)，或以管理员身份运行 Argus 才能更改。

## 资源泄漏提示

Argus 每 30 秒记录一次各进程的句柄数、存活子进程数与处理器时间，保留最近 60 分钟，据此标出三类可能的泄漏：

- **句柄泄漏**：进程持有 10 万个以上句柄（System 进程除外），或观察满 10 分钟后句柄数的低点持续上升，增加至少 1,000 个且不少于起始值的一半。打开大量窗口等一次性跳增不计入。
- **子进程累积**：进程的存活子进程数在观察期间持续上升，新增至少 10 个且当前至少 15 个。
- **残留进程**：同一程序有 5 个以上进程的父进程已退出，且至少 10 分钟未使用处理器。拥有任务栏窗口的进程与 Windows 组件不计入。

有发现时，进程页表头的进程数后出现琥珀色标记与发现数量，单击列出各项，选择一项即在列表中定位该进程。相关进程的名称后显示“句柄泄漏”“子进程累积”或“残留进程”标签，悬停可查看依据；句柄泄漏进程的句柄数同样以琥珀色显示。选中这类进程后，详细信息面板顶部说明依据、近期的数量变化与处理建议。

单击详细信息面板中的“忽略此程序”后不再提示该程序（按程序路径匹配），随后的通知中可撤销；“设置 → 语言与外观 → 资源泄漏提示”可关闭全部提示或恢复已忽略的程序。检测从 Argus 启动时开始，依据增长判断的两类至少需要观察 10 分钟。

## 启动项

启动页列出注册表 Run 项、启动文件夹中的项目，以及当前账户安装的应用包启动任务。同一应用的多个启动任务分别显示；名称优先采用程序描述或应用包的本地化名称，原始项目名仍可搜索，并显示在名称的悬停提示中。

单击开关或使用右键菜单可启用、禁用下次登录时启动的项目，与系统任务管理器共用状态。应用包启动任务可在标准权限下更改；“所有用户”的传统启动项仍需要管理员权限。应用不允许手动更改或暂时无法读取状态时，会禁用开关并说明原因。页面可见时每 10 秒刷新，切回页面后重新读取。

启用应用包启动任务后，下次登录时即可启动。系统任务管理器若仍显示旧状态，可重新打开核对。

## 服务与启动项的列宽

服务页与启动页的各列按内容取宽度，最后一列（服务页的“描述”、启动页的“命令”）延伸至表格右侧，不留空白。PID、状态、启动类型、位置等列按内容收紧；名称、服务名称与发布者按完整列表中多数项目所需的宽度显示，少数过长的内容以省略号截断，悬停可查看全文。列宽按载入的完整列表计算，搜索与筛选不改变列宽。窗口变窄时，名称等文本列先收窄，使最后一列保留约三分之一的表格宽度；窗口足够宽、最后一列已能完整显示时，文本列加宽至完整显示全部内容。

拖动列边界可调整该列宽度，最后一列随之伸缩：拉窄的列让出的宽度归最后一列；加宽时由最后一列和其他文本列让出宽度，直到它们都到最小宽度，表格不会因此横向滚动。调整后的宽度在重启后保留；窗口变窄到放不下时，调整过的列也按比例让出宽度。双击列边界，该列恢复按内容取宽度。

## 删除服务与启动项

服务页与启动页的右键菜单提供“删除”，在确认框中确认后执行。

- **服务**：从系统中删除服务及其配置，服务的程序文件保留。服务尚未停止，或程序位于 Windows 文件夹、可能属于 Windows 时，确认框另有提示。尚未停止或仍被其他程序使用的服务先标记为删除，由 Windows 在其停止并释放后移除。删除服务需要特权服务或以管理员身份运行 Argus；Argus 自己的特权服务只能在设置中卸载。
- **启动项**：注册表中的项删除对应的值，启动文件夹中的文件移到回收站，并一并清除其启用状态记录；所指向的程序保留。删除“所有用户”的项需要以管理员身份运行 Argus。应用包启动任务属于其应用，只能禁用。

删除失败时，通知说明原因（如没有权限、已不存在或特权服务版本不兼容），`argus.log` 记录失败的步骤与错误码。

## 备注与置顶

服务、启动和连接页可为条目添加备注或将其置顶：右键条目，选择“置顶”“取消置顶”，或“添加备注”“编辑备注”“删除备注”。备注显示在名称之后，以带图标的浅色标签与名称区分；名称始终完整显示，空间不足时备注先收窄，指针悬停可看到全文。搜索框同时匹配备注。置顶的条目排在列表最前，名称列末端显示图钉，下方以分隔线与其余条目隔开；置顶条目之间按当前排序排列。

备注与置顶随界面偏好保存在本机，重启后保留。服务按服务名称记忆，启动项按所在位置与项目名称记忆。连接按程序与端口记忆：监听端口、UDP 端口及经监听端口接受的连接按本地端口，程序主动发起的连接按远程地址和端口；同一程序在同一端口上的多个连接共用备注与置顶，程序重启、PID 变化后仍然有效。

## 历史

Argus 运行时每 5 秒记录一帧，数值为这 5 秒内各次采样的平均值：

- **处理器**：CPU 使用率（另记最高采样）、内核时间、频率、封装功耗与温度；CPU 核心电压和主板风扇转速由特权服务读取。
- **内存与系统**：内存使用量、已提交、已缓存、已压缩、分页与非分页缓冲池，以及进程数、线程数和句柄数。
- **存储与网络**：磁盘读取与写入，以及每块磁盘的读写、活动时间、平均响应时间和温度；网络接收与发送，以及每个网络适配器的收发。任一磁盘某个方向的计数缺测时，该方向的总量记为未知。
- **显卡与电池**：最忙的 GPU 引擎，以及每块显卡的使用率、专用与共享 GPU 内存、温度、功耗和频率；电池电量（各块电池的平均值）、充放电功率（各块之和）、电压与温度。
- **进程**：CPU、内存、I/O、磁盘、GPU 和网络各自占用最高的几个进程（每帧约 20 个，可在设置中改为约 40 个或全部活跃进程），记录其 CPU、专用工作集、I/O、磁盘读取与写入、GPU、专用 GPU 内存、网络、电源使用情况、线程数与句柄数。每进程网络流量在本地采集或特权服务采集可用时记录。

设备不提供的读数不记录，也不计为 0。除系统总量外，各组读数可在“设置 → 数据与历史”的“记录内容”中关闭。最近 10 分钟另保留每次采样的读数，仅存于内存。窗口最小化、隐藏在托盘或暂停刷新时照常记录；最小化或后台常驻时的刷新间隔长于 5 秒时按该间隔记录，桌面监控或任务栏监控显示期间则按“刷新频率”采样与记录。

- **读数与轨道**：页面顶部的标签显示 CPU、内存、磁盘、网络、GPU（有多块显卡时每块一个）和电池在所看时刻的值；数值占固定宽度，悬停曲线时标签不会移动。窗口较窄、标签带数值排不下一行时，标签只显示名称，仍排不下的部分可用滚轮横向滚动。单击标签在当前轨道显示该读数，单击标签上的 ＋ 新建轨道显示；把标签拖到某条轨道的曲线上叠加到该轨道，拖到轨道之间或最下方新建轨道。“更多读数”打开读数选择框，列出其余读数：顶部的搜索框按名称、设备或分组筛选，左侧按处理器、内存、存储、网络、显卡、电池与系统分组并注明数量，每块磁盘、每个网络适配器和每块显卡的读数列在设备名称下；需要特权服务的读数带盾牌标记。单击某项在当前轨道显示，单击行末的 ＋ 新建轨道；↑ ↓ 移动、Enter 选择、Esc 关闭。轨道标题的读数名称、“叠加”与“轨道”按钮打开同样的选择框。默认显示一条 CPU 轨道，记录有 CPU 温度时叠加在右侧纵轴。
- **轨道**：标题中的读数名称可更换读数；“叠加”再显示一个读数，使用右侧纵轴，单位相同时共用左轴；叠加与移除时曲线淡入淡出，纵轴随之平滑过渡。没有叠加读数或与左轴共用时，右侧纵轴标出与左侧相同的刻度。拖动标题左侧的把手调整顺序：轨道随指针移动，其余轨道让出位置，松开后落入虚线标出的位置。拖动轨道之间的分隔线调整高度，读数标签右侧的“轨道”添加轨道，标题右端的 × 移除轨道。轨道按高度比例分配图表的空间，最低缩小到约 76 像素；轨道较多、图表放不下时在图表内上下滚动，时间轴与导航条保持可见。在标题与纵轴标签上滚动滚轮可上下滚动轨道，在曲线上滚动滚轮仍为缩放。磁盘与网络以实线和填充表示读取（接收），以同色的暗色实线表示写入（发送）；两者也可作为叠加的读数，叠加时两条线都使用右侧纵轴，不加填充。
- **刻度与范围**：曲线按阶梯绘制，每个点的值在其覆盖的时段内保持水平（5 分钟时为一次采样到下一次采样，更长的范围为合并的时间段），在下一个点开始处变化。纵轴按可见部分的最大值取整。一个点包含 10 秒或更长的记录时，浅色区域表示其中的最低到最高值，CPU 以最高采样为上沿；可在页面栏“更多”菜单中关闭。没有记录的时段以斜纹标出，并注明原因：睡眠、关机或重启、Argus 未运行或记录已关闭；曲线在斜纹两端中断，此前的读数延续到斜纹起点。短于一个合并时间段、且该段前后都有记录的空档，曲线保持连续，不标斜纹。纵轴上限变化时，曲线、刻度线与刻度值平滑过渡，随“曲线动画”设置。
- **时间范围**：单击导航条左侧的时间范围按钮，在其下方展开下拉列表：5 分钟（默认）、3 小时、1 天、3 天与“自定义…”，单击即切换，也可用 ↑ ↓ 移动、Enter 选择、Esc 关闭，当前范围左侧以强调色标出；导航条显示该范围内当前轨道的曲线，方框为图表显示的部分。实时查看全部记录时，方框保持铺满导航条，新记录从右端加入。放大后跟随最新记录时，主图保持放大后的时长；恢复全范围后重新显示全部记录。切换范围时，图表在新范围的读数就绪后缩放到新范围，原范围的曲线淡出、新范围的曲线淡入，纵轴刻度随之交替；打开下拉列表时即预先读取各个范围，切回刚才的范围也无需重新读取。“自定义…”打开“自定义时间范围”对话框：左侧为常用范围（最近 5 分钟至 30 天、全部记录、今天、昨天），单击即应用；日历每次显示一个月，每天下方的细条表示当天有记录的时长，单击一天选择这一天，再单击之后的一天选择两天之间的整段，双击一天直接显示这一天；也可直接输入开始与结束时间（如 2026/11/19 16:40），勾选“结束于当前时间时跟随最新记录”后，所选起点保持固定，结束时间随当前时间推进，单击“应用”或按 Enter 生效，“取消”或 Esc 保持原范围。展开“显示 30 天概览与事件”后，对话框右侧单独一列列出事件（较多时在列内滚动），日历下方显示最近 30 天每小时的热力图（可选 CPU、GPU、内存使用率、CPU 温度或网络接收），拖动热力图选择时段，单击日期选择全天。夏令时开始时跳过的小时留空，结束时重复的小时分为两格，可分别选择。事件包括所选日期内检测到的 CPU 高负载、CPU 温度过高、内存紧张、GPU 长时间高负载、大量下载、磁盘繁忙与无记录，注明持续时间、最高值与占用最高的进程，单击事件选择其前后时段。5 分钟时每个点是一次采样；更长的范围按图表宽度合并为 1 秒到 6 小时的时间段，各段按整点对齐，曲线随时间移动时形状不变。
- **跟随最新**：页面栏显示“实时”时，图表停在最新读数：范围在 15 分钟以内时曲线随时间连续向左移动，6 小时以内每秒更新，更长的范围每分钟更新。更长的范围按合并的时间段绘制，曲线只画到已结束的时间段：正在累积的一段不画，以免其平均值随每次读数上下变化；每结束一段，新的一段从左向右画出，数值由前一段平滑过渡。在曲线上滚动滚轮以指针所在时刻为中心缩放，并暂停跟随；Shift+滚轮平移；+、− 缩放（跟随时右端保持在最新），0、双击图表或导航条显示整个范围。拖动导航条中的方框或其边缘可平移和缩放，平移只会暂停跟随，拖回最右端仍保持暂停；单击“回到最新”、右键单击图表或按 End 恢复跟随。
- **时刻与区间**：悬停时竖线停在指针处，只出现在指针所在的轨道，圆点标出该轨道各曲线在该处的值；提示显示该点的时间与读数，以及当时按该轨道读数占用最高的 5 个进程，合并的时间段显示平均值与其中的最高值。最近 10 分钟的单次采样按与上一次采样的间隔标为“每秒读数”或“每 5 秒读数”等，最小化或后台常驻时间隔达到 5 秒以上也不作为平均值显示。进程数轨道改为列出进程最多的 5 个程序及其进程数，并注明其余程序的个数与它们的进程数（取该时刻或该时间段内某一帧的记录，此前的版本记录的时段不显示）；电池电量、温度等不由各进程构成的读数不列出进程。跟随最新时曲线从静止的指针下方移过，圆点、读数与提示随之更新。点为一次采样或一帧时，单击固定游标，游标只显示在单击的轨道中；点为合并的时间段时，单击选中这一段。单击曲线时暂停跟随，图表停在单击时的位置。在图表上拖动选择区间，选区上的“放大到所选”使其占满图表。← → 逐点移动（加 Shift 每次 10 点），Home 移到图表中最早的点。Esc、游标顶端的 × 或进程表标题旁的 × 清除游标与选区。范围跨越夏令时切换时，时间后附 UTC 偏移。
- **进程表**：“此刻”在跟随最新且未固定游标时列出正在运行的进程（占用最高的 40 组），每秒更新；固定游标或暂停跟随后，列出该时刻一帧中记录的进程；“区间”列出所选区间（未选择时为图表显示的部分）内的进程：CPU 平均与最高、内存最高、磁盘与网络的读写量、GPU 平均、电源使用情况、记录时长，以及跟随最上方轨道读数的趋势。同名进程合并为一行，单击展开占用最高的 4 个实例与其余实例的合计。按名称排序时，与进程页相同分为“应用”“后台进程”和“Windows 进程”三组，组标题显示数量与合计，单击可折叠（搜索时全部展开）；记录中不再运行的程序按 Argus 此前见到它运行时的类别归组，从未见过的归入后台进程。清除历史记录时一并清除这些类别。搜索框按名称筛选；“列”选择显示的列，两种模式分别保存。右键菜单可将该进程的曲线以虚线叠加到对应轨道，或复制名称与 PID。页面栏“更多”菜单中的“快捷键说明”列出图表的按键与鼠标操作。
- **转到进程**：双击单个实例，或在右键菜单中选择“转到进程”，仅在 PID、名称和记录的创建时间与当前运行实例一致时转到进程页；执行跳转时再次核对。旧记录没有创建时间时保留历史读数，不提供跳转。创建时间可以位于该帧的 5 秒记录窗口内，不能晚于该窗口。

记录默认保存在 `%LOCALAPPDATA%\dev.argus.taskmanager\history`，每个 UTC 日一组文件，默认保留 30 天、最多 2 GB，先达到的上限生效。早于 7 天的记录合并为每分钟一帧，保留平均值、最高值与占用最高的进程；开发机上一整天的记录合并后约为原大小的 13%。保存位置、保留上限、合并时机与记录内容都可在“设置 → 数据与历史”中更改，见[设置](settings.md#数据与历史)。

历史文件使用 v3 格式，按读数记录，新增设备或读数不需要更改格式；合并为每分钟的日期使用 v4。0.6 之前的版本记录的 v1、v2 历史不再读取，这些日期显示为没有记录，到期后按保留天数清理；当天的文件是旧格式时，继续录制会以新文件取代当天的旧记录。旧版 Argus 无法读取 v3 与 v4 文件，降级前需备份历史目录；旧版记录器可能重建格式不受支持的当天文件。旧格式的记录仍需用对应旧版读取备份。

### 观察进程

在进程列表中右键单击进程并选择“观察进程”，或在详细信息面板中单击“取消选中”下方的观察按钮，即可开始观察并跳转到“历史记录”下的“进程观察”子页（可通过顶部切换控件在“系统历史”与“进程观察”之间切换）。即使该进程未进入系统历史的排行榜，也会随主采样器读取其专用工作集、专用提交量、工作集、CPU、GPU、专用显存、磁盘读写、I/O 读写、网络收发（已启用每进程网络采集时）、线程数与句柄数。工作集表示当前驻留的私人内存；提交量表示程序获得的私人已提交内存，工作集增长本身不证明内存泄漏。

图表与系统历史页相同：读数标签、阶梯曲线与多轨道、第二读数与右轴、悬停提示、时间范围（默认 5 分钟，也可选择 1 小时、3 小时、1 天或全部）与预览条、实时跟随与平滑过渡。图表显示所选运行实例的记录，最新的读数在右端；实例已结束时图表停在其最后记录，不显示“实时”。缺少有效采样的时段以斜线标出。下方列出观察的程序（名称、路径、状态、停止与删除）及其各次运行实例，单击实例即在图表中显示其记录。

观察从所选实例的已验证句柄读取本机映像路径，记录当前及随后启动的同路径程序；界面名称只作标签，不用于认定程序身份。不同目录的同名 EXE 不合并，路径比较保持大小写敏感目录的区别，不承诺合并路径别名，也不以文件签名或哈希定义二进制版本。每个已确认的实例保留一个只读查询句柄，直到退出；各实例的曲线按 PID 与创建时间分开。新实例的身份暂时无法读取时，显示无法确认的同名实例数，每分钟重试，不拼接到旧实例的数据。程序全部退出后保持等待，直到后续运行、手动停止或达到同时观察 512 个实例的上限。无法读取本机映像路径时，退化为仅记录当前实例，不从同名进程补全，并在该实例退出后结束观察。

观察记录使用独立文件 `program-watch.v1.bin`，最多保留 7 天、131072 个记录点及约 20 MiB；先到的上限触发最旧记录清理，时间过期的记录槽位会清零。停止后的数据也按此策略清理，Argus 关闭期间的过期记录在再次打开时清理。记录带序列与完整性校验，损坏记录不会当成读数。实例列表每页最多 256 项，可浏览较早实例或返回最新实例。

最近 10 分钟在内存中保留每次采样的读数，悬停时按实际采样间隔标注。前台每秒采样时可查看每秒读数，后台按实际刷新频率采样。较早的时段以及重启 Argus 后的曲线使用磁盘记录，通常约每 5 秒一笔。读数无效或采样中断的时段显示空缺。新启动的实例不继承其启动前的采样空缺。通过同一进程句柄确认退出。系统时钟倒退时中断观察，不把逆序时间拼接进曲线。观察文件与排行榜文件独立，关闭排行榜记录不停止显式选择的观察。

“停止记录”保留已有数据；“删除记录”停止观察并删除该条文件。开始另一条记录前需删除已有记录。退出或重启 Argus 不会自动继续旧观察，保留的未完成记录显示为中断。未知格式或损坏的记录也可删除。设置中的历史占用包含观察文件，“清除历史记录”同时停止并删除观察。

## 文件占用

在“更多”菜单中选择“查找占用文件的进程”，或者直接把文件、文件夹拖到窗口上，即可查询占用。结果合并两种来源：Restart Manager 查找文件引用和已加载的模块，句柄扫描补充打开的文件、目录及后代，包括把所选文件夹当作当前目录的命令行进程。文件 ID 可识别通过硬链接打开同一文件的情况。

对话框打开后，可继续将文件或文件夹拖入对话框，以更新查询目标。管理员窗口也支持从普通权限的文件管理器拖入文件。

占用进程是当前桌面的资源管理器时，操作按钮显示“重新启动”；确认后恢复桌面与任务栏，再重新检查文件占用。其他进程仍可通过“结束”释放占用。

有可用且已授权的特权服务时，句柄查询交给服务；否则以当前账户的权限查询，普通权限也能发现许多自有进程。每个结果显示匹配路径和句柄数量，重复来源按 PID 与启动时间合并。“结束”仍会确认，并核对同一进程实例，避免 PID 复用后结束其他进程。

结果会列出无法访问的进程、跳过的句柄和超时情况。“未发现”表示本次查询范围内没有匹配。查询卡住时保留已找到的结果；达到时间或数量上限时返回部分结果。允许共享删除的句柄也可能列出。

句柄扫描使用本地磁盘绝对路径。符号链接、目录联接、网络驱动器与 SUBST 路径保留 Restart Manager 的查询结果，指定实际目标可补查句柄。受保护进程和已关闭句柄的映射可能漏检。见[已知问题](../known-issues.md)。

## 关于

关于页位于导航栏中“设置”之后，显示版本、当前权限和许可证，提供更新内容、退出及重新打开首次引导的入口。打开关于页或引导第一步时，10 × 10 的点阵先拼出字母 A，再变为最近 10 次 CPU 占用的点阵图：每列对应一次采样，按当时的占用由下往上点亮，最上方的点最亮，最右一列为最新一次；占用达到 80% 的列为琥珀色。每次采样时各列左移一格，点的位置不变。关闭“界面动画”时直接显示点阵图。版本号与发行版相同；从未发布的提交构建的测试版本在后面附加提交数与提交的短哈希，例如 `0.3.4+583.g4c638d7`，便于确认所用的构建。版本信息下方的两张卡片分别链接 [Argus 官网](https://argustask.com/) 和 [GitHub 仓库](https://github.com/Ray-lea/Argus)：单击卡片打开对应首页，卡片底部的按钮直接打开常用页面，官网为“下载”“使用指南”“更新日志”，GitHub 为“问题反馈”（选择问题类型的页面）、“讨论区”和“发行版”。下载与更新日志页按界面语言打开，使用指南仅有中文版。“交流与反馈”可打开 QQ 群邀请或复制群号（453803497）；“Telegram 频道”可打开频道页面或复制频道链接（[t.me/argustask](https://t.me/argustask)）。“第三方组件”列出开源组件及许可证。

单击“打开日志文件夹”可查看 `%LOCALAPPDATA%\dev.argus.taskmanager\logs\diagnostics`。`argus.log` 记录系统版本、渲染器、传感器和特权功能状态，以及运行程序的 SHA-256，可用来区分同版本号的不同构建。失败记录包含具体步骤、系统错误码及相关路径。日志仅保存在本机，不记录命令行、凭据或文件内容；当前日志超过 1 MB 后，在写入下一条记录前另存为旧日志，最多保留 3 份旧日志。公开提交日志前，请检查这些路径中的用户目录名称。

单击“复制诊断信息”可将摘要复制为适合粘贴到 Issue 的文本，包含 Argus 完整版本、Windows 版本、构建与安装类型、当前权限、已读取的特权服务及任务管理器替换状态、内核传感器设置与快照状态、快照时间（UTC）、CPU 与内存、显卡及驱动、磁盘型号与总线、当前显示器分辨率、窗口客户区尺寸、系统与界面缩放、字号、界面语言及刷新间隔。摘要复用已有快照和设置，缺失信息显示为未知；暂停采样时保留原快照时间。摘要按上述字段生成，省略进程列表、命令行、账户、设备序列号、文件路径与网络地址。可粘贴到缺陷报告或读数异常报告的“诊断信息”栏目，并另附问题发生前后的诊断日志。

时间戳包含本地日期、毫秒及 UTC 偏移，时区查询失败时使用 `+00:00`。`argus.log` 超过 1 MiB 时轮换，保留最近三份归档。任务管理器替换启动器另写 `taskmgr.log`。

## 触屏操作

Windows 触摸屏支持点按按钮、选择列表项，以及双击展开或折叠进程树。手指在列表或页面内容上滑动可纵向或横向滚动，快速滑动后继续惯性滚动，再次触摸可停止。

长按进程、表头、设备或图表可打开对应的右键菜单；列表菜单以手指按下时的条目为目标。点按菜单项执行操作，点按菜单外部关闭。滚动条滑块可直接拖动。输入框支持点按定位、长按选择文字，并在前台窗口中请求显示 Windows 触摸键盘。界面大小可在[设置 → 外观](settings.md)中调整。

## 键盘操作

| 操作 | 按键 |
|---|---|
| 切换页面 | Ctrl+1 … Ctrl+9 |
| 搜索进程 | Ctrl+F 或 /；进程页直接键入字母或数字 |
| 运行新任务 | Ctrl+N（输入文字时不生效） |
| 临时暂停刷新 | 进程页、性能页按住 Ctrl，松开后恢复；手动暂停的状态保留 |
| 选择 | ↑ ↓ |
| 折叠 / 展开 | ← →；分组标题上也可按 Enter 或空格 |
| 打开详细信息 | Enter |
| 复制名称 / 详细信息 | 进程、服务、启动与连接页 Ctrl+C / Ctrl+Shift+C；有选中的文字时复制所选文字 |
| 横向滚动列表 | Shift+滚轮（指针位于列表上） |
| 结束进程 | 进程页 Alt+E；列表获得焦点时也可按 Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

分组标题的折叠状态在重启后保留；在进程列表中按 ← 可从顶层的条目移到所属分组的标题。搜索时各组显示全部匹配项，暂不能折叠，清除搜索后恢复原来的折叠状态。列表处于筛选状态时，外框、表头与搜索框以强调色标示，名称列表头的计数前显示漏斗图标（指针悬停时显示说明）；开始筛选时外框以一次光圈提示，随“界面动画”设置。转到某个进程时（例如从服务页或连接页），其所在的分组随之展开。

各分类与用户分组以颜色区分：“应用”为蓝色，“后台进程”为玫红色，“Windows 进程”与“系统”分组为石板灰，其他用户分组依次为青绿、黄绿和蓝紫色。分组标题带同色的浅色底色，分类标题前有同色色块，数量徽标与标题右侧的细线也使用该颜色；用户标题的头像使用该颜色。滚动列表时，当前分组的标题固定在表头下方，显示该组的数量与合计，下一组的标题到达时将其推出；按用户分组时，用户标题与分类标题上下叠放。单击固定的标题同样可折叠该组。列表滚动条外侧以对应颜色的细线标出各组的位置与长度，列表顶部所在的分组颜色较深；滚动时滚动条滑块旁显示当前分组与所在位置（例如“Windows 进程 23 / 56”，按用户分组时为“用户名 · 分类”），停止滚动 1 秒后淡出。

进程页的列表、按钮或空白区域获得焦点时，直接键入字母或数字会将文字追加到搜索框。按 ↓ 回到列表，按 Esc 清除搜索并回到原位置。使用中文输入法时，从第一个按键开始组字，选定文字后才筛选列表；组字期间的 Enter、方向键和 Esc 由输入法处理。

Alt+E 使用与右键菜单相同的确认和权限处理，选中应用组时作用于该组；输入框、弹窗或菜单打开时不触发。完整按键说明见“设置 → 快捷键 → 查看快捷键”。

## 权限

在[设置 → 权限](settings.md#权限)或首次启动引导中可开启“管理员运行”。完成一次授权后，各启动入口遵循相同策略；登录启动保持隐藏，常驻快捷键显示当前管理员实例。该模式默认关闭，与特权服务分别管理。

使用其他管理员账户启动时，设置、历史和日志保存在该管理员账户中，进程视图、列宽等界面偏好单独保存。

以管理员身份启动时，若 Windows 资源管理器已经退出，Argus 会询问是否先恢复桌面。确认后以原桌面账户的普通权限打开资源管理器，再继续启动界面；选择“否”则取消本次启动。

标准权限可读取一般进程的路径和资源用量，受保护进程的部分信息可能缺失。服务可协助执行的操作见[设置 → 权限](settings.md#权限)。进程详情和所有用户启动项的修改使用界面进程自身的权限。状态栏显示“管理员”“特权服务”或“标准权限”。

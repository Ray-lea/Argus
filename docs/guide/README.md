# 界面与操作

本页介绍 Argus 窗口的布局、首次启动的引导、各页面的入口与跨页面的通用操作，并列出键盘与触屏操作、权限与关于页的内容。各页面的详细说明见[本指南的其他页面](#本指南的其他页面)。

## 窗口布局

Argus 的窗口顶部是标题栏，下方是导航栏、当前页面和状态栏。导航栏默认位于标题栏下方，也可以改为位于窗口左侧；进程页可在列表上方显示系统概况带。

### 标题栏

标题栏左侧是 Argus 的图标与名称，中间是当前页面的搜索框，最右端是最小化、最大化与关闭按钮。指针停在最大化按钮上时，Windows 11 显示贴靠布局。

搜索框的宽度约为窗口宽度的 30%，不窄于占位文字，不超过 480 px；空间足够且未输入时，右端显示快捷键 Ctrl+F。两侧空间足够时，搜索框位于窗口正中，否则紧随左侧的名称。

标题栏的空白处可拖动窗口，双击可最大化。最小化按钮左侧的图钉按钮切换**置顶显示**：开启后窗口始终显示在其他窗口之上，图钉以强调色填充，再次单击恢复。该状态在重启后保留。

### 导航栏

导航栏默认以标签形式排列在标题栏下方，标签右侧是页面栏。页面栏空间不足时（例如窗口较窄），标签收为图标，与侧边导航栏收起时相同，指针悬停可看到页面名称与快捷键；空间足够后恢复为文字。两种形态之间以动画过渡。

在**设置 → 语言与外观**或首次启动引导中，可改为侧边导航栏。侧边导航栏位于窗口左侧，**设置**与**关于**位于底部；默认仅显示图标，指针悬停可看到页面名称与快捷键。

单击侧边导航栏顶部的 ☰ 按钮可展开，显示页面名称，再次单击收起。展开后，拖动侧边栏的右边缘可调整宽度（150–320 px），双击右边缘恢复默认宽度。导航栏的位置、展开状态与宽度在重启后保留。

### 页面栏

顶部导航时，页面栏位于标签右侧；侧边导航时，页面栏位于页面顶部，左侧显示页面名称。页面栏依次是当前页面的控件和**更多操作**按钮，各页面的控件如下：

| 页面 | 页面栏的控件 |
| --- | --- |
| 进程 | 视图切换（**按应用**、**进程树**、**列表**，仅显示图标）、**隐藏系统进程**与详细信息面板按钮 |
| 服务 | 针对所选服务的**启动**、**停止**、**重新启动** |
| 连接 | 视图切换（**按应用**、**列表**，仅显示图标）与**隐藏系统进程** |
| 历史 | **实时**或**回到最新** |

**更多操作**在每个页面都位于最右端，其中有**运行新任务**（Ctrl+N）、**查找占用文件的进程**、服务页的**打开 Windows 服务管理器**和**快捷键说明**。

标签（或页面名称）与控件之间的空白同样可拖动窗口、双击最大化。顶部导航的标签收为图标后仍放不下时，页面控件移到下方单独一行，指针悬停仍可看到按钮名称。

### 状态栏

状态栏的左端是版本号，其后是系统读数，右端是刷新控件和权限标记：

- **版本号**：测试构建在版本号后附带提交数，悬停可看到完整版本与更新通道。单击打开本版本的更新内容，右键复制版本号；有新版本时改为更新标记，见[设置 → 更新](settings.md#更新)。
- **系统读数**：线程数、句柄数、缓存、分页缓冲池与系统已运行时间。窗口较窄时，从最后一项起依次隐藏。
- **刷新控件**：左侧显示刷新状态，例如“每 1 秒刷新”“已暂停刷新”，单击可选择刷新频率，再次单击收起。右端的按钮暂停或继续刷新，对所有页面生效，位置不随状态文字变化。
- **权限标记**：显示“管理员”时，Argus 以管理员身份运行；显示“特权服务”时，Argus 以标准权限运行，需要管理员权限的操作由已连接的特权服务执行；显示“标准权限”时两者都不具备。指针悬停可看到说明。

### 概况带

进程页可在列表上方显示概况带，列出 CPU、内存、最忙的磁盘、网络和 GPU。大号数字下方是辅助读数：

| 卡片 | 辅助读数 |
| --- | --- |
| CPU | 频率、温度与功耗 |
| 内存 | 占用比例 |
| 磁盘 | 活动时间 |
| 网络 | 接收与发送速率 |
| GPU | 温度与功耗，取自当前最忙的显卡 |

缺失的读数不显示；卡片较窄时，数字与辅助读数随之缩小字号。曲线铺满卡片，在文字下方渐隐；顶部细线标出量程上限，右上角注明上限数值：使用率为 100%，内存为总容量，磁盘与网络为当前档位。

CPU 温度与功耗的来源可悬停查看；GPU 功耗优先显示瓦数，仅有相对读数时显示“% TDP”。单击卡片转到**性能**页的对应设备。

**设置 → 语言与外观 → 进程概况带**提供**自动**（默认）、**始终显示**和**隐藏**三个选项。自动模式仅按固定的高度预算预留概况带、表头、滚动条与虚拟的 10 行进程，窗口空间不足时收起。

自动模式的计算使用完整的页面高度，与实际进程数量、分组折叠、搜索筛选、滚动位置及概况带当前是否显示无关，以免收起后空间增大又反复展开。

展开和收起以高度过渡带动列表移动，关闭界面动画时直接切换。隐藏期间，Argus 仍继续采集数据和维护曲线历史。

## 首次启动

第一次启动时显示引导，依次完成常用设置。每一步的修改立即保存。任何一步都可单击**跳过**或按 Esc 结束引导，之后可随时在[关于](#关于)页重新打开。

### 引导的步骤

> [!NOTE]
> 在引导中安装特权服务、开启内核传感器与替换系统任务管理器都需要管理员授权；内核传感器与任务管理器替换依赖特权服务。

引导依次包含以下步骤：

1. 选择界面语言。
2. 设置导航栏的位置、界面动画、曲线动画与刷新频率。
3. 设置登录 Windows 时启动、关闭窗口时保留在托盘、最小化与后台常驻时的刷新间隔，以及显示或隐藏窗口的快捷键。
4. 设置自动检查更新、更新通道与下载线路。
5. 可选：开启**管理员运行**。授权后，在完成引导时切换权限。
6. 可选：配置特权服务及其授权范围。可在引导中直接安装，也可跳过，之后在**设置 → 权限**中安装。
7. 可选：开启内核传感器。开启时自动准备 PawnIO 驱动。
8. 选择是否用 Argus 替换系统任务管理器。
9. 查看常用操作的提示。

### 免安装版的提示

免安装版在引导第一步的**界面语言**下方，说明与安装版相比缺少的功能：应用内更新、开始菜单快捷方式与卸载入口，以及特权服务与任务管理器替换随版本自动更新。**前往官网下载**打开官网下载页，**前往 GitHub 下载**打开 GitHub 上的最新版本。

首次启动的引导结束后，右下角再提示一次相同的内容和两个下载入口，约 30 秒后自动收起，指针停留时保持显示。此前已完成引导的账户，在下一次以免安装版启动并显示窗口时提示。

该提示在每个 Windows 账户下仅出现一次：从关于页重新打开引导时不再出现，出现提示的那一次运行不再显示 Star 提醒。由任务管理器替换入口启动的那一次运行不提示，留到之后的正常启动。

安装版与免安装版共用设置和历史数据，改用安装版后无需重新配置。

## 历史

历史页显示 Argus 运行时每 5 秒记录一帧的系统读数，以及当时占用最高的进程。记录默认保存在 `%LOCALAPPDATA%\dev.argus.taskmanager\history`；需要保留旧记录时，先备份该文件夹。记录内容、图表操作、保留策略与文件格式见[历史](history.md)。

## 运行新任务

**运行新任务**位于页面栏最右端的**更多操作**菜单中，可在任意页面使用，也可按 Ctrl+N 打开。在对话框中输入程序名称、文件或文件夹路径，也可附加启动参数；单击**浏览**可选择文件。

勾选**以管理员身份运行**时，由 Windows 处理授权。未勾选时以普通权限启动，即使 Argus 本身以管理员身份运行。取消授权或启动失败后保留输入，可修改后重试。

## 重新启动资源管理器

> [!WARNING]
> 确认没有正在进行的文件操作后再重新启动：重新启动可能影响资源管理器窗口及正在进行的文件操作。

在进程页右键当前桌面的 Windows 资源管理器，选择**重新启动**并确认，可恢复桌面和任务栏。

该操作支持普通权限和高权限的资源管理器，重启后保持原账户与权限；重启高权限实例时，Argus 需以管理员权限运行。它仅作用于承载当前桌面的实例：该实例提供**重新启动**操作，**结束**和**结束进程树**均禁用。

重启前，Argus 检查权限并准备替代进程。旧资源管理器在退出清理或错误报告阶段卡住时，Argus 在超时后结束已确认的旧实例，确认其退出后再恢复桌面；Windows 已恢复桌面时，使用现有的实例。桌面和任务栏均能够响应后，才提示重启完成。

资源管理器已经退出时，可在**运行新任务**中输入 `explorer.exe` 重新打开。

## 文件占用

在**更多操作**菜单中选择**查找占用文件的进程**，或直接把文件、文件夹拖到窗口上，即可查询占用。对话框打开后，可继续把文件或文件夹拖入对话框，以更新查询目标。管理员窗口也支持从普通权限的文件管理器拖入文件。

### 查询的来源

结果合并两种来源：Restart Manager 查找文件引用和已加载的模块；句柄扫描补充打开的文件、目录及后代，包括把所选文件夹当作当前目录的命令行进程。文件 ID 可识别通过硬链接打开同一文件的情况。

有可用且已授权的特权服务时，句柄查询交给服务；否则以当前账户的权限查询，普通权限也能发现许多自有进程。

### 查询结果

每个结果显示匹配路径和句柄数量，重复来源按 PID 与启动时间合并。结果还会列出无法访问的进程、跳过的句柄和超时情况。

“未发现”表示本次查询范围内没有匹配。查询卡住时保留已找到的结果；达到时间或数量上限时，返回部分结果。允许共享删除的句柄也可能列出。

句柄扫描使用本地磁盘的绝对路径。符号链接、目录联接、网络驱动器与 SUBST 路径保留 Restart Manager 的查询结果，指定实际目标可补查句柄。受保护进程和已关闭句柄的映射可能漏检，见[已知问题](../known-issues.md)。

### 释放占用

占用进程是当前桌面的资源管理器时，操作按钮显示**重新启动**；确认后恢复桌面与任务栏，再重新检查文件占用。其他进程仍可通过**结束**释放占用。

**结束**仍会确认，并核对同一进程实例，避免 PID 复用后结束其他进程。

## 导出当前页为 CSV

进程、服务、启动与连接页可把当前列表导出为 CSV 文件：

1. 单击右上角的**更多操作**（…）。
2. 选择**导出当前页为 CSV**。
3. 选择保存位置。保存时可修改文件名。

文件保留单击导出时的筛选、排序、列顺序、显示单位和分组展开状态，包含滚动区域外的行。筛选结果为空时，文件仅含表头。

默认文件名包含页名、导出时的本地日期和时间，以及表头以外的行数；进程页还包含视图名称，例如 `Argus-进程-列表-2026-11-21_13-35-42-128行.csv`。

CSV 使用带 BOM 的 UTF-8 编码，可在 Excel 中打开。名称、描述或命令行等文本以公式符号开头时，会添加前导单引号，使电子表格按文本读取。

## 备注与置顶

服务、启动和连接页可为条目添加备注或将其置顶：右键条目，选择**置顶**、**取消置顶**，或**添加备注**、**编辑备注**、**删除备注**。

备注显示在名称之后，以带图标的浅色标签与名称区分。名称始终完整显示，空间不足时备注先收窄，指针悬停可看到全文。搜索框同时匹配备注。

置顶的条目排在列表最前，名称列末端显示图钉，下方以分隔线与其余条目隔开；置顶条目之间按当前排序排列。

备注与置顶随界面偏好保存在本机，重启后保留。各页按以下方式记住条目：

- **服务**：按服务名称。
- **启动项**：按所在位置与项目名称。
- **连接**：按程序与端口。监听端口、UDP 端口及经监听端口接受的连接按本地端口，程序主动发起的连接按远程地址和端口。

同一程序在同一端口上的多个连接共用备注与置顶，程序重启、PID 变化后仍然有效。

## 暂停刷新

暂停刷新只冻结界面上的数据，历史记录和规则照常进行，这期间每 5 秒采样一次。暂停与继续刷新的按钮位于[状态栏](#状态栏)右端。

在进程页或性能页按住 Ctrl，可临时暂停刷新，曲线保持暂停瞬间的位置。松开 Ctrl、切换到其他窗口或隐藏窗口后，临时暂停解除。

手动暂停的状态保留。按住 Ctrl 时单击状态栏的暂停按钮，可选择在松开后保持暂停或继续刷新。

## 键盘操作

常用的按键如下：

| 操作 | 按键 |
| --- | --- |
| 切换页面 | Ctrl+1 … Ctrl+9 |
| 下一个 / 上一个页面 | Ctrl+Tab / Ctrl+Shift+Tab（到末尾后从另一端继续） |
| 搜索进程 | Ctrl+F 或 /；进程页直接键入字母或数字，见[搜索与筛选](processes.md#搜索与筛选) |
| 运行新任务 | Ctrl+N（输入文字时不生效） |
| 临时暂停刷新 | 进程页、性能页按住 Ctrl，松开后恢复，见[暂停刷新](#暂停刷新) |
| 选择 | ↑ ↓ |
| 折叠 / 展开 | ← →；分组标题上也可按 Enter 或空格 |
| 打开详细信息 | Enter |
| 复制名称 / 详细信息 | 进程、服务、启动与连接页 Ctrl+C / Ctrl+Shift+C；有选中的文字时复制所选文字 |
| 横向滚动列表 | Shift+滚轮（指针位于列表上） |
| 结束进程 | 进程页 Alt+E；列表获得焦点时也可按 Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc，可在设置中更改 |

Alt+E 使用与右键菜单相同的确认和权限处理，选中应用组时作用于该组；输入框、弹窗或菜单打开时不触发。完整的按键说明见**设置 → 快捷键 → 查看快捷键**。

## 触屏操作

Windows 触摸屏支持点按按钮、选择列表项，以及双击展开或折叠进程树。手指在列表或页面内容上滑动可纵向或横向滚动，快速滑动后继续惯性滚动，再次触摸可停止。

长按进程、表头、设备或图表，可打开对应的右键菜单；列表菜单以手指按下时的条目为目标。点按菜单项执行操作，点按菜单外部关闭菜单。滚动条滑块可直接拖动。

输入框支持点按定位、长按选择文字，并在前台窗口中请求显示 Windows 触摸键盘。界面大小可在**设置 → 语言与外观**中调整，见[设置](settings.md)。

## 权限

在[设置 → 权限](settings.md#权限)或首次启动引导中可开启**管理员运行**。完成一次授权后，各启动入口遵循相同的策略：登录启动保持隐藏，常驻快捷键显示当前的管理员实例。该模式默认关闭，与特权服务分别管理。

使用其他管理员账户启动时，设置、历史和日志保存在该管理员账户中，进程视图、列宽等界面偏好单独保存。

以管理员身份启动时，若 Windows 资源管理器已经退出，Argus 会询问是否先恢复桌面。确认后，Argus 以原桌面账户的普通权限打开资源管理器，再继续启动界面；选择**否**则取消本次启动。

标准权限可读取一般进程的路径和资源用量，受保护进程的部分信息可能缺失。特权服务可协助执行的操作见[设置 → 权限](settings.md#权限)。进程详情、内存转储、调试和所有用户启动项的修改，使用界面进程自身的权限。当前的权限见[状态栏](#状态栏)的权限标记。

## 关于

关于页位于导航栏中**设置**之后，显示版本、当前权限和许可证，提供更新内容、退出及重新打开首次引导的入口。

### 点阵图

打开关于页或引导第一步时，10 × 10 的点阵先拼出字母 A，再变为最近 10 次 CPU 占用的点阵图。每列对应一次采样，按当时的占用由下往上点亮，最上方的点最亮，最右一列为最新一次；占用达到 80% 的列为琥珀色。

每次采样时各列左移一格，点的位置不变。关闭**界面动画**时直接显示点阵图。

### 版本与链接

版本号与发行版相同。从未发布的提交构建的测试版本，在版本号后附加提交数与提交的短哈希，例如 `0.3.4+583.g4c638d7`，便于确认所用的构建。

版本信息下方的两张卡片分别链接 [Argus 官网](https://argustask.com/) 和 [GitHub 仓库](https://github.com/Ray-lea/Argus)。单击卡片打开对应的首页，卡片底部的按钮直接打开常用页面：

- **官网**：**下载**、**使用指南**、**更新日志**。下载与更新日志页按界面语言打开，使用指南仅有中文版。
- **GitHub**：**问题反馈**（选择问题类型的页面）、**讨论区**和**发行版**。

**交流与反馈**可打开 QQ 群邀请或复制群号 `453803497`；**Telegram 频道**可打开频道页面或复制频道链接 [t.me/argustask](https://t.me/argustask)。**第三方组件**列出开源组件及许可证。

### 日志

单击**打开日志文件夹**可查看 `%LOCALAPPDATA%\dev.argus.taskmanager\logs\diagnostics`。`argus.log` 记录系统版本、渲染器、传感器和特权功能状态，以及运行程序的 SHA-256，可用来区分同版本号的不同构建。失败记录包含具体步骤、系统错误码及相关路径。

日志仅保存在本机，不记录命令行、凭据或文件内容。时间戳包含本地日期、毫秒及 UTC 偏移，时区查询失败时使用 `+00:00`。

`argus.log` 超过 1 MiB 后，在写入下一条记录前另存为旧日志，最多保留 3 份旧日志。任务管理器替换启动器另写 `taskmgr.log`。

> [!WARNING]
> 公开提交日志前，检查其中的路径是否含有用户目录名称。

### 诊断信息

单击**复制诊断信息**，可把摘要复制为适合粘贴到 Issue 的文本。摘要包含以下内容：

- Argus 完整版本、Windows 版本、构建与安装类型
- 当前权限、已读取的特权服务及任务管理器替换状态、内核传感器设置与快照状态、快照时间（UTC）
- CPU 与内存、显卡及驱动、磁盘型号与总线
- 当前显示器分辨率、窗口客户区尺寸、系统与界面缩放、字号、界面语言及刷新间隔

摘要复用已有的快照和设置，缺失信息显示为未知；暂停采样时保留原快照时间。摘要按上述字段生成，省略进程列表、命令行、账户、设备序列号、文件路径与网络地址。

可把摘要粘贴到缺陷报告或读数异常报告的**诊断信息**栏目，并另附问题发生前后的诊断日志。

# 设置

本页介绍设置页的布局与通用行为。各分组的设置项、取值、默认值与作用分别在子页面中说明，**权限**分组中的内核传感器与系统任务管理器替换也各有一页。

设置页左侧列出各分组的完整名称，宽度随界面语言和字号调整。列表跟随滚动标出当前位置，单击分组可直接跳转。窗口较宽时，设置内容随窗口适当加宽，最宽 960 px，其余空间留在两侧；窗口较窄时，设置内容占满可用宽度。

进程、服务、启动项和连接列表分别记住排序列及方向；视图、常用筛选、导航栏、刷新间隔等偏好也随配置保存。

## 内核传感器

**权限**分组的**内核传感器**开关默认关闭，仅在 x64 系统上提供；手动开启时，Argus 按需下载并安装 PawnIO 驱动，用于读取处理器、主板与部分核显的内部传感器。开启前的准备、PawnIO 的安装与升级、故障处理与关闭方法见[内核传感器](settings/kernel-sensors.md)。

## 更新

Argus 从 GitHub Releases 获取新版本，也可经官方镜像或加速代理下载，仅安装签名与版本号校验通过的软件包。自动检查、通知、更新通道与下载线路等设置项见[更新](settings/updates.md)，代理的隐私提示与签名校验见[加速代理与签名校验](settings/updates.md#加速代理与签名校验)。

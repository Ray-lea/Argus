# 设置

设置页左侧列出各分组的完整名称，宽度随界面语言和字号调整。列表跟随滚动标出当前位置，单击分组可直接跳转。窗口较窄时，设置内容占满可用宽度。

## 语言与外观

“界面缩放”可在 80%–150% 范围内调整文字、图标和控件的整体大小，默认 100%；“字体大小”可将基础字号设为 11–20 px，默认 13 px，标题和辅助文字按比例变化。两项独立设置，可组合使用，立即生效并自动保存，也可分别恢复默认值。可输入数值后按 Enter，或按 ↑ / ↓ 键逐步调整；指针悬停时输入框右侧显示上下箭头，单击步进一次，按住可连续调整，松开后生效。

进程、服务、启动项和连接列表分别记住排序列及方向；视图、常用筛选、导航栏、刷新间隔等偏好也随配置保存。

界面支持简体中文、繁体中文、英文、西班牙文、德文、日文、法文和俄文，默认“跟随系统”。优先采用 Windows 显示语言，再按用户首选语言列表选择已支持的语言，最后使用英文。同一语言的地区变体共用译文，例如墨西哥西班牙文、加拿大法文。中文显示语言按脚本和地区选择：繁体脚本或中国台湾、中国香港、中国澳门地区使用繁体中文，简体脚本或其他中文地区使用简体中文；显式脚本优先于地区。切换后立即生效，托盘菜单、窗口标题和错误提示也随之切换；选项始终显示各语言的原生名称。

特权服务和提权维护助手使用 Windows 显示语言。安装程序和卸载程序也提供上述八种语言。Windows 文件选择框、管理员授权框，以及其他应用提供的进程名称、服务描述，保持各自的来源语言。

数字与完整日期采用 Windows 区域格式，时区采用系统设置，独立于界面语言。运行中修改数字区域格式后，重新启动 Argus 生效。字号和缩放输入支持区域小数符、点号和全角数字；输入时保留输入法组字，确认后检查数值。历史曲线的紧凑日期标签随界面语言显示，时间轴使用 24 小时制。跨夏令时切换时，刻度按各时刻的本地时间排列；选中或悬停时显示 UTC 偏移，可区分回拨时重复出现的时刻。

“主题”默认跟随 Windows“个性化 → 颜色”中的应用模式。手动选择“浅色”或“深色”会固定窗口内容、标题栏与背景的主题。托盘菜单、系统对话框和安装程序使用 Windows 主题。

“导航栏位置”可选“顶部”（默认）或“侧边”。顶部导航栏以标签形式排列在工具栏下方，切换页面时新页面从右侧或左侧（取决于标签的先后）滑入；侧边导航栏位于窗口左侧，新页面从下方或上方滑入，默认仅显示图标，可通过左上角的 ☰ 按钮展开显示页面名称，展开后可拖动右边缘调整宽度，双击恢复默认。首次启动引导中也可选择，设置保存在本机，重启后保留。

Windows 11 22H2 及以上默认保留云母背景；Windows 11 21H2 和 Windows 10 自动使用实色背景。如曲线在实体屏上的亮度与截图有差异，可从托盘退出 Argus，再使用 `argus.exe --opaque-window` 启动。此模式使用实色窗口背景，保留曲线配色和动画设置。

“语言与外观”末尾的“系统进程隐藏规则”可编辑进程页与连接页共用的始终显示、额外隐藏名单。两页工具栏各自提供图标开关，默认关闭。规则的匹配与连接归属说明见[界面与操作](README.md#页面)。

同一区域的“按用户分组进程”可选择自动（默认）、始终分组或不分组。自动模式仅在多个用户同时登录时分组，含已断开连接但未注销的会话；只有一个用户登录时列表保持不分组。分组的归属与组内行为见[界面与操作](README.md#页面)。

同一区域的“进程概况带”可选择自动、始终显示或隐藏。自动模式预留概况带和虚拟 10 行进程的固定高度预算，仅在窗口空间不足时收起；实际行数与折叠、筛选状态不影响判定。切换遵循界面动画设置。

## 启动与后台

窗口会记住普通状态下的位置、大小和最大化状态。最小化后退出，下次启动恢复原窗口；以托盘模式启动时保持隐藏。原显示器断开后，Windows 会将窗口移到可用屏幕。

| 设置 | 说明 |
|---|---|
| 登录 Windows 时启动 | 登录后以 `--hidden` 启动，在托盘中运行。单击托盘图标或按全局快捷键可打开窗口。从任务管理器替换入口启用此项时，Argus 会定位已安装的程序；若提示未找到，请从安装位置启动后再启用。 |
| 默认页面 | 启动 Argus 后首次显示窗口时打开的页面，可选进程（默认）、性能、服务、启动、连接或历史，与上次退出时停留的页面无关。在托盘中静默启动或由任务管理器替换启动时，首次显示窗口即打开所选页面。应用内更新完成后自动重新启动时，仍回到更新前的页面。 |
| 从托盘打开 | 默认“保留当前页面”，可改为“打开默认页面”。窗口隐藏到托盘后，通过快捷键、托盘图标、托盘菜单或再次启动 Argus 重新打开时生效；最小化恢复与已显示窗口的激活保留当前页面。有未关闭的对话框时保留原页面，便于继续操作。页面内的筛选和排序继续保留。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时按“后台常驻时的刷新间隔”（默认 5 秒）采样，历史记录和规则照常进行。关闭这一项后，关闭窗口即退出 Argus。 |

托盘图标在同一程序路径下沿用稳定标识，Windows 可按同一图标保留任务栏或折叠区的显示位置。首次从旧版标识迁移时，可能需要重新将图标拖出折叠区一次。

## 快捷键

“快捷键说明”中的“查看快捷键”打开完整按键说明，包含当前配置的全局快捷键、页面切换、临时暂停、进程操作与历史曲线操作。展开“列表获得焦点时”等分组时弹窗向下伸展，上边缘保持不动，超出窗口可容纳的高度后在弹窗内滚动。弹窗可按 Esc 关闭，关闭后焦点回到打开按钮。

显示或隐藏 Argus 的全局快捷键，默认 Ctrl+Alt+Esc，在大多数程序中都能使用。

- 右侧的开关可停用快捷键，停用时保留当前组合，重新开启即恢复。
- 单击“更改”，按住修饰键，按下并松开主键即可保存并启用。录制区显示当前组合。按 Esc 或单击“取消”结束录制，单独按 Backspace 停用快捷键。“恢复默认”可改回 Ctrl+Alt+Esc。切换或隐藏窗口、连续 15 秒无输入时，录制结束并保留原设置。
- 组合已被其他程序占用时，卡片下方显示原因和“重试”按钮；占用的程序退出后，再次显示 Argus 窗口时也会自动重试。
- 组合须包含 Ctrl、Alt 或 Win 之一和一个普通键；F13–F24 可以单独使用，Shift+F1–F9 和 Shift+F11 需确认后才保存。这是 Windows 全局快捷键的规则：修饰键不区分左右（左 Ctrl 与右 Ctrl 等效）；仅由修饰键组成的组合（如左 Ctrl+右 Ctrl+左 Alt）不能使用；只能有一个普通键，两个普通键（如小键盘的 + 和 -）不能组合；须先按住修饰键，再按普通键。
- 修饰键按 Ctrl、Alt、Shift、Win 匹配，左右两侧视为同一个键。CapsLock、NumLock 和 ScrollLock 属于锁定键。
- 系统保留组合和 Ctrl+C、Ctrl+V 等常用编辑键会在录制时提示冲突。Ctrl+Shift+Esc 的设置入口在“权限 → 替换系统任务管理器”。带 Ctrl 的 Pause 会被 Windows 识别为 Break，请选择其他主键。
- 主键和可打印键名按当前 Windows 键盘布局映射，支持西里尔字母及 AZERTY、QWERTZ、日文布局中的符号键；更换界面语言保持已保存的组合。AltGr 字符输入与 Ctrl+Alt 组合可能共享 Windows 映射，可选择 Ctrl+Shift 等组合减少冲突。部分常用组合会在保存前要求确认。

背后的实测与取舍见[全局快捷键](../design/hotkey.md)。

## 权限

“管理员运行”适用于发布构建。

“管理员运行”默认关闭。开启“允许以管理员身份运行”并完成一次 Windows 授权后，登录启动、普通快捷方式、固定图标、Ctrl+Shift+Esc 和任务栏“任务管理器”入口均遵循管理员运行策略；后两个入口须先启用系统任务管理器替换。常驻快捷键显示当前管理员实例，不提供未运行时的全局启动功能。

卡片分别显示授权状态和当前进程权限。切换权限会重启 Argus 并保留设置和历史；首次启动引导在完成或跳过后切换。撤销授权会保留登录启动偏好。对于关闭 UAC 的管理员账户，进程使用该账户的默认权限。

此模式要求当前 Windows 账户属于管理员组。标准账户可通过特权服务执行下列操作。管理员启动授权失效时，Argus 以普通权限打开，并在此处提供修复入口。

安装后修改 Program Files 或 Argus 运行目录的所有者、写入权限，可能使管理员启动或特权服务失效。此时仍可撤销管理员启动授权、恢复 Windows 任务管理器或卸载服务。撤销后若普通权限窗口启动失败，当前窗口会保留并提示退出后重新打开。重新启用相关能力前，需由管理员恢复相应目录的安全权限；Argus 不自动修改系统目录权限。

特权服务需手动安装。单击“安装并启用”，阅读授权范围并完成 Windows 管理员确认后，后台服务可执行以下操作。

- 结束进程或进程树（仍拦截系统关键进程）。
- 设置进程优先级、开启或关闭效率模式、暂停或恢复进程。
- 自动规则中的优先级与效率模式操作。
- 每进程网络流量采集（本地采集不可用时）。
- 每进程磁盘读写采集（系统未通过普通进程查询提供计数时）。
- 磁盘详情中的 ATA／SATA、USB-SAT 和 SCSI／SAS 身份与 SMART 健康信息只读查询。
- 按句柄查文件及目录占用（包括进程当前目录）。
- 启动、停止、重启 Windows 服务，以及修改启动类型。
- 断开 IPv4 TCP 连接。

授权范围是整台电脑。当前账户下的普通桌面程序都可调用服务执行上述操作，包括管理其他用户的进程、修改 Windows 服务、查询进程句柄和资源计数。系统关键进程另有保护，服务拒绝受限令牌和 AppContainer 调用。请只为受信任的账户安装。

服务随 Windows 启动，一次安装只授权一个账户；另一个账户需先经管理员授权卸载，再安装。

服务停止时可单击“启动服务”。协议版本不兼容时，单击“更新服务”替换受保护目录中的服务程序。连接恢复前，手动操作和规则按 Argus 自身权限执行，依赖服务的读数暂缺。命令在执行中断线或超时时，先刷新对应页面确认结果，再决定是否重试。

单击“卸载”会移除服务，Argus 继续以当前进程权限运行。从 Windows“设置 → 应用”卸载 Argus 时，可选择一并卸载或保留服务。免安装程序与服务副本各自独立；删除免安装程序前，可在这里卸载已安装的服务。

**免安装版的风险**：安装或更新特权服务、启用任务管理器替换、安装或启动 PawnIO 时，Argus 会以管理员身份运行自身；安装特权服务还会把自身复制为以 SYSTEM 身份运行的服务程序。安装版位于 Program Files，只有管理员能修改；免安装版则可以放在任意位置，如果它所在的文件夹允许标准用户写入（例如“下载”文件夹或桌面），本机已有的恶意程序就可能在这之前替换 `argus.exe`，借用户的管理员授权获得 SYSTEM 权限。需要特权服务时建议使用安装版；使用免安装版时，请把它放在只有管理员能写入的文件夹中。

详细信息、启动项修改，以及文件占用查询中的 Restart Manager 部分仍使用 Argus 本身的权限。句柄查询可使用服务；服务不可用时以当前账户权限降级查询。服务已连接时，状态栏右下角的权限标记显示“特权服务”（界面进程本身仍以标准权限运行），服务停止或断开后约半分钟内恢复为“标准权限”；受保护的系统进程可能拒绝特权服务的操作。

网络流量会在后台异步读取，通常比本地采样晚一个刷新周期；服务断线或采集不可用时隐藏网络列，恢复后先建立计数基线，避免把积累的字节显示成瞬时峰值。没有客户端读取 15 秒后，服务会关闭 ETW 会话；再次读取时重新启动。

## 内核传感器

首次启动引导在配置特权服务后提供“内核传感器”步骤。可单击“配置特权服务”返回上一步，或单击“下一步”跳过。引导和设置页共享进度与错误信息，引导可从[关于](README.md#关于)页重新打开。

“权限”分组提供“内核传感器”开关，默认关闭。先安装或更新并启动 Argus 特权服务，再开启开关。Argus 自动检查 PawnIO：缺少或版本低于 2.2.0 时下载并安装官方版本，已安装且符合要求时启动驱动，已经运行的较新版本直接复用。安装或启动需要管理员授权，界面本身保持原有权限。

官方 2.0 旧版使用不同的安装方式：Argus 识别已知的官方签名驱动文件，确认默认安装位置与卸载信息后，先校验新旧安装包，再通过旧版官方卸载程序移除旧版、安装新版。升级前应退出使用 PawnIO 的其他硬件监控程序；旧服务未移除或安装程序要求重启时，重启 Windows 后再次开启。安装信息不一致时停止自动迁移，可通过 Windows 的应用管理卸载旧版，再从 PawnIO 官网安装新版。

准备期间可切换页面查看进度。仅在手动开启时请求安装或管理员授权。Argus 核验官方安装包的 SHA-256 与 Windows 签名，取消、校验失败或驱动被系统策略阻止时显示原因并保持关闭。若安装程序要求重启，请重启 Windows 后再次开启。也可从“PawnIO 官网”进入手动安装。

PawnIO 设备在 Windows 中被禁用时，须先在设备管理器启用后重试；设备配置标记为待重启时，须先重启。Argus 同时核对服务与设备状态，全部检查通过后才保存开启状态。

PawnIO 已正常运行且版本符合要求时，Argus 核验设备后直接复用。标准权限下由已更新的特权服务提供设备版本；此时驱动存储目录的写入权限不影响开启。安装、升级或启动驱动仍要求文件及父目录权限安全，出现相关提示时须由管理员检查对应目录。Argus 保持系统目录权限原样。

性能页的 CPU 视图在“内部传感器”卡片中按功耗、电压、频率、温度分组显示读数，在“每核读数”卡片中提供每个物理核心的温度、有效频率、功耗、VID 与活跃比例。Ryzen 7000/9000 的 SVI3 供电电压与 VID 分开标注；Intel 提供 PL1／PL2、温度余量、Ring 频率与限制状态；当前状态与硬件历史记录分开显示。Windows 空闲状态与 AMD SMU 驻留比例分别标注。支持的主板还显示风扇通道转速，以及已匹配的电源轨、主板与供电温度。支持的硬件范围见[硬件数据](hardware-data.md#消费级硬件兼容范围)。

关闭开关后停止请求内核读数，Windows 自带采集继续工作；服务在 15 秒无读取后释放模块。关闭开关或卸载 Argus 不卸载共享的 PawnIO 驱动，可通过 Windows 的应用管理单独卸载。

Comet Lake S/H 核显的温度、频率、VID、GT／媒体活动率及限制状态同样由此开关控制，读数显示在对应 GPU 页面，VID 表示请求电压。核心频率与共享逻辑频率直接显示数值，包括有效的 0 MHz；最低／最高工作频率是能力范围，另行列出。共享内存频率由控制器配置按标称参考换算，DDR 传输率约为其两倍。GPU 页面显示内核传感器状态，未启用或读取失败时提供说明。核显 RAPL 功耗优先使用服务直接读取的有效 PP1 能量差分，缺失时回退 Windows 计数器，不在 CPU 页面重复显示。安装新版应用时会刷新已安装的特权服务，未安装服务的系统仍需先完成安装。

## 替换系统任务管理器

“权限”分组的“替换系统任务管理器”卡片显示系统任务管理器替换的状态，首次启动引导中也可直接开启。功能默认关闭，发布版在安装特权服务并授权给当前账户后才提供“启用替换”。它影响整台电脑上 taskmgr.exe 的启动入口，包括 Ctrl+Shift+Esc；授权账户打开 Argus，其他账户仍尝试打开 Windows 任务管理器。已有其他替换或路径过滤配置时拒绝开启，不自动覆盖；卡片显示“已有其他配置”，并写明 taskmgr.exe 的 IFEO 键中发现了什么：与当前 Argus 配置不一致的 Debugger 值、UseFilter 值，或 `PerfOptions` 之类的子项。按卡片所列内容核对配置来源，通过对应程序恢复后，再单击“刷新状态”。

开启时须确认管理员授权。Argus 检查启动器、调试脱离和界面就绪状态，通过后保存恢复记录并修改 `taskmgr.exe` 配置。Argus 无响应时，独立启动器尝试打开 Windows 任务管理器。

单击“临时打开系统任务管理器”可打开 Windows 自带的任务管理器，当前替换设置保持不变。此按钮在替换未启用或特权服务未安装时也可使用；启动失败时，卡片内显示原因。

若提示注册表权限检查通过但操作仍被拒绝，可检查 360 等安全软件的注册表或系统防护记录。找到与本次 Argus 任务管理器替换对应的拦截记录后，可允许本次修改并重试；没有对应记录时，可提供包含失败 API 与错误码的 Argus 诊断日志，以便继续排查。Argus 不自动添加安全软件信任规则、不关闭防护或强制改写注册表权限。持续误报可通过 [360 软件开放平台](https://open.soft.360.cn/guide/guide_1.php?i=3)申诉，提交与被拦截文件一致的版本。

“恢复 Windows 任务管理器”优先通过特权服务还原，服务不可用时请求管理员授权。界面无法运行时，使用卡片底部给出的路径中的 `argus-taskmgr-recover.exe`；它不依赖 Argus 界面或后台服务。独立恢复程序也损坏时，参照其同目录的 `taskmgr-recovery.txt`，核对归属后只还原 Debugger 值，不删除整个键。

卸载特权服务会先关闭替换，单击“卸载”时的确认框中会说明。更新特权服务时替换保持开启，替换所用的界面和启动器随之更新到新版本；通过安装程序升级 Argus 时同样如此。免安装版直接替换程序文件，或安装程序未能完成更新时（例如当时启动器正在运行），按 Ctrl+Shift+Esc 打开的仍是旧版本，卡片中会写明其版本号，在特权服务中单击“更新服务”即改为打开当前版本。升级时由替换打开的旧版 Argus 仍在运行（例如常驻托盘）的，此后打开 Argus 显示的仍是它，从托盘退出后才是新版本，因此升级前宜先退出它。替换已恢复后，其他工具写入的任务管理器替换不影响更新或卸载服务。卸载 Argus 前也必须通过恢复检查；覆盖升级保留任务管理器替换配置。恢复失败会保留文件并阻止相关卸载，其他工具的配置保持原样。详细过程见[系统任务管理器替换](../architecture/task-manager.md)。

## 动画

| 设置 | 说明 |
|---|---|
| 窗口过渡动画 | 控制 Argus 窗口显示、隐藏、最小化与还原时的淡入淡出。关闭后由 Windows 或其他窗口管理软件处理窗口过渡；默认跟随 Windows 的“动画效果”设置。 |
| 界面动画 | 控制页面与对话框过渡、选中标记滑动，以及图标的动效：指针移到按钮、导航项或设置分组上时，其图标播放一次短动效（如齿轮转动、下载箭头下移）；按钮换用另一图标时（如暂停与继续），新图标弹入。默认跟随 Windows 的“动画效果”设置。 |
| 曲线动画 | 流畅、均衡、省电、关闭四档。默认流畅；Windows 关闭了动画效果时默认关闭。图表上限变化时的过渡与上限标签的淡入也随此设置，关闭时直接切换。各档的区别与开销见[曲线动画](../design/charts.md)。 |

三项设置互相独立，修改后立即生效并保存。使用其他软件管理窗口动画时，可关闭“窗口过渡动画”，保留界面与曲线动画。升级时，新的窗口开关继承此前的界面动画状态，此后分别保存。

## 数据与历史

| 设置 | 说明 |
|---|---|
| 刷新频率 | 每 0.5、1（默认）、2 或 5 秒采样一次。间隔越短，读数更新越频繁，采样开销也越高。工具栏可切换间隔或暂停界面刷新。暂停期间历史与规则每 5 秒采样一次。 |
| 最小化时的刷新间隔 | 窗口最小化后的采样间隔：每 0.5、1、2、5（默认）、10 或 30 秒。窗口最小化时界面停止绘制，只保留采样。间隔越长后台开销越低，但规则对新启动程序的生效最多延后一个间隔；长于 5 秒时，历史记录也随之变稀。 |
| 后台常驻时的刷新间隔 | 隐藏到托盘（包括开机启动后未打开窗口）时的采样间隔，选项与默认值同上，托盘的悬停提示按此间隔更新。 |
| 隐藏时释放内存 | 窗口最小化或隐藏到托盘达到 1、10（默认）或 30 分钟后，释放图表图像，并将未使用的内存归还 Windows；选“从不”则一直保留。采样、历史记录和规则照常运行。再次显示窗口时先重绘图表，可能稍有停顿。 |
| 网络速率单位 | 字节每秒（MB/s，默认，与磁盘一致）或比特每秒（Mbps，与网卡的链路速度、宽带套餐一致），整个应用统一切换。性能页的网络视图总是同时显示两种。 |
| 记录历史 | 默认开启，每 5 秒记录资源占用和当时最忙的进程。后台采样间隔长于 5 秒时按该间隔记录。数据在本机保留 7 天，关闭记录后已有数据按原保留期清理。见[历史页](README.md#历史)。 |
| 已保存的历史 | 显示历史记录占用的空间和最早的一条记录；“清除”会在确认后删除全部历史记录。 |

两项后台刷新间隔改为短于 5 秒时，先弹出确认：说明 Argus 将以该间隔在后台采样全部进程与硬件数据，CPU 占用与耗电随之增加，使用电池时更为明显。取消则保持原来的间隔。首次启动引导的“常驻后台”一步也提供这两项，规则相同。

窗口从最小化或托盘回到前台时，如果这段时间的刷新间隔比前台的“刷新频率”长，右下角会提示一次刷新间隔的变化，例如“最小化期间，刷新间隔由 1 秒放宽至 5 秒”。提示中的“调整间隔”打开本页并定位到对应的设置项；“不再提醒”只关闭这一种提示，最小化与后台常驻的提示分别设置。窗口只离开片刻、还不到一个前台刷新周期时不提示；回到前台时正显示首次启动引导、更新对话框或确认框，或是更新后首次显示窗口（此时显示新版本的更新内容）时，这一次也不提示。

## 规则

程序启动时自动设置优先级或效率模式。在分组顶部输入程序名（例如 `chrome.exe`）并单击“添加”即可新建规则。每条规则包括：

- **程序名**：不区分大小写；同名的多个进程都会套用。程序正在运行时，规则前面显示它的图标。
- **优先级**：不改变，或实时、高、高于正常、正常、低于正常、低之一。
- **效率模式**：不改变、开启或关闭。
- **启用开关**决定是否应用该规则。停用时保存规则配置。

规则保存后先应用于匹配的现有进程，之后在程序启动时再次应用。后台线程处理规则，即使 Argus 隐藏在托盘也会执行。慢请求期间保留最新进程列表。

每条规则下方显示已应用、权限不足和执行失败的进程数；保存规则或权限来源改变时重新计数。安装、停止或重启特权服务后，已有进程会重新检查。请求发出后丢失回复时不自动重复操作，可检查服务状态后重新保存规则来重试。

在进程列表中右键选择“添加规则”，可按该进程的优先级和效率模式创建规则。规则按可执行文件名匹配。多个应用共用同一宿主程序，或不同安装路径存在同名程序时，会提示本条规则的作用范围。

## 更新

当前版本后的类型来自实际程序：开发版独立标识，本地测试构建和预发布版本显示为测试版，正式发行显示为稳定版。更新通道决定后续检查的版本来源，切换通道会保留当前程序的版本类型。

Argus 从 GitHub Releases 获取新版本。自动线路支持 `update.argustask.com` 上的官方清单和 `dl.argustask.com` 上的版本化安装包。发现新版本后在后台下载，下载完成并通过签名校验后：

- 标题栏右侧、窗口按钮左边显示一个强调色的圆形更新按钮，各页面均可见，指针悬停时显示新版本号。右键单击该按钮可选择“此版本不再提醒”，之后仅在导航栏的“设置”和设置页的“更新”分组上显示提示点。
- 窗口处于显示状态时，右下角提示一次“Argus x.y.z 已准备就绪”；窗口隐藏在托盘时，在下次显示窗口时提示；首次启动引导打开时，在引导结束后提示。每个版本仅提示一次，启动时不弹出对话框。
- 托盘图标右下角显示强调色圆点，悬停提示增加“新版本 x.y.z 已就绪”，托盘菜单增加“更新到 x.y.z…”。

发现新版本后，“更新”分组的状态卡片显示“查看更新内容”按钮。单击该按钮、标题栏更新按钮或托盘菜单项，可打开更新对话框，阅读当前版本与新版本的差异，查看安装包大小、签名校验结果并安装；首次启动引导打开时，对话框在引导结束后打开。对话框中每个版本的条目按新功能、修复、性能、升级提示等类别分组，以颜色区分并标出条数，新功能以卡片列出；跨越多个版本时，列表上方汇总各类条目的数量，最新版本默认展开，跳过的版本可单击展开，汇总右侧的“展开所有”“折叠所有”可一次展开或折叠全部版本。更新后显示的更新内容中各版本都默认展开，均可单击折叠。对话框打开时各部分依次淡入，版本展开与折叠时高度平滑过渡，指针移到新功能卡片或条目上时逐渐高亮；关闭“界面动画”后直接显示。弹窗的高度随窗口伸展，窗口越高显示的内容越多，超出时在内容区内滚动；下载进度变化时保留展开状态和阅读位置。更新内容按界面语言显示对应的译文；缺少该语言的译文时，繁体中文界面显示简体中文，其他语言显示英文，英文也缺少时显示中文。单击“重启并更新”开始安装，需要管理员授权：安装期间 Argus 将退出，安装程序仅显示进度条，完成后自动以标准权限重新启动 Argus 并回到原来的页面；从托盘隐藏状态开始的更新，重新启动后仍保留在托盘。取消管理员授权时不安装，更新仍可稍后安装。

更新后首次打开窗口时，Argus 显示更新前后的版本号及其间的变化。托盘启动、首次引导或任务管理器替换入口会将说明延后到合适的显示时机。关闭“更新后显示更新内容”后，右下角改为简短提示。需要重读时，单击“查看本版本更新”、关于页的“更新内容”或状态栏左端的版本号。

若程序文件被其他软件占用，安装器会显示占用进程、错误码及诊断日志路径。退出相关程序后，单击“重试”继续安装；单击“取消”可退出安装并保留旧程序。游戏或安全软件持续占用时，可正常退出相关程序，或保存工作并重启电脑后再安装。诊断日志保存在安装账户的临时目录中，可按弹窗给出的路径收集。使用另一管理员账户授权时，原桌面账户也可读取本次安装日志。

安装包缓存在 `%LOCALAPPDATA%\dev.argus.taskmanager\updates`。重新启动时校验缓存，通过后可直接安装。安装前再次验签，文件已修改或删除时重新下载，安装完成后清理缓存。

| 设置 | 说明 |
|---|---|
| 自动检查更新 | 默认开启。启动约 1 分钟后检查一次，此后每天检查一次；检查失败时 6 小时后重试。关闭后仅在单击“检查更新”时检查。 |
| 更新后显示更新内容 | 默认开启。更新完成后首次打开窗口时显示新版本的更新内容，每个版本仅显示一次；关闭后改为右下角的提示。同一行的“查看本版本更新”可随时打开当前版本的更新内容。 |
| 更新通道 | 稳定版（默认）仅接收正式版本。测试版同时接收预发布版本，如 `1.2.0-beta.1`。切回稳定版后，下一次更新须高于已安装版本。 |
| 下载线路 | 自动（默认，依次尝试 GitHub、Argus 官方镜像和加速代理）、仅连接 GitHub、仅使用加速代理。 |
| 加速代理 | 内置 gh-proxy.com、gh-proxy.org、ghfast.top，也可填写自定义代理，即添加在 GitHub 地址之前的前缀，须使用 https。 |
| Star 提醒 | 默认开启。每天至多在窗口右下角显示一次卡片，邀请在 GitHub 上为 Argus 点亮 Star。 |

“Star 提醒”的卡片在窗口显示约 5 秒后出现，约 30 秒后自动收起，指针停留在卡片上时保持显示；正显示对话框时延后到对话框关闭之后，打开了首次启动引导或出现了[免安装版提示](README.md#首次启动)的那一次运行不显示。由任务管理器替换（如 Ctrl+Shift+Esc）启动的那一次运行同样不显示，当天的提醒留到之后的正常启动。卡片上的操作：

- “前往 GitHub”在浏览器中打开 Argus 的仓库页面，并关闭“Star 提醒”。
- “不再提醒”关闭“Star 提醒”，右下角随即提示可在设置中重新开启，提示中的“打开设置”定位到此项。
- 右上角的关闭按钮仅收起当天的卡片。

日期按本机时间判断，显示卡片不访问网络。

第三方加速代理可获知本机 IP 地址和请求的文件。Argus 核验安装包签名及绑定的版本号，仅安装高于当前版本且校验通过的软件包。更新说明也须通过签名与版本校验才会显示。

安装版支持应用内更新，包括通过管理员启动或任务管理器替换打开的副本。免安装版发现新版本时显示更新内容，单击“前往下载”手动替换程序。开发构建跳过更新检查。

已安装特权服务时，安装程序在同一次管理员授权中一并更新服务；启用了任务管理器替换时，替换保持开启，所用的界面和启动器也随之更新到新版本。安装程序未能更新服务时，更新后首次启动时询问是否更新服务，见[权限](#权限)。

### 旧版升级与数据

从 v0.3.3／v0.3.4 升级可继承独立保存的界面偏好；从 v0.3.2 及更早版本直接升级到 v0.4.0 时，仅保存在旧 WebView2 缓存中的界面偏好（如布局、行备注与置顶标记）恢复默认值，需要重新设置。应用设置、历史文件与日志保留。

升级后，Argus 启动时在后台清理本地数据目录中的 `EBWebView`、`WebView2` 旧版浏览器数据。仍被占用的文件将在后续启动时继续清理。实现见[原生宿主](../architecture/host.md)。

# 设置

设置页按分组排列，左侧的分组列表跟随滚动标出当前位置，单击可以直接跳到对应分组；窗口较窄时只显示设置本身。

## 语言与外观

界面支持简体中文与英文，默认“跟随系统”：Windows 的显示语言为中文（任一地区）时使用简体中文，其他语言使用英文。切换后立即生效，托盘菜单、窗口标题和错误提示也随之切换。

特权服务以 SYSTEM 身份运行，管理员授权后运行的维护助手也在独立的进程中，它们使用 Windows 的显示语言；当 Argus 的语言与 Windows 显示语言不同时，来自这些进程的少量提示会以 Windows 的语言显示。安装程序和卸载程序同样按 Windows 的显示语言显示中文或英文。

“主题”可选“跟随系统”“浅色”或“深色”，默认跟随系统：使用 Windows“个性化 → 颜色”中的应用模式，系统切换时随之切换。选择浅色或深色后，窗口内容、标题栏与背景都固定为该主题，不再跟随系统。托盘菜单、系统对话框以及安装和卸载程序仍跟随 Windows。

## 启动与后台

| 设置 | 说明 |
|---|---|
| 登录 Windows 时启动 | 在托盘中静默启动（`--hidden`），需要时用快捷键或单击托盘图标打开。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时每 5 秒采样一次，历史记录和规则照常进行。关闭这一项后，关闭窗口即退出 Argus。 |

## 快捷键

显示或隐藏 Argus 的全局快捷键，默认 Ctrl+Alt+Esc，在任何程序中都能使用。单击“更改”后按下新的组合键；录制时按 Esc 取消，按 Backspace 关闭快捷键。组合键至少要包含一个修饰键（Ctrl、Alt、Shift 或 Win）；被其他程序占用时，设置页会提示换一个组合键。

## 权限

“特权服务”默认未安装。单击“安装并启用”，确认授权范围后完成 Windows 的管理员授权，Argus 的界面继续以标准权限运行，以下功能会使用后台服务：

- 结束进程或进程树（仍拦截系统关键进程）。
- 设置进程优先级、开启或关闭效率模式。
- 自动规则中的优先级与效率模式操作。
- 每进程网络流量采集（本地采集不可用时）。
- 按句柄查文件及目录占用（包括进程当前目录）。
- 启动、停止、重启 Windows 服务，以及修改启动类型。
- 断开 IPv4 TCP 连接。

这一授权属于当前 Windows 账户，而不是 Argus 这个程序：此账户下以标准权限运行的任何程序都能调用服务的管理功能，无需再次授权。这些功能的作用范围是整台电脑，包括结束任意用户的进程（系统关键进程除外）、启动或停止任意 Windows 服务并修改启动类型（安全软件与 Windows 更新相关的服务也不例外）、断开任意 IPv4 TCP 连接，以及查询所有进程的文件占用。安装特权服务相当于让该账户获得了部分管理员权限，请只在自己使用的账户上安装。在受限环境（受限令牌或 AppContainer 沙盒）中运行的程序不能调用服务。

服务随 Windows 启动，一次安装只授权一个账户；另一个账户需先经管理员授权卸载，再安装。

状态行显示未安装、已连接、已停止或错误。服务停止后可“启动服务”；更新 Argus 后可“更新服务”，将新版程序复制到受保护的服务目录。服务版本与 Argus 不一致时状态行会提示；通过应用内更新升级后，Argus 首次启动时也会询问是否更新服务。取消管理员授权会保留现状。连接中断或操作超时时不会自动重复执行，请刷新对应页面确认结果。

“卸载”会停止并移除服务，Argus 继续运行，操作恢复为当前进程的权限。从“设置 → 应用”卸载 Argus 时，卸载程序检测到特权服务会询问是否一并卸载（需要管理员授权）；选择保留时服务继续随 Windows 启动。使用免安装版时，删除程序前应先在这里卸载服务。后台程序是独立副本，移动免安装版不会中断已经安装的服务。

**免安装版的风险**：安装或更新特权服务、启用任务管理器替换时，Argus 会以管理员身份运行自身，并把自身复制为以 SYSTEM 身份运行的服务程序。安装版位于 Program Files，只有管理员能修改；免安装版则可以放在任意位置，如果它所在的文件夹允许标准用户写入（例如“下载”文件夹或桌面），本机已有的恶意程序就可能在这之前替换 `argus.exe`，借你的管理员授权获得 SYSTEM 权限。需要特权服务时建议使用安装版；使用免安装版时，请把它放在只有管理员能写入的文件夹中。

详细信息、启动项修改，以及文件占用查询中的 Restart Manager 部分仍使用 Argus 本身的权限。句柄查询可使用服务；服务不可用时以当前账户权限降级查询。工具栏的权限标记仍表示界面进程的权限，受保护的系统进程可能拒绝特权服务的操作。

网络流量会在后台异步读取，通常比本地采样晚一个刷新周期；服务断线或采集不可用时隐藏网络列，恢复后先建立计数基线，避免把积累的字节显示成瞬时峰值。没有客户端读取 15 秒后，服务会关闭 ETW 会话；再次读取时重新启动。更新到这个版本后，已安装旧版服务的用户需要单击“更新服务”。

## 替换系统任务管理器

“权限”分组内可查看系统任务管理器替换状态。功能默认关闭，发布版在安装特权服务并授权给当前账户后才提供“启用替换”。它影响整台电脑上 taskmgr.exe 的启动入口，包括 Ctrl+Shift+Esc；授权账户打开 Argus，其他账户仍尝试打开 Windows 任务管理器。已有其他替换或路径过滤配置时拒绝开启，不自动覆盖。

开启需要管理员授权，并先完成临时程序的重定向自检与界面就绪检查。Argus 无响应时，独立启动器尝试打开原生任务管理器。该路径仍可能受系统策略、权限或文件损坏限制；真实管理员环境的验收目前尚未完成。

“恢复 Windows 任务管理器”优先通过特权服务还原，服务不可用时请求管理员授权。界面无法运行时，使用状态行提供路径中的 `argus-taskmgr-recover.exe`；它不依赖 WebView2 或后台服务。独立恢复程序也损坏时，参照其同目录的 `taskmgr-recovery.txt`，核对归属后只还原 Debugger 值，不删除整个键。

更新或卸载特权服务会先关闭替换；更新后需手动重新开启。卸载 Argus 前也必须通过恢复检查；升级安装时选择“先卸载再安装”不做这项检查，替换保持原样。冲突或恢复失败会保留文件并阻止相关卸载。详细过程见[系统任务管理器替换](../architecture/task-manager.md)。

## 数据与历史

| 设置 | 说明 |
|---|---|
| 刷新频率 | 每 0.5、1（默认）、2 或 5 秒采样一次。间隔越短曲线越细腻，Argus 自身的开销也越高。工具栏上也可以切换刷新频率或暂停刷新；暂停时界面不再更新，历史记录和规则照常进行。 |
| 网络速率单位 | 字节每秒（MB/s，默认，与磁盘一致）或比特每秒（Mbps，与网卡的链路速度、宽带套餐一致），整个应用统一切换。性能页的网络视图总是同时显示两种。 |
| 记录历史 | 默认开启。每 5 秒记录一次资源占用和当时最忙的进程，只保存在本机，保留 7 天，在[历史页](README.md#历史)查看。关闭后不再记录新的数据，已有的记录照常在 7 天后过期。 |
| 已保存的历史 | 显示历史记录占用的空间和最早的一条记录；“清除”会在确认后删除全部历史记录。 |

## 规则

程序启动时自动设置优先级或效率模式。在分组顶部输入程序名（例如 `chrome.exe`）并单击“添加”即可新建规则。每条规则包括：

- **程序名**：不区分大小写；同名的多个进程都会套用。程序正在运行时，规则前面显示它的图标。
- **优先级**：不改变，或实时、高、高于正常、正常、低于正常、低之一。
- **效率模式**：不改变、开启或关闭。
- **启用开关**：停用后保留规则但不再套用。

规则保存后会立即排入后台应用队列，作用于已在运行的进程，此后每当这个程序启动就再套用一次；窗口隐藏在托盘时也照常生效。规则通信不会阻塞刷新，慢请求期间只保留最新的进程列表。

每条规则下方显示已应用、权限不足和执行失败的进程数；保存规则或权限来源改变时重新计数。安装、停止或重启特权服务后，已有进程会重新检查。请求发出后丢失回复时不自动重复操作，可检查服务状态后重新保存规则来重试。

也可以在进程列表中右键一个进程，选择“添加规则”：Argus 会以它当前的优先级和效率模式建好规则，并转到这里。

## 更新

Argus 从 GitHub Releases 获取新版本。发现新版本后在后台下载，下载完成时设置页的“更新”分组和工具栏的“设置”标签上显示提示点，托盘菜单增加“重启并更新到 x.y.z”。安装需手动确认，并需要管理员授权：安装期间 Argus 将退出，安装程序仅显示进度条，完成后自动以标准权限重新启动 Argus；从托盘隐藏状态开始的更新，重新启动后仍保留在托盘。

| 设置 | 说明 |
|---|---|
| 自动检查更新 | 默认开启。启动约 1 分钟后检查一次，此后每天检查一次；检查失败时 6 小时后重试。关闭后仅在单击“检查更新”时检查。 |
| 更新通道 | 稳定版（默认）仅接收正式版本；测试版同时接收预发布版本（如 `1.2.0-beta.1`），提前提供新功能，稳定性可能不及稳定版。由测试版切换到稳定版后，需等到稳定版的版本号高于当前版本时才会更新，不会降级。 |
| 下载线路 | 自动（默认，优先连接 GitHub，失败时依次使用加速代理）、仅连接 GitHub、仅使用加速代理。 |
| 加速代理 | 内置 gh-proxy.com、gh-proxy.org、ghfast.top，也可填写自定义代理，即添加在 GitHub 地址之前的前缀，须使用 https。 |

加速代理由第三方提供，可获知本机的 IP 地址及所下载的文件。安装包带有发布者的签名，签名同时覆盖版本号；Argus 仅安装签名正确、版本号与签名一致且高于当前版本的安装包，因此代理无法篡改更新，也无法以旧版本冒充新版本，至多导致暂时无法获取更新。更新说明不在签名范围内，仅以纯文本显示。

免安装版（`Argus_<版本>_x64.exe`）不支持自动更新：发现新版本时显示“前往下载”，单击后打开发布页。开发版不检查更新。

应用内更新仅替换 Argus 本身。已安装特权服务时，更新后首次启动会询问是否同时更新服务，见[权限](#权限)。

## 关于

显示版本号、当前权限（标准权限或管理员）和版权声明，并提供“退出 Argus”。“首次启动引导”可以重新打开第一次启动时的引导。“许可证”一项说明 Argus 以 GNU Affero General Public License 第 3 版或更高版本发布、不提供任何担保，单击“查看许可证”可以阅读全文。“第三方组件”列出 Argus 包含的开源组件及其许可证与版权声明。“日志”记录系统与 WebView2 版本、此电脑提供的传感器（例如 CPU 温度来自哪些 ACPI 热区、显卡功耗的来源）、特权服务与任务管理器替换的状态，以及更新、特权服务、任务管理器替换和界面中出现的错误，不含文件路径、用户名等个人信息。日志仅保存在本机（`%LOCALAPPDATA%\dev.argus.taskmanager\logs`），`argus.log` 超过 1 MB 时轮换并保留一份旧文件；任务管理器替换的启动器另写 `taskmgr.log`，记录 Argus 未能打开、改为打开 Windows 任务管理器的原因。提交缺陷报告时可单击“打开日志文件夹”附上日志。

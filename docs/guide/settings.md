# 设置

## 启动与后台

| 设置 | 说明 |
|---|---|
| 登录 Windows 时启动 | 在托盘中静默启动（`--hidden`），需要时用快捷键或单击托盘图标打开。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时每 5 秒采样一次，历史曲线不中断。关闭这一项后，关闭窗口即退出 Argus。 |

## 快捷键

显示或隐藏 Argus 的全局快捷键，默认 Ctrl+Alt+Esc，在任何程序中都能使用。单击“更改”后按下新的组合键；录制时按 Esc 取消，按 Backspace 关闭快捷键。组合键至少要包含一个修饰键（Ctrl、Alt、Shift 或 Win）；被其他程序占用时，设置页会显示原因。

## 动画

| 设置 | 说明 |
|---|---|
| 界面动画 | 切换页面、打开菜单和对话框时的过渡，以及滑动的选中标记。默认跟随 Windows 的“动画效果”设置。 |
| 曲线动画 | 流畅、均衡、省电、关闭四档。默认流畅；Windows 关闭了动画效果时默认关闭。各档的区别与开销见[曲线动画](../design/charts.md)。 |

## 数据

刷新频率：每 0.5、1（默认）、2 或 5 秒采样一次。间隔越短曲线越细腻，Argus 自身的开销也越高。工具栏上也可以切换刷新频率或暂停刷新。

## 关于

显示版本号和当前权限（标准权限或管理员），并提供“退出 Argus”。

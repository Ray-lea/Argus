# 硬件数据的来源与限制

Argus 默认使用标准用户可读取的系统及显卡驱动接口，不使用 WMI。可在“设置 → 权限”启用内核传感器，通过 Argus 特权服务和官方 PawnIO 驱动读取 CPU 内部传感器。手动开启时，Argus 自动检查驱动，按需请求管理员授权安装或启动；准备成功后才保存开启状态。缺少接口、访问被拒绝或读数失效时，对应项不显示。

| 数据 | 来源 | 说明 |
|---|---|---|
| CPU 占用 | Windows 独立空闲计数、处理器总时间和进程周期计数 | 整体与各逻辑处理器计入短时运行；进程占用按全机容量归一化，单线程占满一个逻辑处理器时约为 `100 ÷ 逻辑处理器数`。不按睿频倍数放大；系统任务管理器采用不同统计口径或采样窗口时，数值可能不同。标准权限即可读取；时基或计数不可用时回退系统时间计数 |
| 累计 CPU 时间、内核占用 | Windows 用户态与内核态时间计数 | 保留系统原始时间口径；短时运行可能受系统计时粒度影响，因此累计时间的差量不一定等于占用率对应的运行量 |
| CPU 标识 | CPUID、Windows 硬件注册表、处理器拓扑 API | 厂商、家族／型号／步进、微码、硬件指令集、物理核心与逻辑处理器、缓存 |
| CPU 频率 | 性能计数器 `Processor Information`；内核 MSR | 整体与每个逻辑处理器；每核实际频率、有效频率、倍频与 C0 活跃比例；支持的 Intel 型号另有 Ring 频率、倍频及频率上下限。有效频率按 APERF 的时间差计算，每核的有效频率与 C0 为所属逻辑线程的平均值；休眠或计数器重置后重新建立基线 |
| CPU 基准速度 | CPUID `0x16`；缺失时使用 Windows `ProcessorInformation` 电源接口 | 不将注册表 `~MHz` 的 TSC／性能计数器参考频率当作基准速度；悬停可查看来源 |
| CPU 空闲状态 | Windows `Processor Information`；已映射 AMD SMU 表 | Windows C1／C2／C3 为系统空闲状态类别；SMU 的 C0／C1／CC6 单独显示，不将系统 C3 改称硬件 C6 |
| CPU 限制状态 | Intel `IA32_THERM_STATUS` 和封装热状态 MSR | 温度、PROCHOT、临界温度、功耗及支持的电流／跨域限制；当前位与历史锁存位分别呈现，读取不清除记录 |
| CPU 温度 | 处理器内部传感器；无读数时回退至 ACPI 热区（`Thermal Zone Information`） | 内部温度需启用内核传感器；ACPI 通常反映封装附近温度，部分主板没有该接口或只提供固定值。性能页标明来源 |
| CPU 功耗 | `Energy Meter`；内核传感器的 RAPL / AMD 能量计数器 | CPU 页面显示封装与 CPU 核心功耗，不重复显示核显功耗；GPU 页面按对应显卡的数据源显示功耗。有效的零功耗读数保留，缺测不当作零。Windows 未提供时以驱动的封装能量差分补充封装功耗；计数回绕有界处理，休眠、异常跳变和过长间隔不产生峰值 |
| 每核温度、CPU 电压 | PawnIO 固定 CPU／SMU 模块，经特权服务读取 | Intel DTS 提供核心温度、温度余量和节流状态；AMD 按明确的 SMU 表版本读取每核温度。SVI2／SVI3 供电电压与 VID 请求电压分别标注；SMT 线程共享的核心传感器只统计一次 |
| 功耗与限制 | Intel RAPL；AMD 能量计数器和 SMU 表 | Intel 封装、核心、核显、内存与平台功耗、PL1／PL2 和时间窗口、TDP；AMD 每核功耗以及表中明确的 PPT／TDC／EDC 当前值与上限 |
| AMD 扩展数据 | SMU 表，按精确版本匹配 | 核心、SoC、Misc 供电电压／VID／电流／VRM 温度，FCLK／UCLK／MCLK、VDDP／VDDG、I/O 芯粒和 L3 温度。供电轨功耗由同一快照的电压与电流相乘计算 |
| 主板传感器 | Nuvoton NCT6779／NCT679x | 按硬件通道编号显示风扇转速。ROG STRIX X670E-A / NCT6799D 另提供 +5 V、+12 V、+3.3 V、AVCC、待机电压、已启用的电池电压，以及主板与供电温度。未知主板不套用分压与接线；不将未确认的通道标为 CPU 或水泵接口 |
| 电池 | 电池类驱动（`powercfg /batteryreport` 背后的接口） | 电量、充放电功率、电压、设计 / 完全充电容量、健康度、循环次数 |
| 磁盘 | 存储 IOCTL | 活动时间、读写速率、响应时间、型号、容量、SSD / HDD、所含的卷；硬盘提供时显示温度 |
| GPU | D3DKMT、进程引擎计数；AMD ADL2、Intel IGCL 遥测；NVIDIA 可补充 NVML 核心利用率 | 各引擎利用率、专用 / 共享显存、温度、核心 / 显存频率。整体取最忙引擎，结合有效进程计数及 NVIDIA 核心读数，界面标明来源；不同来源的覆盖范围与采样窗口可能不同。温度、频率与电压按驱动支持情况显示，支持的零频率、零电压不隐藏；NVIDIA 不提供电压。部分驱动以占功耗预算的百分比报告功耗 |
| GPU 功耗（瓦） | NVIDIA NVML、AMD ADL2、Intel IGCL | 均从 System32 加载厂商库，按 PCI 总线、设备与功能号匹配适配器。NVML 提供板卡功耗和限制；ADL 优先板卡功耗，再回退芯片功耗；IGCL 优先对单一 GPU 电源域的微焦耳计数与设备时间求差，并读取启用的持续功耗限制；电源域不可用时，可由受支持的 GPU 芯片能量和时间差分补充。界面分别标明电源域与芯片来源，缺测或计数重置后重新建立基线；AMD 的百分比调节范围不换算为瓦数 |
| 每进程 GPU | 性能计数器 `GPU Engine` 与 `GPU Process Memory`（与系统任务管理器同源） | 进程在每个引擎上的占用和使用的 GPU 内存；标准权限即可读取所有进程 |
| 每进程磁盘读写 | `PROCESS_DISK_COUNTERS` | Windows 11 24H2 及以上复用普通进程查询中的计数尾部；布局未提供时通过已授权的特权服务或管理员权限查询完整进程信息。按 PID、创建时间及采样时间计算速率，与通用 I/O 分开；无需内核驱动，不采集访问的文件名，缺失读数不当作空闲 |
| 每进程网络 | 内核网络事件（ETW 提供程序 `Microsoft-Windows-Kernel-Network`，与资源监视器同源） | TCP 与 UDP 的发送、接收字节数。会话可由管理员权限的 Argus 或已授权的特权服务启动；本地与服务采集都不可用时不显示这项数据 |
| 内存条 | SMBIOS | 速度、插槽、外形规格、DDR 代数 |
| 网络 | 接口表与适配器地址 | 吞吐量、IP 地址 |

CPU 总使用率、内核时间和每逻辑处理器使用率覆盖全部处理器组。频率、空闲状态、核心拓扑与曲线按组号及组内处理器号对应；缺失的每核采样保留曲线间断，不作为 0% 使用率。

逻辑处理器小图的外框只围住曲线，上沿即 100%，与大图一致；标题行位于外框上方、框外，不与曲线重叠：左侧为核心类型（P / E，以核心颜色标示）、编号和频率，右侧为占用率，正对最新的数据点。行列数随可用宽高调整，优先保证曲线的可读尺寸和较整齐的排列；临界尺寸附近保留当前布局，减少轻微缩放造成的反复换列。换列时卡片平滑移位、缩放，关闭“界面动画”后直接切换。空间不足时可纵向滚动。

CPU 占用统计已验证的 x64 系统包括 Windows 10 LTSC 2019（17763）、21H2、22H2，以及 Windows 11 21H2、22H2、23H2、24H2、25H2 和 26H2；整体、各逻辑处理器和进程占用均可在标准权限下采集。

## 系统兼容范围

安装版与免安装版支持 Windows 10 22H2（内部版本 19045）及以上的 x64 系统，包括 Windows 11，均需 WebView2 运行时。完整功能验证以 Windows 10 22H2 为最低基线；CPU 采集专项验证还覆盖 Windows 10 LTSC 2019（17763）和 21H2。

| 功能 | Windows 10 22H2 | Windows 11 |
|---|---|---|
| 进程、性能、服务、启动项、连接与历史界面 | 支持；管理操作按账户权限或特权服务授权执行 | 相同 |
| 每进程磁盘读写 | 需要已授权的特权服务或管理员权限 | 24H2 及以上支持标准权限读取；更早版本需要特权服务或管理员权限 |
| 每进程网络流量 | 需要已授权的特权服务或管理员权限 | 相同 |
| 内核传感器 | 需要已授权的特权服务和 PawnIO 2.2.0 及以上 | 相同 |
| 窗口背景 | 随主题切换的实色背景 | Mica |

PawnIO 的安装、官方 2.0.1／2.1.0 升级与启动均由手动开启触发，并在需要时请求 UAC 授权。完成开启后，应用重启及 Windows 重启会保留设置，通过特权服务恢复读取；具体温度、电压等项目仍取决于硬件与驱动接口，虚拟机不能代替物理传感器。安装与故障处理见[内核传感器设置](settings.md#内核传感器)。

## 消费级硬件兼容范围

兼容目标为 2010 年后发布的消费级产品，按接口能力及处理器代际选择采集方法。发布时间本身不保证传感器可用；旧驱动、虚拟机、混合显卡、厂商固件及系统安全策略均可能限制数据。

| 产品范围 | 采集方法与边界 |
|---|---|
| Intel Core / Pentium / Celeron / Atom | 支持的 Family 6 处理器使用 DTS、封装温度与 RAPL MSR。校验温度有效位和温度目标；Atom 部分代际使用不同能量单位。请求电压仅对已明确编码的型号开放 |
| AMD Phenom II / Athlon / FX / A 系列及早期 APU | Family 10h–16h 使用对应模块的 PCI / SMU 温度接口与 COFVID。旧式 Tctl 仅标为控制温度，不等同于实际结温 |
| AMD Ryzen / Threadripper，含 Ryzen 9 9950X | Family 17h–1Ah 使用 SMN 温度、每核及封装能量、APERF／MPERF 与 SMU 表。Zen 4／Zen 5 的供电电压从 SVI3 遥测字段读取。`0x00620205` 按 16 核 Granite Ridge 布局读取每核温度／电压、C0／C1／CC6、PPT／TDC 当前值及 PPT／TDC／EDC 上限；`0x00620105` 使用独立的 8 核布局。`0x00380905` 为 6 核 Vermeer 提供每核温度和驻留比例。每核槽位按 CPUID CoreId 匹配，保留禁用核心造成的空洞 |
| AMD Radeon / 集成显卡 | ADL2 PMLog；接口缺失时使用 Overdrive 6 功耗、Overdrive 5 温度／频率／电压。更早驱动或不提供这些接口的型号保留 D3DKMT 数据 |
| Intel HD / UHD / Iris / Arc | D3DKMT 为基础；支持 IGCL 的设备按各字段的支持标记补充温度、频率、电压与功耗。IGCL 不支持第 10 代 Core。单插槽 Comet Lake S/H（Family 6、Model A5h，例如 i7-10700K / UHD 630）开启内核传感器后，通过固定 IntelMCHBAR 模块读取 GT 温度、频率与请求电压 VID；RAPL PP1 功耗按硬件身份对应到核显。温度等 IGCL 遥测不要求存在电源域，多个未标明范围的电源域不求和。未开放的字段保持不可用，不以 CPU 温度或封装功耗代替核显数据 |

SMU 布局表收录 72 个明确版本，定义来自固定提交的 ZenStates-Core、LibreHardwareMonitor 与 GNR-SMU；排除未有明确身份的候选字段。`0x00620205` 不套用 `0x00621202` 的头部与供电布局，不将 FIT 字段当作实时频率，也不显示未经确认的 EDC 实时值和 VRM／L3 候选。未知版本继续提供 MSR／SMN 基础读数，并显示表版本以便定位；不套用相邻版本。大型 Threadripper 表只读取签名模块允许的首个 4 KiB 页面。性能页的“内部传感器”按功耗、电压、频率、温度分组，“每核读数”单独列出，悬停可查看来源。

AMD／Intel SDK 调用在独立线程执行，GUI 与主采样线程只读取有时效的缓存。内核读数通过特权服务异步取得；没有客户端读取 15 秒后释放模块句柄。关闭开关不会卸载共享的 PawnIO 驱动。

GPU 的 D3DKMT 性能查询和 IGCL 遥测暂时失败后会间隔 5 秒重试，期间不沿用旧值。驱动版本较新不代表所有显卡型号均开放全部遥测；例如旧 Intel 核显的部分指标可能仅由专用硬件监控接口提供。

Comet Lake 的切片频率在 RC6 休眠或切片关闭时可为零，GPU 页直接显示频率数值，包括有效的 0 MHz，不以最低工作频率代替，也不以此单独确认整个核显处于 RC6。频率按当前寄存器倍率与标称步进换算，最低／最高工作频率是能力范围，不是历史观测的最小值／最大值。共享内存频率按控制器配置换算为 DCLK，DDR 传输率约为其两倍；这些配置读数不包含实测基准时钟偏差。GT／媒体活动率来自硬件计数器，不改写 Windows 引擎曲线。核显功耗优先采用服务直接读取的有效 RAPL PP1 差分，缺失时回退 Windows 计数器；功耗与活动率均反映各自采样区间，异步服务缓存也可能落后一个刷新周期。性能限制显示已确认的状态，悬停可查看各项当前与历史锁存状态，不生成没有明确寄存器定义的电压限制值。

布局依据：[Intel 第十代 Comet Lake 数据手册，615212-003](https://cdrdv2-public.intel.com/615212/615212-003.pdf)，第 9.8、9.9、9.30–9.32、9.36、9.38、9.41 节。

AMD `0x00620205` 的 SoC 设定电压明确标注为设定值，不代替 SVI3 遥测电压；不能确认含义的字段不作为 VID 上限显示。PPT／TDC／EDC 上限反映当前固件配置，UCLK／MCLK 反映实际内存分频，不按标称默认值覆盖。

当前官方 PawnIO Intel 模块未开放完整的性能限制原因寄存器和硬件核心／封装 C-state 计数器；因此 Intel 提供已允许的热状态与功耗／电流限制，以及 Windows 空闲类别。PL1／PL2 精细原因、原生封装 C6／C10、笔记本 EC 风扇与供电控制器遥测不以估算值代替。

接口资料：[Intel IGCL](https://github.com/intel/drivers.gpu.control-library)、[AMD ADL](https://github.com/GPUOpen-LibrariesAndSDKs/display-library)、[PawnIO 模块](https://github.com/namazso/PawnIO.Modules)、[AMD Family 17h OSRR](https://www.amd.com/content/dam/amd/en/documents/processor-tech-docs/programmer-references/56255_OSRR.pdf)。

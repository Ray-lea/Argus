# 性能页

性能页按设备显示 CPU、内存、磁盘、网络、GPU、NPU 与电池的实时读数、曲线与规格。本页说明设备列表的操作、视图的布局、各设备视图的内容、磁盘详情与曲线的量程。

## 设备列表

设备列表列出 CPU、内存、各个磁盘、网络适配器、GPU、NPU 与电池；NPU 为 Windows 识别的硬件 NPU，显示利用率与曲线。拖动设备列表右侧的分隔条可调整列表宽度，双击恢复默认宽度。

### 隐藏设备

在设备列表的某一项上单击右键，可隐藏该项，例如不常用的可移动磁盘或虚拟网络适配器，其余各项随之上移。右键菜单的**显示的设备**子菜单可逐项勾选，**恢复默认显示**恢复全部设备。

隐藏的设备按型号、容量、连接名称等信息记录，重新插拔或重启后仍保持隐藏。列表至少保留一项，隐藏当前选中的项时，改为选中其后一项。从概况带或详细信息面板打开已隐藏的设备时，该项回到列表。

### 调整设备顺序

上下拖动设备列表中的某一项可调整顺序：该项浮起并跟随指针，其余各项实时让位，松开后滑入新位置。

右键菜单的**磁盘排序**提供以下三种方式：

- **按磁盘编号**：即 Windows 磁盘管理中的磁盘编号，为默认方式。
- **按盘符**：有多个盘符的磁盘按首个盘符，没有盘符的磁盘排在后面。
- **自定义（拖动调整）**：拖动打乱了所选的磁盘顺序时，自动改为此项；只调整其他设备的位置时，保持原选择。

**恢复默认顺序**恢复全部设备的初始顺序。顺序按设备的记录信息保存：暂时拔出的设备重新接入后回到原位置，新接入的设备排在原顺序中与其相邻的设备之后。

> [!NOTE]
> 记录信息完全相同的设备（如同型号、同容量的两块磁盘）按采集顺序区分。其中一台拔出或磁盘编号改变后，隐藏状态与顺序可能转到另一台。

## 视图的布局

曲线随窗口大小伸缩，填满实时数字以外的空间；窗口较矮时压扁曲线，以显示实时数字。

实时数字与规格在较宽的窗口中左右并排。窗口较窄时（含默认尺寸），规格排在实时数字下方并分为两列，实时数字按能占最少行数的列数排列。

## CPU

CPU 视图显示利用率曲线，以及频率、温度与功耗。在 CPU 图表上单击右键，可切换**整体视图**与**多核视图**。两种视图都在利用率曲线下叠加内核时间，同一菜单可取消或重新勾选**显示内核时间**。所选视图、核心类型与内核时间在重启后保留。

### 多核视图

多核视图为每个逻辑处理器显示一张小图，优先排成没有空位的整齐行列；逻辑处理器的数量在当前窗口大小下排不满时，才留出空位。小图保持接近原生任务管理器的比例。

空间不足时，小图上方的文字先省去频率，再整行隐藏，省去的内容在悬停提示中显示。窗口较小时小图优先，实时数字与规格移至下方，详见[硬件数据](hardware-data.md)。

混合架构处理器的性能核、能效核与低功耗能效核各用一种颜色，并标注 P、E、LP。多核视图下，右键菜单另可选择**全部核心**，或仅显示某一类核心，例如**仅性能核**。

### 概览与详情

CPU 标题旁的**概览**与**详情**切换两页，所选页面在重启后保留：

- **概览**：曲线、实时数据与规格。
- **详情**：以卡片列出处理器信息（含指令集）、温度与功耗曲线、内部传感器、每核读数、主板传感器、封装限制与空闲状态，标题行显示摘要。

## 内存

内存视图的组成条区分“使用中”“已修改”“备用”和“空闲”。已修改的内容须先写入磁盘才能重新使用；备用内存包含未在使用的缓存数据与代码；空闲内存可直接分配。“已缓存”包含备用与已修改内存，“可用”包含备用与空闲内存。

各项说明仅在下方的色块图标上悬停时显示，说明文字不随采样数值变化，悬停期间图标位置保持稳定。没有组成明细时显示“—”。

已压缩内存是使用中内存的一部分，即内存压缩进程（Memory Compression）占用的物理内存。组成条以斜纹把它显示在“使用中”的末端，图例另列“已压缩”；“使用中（已压缩）”的括号内为其数值，悬停可查看压缩内存估计存储的数据量与为系统节省的内存。

系统未报告压缩存储时，组成条与图例不显示已压缩部分，该项仅显示“使用中”。进程合计与整机占用的区别见[内存统计口径](metrics.md#内存统计口径)。

## 磁盘详情

磁盘标题旁的**概览**与**详情**切换两页，所选页面在重启后保留。详情页显示健康状况、设备信息与 SMART 属性。

### 读取磁盘信息

详情页每次打开时读取一次磁盘信息。单击切换按钮旁的**重新读取**可再次读取，健康状况卡片右上方显示读取时间。温度显示实时读数，其余数值保持读取时的状态。

读取会向磁盘的存储驱动发送只读查询。读取期间或读取返回后的 2 分钟内，Argus 未正常退出时（系统崩溃、断电、整机无响应后重启，或进程被强制结束），此后启动不再自动读取，详情页显示“已暂停自动读取”及原因。

单击其中的**仍要读取**或标题旁的**重新读取**，可照常读取，所选页面与磁盘保持不变。读取返回后 Argus 继续运行满 2 分钟，自动读取恢复；在此之前退出，下次启动仍显示该说明。

### 健康状况

健康状况卡片显示状态、剩余寿命、温度与可用备用空间，下方列出读取总量、写入总量、通电时间、通电次数、不安全关机与介质错误。

部分磁盘另有以下读数：

- **已适配的 SATA SSD**：按型号显示对应的寿命、累计主机读写、通电统计、异常断电及不可校正错误；提供备用空间比例的型号还显示其比例和阈值。
- **SATA/ATA HDD**：显示可读取的通电、启停、磁头加载、重映射／待映射／离线不可校正扇区及接口 CRC 计数；已适配的型号也列出读写总量。

NVMe 温度条以硬盘报告的严重温度为满刻度，刻线标出警告温度；备用空间条的刻线标出阈值。

### 设备信息

设备信息卡片列出型号、固件版本、序列号、容量、卷、接口、PCIe、SATA 或 PATA UDMA 传输模式、NVMe 或 ATA 标准版本、扇区大小与支持的功能。传输模式在当前链路与设备支持的最高链路不同时，同时列出两者；支持的功能包含设备报告的 SMART、TRIM、写入缓存及 NCQ。

序列号默认隐藏，单击**显示**查看。序列号优先采用 NVMe／ATA 厂商 SN，缺失时回退至 SCSI 单元序列号及 Windows 通用存储描述符。转速按 ATA 设备报告的值显示。

### SMART 属性

SMART 属性卡片按设备的类型显示：

- **NVMe**：健康日志按健康、使用情况和温度分组，读写量按每单位 512,000 字节换算；温度原始值的单位为开尔文，未报告的传感器不列出。
- **ATA／SATA 和支持 SAT 的桥接设备**：属性编号、名称、当前值、最差值、阈值及原始值。原始值的 6 个字节合为一个数，已识别的 SSD 字段按型号命名。
- **SCSI／SAS**：设备提供的健康状态、温度与读写错误统计。

异常的数值以红色显示。卡片右上方的**十进制** / **十六进制**切换原始值的进制，默认为十进制；所选进制对所有磁盘生效，重启后保留。

属性的表格随窗口宽度调整。各列按其中最宽的文字定宽，名称与数值相邻，多出的宽度平均分给各数值列。

NVMe 的健康、使用情况与温度三组在各栏高度相近时并排，否则上下排列，每组的行再分栏。ATA／SATA 属性在放得下时拆成至多 3 张并排的表，每张不少于 5 行。

不再分栏后，每张表的宽度以文字所需宽度的 2 倍为限，其余宽度留在表格之间。窗口较窄时名称换行，仍放不下时数值移到名称下方。指针所在的行以底色标出。

### 健康状态的判定

健康状态按下表判定：

| 状态 | 条件 |
| --- | --- |
| 异常 | 严重警告中的备用空间低于阈值、可靠性下降、介质转为只读、易失性存储备份设备故障或持久性内存区域转为只读，或可用备用空间低于阈值 |
| 注意 | 严重警告中的温度超出阈值或尚未定义的警告位，存在介质与数据完整性错误，剩余寿命不高于 10%，或 HDD 存在重映射、待映射、离线不可校正扇区 |
| 良好 | 以上情况均未出现 |

NVMe 剩余寿命为 `100 − 已用寿命`，已用寿命是厂商对耐久度的估计，可超过 100%。严重警告与剩余寿命分别判定。缺失的阈值与读数显示“—”。

USB 桥接设备常不回传 SMART 状态。未取得设备故障预测时，按属性与阈值判定：有预故障属性达到阈值为“异常”，均未达到时按上表判定；阈值也未取得时，健康状态显示“未知”。读取保留设备的 SMART 启用状态。

ATA／SATA、USB-SAT 和 SCSI／SAS 的扩展数据经已运行的特权服务读取，可在**设置 → 权限**中安装、启动或更新服务。厂商专用 USB／RAID 通道的覆盖情况见[路线图](../roadmap.md)。

## 网络

网络适配器的 IPv4 地址、IPv6 地址与物理地址右侧带有复制按钮，单击可复制该地址。IPv4、IPv6 地址超过 3 个时，单击**展开全部**可查看其余地址。速率的单位见[网络速率的单位](metrics.md#网络速率的单位)。

## GPU

GPU 视图的引擎利用率默认为**智能显示**：仅列出曲线时间范围内有占用的引擎，引擎空闲满一个时间范围后才收起。也可改为固定数量，并选择每张小图显示的引擎，所选引擎按显卡型号保存。

显卡按驱动的支持情况显示温度、频率、电压与功耗瓦数。GPU 读数的统计方法见[GPU 统计口径](metrics.md#gpu-统计口径)。

### 引擎小图的排列

引擎小图有三种排列，均始终铺满、不留空位：

- **网格**：引擎数不能排成整齐的行列时，由第一个引擎多占一格。
- **焦点**：第一个引擎放大，其余排在旁边或围成 L 形。
- **列表**：每个引擎一行。

除放大的第一个引擎外，其余小图大小一致。拖动引擎图与显存图之间的分隔条，可调整两者的高度比例，双击恢复默认。

### 电源状态

空闲时由 Windows 断电的显卡（如混合显卡笔记本的独立显卡）进入低功耗状态后，**电源状态**一行显示“已休眠”，悬停可查看说明。此时 Argus 不读取温度、风扇、频率、电压与功耗，以免将其唤醒；利用率与显存照常显示。显卡恢复工作后，该行消失，读数继续更新。

## 曲线与量程

磁盘与网络曲线按峰值选择预设的量程档位，最低分别为 100 KB/s 和 100 Kbps（字节单位下为 100 KB/s），各级档位见[速率量程](../design/charts.md#速率量程)。功耗等其他动态量程取整数或整十数。

量程上限变化时，曲线平滑过渡，上限标签淡入，随**曲线动画**设置；关闭曲线动画时直接切换。

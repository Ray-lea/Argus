# 启动与后台

本页说明设置页**启动与后台**分组的内容：登录 Windows 时启动、默认页面、托盘与组件的入口，以及主窗口记住的状态。

本分组包含以下设置项：

- **登录 Windows 时启动**：默认关闭。开启后，登录时以 `--hidden` 启动，在托盘中运行；单击托盘图标或按全局快捷键可打开窗口。从任务管理器替换入口启用此项时，Argus 会定位已安装的程序；提示未找到时，从安装位置启动 Argus 后再启用。
- **默认页面**：启动 Argus 后首次显示窗口时打开的页面，可选进程（默认）、性能、服务、启动、连接或历史，与上次退出时停留的页面无关。在托盘中静默启动或由任务管理器替换启动时，首次显示窗口即打开所选页面；应用内更新完成后自动重新启动时，仍回到更新前的页面。
- **托盘与组件**：托盘图标、悬停卡片、右键单击托盘图标的作用、关闭窗口时保留在托盘、从托盘打开与后台常驻时的刷新间隔位于[组件页](../resident-mode.md#组件页)，单击**打开组件页**前往。

主窗口会记住上次使用的状态：

- 最大化后退出或关闭到托盘，再次打开时仍为最大化。
- 还原为普通窗口后，再次打开时沿用上次的位置和大小。
- 最小化后退出，下次启动时恢复最小化前的状态。
- 以托盘模式启动时，窗口保持隐藏，首次打开时恢复。
- 原显示器断开后，Windows 会将窗口移到可用屏幕。

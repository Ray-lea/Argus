# 语言与外观

本页说明设置页**语言与外观**分组的内容：界面语言与区域格式、主题与窗口背景、导航栏位置、界面缩放与字体大小，以及进程页的显示。

本分组的设置项如下：

| 设置项 | 取值 | 作用 |
| --- | --- | --- |
| 界面语言 | 跟随系统（默认）或九种界面语言之一 | 界面显示的语言 |
| 主题 | 跟随系统（默认）、浅色、深色 | 窗口与托盘卡片、面板的深浅色 |
| 导航栏位置 | 顶部（默认）、侧边 | 页面导航栏的位置 |
| 界面缩放 | 80%–150%，默认 100% | 文字、图标和控件的整体大小 |
| 字体大小 | 11–20 px，默认 13 px | 基础字号，标题和辅助文字按比例变化 |
| 进程概况带 | 自动（默认）、始终显示、隐藏 | 进程页概况带的显示方式 |
| 系统进程隐藏规则 | 始终显示与额外隐藏的名单 | 进程页与连接页共用的隐藏规则 |
| 按用户分组进程 | 自动（默认）、始终分组、不分组 | 进程列表是否按用户分组 |
| 指针悬停时暂停排序 | 开启（默认）、关闭 | 指针停在进程列表上时保持行位置 |
| 资源泄漏提示 | 开启（默认）、关闭 | 在进程页标出可能泄漏句柄或进程的程序 |

## 界面语言

界面支持简体中文、繁体中文、英文、西班牙文、德文、日文、韩文、法文和俄文，选项始终显示各语言的原生名称。切换后立即生效，托盘的卡片、面板与菜单、窗口标题和错误提示也随之切换。

选择**跟随系统**时，按以下顺序确定界面语言：

1. Windows 显示语言
2. 用户首选语言列表中已支持的语言
3. 英文

同一语言的地区变体共用译文，例如墨西哥西班牙文、加拿大法文。中文显示语言按脚本和地区选择，显式脚本优先于地区：

- 繁体脚本，或中国台湾、中国香港、中国澳门地区，使用繁体中文。
- 简体脚本，或其他中文地区，使用简体中文。

特权服务和提权维护助手使用 Windows 显示语言。安装程序和卸载程序也提供上述九种语言。Windows 文件选择框、管理员授权框，以及其他应用提供的进程名称、服务描述，保持各自的来源语言。

## 区域格式

数字与完整日期采用 Windows 区域格式，时区采用系统设置，均独立于界面语言。运行中修改数字区域格式后，重新启动 Argus 生效。

历史曲线的紧凑日期标签随界面语言显示，时间轴使用 24 小时制。跨夏令时切换时，刻度按各时刻的本地时间排列；选中或悬停时显示 UTC 偏移，可区分回拨时重复出现的时刻。

## 主题与窗口背景

**主题**默认跟随 Windows **个性化 → 颜色**中的应用模式。手动选择**浅色**或**深色**会固定窗口内容、标题栏与背景的主题，托盘的悬停卡片与快捷面板也随之切换。托盘菜单、系统对话框和安装程序使用 Windows 主题。

Windows 11 22H2 及以上默认保留云母背景；Windows 11 21H2 和 Windows 10 自动使用实色背景。

曲线在实体屏上的亮度与截图有差异时，可从托盘退出 Argus，再使用 `argus.exe --opaque-window` 启动。此模式使用实色窗口背景，保留曲线配色和动画设置。

## 导航栏位置

**导航栏位置**可选**顶部**或**侧边**，首次启动引导中也可选择。设置保存在本机，重启后保留。

- **顶部**：导航栏以标签形式排列在标题栏下方。切换页面时，新页面按标签的先后从右侧或左侧滑入。
- **侧边**：导航栏位于窗口左侧，新页面从下方或上方滑入。默认仅显示图标，单击左上角的 ☰ 按钮可展开显示页面名称；展开后可拖动右边缘调整宽度，双击恢复默认。

## 界面缩放与字体大小

**界面缩放**调整文字、图标和控件的整体大小，**字体大小**设定基础字号，标题和辅助文字按比例变化。两项独立设置，可组合使用，立即生效并自动保存，也可分别恢复默认值。

数值的调整方式如下：

- 输入数值后按 Enter。
- 按 ↑ 或 ↓ 键逐步调整。
- 指针悬停时，输入框右侧显示上下箭头。单击步进一次，按住可连续调整，松开后生效。

输入框支持区域小数符、点号和全角数字；输入时保留输入法组字，确认后检查数值。

## 进程页的显示

以下设置调整进程页的显示，其中系统进程隐藏规则也用于连接页：

- **进程概况带**：自动模式预留概况带和虚拟 10 行进程的固定高度预算，仅在窗口空间不足时收起；实际行数与折叠、筛选状态不影响判定。切换遵循界面动画设置。
- **系统进程隐藏规则**：编辑进程页与连接页共用的始终显示、额外隐藏名单。两页的页面栏各自提供图标开关，默认关闭。规则的匹配见[隐藏系统进程](../processes.md#隐藏系统进程)，连接的归属见[隐藏无所属进程的记录](../connections.md#隐藏无所属进程的记录)。
- **按用户分组进程**：自动模式仅在多个用户同时登录时分组，含已断开连接但未注销的会话；只有一个用户登录时列表保持不分组。分组的归属与组内行为见[按用户分组](../processes.md#按用户分组)。
- **指针悬停时暂停排序**：指针停在进程列表上时行位置保持不变，读数照常刷新，移出列表后重新排序。关闭后列表随读数实时排序；右键菜单或确认框打开时仍保持行位置。显示方式见[排序暂停](../processes.md#排序暂停)。
- **资源泄漏提示**：在进程页标出可能泄漏句柄或进程的程序，判断依据与显示方式见[资源泄漏提示](../processes.md#资源泄漏提示)。关闭后不再显示任何标记；忽略过的程序可在此一并恢复。

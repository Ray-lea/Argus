# 替换系统任务管理器

本页说明设置页**权限**分组中的系统任务管理器替换：开启替换、临时打开与恢复、安全软件的拦截，以及更新与卸载时的处理。

**权限**分组的**替换系统任务管理器**卡片显示系统任务管理器替换的状态，首次启动引导中也可直接开启。功能默认关闭；发布版在安装特权服务并授权给当前账户后，才提供**启用替换**。

> [!IMPORTANT]
> 替换影响整台电脑上 `taskmgr.exe` 的启动入口，包括 Ctrl+Shift+Esc。授权账户打开 Argus，其他账户仍尝试打开 Windows 任务管理器。

## 开启替换

开启时须确认管理员授权。Argus 检查启动器、调试脱离和界面就绪状态，通过后保存恢复记录并修改 `taskmgr.exe` 配置。Argus 无响应时，独立启动器尝试打开 Windows 任务管理器。

已有其他替换或路径过滤配置时，Argus 拒绝开启，不自动覆盖。卡片显示“已有其他配置”，并写明 `taskmgr.exe` 的 IFEO 键中发现的内容：

- 与当前 Argus 配置不一致的 `Debugger` 值
- `UseFilter` 值
- `PerfOptions` 之类的子项

按卡片所列内容核对配置来源，通过对应程序恢复后，再单击**刷新状态**。

## 临时打开与恢复

单击**临时打开系统任务管理器**可打开 Windows 自带的任务管理器，当前替换设置保持不变。此按钮在替换未启用或特权服务未安装时也可使用；启动失败时，卡片内显示原因。

**恢复 Windows 任务管理器**优先通过特权服务还原，服务不可用时请求管理员授权。

界面无法运行时，使用卡片底部给出的路径中的 `argus-taskmgr-recover.exe`，它不依赖 Argus 界面或后台服务。独立恢复程序也损坏时，参照其同目录的 `taskmgr-recovery.txt`，核对归属后只还原 `Debugger` 值，不删除整个键。

## 安全软件的拦截

安全软件可能拦截替换所需的注册表修改，或在之后清除已写入的配置。

### 注册表操作被拒绝

提示注册表权限检查通过但操作仍被拒绝时，可检查 360 等安全软件的注册表或系统防护记录：

- 找到与本次 Argus 任务管理器替换对应的拦截记录后，可允许本次修改并重试。
- 没有对应记录时，可提供包含失败 API 与错误码的 Argus 诊断日志，以便继续排查。

Argus 不自动添加安全软件信任规则、不关闭防护，也不强制改写注册表权限。持续误报可通过 [360 软件开放平台](https://open.soft.360.cn/guide/guide_1.php?i=3)申诉，提交与被拦截文件一致的版本。

### 替换被撤销

已启用的替换被外部撤销后，卡片显示“替换已被撤销”，诊断摘要同步显示该状态。Argus 保留原启用记录，启动与刷新状态时保持现有系统入口；核对安全软件记录后，可手动重新启用。

### 卡巴斯基的检测

卡巴斯基的 `HEUR:Trojan.Multi.Ifeodeb.a` 可能将此功能写入的 `taskmgr.exe:Debugger` 配置判为木马并清除。卡巴斯基将 [Ifeodeb](https://threats.kaspersky.com/en/threat/Trojan.Multi.Ifeodeb/) 定义为 Windows 系统程序的非标准调试配置检测。

申诉时按[官方误报流程](https://support.kaspersky.com/kaspersky-for-windows/21.27/troubleshooting/other/1870)提供检测对象、检测名、产品与病毒库版本、Argus 版本及启用步骤。记录中的对象是注册表项时，应一并说明其用于用户主动启用的任务管理器替换。排查期间可保留 Windows 任务管理器入口，使用 Argus 的常驻快捷键打开窗口。

安装特权服务或执行替换自检时，也可能出现 `PDM:Trojan.Win32.Generic`（包括 `.nblk` 变体）行为检测：维护助手会被终止，相关文件和快捷方式可能被移除。任务管理器替换尚未写入时，当前仍使用 Windows 原生入口。

维护助手未留下错误报告时，Argus 显示实际退出码，诊断日志也保留该值；应将发生时间与安全软件事件对应核查。PDM 误报复核按上述官方流程另附 GSI 系统报告。

### 信任列表的路径

Argus 以管理员或 SYSTEM 身份运行的程序都位于 `C:\Program Files\Argus Privileged`，文件名固定，不随更新或自检变化：

- `argus-service.exe`：特权服务
- `argus-taskmgr-launcher.exe`：启动器
- `argus-taskmgr-ui.exe`：替换打开的界面
- `argus-taskmgr-probe.exe`：开启替换时的自检
- `runtime\<应用标识>\<账户 SID>\argus-admin.exe`：管理员运行

可按这些路径或整个文件夹加入安全软件的信任列表。

> [!NOTE]
> 信任 Argus 的程序或文件夹不能消除上述 `taskmgr.exe:Debugger` 检测：它针对的是注册表值本身，只能申诉或在安全软件中允许该项配置。

## 更新与卸载

卸载特权服务会先关闭替换，单击**卸载**时的确认框中会说明。替换已恢复后，其他工具写入的任务管理器替换不影响更新或卸载服务。

更新特权服务时替换保持开启，替换所用的界面和启动器随之更新到新版本；通过安装程序升级 Argus 时同样如此，覆盖升级保留任务管理器替换配置。

以下情况下，按 Ctrl+Shift+Esc 打开的仍是旧版本，卡片中会写明其版本号：

- 免安装版直接替换程序文件。
- 安装程序未能完成更新，例如当时启动器正在运行。

此时在特权服务中单击**更新服务**，即改为打开当前版本。

> [!TIP]
> 升级前，先退出由替换打开的旧版 Argus，例如常驻托盘的实例。它仍在运行时，此后打开 Argus 显示的仍是它，从托盘退出后才是新版本。

卸载 Argus 前也必须通过恢复检查。恢复失败会保留文件并阻止相关卸载，其他工具的配置保持原样。详细过程见[系统任务管理器替换](../../architecture/task-manager.md)。

# 内核传感器

本页说明设置页**权限**分组中的**内核传感器**开关：首次启动引导、PawnIO 驱动的准备与升级、故障处理、传感器读数、关闭与卸载，以及 Comet Lake 核显的读数。

内核传感器仅在 x64 系统上提供；ARM64 系统隐藏该引导步骤与设置项。

## 首次启动引导

首次启动引导在配置特权服务后提供**内核传感器**步骤。可单击**配置特权服务**返回上一步，或单击**下一步**跳过。引导和设置页共享进度与错误信息，引导可从[关于](../README.md#关于)页重新打开。

## 开关与驱动准备

> [!IMPORTANT]
> 开启开关前，先安装或更新并启动 Argus 特权服务。安装或启动 PawnIO 需要管理员授权，界面本身保持原有权限。

**权限**分组提供**内核传感器**开关，默认关闭。开启后，Argus 自动检查 PawnIO：

- 缺少或版本低于 2.2.0 时，下载并安装官方版本。
- 已安装且符合要求时，启动驱动。
- 已经运行的较新版本直接复用。

Argus 仅在手动开启时请求安装或管理员授权，并核验官方安装包的 SHA-256 与 Windows 签名。取消、校验失败或驱动被系统策略阻止时，显示原因并保持关闭。准备期间可切换页面查看进度。

安装程序要求重启时，重启 Windows 后再次开启。也可从 **PawnIO 官网**进入手动安装。

PawnIO 已正常运行且版本符合要求时，Argus 核验设备后直接复用。标准权限下，设备版本由已更新的特权服务提供，此时驱动存储目录的写入权限不影响开启。安装、升级或启动驱动仍要求文件及父目录权限安全，出现相关提示时须由管理员检查对应目录；Argus 保持系统目录权限原样。

Argus 同时核对服务与设备状态，全部检查通过后才保存开启状态。

## 旧版 PawnIO 的升级

> [!IMPORTANT]
> 升级前，退出使用 PawnIO 的其他硬件监控程序。

官方 2.0 旧版使用不同的安装方式。Argus 识别已知的官方签名驱动文件，确认默认安装位置与卸载信息后，先校验新旧安装包，再通过旧版官方卸载程序移除旧版、安装新版。

旧服务未移除或安装程序要求重启时，重启 Windows 后再次开启。安装信息不一致时，Argus 停止自动迁移；可通过 Windows 的应用管理卸载旧版，再从 PawnIO 官网安装新版。

## 驱动与设备的故障处理

PawnIO 设备的状态异常时，按以下方式处理：

- 设备在 Windows 中被禁用时，先在设备管理器中启用，再重试。
- 设备配置标记为待重启时，先重启 Windows，再次开启开关。
- 设备已被删除（如在设备管理器中卸载了该设备）而驱动仍在时，驱动无法加载，内核传感器显示驱动不可用。关闭后重新开启开关，Argus 会以官方 2.2.0 安装程序先卸载再安装 PawnIO，恢复该设备；已安装的版本高于 2.2.0 时不降级，须从 PawnIO 官网重新安装。

## 传感器读数

性能页的 CPU 视图在**内部传感器**卡片中按功耗、电压、频率、温度分组显示读数，在**每核读数**卡片中提供每个物理核心的温度、有效频率、功耗、VID 与活跃比例。

各平台的读数与标注：

- Ryzen 7000/9000 的 SVI3 供电电压与 VID 分开标注。
- Intel 提供 PL1／PL2、温度余量、Ring 频率与限制状态，当前状态与硬件历史记录分开显示。
- Windows 空闲状态与 AMD SMU 驻留比例分别标注。
- 支持的主板还显示风扇通道转速，以及已匹配的电源轨、主板与供电温度。

支持的硬件范围见[硬件数据](../hardware-data.md#消费级硬件兼容范围)。

## 关闭与卸载

关闭开关后，Argus 停止请求内核读数，Windows 自带采集继续工作；服务在 65 秒无读取后释放模块。

关闭开关或卸载 Argus 不卸载共享的 PawnIO 驱动，可通过 Windows 的应用管理单独卸载。

## Comet Lake 核显

Comet Lake S/H 核显的温度、频率、VID、GT／媒体活动率及限制状态同样由此开关控制，读数显示在对应 GPU 页面，VID 表示请求电压。GPU 页面显示内核传感器状态，未启用或读取失败时提供说明。

核心频率与共享逻辑频率直接显示数值，包括有效的 0 MHz；最低／最高工作频率是能力范围，另行列出。共享内存频率由控制器配置按标称参考换算，DDR 传输率约为其两倍。

核显 RAPL 功耗优先使用服务直接读取的有效 PP1 能量差分，缺失时回退 Windows 计数器，不在 CPU 页面重复显示。

安装新版应用时会刷新已安装的特权服务，未安装服务的系统仍需先完成安装。

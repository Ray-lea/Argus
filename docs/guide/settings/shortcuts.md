# 快捷键

本页说明设置页**快捷键**分组的内容：显示或隐藏 Argus 的全局快捷键，以及完整的快捷键说明。全局快捷键背后的实测与取舍见[全局快捷键](../../design/hotkey.md)。

## 全局快捷键

显示或隐藏 Argus 的全局快捷键默认为 Ctrl+Alt+Esc，在大多数程序中都能使用。

- 右侧的开关可停用快捷键。停用时保留当前组合，重新开启即恢复。
- **恢复默认**可改回 Ctrl+Alt+Esc。
- 组合已被其他程序占用时，卡片下方显示原因和**重试**按钮。占用的程序退出后，再次显示 Argus 窗口时也会自动重试。

更改组合的步骤：

1. 单击**更改**。录制区显示当前组合。
2. 按住修饰键，再按下并松开主键。组合随即保存并启用。

录制期间，按 Esc 或单击**取消**结束录制，单独按 Backspace 停用快捷键。切换或隐藏窗口、连续 15 秒无输入时，录制结束并保留原设置。

## 组合键的规则

组合须包含 Ctrl、Alt 或 Win 之一和一个普通键。F13–F24 可以单独使用，Shift+F1–F9 和 Shift+F11 需确认后才保存。

以下是 Windows 全局快捷键的规则：

- 修饰键不区分左右，左 Ctrl 与右 Ctrl 等效。
- 仅由修饰键组成的组合不能使用，例如左 Ctrl+右 Ctrl+左 Alt。
- 只能有一个普通键，两个普通键不能组合，例如小键盘的 + 和 -。
- 须先按住修饰键，再按普通键。

修饰键按 Ctrl、Alt、Shift、Win 匹配，左右两侧视为同一个键。CapsLock、NumLock 和 ScrollLock 属于锁定键。

## 冲突提示与键盘布局

录制时的冲突提示与按键映射如下：

- 系统保留组合和 Ctrl+C、Ctrl+V 等常用编辑键会在录制时提示冲突，部分常用组合会在保存前要求确认。
- Ctrl+Shift+Esc 的设置入口在**设置 → 权限 → 替换系统任务管理器**。
- 带 Ctrl 的 Pause 会被 Windows 识别为 Break，应选择其他主键。
- 主键和可打印键名按当前 Windows 键盘布局映射，支持西里尔字母及 AZERTY、QWERTZ、日文布局中的符号键。更换界面语言保持已保存的组合。
- AltGr 字符输入与 Ctrl+Alt 组合可能共享 Windows 映射，可选择 Ctrl+Shift 等组合减少冲突。

## 快捷键说明

**快捷键说明**中的**查看快捷键**打开完整的按键说明，包含当前配置的全局快捷键、页面切换、临时暂停、进程操作与历史曲线操作。

展开**列表获得焦点时**等分组时，弹窗向下伸展，上边缘保持不动；超出窗口可容纳的高度后，在弹窗内滚动。按 Esc 可关闭弹窗，关闭后焦点回到打开按钮。

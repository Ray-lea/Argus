# 动画

本页说明设置页**动画**分组的设置项：窗口过渡动画、界面动画、曲线动画与硬件加速的默认值和作用。

本分组的设置项如下：

| 设置项 | 默认值 | 作用 |
| --- | --- | --- |
| 窗口过渡动画 | 跟随 Windows 的**动画效果**设置 | 窗口显示、隐藏、最小化与还原时的淡入淡出 |
| 界面动画 | 跟随 Windows 的**动画效果**设置 | 页面与对话框过渡、选中标记滑动、点阵动画与图标动效 |
| 曲线动画 | 流畅；Windows 关闭了动画效果时为关闭 | 曲线的动画档位：流畅、均衡、省电、关闭 |
| 硬件加速 | 开启 | 由 GPU 绘制界面，关闭后改由 CPU 绘制 |

三项动画设置互相独立，修改后立即生效并保存；**硬件加速**不改变动画设置。

## 窗口过渡动画与界面动画

**窗口过渡动画**控制 Argus 窗口显示、隐藏、最小化与还原时的淡入淡出。最大化与从最大化还原始终使用 Windows 的窗口动画。关闭后，由 Windows 或其他窗口管理软件处理窗口过渡。

使用其他软件管理窗口动画时，可关闭**窗口过渡动画**，保留界面与曲线动画。升级时，新的窗口开关继承此前的界面动画状态，此后分别保存。

**界面动画**控制页面与对话框过渡、选中标记滑动、关于页与引导中的点阵动画，以及图标的动效：

- 指针移到按钮、导航项或设置分组上时，其图标播放一次短动效，如齿轮转动、下载箭头下移。
- 按钮换用另一图标时，例如暂停与继续，新图标弹入。

## 曲线动画

**曲线动画**分为流畅、均衡、省电、关闭四档。图表上限变化时的过渡与上限标签的淡入也随此设置，关闭时直接切换。各档的区别与开销见[曲线动画](../../design/charts.md)。

## 硬件加速

**硬件加速**开启时由 GPU 绘制界面。关闭后改由 CPU 绘制（Windows 自带的软件渲染器 WARP），Argus 不再占用 GPU；CPU 占用随之升高，可同时调低**曲线动画**。切换后立即生效，无需重新启动。

关闭硬件加速适用于以下情况：

- GPU 满载时 Argus 界面卡顿。
- 游戏、渲染、训练等任务运行期间，需要避免 Argus 占用 GPU。

窗口最小化或隐藏到托盘时界面停止绘制，两种绘制方式都不产生绘制开销；**硬件加速**影响的是窗口可见时的开销。

关闭后窗口画面仍由 Windows 合成到屏幕，曲线的滚动也交给 Windows 合成，CPU 主要在每次采样时重绘曲线。托盘的悬停卡片与快捷面板同样由 CPU 绘制。

未检测到可用 GPU 的电脑始终由 CPU 绘制，此开关不改变绘制方式。

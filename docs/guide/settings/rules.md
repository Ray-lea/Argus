# 规则

规则在程序启动时自动设置优先级或效率模式。本页说明设置页**规则**分组中规则的新建、组成、匹配方式与执行结果。

在分组顶部输入程序名（例如 `chrome.exe`）并单击**添加**，即可新建规则；也可在进程列表中右键单击进程，选择**添加规则**，按该进程的优先级和效率模式创建规则。

每条规则包括：

- **程序名**：不区分大小写，同名的多个进程都会套用。程序正在运行时，规则前面显示它的图标。
- **优先级**：不改变，或实时、高、高于正常、正常、低于正常、低之一。
- **效率模式**：不改变、开启或关闭。
- **启用开关**：决定是否应用该规则。停用时保存规则配置。

规则保存后先应用于匹配的现有进程，之后在程序启动时再次应用。规则由后台线程处理，Argus 隐藏在托盘时也会执行；慢请求期间保留最新进程列表。

规则按可执行文件名匹配。多个应用共用同一宿主程序，或不同安装路径存在同名程序时，会提示本条规则的作用范围。

每条规则下方显示已应用、权限不足和执行失败的进程数；保存规则或权限来源改变时重新计数。安装、停止或重启特权服务后，已有进程会重新检查。

请求发出后丢失回复时，不自动重复操作；可检查服务状态后重新保存规则来重试。

# 更新

本页说明设置页**更新**分组的设置项、新版本的提示与安装过程、更新后显示的内容与 Star 提醒，以及从旧版升级时的数据处理。

Argus 从 GitHub Releases 获取新版本。自动线路支持 `update.argustask.com` 上的官方清单和 `dl.argustask.com` 上的版本化安装包。

本分组包含以下设置项：

- **自动检查更新**：默认开启。启动约 1 分钟后检查一次，此后每天检查一次；检查失败时 6 小时后重试。关闭后仅在单击**检查更新**时检查。
- **有新版本时发送通知**：默认开启。窗口隐藏在托盘或未处于前台时，以 Windows 通知提示新版本，每个版本一次；关闭后仅在窗口显示时于右下角提示。
- **更新后显示更新内容**：默认开启。更新完成后首次打开窗口时显示新版本的更新内容，每个版本仅显示一次；关闭后改为右下角的提示。同一行的**查看本版本更新**可随时打开当前版本的更新内容。
- **更新通道**：**稳定版**（默认）仅接收正式版本。**测试版**同时接收预发布版本，如 `1.2.0-beta.1`。切回稳定版后，下一次更新须高于已安装版本。
- **下载线路**：**自动**（默认，依次尝试 GitHub、Argus 官方镜像和加速代理）、**仅连接 GitHub** 或**仅使用加速代理**。
- **加速代理**：默认为 gh-proxy.com，另内置 gh-proxy.org、ghfast.top，也可填写自定义代理，即添加在 GitHub 地址之前的前缀，须使用 https。
- **Star 提醒**：默认开启。每天至多在窗口右下角显示一次卡片，邀请在 GitHub 上为 Argus 点亮 Star。

## 版本类型

**更新**分组中，当前版本后的类型来自实际程序：开发版独立标识，本地测试构建和预发布版本显示为测试版，正式发行显示为稳定版。更新通道决定后续检查的版本来源，切换通道会保留当前程序的版本类型。

安装版支持应用内更新，包括通过管理员启动或任务管理器替换打开的副本。免安装版发现新版本时显示更新内容，单击**前往下载**手动替换程序。开发构建跳过更新检查。

## 加速代理与签名校验

> [!NOTE]
> 第三方加速代理可获知本机 IP 地址和请求的文件。

Argus 核验安装包签名及绑定的版本号，仅安装高于当前版本且校验通过的软件包。更新说明也须通过签名与版本校验才会显示。

## 新版本的提示

发现新版本后，Argus 在后台下载；下载完成并通过签名校验后，在状态栏、窗口右下角或 Windows 通知以及托盘中提示。

### 状态栏的版本号

状态栏左端的版本号改为强调色的“安装 x.y.z”，各页面均可见，指针悬停时显示说明。下载期间该处显示下载进度。免安装版不自动下载，发现新版本时显示“新版本 x.y.z”。

右键单击该处可选择**此版本不再提醒**，之后仅在导航栏的**设置**和设置页的**更新**分组上显示提示点。

### 右下角提示与 Windows 通知

窗口处于前台时，右下角提示一次“Argus x.y.z 已准备就绪”。窗口隐藏在托盘或未处于前台时，改为发送一条 Windows 通知，单击通知显示窗口并打开更新对话框。

关闭**有新版本时发送通知**后，窗口显示时在右下角提示，隐藏在托盘时留到下次显示窗口时提示。首次启动引导打开时，在引导结束后提示。

每个版本仅提示一次，选择**此版本不再提醒**后不再提示；启动时不弹出对话框。

通知由 Argus 的托盘图标发出，以 Argus 的名称和图标显示，可在 Windows 的**设置 → 系统 → 通知**中单独关闭；免打扰期间通知直接进入通知中心。Argus 退出后，单击通知中心里留下的旧通知不再打开 Argus。

### 托盘的提示

托盘图标显示强调色圆点，悬停卡片标出新版本号，快捷面板顶部显示更新入口，托盘菜单增加**更新到 x.y.z**。关闭悬停卡片时，系统提示增加“新版本 x.y.z 已就绪”。

## 更新对话框

发现新版本后，**更新**分组的状态卡片显示**查看更新内容**按钮。单击该按钮、状态栏的更新标记、快捷面板的**更新**或托盘菜单项，可打开更新对话框；首次启动引导打开时，对话框在引导结束后打开。

对话框中可阅读当前版本与新版本的差异，查看安装包大小、签名校验结果并安装。每个版本的条目按新功能、修复、性能、升级提示等类别分组，以颜色区分并标出条数，新功能以卡片列出。

跨越多个版本时，列表上方汇总各类条目的数量。最新版本默认展开，跳过的版本可单击展开；汇总右侧的**展开所有**、**折叠所有**可一次展开或折叠全部版本。更新后显示的更新内容中，各版本都默认展开，均可单击折叠。

对话框打开时各部分依次淡入，版本展开与折叠时高度平滑过渡，指针移到新功能卡片或条目上时逐渐高亮；关闭**界面动画**后直接显示。

弹窗的高度随窗口伸展，窗口越高显示的内容越多，超出时在内容区内滚动；下载进度变化时保留展开状态和阅读位置。

更新内容按界面语言显示对应的译文。缺少该语言的译文时，繁体中文界面显示简体中文，其他语言显示英文；英文也缺少时显示中文。

## 安装更新

单击**重启并更新**开始安装，需要管理员授权。安装期间 Argus 将退出，安装程序仅显示进度条；完成后自动以标准权限重新启动 Argus，并回到原来的页面。从托盘隐藏状态开始的更新，重新启动后仍保留在托盘。取消管理员授权时不安装，更新仍可稍后安装。

已安装特权服务时，安装程序在同一次管理员授权中一并更新服务。启用了任务管理器替换时，替换保持开启，所用的界面和启动器也随之更新到新版本。安装程序未能更新服务时，更新后首次启动时询问是否更新服务，见[权限](permissions.md)。

安装包缓存在 `%LOCALAPPDATA%\dev.argus.taskmanager\updates`。重新启动时校验缓存，通过后可直接安装。安装前再次验签，文件已修改或删除时重新下载，安装完成后清理缓存。

程序文件被其他软件占用时，安装器会显示占用进程、错误码及诊断日志路径。退出相关程序后，单击**重试**继续安装；单击**取消**可退出安装并保留旧程序。

游戏或安全软件持续占用时，可正常退出相关程序，或保存工作并重启电脑后再安装。

诊断日志保存在安装账户的临时目录中，可按弹窗给出的路径收集。使用另一管理员账户授权时，原桌面账户也可读取本次安装日志。

## 更新后显示的内容

更新后首次打开窗口时，Argus 显示更新前后的版本号及其间的变化。托盘启动、首次引导或任务管理器替换入口会将说明延后到合适的显示时机。关闭**更新后显示更新内容**后，右下角改为简短提示。

需要重读时，单击**查看本版本更新**、关于页的**更新内容**或状态栏左端的版本号。

## Star 提醒

**Star 提醒**的卡片在窗口显示约 5 秒后出现，约 30 秒后自动收起，指针停留在卡片上时保持显示。日期按本机时间判断，显示卡片不访问网络。

正显示对话框时，卡片延后到对话框关闭之后。以下情况下，当次运行不显示卡片：

- 打开了首次启动引导，或出现了[免安装版的提示](../README.md#免安装版的提示)。
- 由任务管理器替换启动，例如按 Ctrl+Shift+Esc。当天的提醒留到之后的正常启动。

卡片上的操作：

- **前往 GitHub** 在浏览器中打开 Argus 的仓库页面，并关闭 **Star 提醒**。
- **不再提醒**关闭 **Star 提醒**，右下角随即提示可在设置中重新开启；提示中的**打开设置**定位到此项。
- 右上角的关闭按钮仅收起当天的卡片。

## 旧版升级与数据

从 v0.3.3／v0.3.4 升级可继承独立保存的界面偏好。从 v0.3.2 及更早版本直接升级到 v0.4.0 时，仅保存在旧 WebView2 缓存中的界面偏好（如布局、行备注与置顶标记）恢复默认值，需要重新设置。应用设置、历史文件与日志保留。

从 v0.5.0 及更早版本升级后，历史页从默认的最近 5 分钟开始显示，不沿用旧版保存的时间范围。

升级后，Argus 启动时在后台清理本地数据目录中的 `EBWebView`、`WebView2` 旧版浏览器数据。仍被占用的文件将在后续启动时继续清理。实现见[原生宿主](../../architecture/host.md)。

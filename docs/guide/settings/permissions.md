# 权限

本页说明设置页**权限**分组中管理员运行与特权服务的设置。同一分组中的内核传感器与任务管理器替换见[内核传感器](kernel-sensors.md)与[替换系统任务管理器](task-manager.md)。

## 管理员运行

**管理员运行**适用于发布构建，默认关闭。

> [!IMPORTANT]
> 管理员运行要求当前 Windows 账户属于管理员组。标准账户可通过[特权服务](#特权服务)执行该节列出的操作。

开启**允许以管理员身份运行**并完成一次 Windows 授权后，以下入口均遵循管理员运行策略：

- 登录启动
- 普通快捷方式与固定图标
- Ctrl+Shift+Esc 和任务栏的**任务管理器**入口，须先启用系统任务管理器替换

常驻快捷键显示当前管理员实例，不提供未运行时的全局启动功能。

卡片分别显示授权状态和当前进程权限。切换权限会重启 Argus，并保留设置和历史；在首次启动引导中切换时，引导完成或跳过后才切换。撤销授权会保留登录启动偏好。

对于关闭 UAC 的管理员账户，进程使用该账户的默认权限。管理员启动授权失效时，Argus 以普通权限打开，并在此处提供修复入口。

## 程序目录的权限

安装后修改 Program Files 或 Argus 运行目录的所有者、写入权限，可能使管理员启动或特权服务失效。此时仍可撤销管理员启动授权、恢复 Windows 任务管理器或卸载服务。

撤销后普通权限窗口启动失败时，当前窗口会保留，并提示退出后重新打开。重新启用相关能力前，需由管理员恢复相应目录的安全权限；Argus 不自动修改系统目录权限。

## 特权服务

特权服务需手动安装，随 Windows 启动。单击**安装并启用**，阅读授权范围并完成 Windows 管理员确认后，后台服务可执行以下操作：

- 进程管理：
  - 结束进程或进程树，仍拦截系统关键进程。
  - 设置进程优先级、I/O 优先级与内存优先级，开启或关闭效率模式，暂停或恢复进程。
  - 执行自动规则中的优先级与效率模式操作。
- 采集与查询：
  - 本地采集不可用时，采集每进程网络流量。
  - 系统未通过普通进程查询提供计数时，采集每进程磁盘读写。
  - 只读查询磁盘详情中的 ATA／SATA、USB-SAT 和 SCSI／SAS 身份与 SMART 健康信息。
  - 按句柄查询文件及目录占用，包括进程当前目录。
- 服务与连接：
  - 启动、停止、重启、删除 Windows 服务，以及修改启动类型。
  - 断开 IPv4 TCP 连接。

一次安装只授权一个账户；另一个账户需先经管理员授权卸载，再安装。

### 授权范围

> [!CAUTION]
> 只为受信任的账户安装特权服务。授权范围是整台电脑，当前账户下的普通桌面程序都可调用服务执行上述操作。

这些操作包括管理其他用户的进程、修改 Windows 服务、查询进程句柄和资源计数。系统关键进程另有保护，服务拒绝受限令牌和 AppContainer 调用。

### 免安装版的风险

> [!CAUTION]
> 需要特权服务时，建议使用安装版。使用免安装版时，把它放在只有管理员能写入的文件夹中。

安装或更新特权服务、启用任务管理器替换、安装或启动 PawnIO 时，Argus 会以管理员身份运行自身；安装特权服务还会把自身复制为以 SYSTEM 身份运行的服务程序。

安装版默认位于 Program Files。安装程序检查实际安装文件夹及其上层目录的权限，并为新建的安装文件夹设置仅管理员可修改的权限。所选位置无法这样保护时（例如其他账户可以重命名上层文件夹，或位于 U 盘、网络位置），安装程序在安装前说明原因，可改选其他位置。

免安装版则可以放在任意位置。它所在的文件夹允许标准用户写入时（例如“下载”文件夹或桌面），本机已有的恶意程序就可能在这之前替换 `argus.exe`，借用户的管理员授权获得 SYSTEM 权限。

### 服务的启动与更新

服务停止时可单击**启动服务**。协议版本不兼容时，单击**更新服务**替换受保护目录中的服务程序。连接恢复前，手动操作和规则按 Argus 自身权限执行，依赖服务的读数暂缺。

命令在执行中断线或超时时，先刷新对应页面确认结果，再决定是否重试。

### 已损坏的服务

状态显示“已损坏”时，服务仍在 Windows 中注册，但服务程序文件、授权记录或服务目录已丢失，例如更新或卸载期间断电、蓝屏。该服务无法启动，Windows 每次启动时都会记录一次服务启动失败。

卡片写明缺少的项目。Argus 启动后读到该状态时，在右下角提示一次。

可执行的操作如下，均需要管理员授权：

- **修复服务**：重新安装服务文件并启动服务。授权记录丢失时，修复先显示与安装相同的授权说明；确认后把服务授权给当前账户，已启用的任务管理器替换先恢复为 Windows 任务管理器。
- **卸载**：授权记录指向另一个账户时，仅提供此项。

### 卸载服务

单击**卸载**会移除服务，Argus 继续以当前进程权限运行。

卸载后状态显示“正在移除”时，另有程序仍打开着该服务，例如**服务**管理单元。服务文件已删除，Windows 在这些程序关闭后移除服务注册，重新启动 Windows 也会完成移除；期间不能重新安装。

从 Windows **设置 → 应用**卸载 Argus 时，可选择一并卸载或保留服务。免安装程序与服务副本各自独立；删除免安装程序前，可在此处卸载已安装的服务。

### 服务注册被删除

安全软件或注册表清理工具可能把服务的注册从注册表中删除。此后服务无法启动，Windows 在重新启动前仍保留它的名称。

Argus 将这种情况显示为“未安装”，单击**安装并启用**可直接重新安装，无需先重新启动 Windows。安装前建议在安全软件中核对清除记录，并按[信任列表的路径](task-manager.md#信任列表的路径)把 Argus 加入信任列表。

### 自身权限与权限标记

详细信息、启动项修改，以及文件占用查询中的 Restart Manager 部分，仍使用 Argus 本身的权限。句柄查询可使用服务；服务不可用时，以当前账户权限降级查询。受保护的系统进程可能拒绝特权服务的操作。

服务已连接时，状态栏右下角的权限标记显示“特权服务”，界面进程本身仍以标准权限运行。服务停止或断开后约半分钟内，标记恢复为“标准权限”。

### 每进程网络流量

网络流量在后台异步读取，通常比本地采样晚一个刷新周期。服务断线或采集不可用时隐藏网络列；恢复后先建立计数基线，避免把积累的字节显示成瞬时峰值。没有客户端读取 15 秒后，服务会关闭 ETW 会话，再次读取时重新启动。

# 连接页

连接页列出 TCP 与 UDP 端点及其所属进程，可按端口搜索、按状态与协议筛选、断开 IPv4 TCP 连接，并可按应用分组。

连接可添加备注或置顶，见[备注与置顶](README.md#备注与置顶)；列表的复制方式见[复制](processes.md#复制)，文字列的排序规则见[排序规则](processes.md#排序规则)。

## 刷新与搜索

页面可见时，连接页每 2 秒刷新 TCP / UDP 端点及其所属进程。搜索框可按端口精确搜索。

## 筛选连接

单击**状态**列表头右端的 ⌄，可选择**全部**、**监听**或**已连接**。**协议**列另有协议筛选，可选**全部**、**TCP**、**TCPv6**、**UDP** 或 **UDPv6**，与状态筛选同时生效。筛选生效时的显示与服务页相同，见[筛选服务](services.md#筛选服务)。

## 转到进程与断开连接

双击连接可转到所属进程。连接页支持断开 IPv4 TCP 连接。

## 隐藏无所属进程的记录

连接页的**隐藏系统进程**按钮与进程页相同，见[隐藏系统进程](processes.md#隐藏系统进程)。开启后，连接页还会过滤 PID 为 0 的“无所属进程”记录。

这类记录常见于 TCP 关闭后的 `TimeWait` 阶段，等待协议回收；UDP 的 PID 为 0 表示系统未提供归属。它们没有可供定位或结束的用户进程。其他 PID 暂时缺少身份信息时，记录保留显示。

## 按应用分组

连接页默认显示**列表**。切换到**按应用**后，同一可执行文件路径的连接归入一组，路径缺失时按文件名分组。无所属进程和所属进程已退出的连接分别归组。

分组行显示应用名称与连接数。单击箭头、双击分组行或按 Enter 可展开或折叠，也可用左右方向键操作。只有一条连接时，直接显示该连接。

筛选和排序先于分组生效，搜索时自动展开匹配结果。视图与手动展开的分组在重启后保留。

分组内的连接由同一进程持有时，可从分组行的右键菜单转到或结束该进程。备注与置顶作用于单条连接。

# 服务与启动项

服务页列出 Windows 服务，可启动、停止服务并修改启动类型；启动页列出登录时启动的程序，可启用或禁用。本页还说明两页的列宽与删除操作。

两页的条目可添加备注或置顶，见[备注与置顶](README.md#备注与置顶)；列表的复制方式见[复制](processes.md#复制)，文字列的排序规则见[排序规则](processes.md#排序规则)。

## 服务页

启动、停止与重新启动所选服务的按钮位于[页面栏](README.md#页面栏)。服务主机进程承载了哪些服务，可在进程页查看，见[按应用](processes.md#按应用)。

### 修改启动类型

服务页可修改服务的启动类型。Windows 拒绝更改应用包服务的启动类型时，可确认将设置写入注册表；受 Windows 启动保护的服务除外。需要重启时，列表会标注。

### 筛选服务

服务页的筛选位于列表**状态**列的表头：单击表头右端的 ⌄，可选择**全部**、**正在运行**或**已停止**。筛选生效时，该按钮显示为强调色的漏斗图标；单击表头的其余部分，仍按该列排序。

## 启动页

启动页列出注册表 Run 项、启动文件夹中的项目，以及当前账户安装的应用包启动任务。页面可见时每 10 秒刷新，切回页面后重新读取。

同一应用的多个启动任务分别显示。名称优先采用程序描述或应用包的本地化名称；原始项目名仍可搜索，并显示在名称的悬停提示中。启动页会标出已失效的项目。

单击开关或使用右键菜单，可启用或禁用下次登录时启动的项目。启动页与系统任务管理器使用同一个开关，状态共用。

应用包启动任务可在标准权限下更改；“所有用户”的传统启动项仍需要管理员权限。应用不允许手动更改或暂时无法读取状态时，开关被禁用，并说明原因。

启用应用包启动任务后，下次登录时即可启动。系统任务管理器若仍显示旧状态，可重新打开核对。

## 列宽

服务页与启动页的各列按内容取宽度，最后一列延伸至表格右侧，不留空白：服务页为**描述**，启动页为**命令**。

**PID**、**状态**、**启动类型**、**位置**等列按内容收紧。**名称**、**服务名称**与**发布者**按完整列表中多数项目所需的宽度显示，少数过长的内容以省略号截断，悬停可查看全文。列宽按载入的完整列表计算，搜索与筛选不改变列宽。

窗口变窄时，名称等文本列先收窄，使最后一列保留约三分之一的表格宽度。窗口足够宽、最后一列已能完整显示时，文本列加宽至完整显示全部内容。

拖动列边界可调整该列宽度，最后一列随之伸缩：拉窄的列让出的宽度归最后一列；加宽时，由最后一列和其他文本列让出宽度，直到它们都到最小宽度，表格不会因此横向滚动。

调整后的宽度在重启后保留；窗口变窄到放不下时，调整过的列也按比例让出宽度。双击列边界，该列恢复按内容取宽度。

## 删除服务与启动项

服务页与启动页的右键菜单提供**删除**，在确认框中确认后执行。

> [!CAUTION]
> 删除前确认服务的用途：删除服务会从系统中删除该服务及其配置，服务的程序文件保留。

删除的范围与条件如下：

- **服务**：服务尚未停止，或程序位于 Windows 文件夹、可能属于 Windows 时，确认框另有提示。尚未停止或仍被其他程序使用的服务先标记为删除，由 Windows 在其停止并释放后移除。Argus 自己的特权服务只能在设置中卸载。
- **启动项**：注册表中的项删除对应的值，启动文件夹中的文件移到回收站，并一并清除其启用状态记录；所指向的程序保留。应用包启动任务属于其应用，只能禁用。

删除服务需要特权服务或以管理员身份运行 Argus；删除“所有用户”的启动项需要以管理员身份运行 Argus。

删除失败时，通知说明原因，如没有权限、已不存在或特权服务版本不兼容；`argus.log` 记录失败的步骤与错误码。

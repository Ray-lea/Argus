# 常驻、托盘与快捷键

- 默认关闭窗口时留在托盘。单击托盘图标或按 **Ctrl+Alt+Esc** 显示 / 隐藏窗口；快捷键可在[设置](settings.md#快捷键)中更改或停用。
- 托盘提示实时显示 CPU 与内存占用；托盘菜单有“显示 Argus”和“退出”，新版本就绪时另有“更新到 x.y.z…”，见[设置 → 更新](settings.md#更新)。
- 窗口隐藏时 WebView2 停止渲染并降低内存占用，按“后台常驻时的刷新间隔”（默认 5 秒）采样，历史记录与规则照常进行，可快速重新打开；窗口最小化时按“最小化时的刷新间隔”（默认 5 秒）采样。两项间隔可在[设置 → 数据与历史](settings.md#数据与历史)中分别设置，长于 5 秒时历史记录随之变稀。
- 只允许单个实例：再次启动 Argus 会唤出已运行的窗口。
- 设置中可开启登录 Windows 时启动：带 `--hidden` 参数启动，静默进入托盘。
- 开启[管理员运行](settings.md#权限)后，上述入口遵循同一授权，登录启动仍保持隐藏；该授权独立于特权服务。

隐藏在托盘时的资源占用见[性能基线](../development/performance.md)。

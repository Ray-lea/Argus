# 常驻、托盘与快捷键

- 默认关闭窗口时留在托盘。单击托盘图标或按 **Ctrl+Alt+Esc** 显示 / 隐藏窗口：单击时窗口未被其他窗口遮挡即隐藏，按快捷键时窗口为当前使用的窗口才隐藏；窗口被遮挡、已最小化或位于其他虚拟桌面时显示到最前；快捷键可在[设置](settings.md#快捷键)中更改或停用。托盘图标获得键盘焦点时，按 Enter 或空格同样显示 / 隐藏窗口。
- 托盘相关的设置集中在[组件](#组件页)页（Ctrl+7）。
- 隐藏到托盘后，界面暂停绘制，采样、历史记录和规则继续运行。托盘与最小化状态各有独立的采样间隔，均默认为 5 秒。间隔超过 5 秒时，历史记录按该间隔写入。详见[数据与历史](settings.md#数据与历史)。
- 隐藏或最小化默认满 10 分钟后，Argus 释放图表图像并归还未使用的内存，再次显示窗口时重绘图表。时长可在[数据与历史](settings.md#数据与历史)中调整或关闭。
- 再次启动同一实例时会显示已有窗口。
- 设置中可开启登录 Windows 时启动：带 `--hidden` 参数启动，静默进入托盘。
- 开启[管理员运行](settings.md#权限)后，上述入口遵循同一授权，登录启动仍保持隐藏；该授权独立于特权服务。

## 托盘图标

托盘图标默认为“走势”：Argus 标志中的每列点对应一次采样，按当时的 CPU 占用由下往上点亮，最右一列为最新一次，以强调色显示。也可改为“占比”，按当前占用点亮相应数量的点（图标为 16–24 px 时共 25 个点，每点代表 4%；32 px 时为 100 个点，每点代表 1%）；或改为显示占用百分比的“数字”，或改回应用图标。占用达到 80% 时，最新一列、已点亮的点与数字变为琥珀色。标志与数字随任务栏的深浅色切换为白色或黑色，与系统图标一致。图标按当前刷新间隔更新：窗口显示时按“刷新频率”，隐藏到托盘时按“后台常驻时的刷新间隔”；走势每次更新左移一列。

新版本就绪时，图标上显示强调色圆点：走势在标志的标题栏右侧，占比替换右上角的一个点，数字在右上角，应用图标在右下角。

托盘图标在同一程序路径下沿用稳定标识，Windows 可按同一图标保留任务栏或折叠区的显示位置。首次从旧版标识迁移时，可能需要重新将图标拖出折叠区一次。

## 悬停卡片与快捷面板

指针在托盘图标上停留片刻后显示悬停卡片（系统判定悬停后再等待 0.4 秒，指针掠过图标时不显示）：CPU、内存与 GPU 的占用和网络的接收、发送速率，以及单击与右键单击的作用。关闭“悬停卡片”后改为系统提示，显示 CPU 与内存占用。

右键单击托盘图标（或在图标获得焦点时按菜单键）默认打开快捷面板，位于托盘图标旁、任务栏上方：

- 顶部为版本号；有新版本时显示更新入口，单击“更新”打开更新对话框。
- CPU、内存、GPU 与网络四块读数，各带最近 60 次采样的曲线。单击某一块打开性能页的对应设备。
- CPU 占用最高的三个进程，单击在进程页中定位该进程。
- 底部为“打开 Argus”、暂停 / 继续刷新、托盘设置（打开组件页）与退出。

单击面板以外的位置或按 Esc 关闭面板；再次右键单击托盘图标也会关闭它。面板关闭后可立即再次右键单击打开，不必等待。托盘图标位于“显示隐藏的图标”区域时，卡片与面板显示在该区域上方，不遮挡它；打开面板、指针移入面板或单击面板中的按钮时，隐藏的图标保持展开，单击其他位置或按 Esc 时两者一同关闭。“右键单击托盘图标”可改为“菜单”，只列出“显示 Argus”“更新到 x.y.z…”（新版本就绪时）与“退出”。

悬停卡片或快捷面板打开期间，采样按窗口显示时的“刷新频率”进行，读数与曲线随之更新；关闭后恢复后台常驻时的间隔。卡片与面板跟随界面主题，开启“窗口动画”且 Windows 动画效果开启时淡入淡出。

## 桌面监控

桌面监控以小窗口在桌面上显示所选读数，默认关闭，在[组件页](#组件页)开启。组件页的“显示的读数”像一张表：按设备类别分块，每块中左列是设备及区分它的信息，右侧是该设备可选的读数。桌面监控与任务栏监控按表中的顺序显示，默认顺序如下：

| 设备 | 读数 |
|---|---|
| CPU | 利用率（默认）、温度、频率、功耗 |
| 内存 | 占比（默认）、用量（GB） |
| GPU | 利用率（默认）、温度、显存占比、频率、功耗、风扇转速 |
| 磁盘 | 读写速度（默认）、活动时间、温度 |
| 网络 | 收发速率（默认） |
| 其他 | 电池电量、正常运行时间 |

检测到多块显卡、磁盘或多个网卡时，表中为每个设备单独列出一行，可分别选择：

- 磁盘列出盘符（没有盘符时为“磁盘 N”）、型号与容量，网卡列出连接名称与适配器型号，显卡列出名称与专用显存。
- 磁盘与网卡的第一行为“磁盘智能显示”“全部网卡”：读写速度与收发速率为合计，磁盘活动时间与温度取最高的一块。只有一块磁盘或一个网卡时只显示这一行。
- 显卡的第一行为默认显卡（专用显存最大的一块），未指定显卡的读数取它。
- 所选设备按型号、名称记住，重新启动或重新插拔后仍对应同一设备；设备断开时读数显示破折号，表中保留一行“未连接”的设备以便取消选择。
- 指定设备的读数在桌面监控上以设备名开头（如“C: 温度”“UHD Graphics 770 利用率”），速率行以设备名为标题；在任务栏上以盘符、连接名称或 GPU1、GPU2 区分。

两个监控的顺序各自调整，松开后立即显示并保存：

- 按住类别左侧的手柄或设备名称上下拖动，可调整类别的顺序，如把磁盘排在 CPU 之前。拖动中的类别跟随指针，原位置留出浅色空位，其余类别随之让位。
- 拖动读数可调整它在本类别中的顺序，同一类别的各设备共用这一顺序；单击读数仍为勾选或取消。每组的第一项读数在桌面监控上以大号数值显示（曲线样式为该读数的曲线），如把功耗排在利用率之前，CPU 组即以功耗为首。
- 设备的顺序不变：默认设备在前，其余按系统报告的顺序排列。

同一设备的连续读数合为一组，组名只写一次，组内其余读数以组件页的选项名（温度、频率、功耗、用量等）标注。显示方式分为面板与横条，在组件页的“显示方式”中选择：

- **面板**（默认）按组竖排，有三种样式，在组件页的“样式”中以卡片按所选读数预览，单击即切换：
  - **列表**（默认）：每组首行为组名、进度条与数值；组内其余带刻度的读数（占比、温度、内存用量）各占一行进度条，同组的进度条左右对齐；频率、功耗等没有刻度的读数排在下方三列。
  - **曲线**：左侧为组名与数值，右侧为该组首项读数最近一分钟的曲线，曲线占满整组的高度，底边为 0、顶边为满值，磁盘与网络画出读写（收发）两条。
  - **仪表**：每组一块磁贴，两列排布，首项带刻度时画成圆环，右侧为组名与数值，其余读数排在磁贴下方；最后一行只剩一块时占满整行。
- 列表与曲线样式可在“分组”中选择组与组之间的区分方式：卡片（默认）、色条或分隔线。
- **横条**把所有读数排成一行，适合放在屏幕边缘；组之间以竖线分隔，宽于显示器工作区时在组之间换行。

占比、温度与电量带进度条（仪表样式为圆环，横条为竖向小条），频率、功耗、转速与运行时间只显示数值。占比与 CPU、GPU 温度达到 80%（80 °C）时数值与进度条变为琥珀色；磁盘温度在达到磁盘报告的警告温度时变色，未报告时为 70 °C；电池在未接通电源且电量不高于 20% 时变色。磁盘与网络显示读取与写入、接收（↓）与发送（↑）速率，网络速率的单位跟随“网络速率单位”设置。显卡读数取专用显存最大的一块显卡，没有实测功耗时显示功耗占功耗预算的比例（% TDP）；磁盘活动时间取最忙的磁盘，磁盘温度取最热的磁盘；CPU 功耗取封装功耗，没有时取核心功耗。没有读数时显示破折号。

- 首次开启时显示在主显示器工作区的右上角。按住任意位置可拖动，松开后记住位置；拖动时不会移出指针所在显示器的工作区。该位置所在的显示器断开后，重新显示在主显示器右上角。
- 切换显示方式、样式或读数时小窗口随内容改变大小：位于显示器右半边时保持右边缘不动，否则保持左边缘不动，并始终留在工作区内。
- 单击不会让小窗口取得焦点，当前窗口保持活动。双击打开 Argus，右键单击打开菜单：打开 Argus、显示方式（列表面板、曲线面板、仪表面板或横条）、置顶显示、锁定位置、组件设置（打开组件页）与关闭桌面监控。
- 默认置顶显示；关闭后与其他窗口按层叠顺序排列。锁定位置后无法拖动。
- 开启“鼠标穿透”后，单击和拖动作用于下方的窗口，小窗口不再响应指针，只能在组件页关闭这一项。
- 不透明度可选 100%（默认）、90%、80%、70% 或 60%，作用于整个小窗口。
- 小窗口跟随界面主题与语言。

## 任务栏监控

任务栏监控在任务栏上显示所选读数，默认关闭，在[组件页](#组件页)开启。默认显示 CPU、内存与网络，可选项与桌面监控相同。文字颜色跟随任务栏的深浅色，与托盘图标一致；数值达到 80%（温度为 80 °C）时数值变为琥珀色（曲线样式的曲线同样变色），名称与胶囊的设备色圆点保持设备的颜色。文字大小随任务栏高度调整，在 Windows 11 的任务栏上占满大部分高度。标签、胶囊与大数字样式按最近一分钟内出现过的最宽数值为每项读数留出位置：数值变宽时立即加宽，变窄一分钟后才收窄，读数之间不留多余空白；曲线样式按数值可能的最大宽度定宽，读数变化时位置不变。组件页的“样式”以四张卡片按所选的前两项读数预览各样式在任务栏上的效果，单击即切换；窗口较窄时卡片排成两行。四种显示方式如下：

| 样式 | 显示方式 |
|---|---|
| 标签（默认） | 设备色的名称在左、数值在右，排成两行：单个数值的读数按顺序两两成列，磁盘与网络的两项速率各占一列。任务栏低于两行文字所需的高度时排成一行。 |
| 曲线 | 每项一张浅色小卡片：名称和数值在上，下方是最近 40 次采样的走势，曲线使用设备的颜色（CPU 青、内存紫、GPU 粉、磁盘琥珀、网络绿），读数偏高时变为琥珀色。占比与温度按 100 计，速率按这段时间的最高值计（至少 1 MB/s，空闲时曲线贴近底部），频率、功耗与转速按这段时间的最低值与最高值之间计，以便看出变化。 |
| 胶囊 | 每项一枚圆角胶囊，排成一行：设备色圆点、名称和紧随其后的数值；磁盘与网络的两项速率合用一枚，各自跟在设备色箭头之后。 |
| 大数字 | 每项一栏：设备色的小名称在上，大号数字在下并与名称左对齐，单位缩小并减淡；磁盘与网络的两项速率排成两行。 |

读数以设备名称标注（CPU、GPU1、C: 等）。同一 CPU 或 GPU 的读数相邻时，第一项写设备名称，其后各项写参数名称，如“CPU 74%”之后为“温度 75 °C”“功耗 88 W”。曲线、胶囊与大数字以设备的颜色区分设备，参数名称总是如此显示；标签样式的名称同样使用设备的颜色（运行时间不属于任何设备，名称保持较浅的文字颜色），参数名称只在同一设备的读数正上方（排成一行时为紧邻的左侧）时使用，否则仍写设备名称。

曲线、胶囊与大数字需要两行文字的高度，任务栏较矮时按标签显示。

- 默认显示在主显示器的任务栏上。有多个显示器时，可在组件页的“显示器”或面板中改为其他显示器的任务栏，所选显示器按显示器本身记住，重新启动或在同一接口重新插拔后仍对应同一台；“主显示器”始终跟随系统设置的主显示器。所选显示器未连接或未显示任务栏（关闭了“在所有显示器上显示任务栏”）时，暂时显示在主显示器的任务栏上，该显示器的任务栏出现后约两秒内移回。其他显示器的任务栏没有通知区域，读数位于其右端的时钟旁。
- 默认位于托盘旁。Windows 11 任务栏按钮居中时可改为“任务栏左侧”；开启了小组件按钮时向内让出它的位置。Windows 10 的任务栏没有空余位置，任务按钮区按读数的宽度收窄；托盘区随图标增减变宽或变窄时，读数随之移动，不遮挡托盘。关闭任务栏监控或退出 Argus 时恢复。
- 单击显示或隐藏窗口，与单击托盘图标相同。指针停留时仅显示底色，不显示悬停卡片。
- 右键单击打开任务栏监控的面板，位于监控上方。“样式”的四张卡片按所选的前两项读数显示各样式的实际效果，单击即切换；有多个显示器时，“显示器”列出主显示器与各显示器的名称，单击后监控移到该显示器的任务栏，面板随之关闭；“显示的读数”按任务栏监控的顺序分行列出 CPU、内存、GPU、磁盘、网络与其他，选项与组件页相同，选中的读数以该设备在任务栏上的颜色标示。按住类别名称上下拖动可调整类别的顺序，拖动读数可调整它在本类别中的顺序，与在组件页调整相同。GPU 与磁盘有多个设备时以标签切换设备，标签上的圆点表示该设备有已选读数，指针停留在标签上时显示型号；网卡各自作为一项。底部为“组件设置…”与“关闭任务栏监控”。切换样式与勾选读数时面板保持打开，更改立即显示在任务栏上并保存；单击面板以外的位置、按 Esc 或再次右键单击任务栏监控时关闭。
- 资源管理器重新启动后自动回到任务栏。垂直任务栏不显示任务栏监控。

桌面监控或任务栏监控显示期间，即使窗口最小化或隐藏到托盘，采样也按“刷新频率”进行，读数与窗口显示时一样随之更新，历史记录同样按此记录；“最小化时的刷新间隔”与“后台常驻时的刷新间隔”在此期间不生效。

## 组件页

组件页集中托盘、桌面监控与任务栏监控的设置，并列出规划中的瞭望台。左侧列出托盘、桌面监控、任务栏监控与更多组件四个分组，与[设置页](settings.md)相同：列表跟随滚动标出当前位置，单击分组可直接跳转；内容随窗口适当加宽，最宽 960 px；窗口较窄时不显示列表。从快捷面板的托盘设置、桌面监控菜单的“组件设置”或任务栏监控面板的“组件设置…”打开组件页时，直接显示对应的分组。

| 设置 | 说明 |
|---|---|
| 托盘图标 | 应用图标、走势（默认）、占比或数字，见[托盘图标](#托盘图标)。 |
| 悬停卡片 | 默认开启，见[悬停卡片与快捷面板](#悬停卡片与快捷面板)。 |
| 右键单击托盘图标 | 快捷面板（默认）或菜单。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时按“后台常驻时的刷新间隔”（默认 5 秒）采样，历史记录和规则照常进行。关闭这一项后，关闭窗口即退出 Argus。 |
| 从托盘打开 | 默认“保留当前页面”，可改为“打开默认页面”。窗口隐藏到托盘后，通过快捷键、托盘图标、快捷面板、托盘菜单或再次启动 Argus 重新打开时生效；最小化恢复与已显示窗口的激活保留当前页面。有未关闭的对话框时保留原页面，便于继续操作。页面内的筛选和排序继续保留。 |
| 后台常驻时的刷新间隔 | 隐藏到托盘（包括开机启动后未打开窗口）时的采样间隔：每 0.5、1、2、5（默认）、10 或 30 秒。托盘图标与系统提示按此间隔更新。间隔越长后台开销越低，但规则对新启动程序的生效最多延后一个间隔；长于 5 秒时，历史记录也随之变稀。桌面监控或任务栏监控显示期间按“刷新频率”采样，此项不生效；其中任一开启、且此项与“刷新频率”不同时，下拉框变淡（仍可选择，监控关闭后生效），说明下方注明开启的监控与实际的采样间隔。 |

设置页“启动与后台”分组中的“托盘与组件”卡片可直接打开本页。

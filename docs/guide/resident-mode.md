# 常驻、托盘与快捷键

- 默认关闭窗口时留在托盘。单击托盘图标或按 **Ctrl+Alt+Esc** 显示 / 隐藏窗口；快捷键可在[设置](settings.md#快捷键)中更改或停用。托盘图标获得键盘焦点时，按 Enter 或空格同样显示 / 隐藏窗口。
- 托盘相关的设置集中在[组件](#组件页)页（Ctrl+7）。
- 隐藏到托盘后，界面暂停绘制，采样、历史记录和规则继续运行。托盘与最小化状态各有独立的采样间隔，均默认为 5 秒。间隔超过 5 秒时，历史记录按该间隔写入。详见[数据与历史](settings.md#数据与历史)。
- 隐藏或最小化默认满 10 分钟后，Argus 释放图表图像并归还未使用的内存，再次显示窗口时重绘图表。时长可在[数据与历史](settings.md#数据与历史)中调整或关闭。
- 再次启动同一实例时会显示已有窗口。
- 设置中可开启登录 Windows 时启动：带 `--hidden` 参数启动，静默进入托盘。
- 开启[管理员运行](settings.md#权限)后，上述入口遵循同一授权，登录启动仍保持隐藏；该授权独立于特权服务。

## 托盘图标

托盘图标默认为 Argus 的眼睛，下方的负载条随 CPU 占用实时伸缩；也可改为显示 CPU 占用的数字，或改回应用图标。占用达到 80% 时，负载条与数字变为琥珀色。眼睛与数字随任务栏的深浅色切换为白色或黑色，与系统图标一致。图标按当前刷新间隔更新：窗口显示时按“刷新频率”，隐藏到托盘时按“后台常驻时的刷新间隔”。

新版本就绪时，图标上显示强调色圆点：负载条与数字样式在右上角，应用图标在右下角。

托盘图标在同一程序路径下沿用稳定标识，Windows 可按同一图标保留任务栏或折叠区的显示位置。首次从旧版标识迁移时，可能需要重新将图标拖出折叠区一次。

## 悬停卡片与快捷面板

指针停留在托盘图标上时显示悬停卡片：CPU、内存与 GPU 的占用和网络的接收、发送速率，以及单击与右键单击的作用。关闭“悬停卡片”后改为系统提示，显示 CPU 与内存占用。

右键单击托盘图标（或在图标获得焦点时按菜单键）默认打开快捷面板，位于托盘图标旁、任务栏上方：

- 顶部为版本号；有新版本时显示更新入口，单击“更新”打开更新对话框。
- CPU、内存、GPU 与网络四块读数，各带最近 60 次采样的曲线。单击某一块打开性能页的对应设备。
- CPU 占用最高的三个进程，单击在进程页中定位该进程。
- 底部为“打开 Argus”、暂停 / 继续刷新、托盘设置（打开组件页）与退出。

单击面板以外的位置或按 Esc 关闭面板；再次右键单击托盘图标也会关闭它。“右键单击托盘图标”可改为“菜单”，只列出“显示 Argus”“更新到 x.y.z…”（新版本就绪时）与“退出”。

悬停卡片或快捷面板打开期间，采样按窗口显示时的“刷新频率”进行，读数与曲线随之更新；关闭后恢复后台常驻时的间隔。卡片与面板跟随界面主题，开启“窗口动画”且 Windows 动画效果开启时淡入淡出。

## 组件页

组件页集中托盘的设置，并列出规划中的桌面监控、任务栏监控与灵动岛；这些组件推出后在此开启和设置。

| 设置 | 说明 |
|---|---|
| 托盘图标 | 应用图标、负载条（默认）或数字，见[托盘图标](#托盘图标)。 |
| 悬停卡片 | 默认开启，见[悬停卡片与快捷面板](#悬停卡片与快捷面板)。 |
| 右键单击托盘图标 | 快捷面板（默认）或菜单。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时按“后台常驻时的刷新间隔”（默认 5 秒）采样，历史记录和规则照常进行。关闭这一项后，关闭窗口即退出 Argus。 |
| 从托盘打开 | 默认“保留当前页面”，可改为“打开默认页面”。窗口隐藏到托盘后，通过快捷键、托盘图标、快捷面板、托盘菜单或再次启动 Argus 重新打开时生效；最小化恢复与已显示窗口的激活保留当前页面。有未关闭的对话框时保留原页面，便于继续操作。页面内的筛选和排序继续保留。 |
| 后台常驻时的刷新间隔 | 隐藏到托盘（包括开机启动后未打开窗口）时的采样间隔：每 0.5、1、2、5（默认）、10 或 30 秒。托盘图标与系统提示按此间隔更新。间隔越长后台开销越低，但规则对新启动程序的生效最多延后一个间隔；长于 5 秒时，历史记录也随之变稀。 |

设置页“启动与后台”分组中的“托盘与组件”卡片可直接打开本页。

测量托盘常驻的 CPU、GPU 和内存开销，见[性能测量](../development/performance.md)。

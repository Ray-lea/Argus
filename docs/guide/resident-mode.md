# 常驻、托盘与快捷键

- 默认关闭窗口时留在托盘。单击托盘图标或按 **Ctrl+Alt+Esc** 显示 / 隐藏窗口；快捷键可在[设置](settings.md)中更改。
- 托盘提示实时显示 CPU 与内存占用；托盘菜单有“显示 Argus”和“退出”。
- 窗口隐藏时 WebView2 停止渲染并降低内存占用，采样降到每 5 秒一次，历史曲线不中断；再次打开几乎瞬间完成。
- 只允许单个实例：再次启动 Argus 会唤出已运行的窗口。
- 设置中可开启登录 Windows 时启动：带 `--hidden` 参数启动，静默进入托盘。

隐藏在托盘时的资源占用见[性能基线](../development/performance.md)。

# 常驻、托盘与快捷键

- 默认关闭窗口时留在托盘。单击托盘图标或按 **Ctrl+Alt+Esc** 显示 / 隐藏窗口：窗口为当前使用的窗口时隐藏，被其他窗口遮挡或已最小化时显示到最前；快捷键可在[设置](settings.md#快捷键)中更改或停用。托盘图标获得键盘焦点时，按 Enter 或空格同样显示 / 隐藏窗口。
- 托盘相关的设置集中在[组件](#组件页)页（Ctrl+7）。
- 隐藏到托盘后，界面暂停绘制，采样、历史记录和规则继续运行。托盘与最小化状态各有独立的采样间隔，均默认为 5 秒。间隔超过 5 秒时，历史记录按该间隔写入。详见[数据与历史](settings.md#数据与历史)。
- 隐藏或最小化默认满 10 分钟后，Argus 释放图表图像并归还未使用的内存，再次显示窗口时重绘图表。时长可在[数据与历史](settings.md#数据与历史)中调整或关闭。
- 再次启动同一实例时会显示已有窗口。
- 设置中可开启登录 Windows 时启动：带 `--hidden` 参数启动，静默进入托盘。
- 开启[管理员运行](settings.md#权限)后，上述入口遵循同一授权，登录启动仍保持隐藏；该授权独立于特权服务。

## 托盘图标

托盘图标默认为“走势”：Argus 标志中的每列点对应一次采样，按当时的 CPU 占用由下往上点亮，最右一列为最新一次，以强调色显示。也可改为“占比”，按当前占用点亮相应数量的点（图标为 16–24 px 时共 25 个点，每点代表 4%；32 px 时为 100 个点，每点代表 1%）；或改为显示占用百分比的“数字”，或改回应用图标。占用达到 80% 时，最新一列、已点亮的点与数字变为琥珀色。标志与数字随任务栏的深浅色切换为白色或黑色，与系统图标一致。图标按当前刷新间隔更新：窗口显示时按“刷新频率”，隐藏到托盘时按“后台常驻时的刷新间隔”；走势每次更新左移一列。

新版本就绪时，图标上显示强调色圆点：走势在标志的标题栏右侧，占比替换右上角的一个点，数字在右上角，应用图标在右下角。

托盘图标在同一程序路径下沿用稳定标识，Windows 可按同一图标保留任务栏或折叠区的显示位置。首次从旧版标识迁移时，可能需要重新将图标拖出折叠区一次。

## 悬停卡片与快捷面板

指针停留在托盘图标上时显示悬停卡片：CPU、内存与 GPU 的占用和网络的接收、发送速率，以及单击与右键单击的作用。关闭“悬停卡片”后改为系统提示，显示 CPU 与内存占用。

右键单击托盘图标（或在图标获得焦点时按菜单键）默认打开快捷面板，位于托盘图标旁、任务栏上方：

- 顶部为版本号；有新版本时显示更新入口，单击“更新”打开更新对话框。
- CPU、内存、GPU 与网络四块读数，各带最近 60 次采样的曲线。单击某一块打开性能页的对应设备。
- CPU 占用最高的三个进程，单击在进程页中定位该进程。
- 底部为“打开 Argus”、暂停 / 继续刷新、托盘设置（打开组件页）与退出。

单击面板以外的位置或按 Esc 关闭面板；再次右键单击托盘图标也会关闭它。托盘图标位于“显示隐藏的图标”区域时，卡片与面板显示在该区域上方，不遮挡它；打开面板、指针移入面板或单击面板中的按钮时，隐藏的图标保持展开，单击其他位置或按 Esc 时两者一同关闭。“右键单击托盘图标”可改为“菜单”，只列出“显示 Argus”“更新到 x.y.z…”（新版本就绪时）与“退出”。

悬停卡片或快捷面板打开期间，采样按窗口显示时的“刷新频率”进行，读数与曲线随之更新；关闭后恢复后台常驻时的间隔。卡片与面板跟随界面主题，开启“窗口动画”且 Windows 动画效果开启时淡入淡出。

## 桌面监控

桌面监控以小窗口在桌面上显示所选读数，默认关闭，在[组件页](#组件页)开启。组件页的“显示的读数”像一张表：左列是设备及区分它的信息，右侧是该设备可选的读数。桌面监控与任务栏监控按表中的顺序显示：

| 设备 | 读数 |
|---|---|
| CPU | 利用率（默认）、温度、频率、功耗 |
| 内存 | 占比（默认）、用量（GB） |
| GPU | 利用率（默认）、温度、显存占比、频率、功耗、风扇转速 |
| 磁盘 | 读写速度（默认）、活动时间、温度 |
| 网络 | 收发速率（默认） |
| 其他 | 电池电量、正常运行时间 |

检测到多块显卡、磁盘或多个网卡时，表中为每个设备单独列出一行，可分别选择：

- 磁盘列出盘符（没有盘符时为“磁盘 N”）、型号与容量，网卡列出连接名称与适配器型号，显卡列出名称与专用显存。
- 磁盘与网卡的第一行为“全部磁盘”“全部网卡”：读写速度与收发速率为合计，磁盘活动时间与温度取最高的一块。只有一块磁盘或一个网卡时只显示这一行。
- 显卡的第一行为默认显卡（专用显存最大的一块），未指定显卡的读数取它。
- 所选设备按型号、名称记住，重新启动或重新插拔后仍对应同一设备；设备断开时读数显示破折号，表中保留一行“未连接”的设备以便取消选择。
- 指定设备的读数在桌面监控上以设备名开头（如“C: 温度”“UHD Graphics 770 利用率”），速率行以设备名为标题；在任务栏上以盘符、连接名称或 GPU1、GPU2 区分。

占比、温度与电量各带一条进度条，频率、功耗、转速与运行时间只显示数值。占比与 CPU、GPU 温度达到 80%（80 °C）时数值与进度条变为琥珀色；磁盘温度在达到磁盘报告的警告温度时变色，未报告时为 70 °C；电池在未接通电源且电量不高于 20% 时变色。磁盘与网络显示读取与写入、接收（↓）与发送（↑）速率，网络速率的单位跟随“网络速率单位”设置。显卡读数取专用显存最大的一块显卡，没有实测功耗时显示功耗占功耗预算的比例（% TDP）；磁盘活动时间取最忙的磁盘，磁盘温度取最热的磁盘；CPU 功耗取封装功耗，没有时取核心功耗。没有读数时显示破折号。

- 首次开启时显示在主显示器工作区的右上角。按住任意位置可拖动，松开后记住位置；该位置所在的显示器断开后，重新显示在主显示器右上角。
- 单击不会让小窗口取得焦点，当前窗口保持活动。双击打开 Argus，右键单击打开菜单：打开 Argus、置顶显示、锁定位置、组件设置（打开组件页）与关闭桌面监控。
- 默认置顶显示；关闭后与其他窗口按层叠顺序排列。锁定位置后无法拖动。
- 开启“鼠标穿透”后，单击和拖动作用于下方的窗口，小窗口不再响应指针，只能在组件页关闭这一项。
- 不透明度可选 100%（默认）、90%、80%、70% 或 60%，作用于整个小窗口。
- 小窗口跟随界面主题与语言。

## 任务栏监控

任务栏监控在主显示器的任务栏上显示所选读数，默认关闭，在[组件页](#组件页)开启。默认显示 CPU、内存与网络，可选项与桌面监控相同。文字颜色跟随任务栏的深浅色，与托盘图标一致；数值达到 80%（温度为 80 °C）时变为琥珀色。标签、曲线与大数字样式按数值可能的最大宽度为每项读数预留位置，读数变化时位置不变。组件页的“样式”可选四种显示方式：

| 样式 | 显示方式 |
|---|---|
| 标签（默认） | 名称在左、数值在右，排成两行：单个数值的读数按顺序两两成列，磁盘与网络的两项速率各占一列。任务栏低于两行文字所需的高度时排成一行。 |
| 曲线 | 每项一张浅色小卡片：名称和数值在上，下方是最近 40 次采样的走势，曲线使用设备的颜色（CPU 青、内存紫、GPU 粉、磁盘琥珀、网络绿），读数偏高时变为琥珀色。占比与温度按 100 计，速率按这段时间的最高值计（至少 1 MB/s，空闲时曲线贴近底部），频率、功耗与转速按这段时间的最低值与最高值之间计，以便看出变化。 |
| 胶囊 | 每项一枚圆角胶囊，排成一行：设备色圆点、名称和紧随其后的数值；磁盘与网络的两项速率合用一枚，各自跟在设备色箭头之后。胶囊按最近一分钟内的最宽数值定宽：数值变宽时立即加宽，变窄一分钟后才收窄。 |
| 大数字 | 每项一栏：设备色的小名称在上，大号数字在下并与名称左对齐，单位缩小并减淡；磁盘与网络的两项速率排成两行。 |

曲线、胶囊与大数字需要两行文字的高度，任务栏较矮时按标签显示。

- 默认位于托盘旁。Windows 11 任务栏按钮居中时可改为“任务栏左侧”；开启了小组件按钮时向内让出它的位置。Windows 10 的任务栏没有空余位置，任务按钮区按读数的宽度收窄，关闭任务栏监控或退出 Argus 时恢复。
- 单击显示或隐藏窗口，与单击托盘图标相同。指针停留时仅显示底色，不显示悬停卡片。
- 右键单击打开任务栏监控的面板，位于监控上方。“样式”的四张卡片按所选的前两项读数显示各样式的实际效果，单击即切换；“显示的读数”按 CPU、内存、GPU、磁盘、网络与其他分行列出，选项与组件页相同，选中的读数以该设备在任务栏上的颜色标示。GPU 与磁盘有多个设备时以标签切换设备，标签上的圆点表示该设备有已选读数，指针停留在标签上时显示型号；网卡各自作为一项。底部为“组件设置…”与“关闭任务栏监控”。切换样式与勾选读数时面板保持打开，更改立即显示在任务栏上并保存；单击面板以外的位置、按 Esc 或再次右键单击任务栏监控时关闭。
- 资源管理器重新启动后自动回到任务栏。垂直任务栏不显示任务栏监控。

桌面监控或任务栏监控显示期间，即使窗口隐藏到托盘，采样也按“刷新频率”进行，读数与窗口显示时一样随之更新。

## 组件页

组件页集中托盘、桌面监控与任务栏监控的设置，并列出规划中的灵动岛。

| 设置 | 说明 |
|---|---|
| 托盘图标 | 应用图标、走势（默认）、占比或数字，见[托盘图标](#托盘图标)。 |
| 悬停卡片 | 默认开启，见[悬停卡片与快捷面板](#悬停卡片与快捷面板)。 |
| 右键单击托盘图标 | 快捷面板（默认）或菜单。 |
| 关闭窗口时保留在托盘 | 默认开启。窗口隐藏时按“后台常驻时的刷新间隔”（默认 5 秒）采样，历史记录和规则照常进行。关闭这一项后，关闭窗口即退出 Argus。 |
| 从托盘打开 | 默认“保留当前页面”，可改为“打开默认页面”。窗口隐藏到托盘后，通过快捷键、托盘图标、快捷面板、托盘菜单或再次启动 Argus 重新打开时生效；最小化恢复与已显示窗口的激活保留当前页面。有未关闭的对话框时保留原页面，便于继续操作。页面内的筛选和排序继续保留。 |
| 后台常驻时的刷新间隔 | 隐藏到托盘（包括开机启动后未打开窗口）时的采样间隔：每 0.5、1、2、5（默认）、10 或 30 秒。托盘图标与系统提示按此间隔更新。间隔越长后台开销越低，但规则对新启动程序的生效最多延后一个间隔；长于 5 秒时，历史记录也随之变稀。 |

设置页“启动与后台”分组中的“托盘与组件”卡片可直接打开本页。

测量托盘常驻的 CPU、GPU 和内存开销，见[性能测量](../development/performance.md)。

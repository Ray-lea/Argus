# 路线图

- [x] **M0 脚手架**：workspace、Mica 窗口、数据通道
- [x] **M1 进程页**：按应用 / 进程树 / 列表、排序搜索、结束进程 / 进程树、详细信息面板、右键菜单
- [x] **M2 性能页**：CPU（每核、内核时间、频率、性能核 / 能效核、温度、功耗）、内存、磁盘（含温度）、网络、GPU（引擎、显存、温度、频率）、电池（容量、健康度、循环次数、充放电功率）；托盘常驻、全局快捷键、单实例、开机启动
- [x] **M3 系统管理**：服务（启停、启动类型、svchost 显示承载的服务）、启动项（启用 / 禁用、失效项提示）、连接与端口（端口精确搜索、断开连接）、文件占用（拖文件到窗口即查）
- [x] **多语言与首次启动引导**：文案目录（简体中文为源语言，英文译文）、检查脚本、安装程序双语；首次启动引导与设置入口
- [ ] **M4 历史与自动化**
  - [x] 每进程 GPU（占用最高的引擎、专用 / 共享 GPU 内存）
  - [x] 优先级与效率模式：右键菜单设置，规则在程序启动时自动套用
  - [ ] ETW 每进程网络流量（本地采集与特权服务通道已实现）
  - [x] 历史回溯：最近 7 天的系统曲线与每个时刻最忙的进程
- [ ] **M5 特权服务**
  - [x] 特权服务与设置入口：安装、启动、更新、卸载；标准权限界面的手动进程操作、服务控制和 IPv4 TCP 断开连接转交给服务
  - [x] 自动规则与每进程网络采集接入特权服务：后台通信、断线降级、服务恢复后重新应用规则
  - [ ] 替换系统任务管理器（Ctrl+Shift+Esc）：启动器、恢复状态机、设置入口与卸载保护已实现
  - [x] 可选内核传感器：PawnIO 固定 CPU 模块、特权服务快照、设置开关；Intel DTS、AMD 控制与 CCD 温度、封装功耗及按型号支持的电压
  - [x] 扩展 CPU 传感器：AMD SVI3／SMU、电压与电流、SoC、每核功耗及 PPT／TDC／EDC；Intel 分项功耗、PL1／PL2、温度余量；每核有效频率与活跃比例；NCT6779／NCT679x 风扇
  - [x] 开启内核传感器时自动准备 PawnIO：固定官方安装包、签名及摘要校验、管理员授权、启动检查与失败保持关闭
  - [x] AMD／Intel 显卡功耗接口：ADL2 与 IGCL，按 PCI 地址匹配并标明板卡、芯片、电源域来源
  - [ ] 持续扩展 2010 年后消费级硬件覆盖；无可靠接口的指标保持不可用
  - [x] 按句柄查文件占用：系统句柄枚举、特权服务接入、本地降级、超时隔离，补充当前目录及硬链接占用

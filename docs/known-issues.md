# 已知问题

## 功能限制

- **文件占用**合并 Restart Manager 与句柄扫描，已能查到普通进程的当前目录及硬链接引用。受保护进程（例如某些系统 DLL 的使用者）可能拒绝访问，句柄已经关闭的映射也可能漏检。句柄扫描不跟随符号链接、目录联接、网络或 SUBST 路径；超时、权限不足、文件状态变化或扫描上限都会使结果不完整，界面会提示。
- **管理员权限**：多数服务的启停、所有用户启动项的启用 / 禁用需要管理员权限；没有权限时界面会明确提示。
- **任务管理器替换与升级**：替换打开的是启用时复制到特权服务目录的 Argus 副本。安装程序升级会先退出仍在运行的旧副本，并同步更新特权服务与替换程序，替换保持开启。免安装版直接替换主程序，或安装程序未能更新服务时，还需在新版的提示框或“设置 → 权限”中单击“更新服务”；更新前 Ctrl+Shift+Esc 仍可能打开旧副本。免安装版升级前须从托盘退出旧版，避免新程序转交给仍在运行的实例。旧版副本写入的开机启动项在运行已安装的 Argus 后改回安装路径。
- **每进程网络流量**依靠 ETW 事件跟踪会话，可由管理员权限的 Argus 或已授权的特权服务提供；两者都不可用时隐藏网络列。服务数据通过后台读取，通常晚一个刷新周期。GUI 的本地会话在进程被强制结束后会残留，下次启动时清理；服务会话在没有读取请求 15 秒后关闭，服务本身被强制结束时则在下次服务启动时清理。
- **历史记录**每帧（默认每 5 秒一帧）只保存 CPU、内存、I/O、GPU、网络各自占用最高的几个进程（每帧最多 21 个），其余进程不在历史里；每进程网络流量只在本地或服务采集可用时记录。
- **全局快捷键**沿用 Windows 全局快捷键的规则：修饰键不区分左右，不能只用修饰键，只能有一个普通键，CapsLock 不能作为修饰键；用 AltGr 输入字符的键盘布局中，输入字符的组合不能用作快捷键。见[设置](guide/settings.md#快捷键)。
- **CPU 传感器**：默认使用 ACPI 热区；内核采集支持 MSR／SMN、SMU 和 SVI3。AMD 每核温度仅使用已明确映射的 SMU 字段，CCD 温度不作为每核温度。未知 SMU 表版本保留基础读数并报告版本；不采用候选布局。Intel 官方签名模块尚未开放完整限频原因与原生深度 C-state 寄存器，目前分别提供已允许的限制位和 Windows 空闲状态。主板风扇覆盖 NCT6779／NCT679x，风扇按硬件通道编号显示，具体接口名称需核对主板接线。ROG STRIX X670E-A 另提供已知电源轨、主板与供电温度；笔记本 EC、其他主板接线及未确认的供电控制器布局不套用相近型号。固件、虚拟化和系统策略仍可能限制具体读数。
- **功耗**：CPU 优先使用 Windows Energy Meter，内核传感器补充封装功耗。GPU 支持 NVML、ADL2、IGCL，按驱动能力提供板卡、芯片或 GPU 电源域读数并标明来源。AMD 的功耗调节百分比不作为瓦数上限。

更多见[硬件数据的来源与限制](guide/hardware-data.md)。

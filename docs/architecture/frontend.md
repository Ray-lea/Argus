# 原生界面

`src-gpui/src/frontend` 按界面职责拆分：layout 组织标题栏、导航和状态栏；tables 适配虚拟表格；pages 提供进程、性能、服务、启动项、连接、历史与设置；dialogs 与 welcome 管理原生对话框及首次启动引导。

model 负责应用分组、进程树、搜索、排序和源时间历史。身份由 PID 与创建时间共同确定。各页面保留独立的选择、排序、搜索与表格状态。冻结排序只影响显示次序，数据继续更新。

charts 使用 GPUI 原生曲线组件与路径缓存。不同数据源、单位、主题、语言或序列变化时才更新图形；滚动时移动已有几何路径。静态表格与曲线实体隔离，避免动画重复构建表格。

theme 从 resources/theme.json 读取色板与字体，界面文案从 locales 读取；窗口大小、标识和公钥来自 resources/app.json。硬件设备、拓扑、量程和可用字段从实时快照产生，不根据开发机型号写分支。

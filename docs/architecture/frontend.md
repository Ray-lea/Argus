# 前端

`ui/` 是 SolidJS + TypeScript + Tailwind v4 的单页界面，由 Vite 构建。不在 Tauri 中运行时（`start.bat ui`），`lib/ipc.ts` 改用 `lib/mock.ts` 的模拟数据，方便在浏览器里调样式；模拟数据不会进入 Tauri 构建的运行路径。

## 历史曲线

`components/HistoryPage.tsx` 的曲线是静态的：按查询（切换范围、窗口宽度停止变化后、跟随最新数据时每 10 秒到 5 分钟）各画一次，悬停只移动光标元素。每次查询按图表宽度约每两个像素一个点分桶，点与点之间远超分桶间隔的地方是 Argus 没有运行的时段，留出断档。最小化或后台常驻时的刷新间隔可长达 30 秒，帧也随之变稀，所以是否断开还看两侧的帧距：相邻两点的距离超过分桶间隔与两侧较宽帧距（不超过 35 秒）中较大者的 2.5 倍才算断档；悬停读数在连成线的两点之间取较近的一点，在断档处没有读数（`lib/history-gaps.ts`，`ui/tests` 有测试）。

## 实时曲线

`components/Trace.tsx` 在 canvas 上绘制曲线：每次采样只画一次，之后由合成器沿时间轴连续移动画布，主线程不参与。实现要点见[曲线动画](../design/charts.md)。

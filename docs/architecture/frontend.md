# 原生界面

[`src-gpui/src/frontend`](../../src-gpui/src/frontend) 包含窗口布局、虚拟表格、图表、菜单、对话框和各页面。`Desktop` 持有界面状态，采样与系统操作由[原生宿主](host.md)调度。

## 数据、排序与偏好

`model` 以 PID 和创建时间标识进程，生成应用分组与进程树。各页面独立保存选择、筛选和排序。`collation` 用 Windows 的 ICU 按界面语言生成排序键，数字按数值比较，字母忽略大小写与重音。暂停排序期间行位置固定，数值继续更新。

`lists` 生成服务、启动项与连接的表格行。连接数据每两秒读取一次，进程名称和图标来自采样。后台线程根据新连接或所属进程变化准备行，界面线程接收结果。再次进入时，筛选、搜索、排序和备注仍匹配的缓存可直接显示。

`process_icons` 按当前快照保留程序及 WebView2 宿主的图标，表格、详情窗格和规则界面共用同一份图像。快照替换后，过期图标同时从 GPUI 解码缓存和窗口纹理图集中移除，GPU 页面可随之回收；暂停时继续持有原快照的 PNG。

界面偏好在内存中立即生效，由后台线程写入磁盘，退出前完成写入。`tableSort.<表>` 保存各表排序，`services.filter` 和 `connections.filter` 分别保存服务与连接的筛选条件。

性能页的 `cpuKernelTime` 保存 CPU 图表是否叠加内核时间，默认开启。`perfHiddenDevices` 保存设备列表中已隐藏设备的标识（`performance/rail.rs` 的 `stable_key`）：磁盘为总线、型号与容量，网络适配器为适配器型号与连接名称，显卡为名称，电池为名称与序列号；标识相同的设备按列表顺序追加序号。磁盘编号和适配器 LUID 随插拔顺序与重启变化，不用作标识。列表至少显示一项：保存的选择隐藏了当前全部设备时显示第一项。

## 表格、滚动与提示

`tables` 用 `DataTable` 虚拟化可见行。进程表的名称列固定在左侧，其他列按保存的顺序排列。自动宽度测量表头与汇总值，表头另计组件为排序图标保留的右侧内边距；百分比、内存、速率等数值列及其汇总值先按格式的常见最大值预留宽度（`tables::widths::envelope`），其他列约每 2 秒或行数变化时测量全部行，其余采样只测可见行。数字按等宽字形测量，数值列只增不减并按 8 px 取整。名称、路径等文本列记录两个宽度：多数行所需（四分位距上界以外的行视为过长，且至少容纳 95% 的行）和全部行所需（`Natural`）；`widths::allocate` 先给每列前者，再把表格剩余宽度按各列差额比例分配，至多到后者，不拉伸任何列。文本列收窄超过一档才更新。拖动过的列在 `processColumns.overrides` 中保持手动宽度，不参与分配，其他列宽度不受影响，双击列边界移除；“全宽”让未拖动过的名称列取剩余宽度。表头的列边界由组件的调整手柄接管悬停，Argus 在表头放置画布并以窗口级鼠标事件判断指针所在的边界（`header::edge_probe`），绘制提示线。宽度变化由 `TableFrame` 逐帧插值（`WidthGlide`），窗口尺寸、字号或语言变化时直接应用。字号或语言变化时重新测量。拖列表头或滚动期间冻结宽度，汇总值在各自列内裁剪并同步滚动。进程表头由 Argus 自行处理拖动：越过相邻列中线即交换并保存顺序，换位的列由 `flip` 从原位置滑到新位置；移动中的单元格内容以表格可视区为裁剪范围延后绘制，不受单元格自身裁剪。

`scrollbar` 从滚动句柄取得范围与偏移，在内容边缘绘制滑块。拖动可直接定位，单击轨道翻过 87.5% 的视口。虚拟表格的纵向滚轮、横向滚轮和 Shift+滚轮共用平滑滚动，内层到达边缘后再由外层处理。实现见 [GPUI 补丁](../../vendor/gpui-pre/ARGUS-PATCHES.md)。

`tips` 由每张表统一跟踪指针，只让指针下的行报告名称、读数或说明的位置。停留 500 ms 后由独立视图显示提示；按键、按下鼠标、滚动或离开时隐藏。菜单由 `menus` 在指针附近布局，靠近窗口边缘时调整方向。方向键可移动焦点和进入子菜单，Esc 返回。

## 区域绘制与曲线

`regions` 分别缓存标题栏、导航、页面、表格和进程页的概况带与详情窗格。区域内的滚动或悬停只重绘相关区域。服务、启动和连接页若只有状态栏变化，页面继续重放缓存。新的列表行、传感器状态、弹窗或布局变化按需重建相应内容。

切换页面和性能设备时，先按目标位置布局，绘制时再滑入。页面滑入从新页面首次呈现的那一帧起计时：新页面的第一帧要完整布局与绘制，性能页还要先测量布局而不呈现，若从切换时刻计时，页面一出现就已滑过大半距离。页面与导航选中标记的移动都用 250 ms；页面不淡入，曲线取 ease-out cubic，Fluent 的入场曲线把位移集中在开头，交给淡入掩盖。详情窗格和多核网格用实时变换重放画面，图表与所属区域在同一帧移动和裁剪。`ChartLayer` 在滚动帧平移缓存的曲线纹理，更新数据或绘制样式时重新栅格化。图层、显存预算和量程变化见[曲线与时间轴](../design/charts.md)。

## 对话框与输入

对话框打开时居中。表单在异步查询返回或展开说明时保持顶部位置，高度在 167 ms 内过渡到新值；更新和更新内容窗口在内容加载、展开及高度过渡期间保持居中；其中的版本展开或折叠时由内容自身过渡高度，时长与曲线沿用官网更新日志（每像素 1.6 ms，限于 240–420 ms，`cubic-bezier(0.2, 0.8, 0.2, 1)`），窗口在此期间直接跟随内容高度，不再叠加自身的过渡；悬停高亮与入场动画同样使用这条曲线。达到窗口可用高度后，正文使用带持久滚动句柄的原生滚动容器，滚轮沿用页面的平滑动画，页脚固定。调整窗口大小会重新居中。

对话框的正文与页脚测量忽略小于 1/64 物理像素的高度差，避免分数缩放下的浮点误差反复触发布局和高度过渡。内容增减及窗口尺寸变化仍按实际测量更新。

`widgets::text_field` 统一文本框的焦点与边框样式。输入元素由 `widgets::input` 构造，右键菜单为系统原生菜单，剪切、复制、粘贴和全选的文案取自 `common.edit`，随界面语言切换。数字框支持单击和长按增减，方向键步进后立即提交。进程页的 `SearchComposer` 在列表获得文字输入时为输入法保留输入上下文。开始组字后将文字和焦点交给搜索框；取消时恢复原内容与焦点。弹窗、菜单与已聚焦的输入框优先处理按键。

## 缩放与排版

`appearance` 使用 `Window::set_content_zoom` 将界面缩放与 Windows DPI 合并，布局、绘制和命中测试共用坐标。字体大小按 13 px 基准单独换算。概况带根据卡片宽度调整大号数字和单位，辅助读数排成一行，空间不足时缩小字号。窄窗口的标题栏先收起按钮文字，再将页面控件和搜索框分行排列。

`theme` 从 [`theme.json`](../../resources/theme.json) 读取色板、字体和行高。西文使用 Segoe UI Variable，大号数字使用 Display 光学尺寸，简体中文回退至微软雅黑 UI。选中标签和分组标题使用 500 字重。提示框单独设置系统提示字体和行高。正文默认行高为字号的 1.4 倍，换行采用 UAX #14 与 ICU 的中日文调整规则。

文字抗锯齿采用 DirectWrite 的亮度自适应对比度校正：额外增强在前景亮度 50%–75% 之间逐渐减弱，更亮的文字保留原始覆盖率与 Gamma 校正。深色背景上的浅色文字据此避免边缘额外加厚，Markdown 的加粗字重和强调层级保持原设定。参考 [DirectWrite 混合实现](https://github.com/microsoft/terminal/blob/1283c0f5b99a2961673249fa77c6b986efb5086c/src/renderer/atlas/dwrite.hlsl)。

界面统一启用字体的等宽数字特性（`tnum`），文本测量使用相同设置。进程列表、性能读数、图表标注、详情、状态栏和提示框中的数字在位数及格式相同时保持宽度，避免刷新时横向跳动。进程 CPU、GPU 列及分组汇总值显示百分号，自动列宽为百分号预留空间。

字形按 DirectWrite 为该字体、字号和缩放推荐的渲染方式栅格化，与 Windows 和 Chromium 一致：微软雅黑 UI 的字号不超过 21 设备像素时按字体的网格对齐仅做水平抗锯齿，更大时双向抗锯齿；Segoe UI Variable 始终双向抗锯齿。行的上伸与下伸取文字所请求字体的度量，不取回退字体，纯中文、纯西文与中西混排在相同行高中基线一致。云母窗口将 DirectWrite 的子像素覆盖率按亮度加权为灰阶遮罩，合成时应用系统对比度和伽马。整窗实色模式可按系统设置使用 RGB ClearType。区域级 ClearType 方案及取舍见[窗口外观](../design/window.md)。

`inline` 用等宽占位将按钮和键帽嵌入一行文字，使控件随文本整体换行。数字与单位、标题与型号按首行基线对齐，基线取整到设备像素。相关补丁见 [GPUI](../../vendor/gpui-pre/ARGUS-PATCHES.md) 和 [Windows 平台层](../../vendor/gpui-pre-windows/ARGUS-PATCHES.md)。

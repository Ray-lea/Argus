# 原生界面

`src-gpui/src/frontend` 按界面职责拆分：layout 组织标题栏、导航和状态栏；tables 适配虚拟表格；menus 生成表格行的右键菜单；pages 提供进程、性能、服务、启动项、连接、历史与设置；dialogs 与 welcome 管理原生对话框及首次启动引导。

tables 按原版的网格轨道分配列宽：固定宽度的列先占位，其余列按比例分配剩余宽度且不小于各自的最小宽度；进程表随宽度变窄依次隐藏线程与句柄、PID 与 I/O 列。表格本身不绘制背景，由外层工作区卡片提供图层色。行的右键菜单由 desktop 打开，以便嵌套优先级等子菜单。图标使用原版界面自己的 16 px 线性图标（resources/ui-icons，由原版 icons.tsx 逐个导出为 SVG），随所在文字着色；原版没有的少数几个用组件库图标集中最接近的一个。界面字体与原版的 CSS 字体栈相同：西文与数字用 Segoe UI Variable（大号数字用 Display 光学尺寸），界面字体缺少的字符（主要是中文）按 theme.json 中的顺序回退到 Segoe UI 和微软雅黑 UI；不指定回退时，英文系统区域下 DirectWrite 会用日文的 Yu Gothic UI 显示中文。

scrollbar 绘制所有滚动区域共用的滚动条，样式与原版的 `::-webkit-scrollbar` 相同：右侧 10 px 槽位、透明轨道，滑块四周留 3 px 透明边，显示宽 4 px 的圆角滑块，悬停或拖动时加宽到 6 px 并加深。内容超出时即显示；滑块长度与位置按 Blink 的取整方式计算，最短 17 px；拖动滑块直接定位，单击轨道向指针方向翻过可见高度的 87.5%，按住时重复。滚动条不参与布局，从滚动句柄读取范围与偏移，绘制在滚动区域的槽位上；对应原版 `scrollbar-gutter: stable` 的区域在右侧多留 10 px，内容居中时也按扣除槽位后的宽度计算。鼠标滚轮按 Chromium 的方式平滑滚动（GPUI 补丁，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）：系统设置为每次 3 行时每格 100 px，在 100–200 ms 内按缓入缓出曲线到达目标，连续滚动时目标累加并保持当前速度；内层区域到达边缘后滚轮才交给外层。虚拟表格的滚轮在捕获阶段转为同样的滑动。

model 负责应用分组、进程树、搜索、排序和源时间历史，各视图的标题、副文本、分组与排序规则与原版的 `rows.ts` 一致。身份由 PID 与创建时间共同确定。名称排序与原版的 `Intl.Collator(locale, { numeric: true, sensitivity: "base" })` 相同：collation 通过 Windows 自带的 ICU（`icu.dll`，首次使用时加载）按界面语言生成排序键并缓存，数字按数值比较，忽略大小写与重音；中文汉字按拼音排在拉丁字母之前，英文则拉丁字母在前。进程表、服务、启动、连接与历史表的文字列都使用它。各页面保留独立的选择、排序、搜索与表格状态。冻结排序只影响显示次序，数据继续更新。

界面偏好在内存中立即生效，由后台线程写入磁盘，退出前写完。

charts 使用 GPUI 原生曲线组件与路径缓存。不同数据源、单位、主题、语言或序列变化时才更新图形；滚动时移动已有几何路径。静态表格与曲线实体隔离，避免动画重复构建表格。

theme 从 resources/theme.json 读取色板与字体，界面文案从 locales 读取；窗口大小、标识和公钥来自 resources/app.json。硬件设备、拓扑、量程和可用字段从实时快照产生，不根据开发机型号写分支。

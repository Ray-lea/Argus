# 原生界面

`src-gpui/src/frontend` 按界面职责拆分：layout 组织标题栏、导航和状态栏；tables 适配虚拟表格；menus 生成并绘制右键菜单；pages 提供进程、性能、服务、启动项、连接、历史与设置；dialogs 与 welcome 管理原生对话框及首次启动引导。

tables 按原版的网格轨道分配列宽：固定宽度的列先占位，其余列按比例分配剩余宽度且不小于各自的最小宽度；进程表随宽度变窄依次隐藏线程与句柄、PID 与 I/O 列。表格本身不绘制背景，由外层工作区卡片提供图层色。右键菜单由 desktop 打开，menus 按原版 `.menu` 的尺寸自行绘制：文字随字体大小设置缩放，30 px 的行高、内边距、16 px 图标、分隔线与 220 px 的最小宽度保持像素值，菜单宽度取最宽一行；界面缩放整体放大。菜单在指针处打开，放不下时向左或向上展开，子菜单贴在所属项旁。行为与原版相同：打开时第一项获得键盘焦点但不高亮，方向键移动并显示高亮，→、Enter 或单击打开子菜单，←、Esc 返回；指针悬停 250 ms 后打开或收起子菜单；禁用项悬停时同样高亮但不响应单击；菜单打开期间其他快捷键不生效；单击别处、窗口失去焦点或改变大小时关闭，关闭时淡出。图标使用原版界面自己的 16 px 线性图标（resources/ui-icons，由原版 icons.tsx 逐个导出为 SVG），随所在文字着色；原版没有的少数几个用组件库图标集中最接近的一个。界面字体与原版的 CSS 字体栈相同：西文与数字用 Segoe UI Variable（大号数字用 Display 光学尺寸），界面字体缺少的字符（主要是中文）按 theme.json 中的顺序回退到 Segoe UI 和微软雅黑 UI；不指定回退时，英文系统区域下 DirectWrite 会用日文的 Yu Gothic UI 显示中文。

scrollbar 绘制所有滚动区域共用的滚动条，样式与原版的 `::-webkit-scrollbar` 相同：右侧 10 px 槽位、透明轨道，滑块四周留 3 px 透明边，显示宽 4 px 的圆角滑块，悬停或拖动时加宽到 6 px 并加深。内容超出时即显示；滑块长度与位置按 Blink 的取整方式计算，最短 17 px；拖动滑块直接定位，单击轨道向指针方向翻过可见高度的 87.5%，按住时重复。滚动条不参与布局，从滚动句柄读取范围与偏移，绘制在滚动区域的槽位上；对应原版 `scrollbar-gutter: stable` 的区域在右侧多留 10 px，内容居中时也按扣除槽位后的宽度计算。鼠标滚轮按 Chromium 的方式平滑滚动（GPUI 补丁，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）：系统设置为每次 3 行时每格 100 px，在 100–200 ms 内按缓入缓出曲线到达目标，连续滚动时目标累加并保持当前速度；内层区域到达边缘后滚轮才交给外层。虚拟表格的滚轮在捕获阶段转为同样的滑动；滑动尚未到达边缘时，越过边缘的滚轮仍归这次滑动，不交给表格组件自身的滚轮处理（它按行距跳动并中断滑动，列表会停在边缘之前）。

model 负责应用分组、进程树、搜索、排序和源时间历史，各视图的标题、副文本、分组与排序规则与原版的 `rows.ts` 一致。身份由 PID 与创建时间共同确定。名称排序与原版的 `Intl.Collator(locale, { numeric: true, sensitivity: "base" })` 相同：collation 通过 Windows 自带的 ICU（`icu.dll`，首次使用时加载）按界面语言生成排序键并缓存，数字按数值比较，忽略大小写与重音；中文汉字按拼音排在拉丁字母之前，英文则拉丁字母在前。进程表、服务、启动、连接与历史表的文字列都使用它。各页面保留独立的选择、排序、搜索与表格状态。冻结排序只影响显示次序，数据继续更新。

desktop 是唯一的状态持有者，按区域绘制：标题栏、导航、当前页面，以及进程页的资源卡片与详情窗格各是一个缓存视图（regions），表格也各有缓存视图。desktop 的状态变化会重绘所有区域；区域内的动画帧、平滑滚动或悬停只重绘该区域，祖先视图只重建自身的元素并重放其余区域（GPUI 补丁，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）。实时曲线归属于构建它们的区域。切换页面时，新页面按最终位置布局一次，进入动画的位移与淡入只作用于绘制（shift 模块的视觉变换），各帧重放已绘制的页面；动画期间命中测试按最终位置进行，曲线层随页面位移。动画从切换后绘制的第一帧开始计时。进程页的详情窗格打开或收起时同样如此：列表按整张卡片的宽度布局，只在绘制时裁剪到可见宽度（视觉裁剪，不改变内容遮罩，缓存视图得以重放）；窗格按打开后的位置布局，宽度变化与 24 px 的滑入、淡入只作用于绘制，窗格内的曲线随之移动、淡入并裁剪。两者在动画期间重放已绘制的内容，结束时按最终宽度布局一次。列表的纵向滚动条因此由页面绘制，随可见边缘移动。

界面偏好在内存中立即生效，由后台线程写入磁盘，退出前写完；写入失败时提示一次，再次写入成功后才会重新提示。列表的排序与筛选沿用原版的偏好键与取值（`tableSort.<表>` 保存原版的列标识，`services.filter`、`connections.filter`），原版不能排序的列（服务描述、启动命令）在这里同样不能排序。

appearance 处理界面缩放与字体大小。界面缩放通过 GPUI 补丁 `Window::set_content_zoom` 把缩放比例乘入窗口的缩放因子，与原版的 WebView 缩放相同：视口按比例变小，文字、图标与曲线按设备像素重新栅格化，布局、绘制、指针与原生标题栏的命中测试使用同一坐标；窗口在屏幕上的位置、大小与最小尺寸不变（补丁见 `vendor/gpui-pre-windows/ARGUS-PATCHES.md`）。字体大小对应原版的 `calc(N rem / 13)`：各处字号经 `theme::font` 按 13 px 基准换算，组件库的字号随主题变化；间距与控件尺寸保持像素值，由文字撑开的高度（状态栏、表头、性能页的设备行）随字号的行高增加，资源卡片的数字不超过卡片内容宽度的 33%（原版的 `33cqw`），放不下的单位延伸到相邻卡片，不在卡片内截断。标题栏按原版的 fitToolbar 逐级收起（页面控件或右侧按钮越过搜索框的最小宽度、或越过标题栏按钮前的边距时）：先隐藏右侧按钮的文字，再隐藏视图切换的文字，再把页面控件移到第二行，最后把搜索框移到单独一行；每级记住放不下时所需的宽度，窗口足够宽时逐级恢复，换页、语言、字体大小、导航位置，以及更新按钮或历史页“回到最新”按钮出现或消失后重新计算。

charts 使用 GPUI 原生曲线组件与路径缓存。不同数据源、单位、主题、语言或序列变化时才更新图形；滚动时移动已有几何路径。静态表格与曲线实体隔离，避免动画重复构建表格。

theme 从 resources/theme.json 读取色板、字体与行高，界面文案从 locales 读取；窗口大小、标识和公钥来自 resources/app.json。硬件设备、拓扑、量程和可用字段从实时快照产生，不根据开发机型号写分支。

文字的行高默认为字号的 1.4 倍，与原版 body 的 `line-height` 相同，由窗口的根表面继承到页面、对话框与通知；原版单独设置行高的元素（新建任务的说明、更新内容、快捷键说明、代码与许可证文本、引导说明等）沿用原版的值。GPUI 自身的默认行高约为 1.6 倍，沿用它会使多行说明及由其撑开的卡片偏高。文字换行遵循原版 WebView2 对中文的断行规则（UAX #14 及 ICU 的中日文调整，GPUI 补丁，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）：行首不出现 `。`、`，`、`、`、`）`、`」`、`”`、`：`、`……` 等，行尾不出现 `（`、`「`、`“` 等，汉字与英文单词、数字之间无空格也可换行；两个 ASCII 字符之间仍按 GPUI 的规则，只在空格处及部分符号前换行。

# 架构

本页概述 Argus 的分层、各目录的职责与数据流。

Argus 是 Windows（x64 与 ARM64）原生应用。`argus-core` 读取系统数据，`argus-app` 调度采样和管理设置，`src-gpui` 在桌面进程内以 GPUI Kit 绘制界面。GPUI 的平台边界见开发指南的 [GPUI 开发](../development/gpui.md)。

## 目录与职责

各目录的职责如下：

| 目录 | 职责 |
| --- | --- |
| `crates/argus-core` | Windows 原生采集、数据模型、历史记录与系统操作 |
| `crates/argus-service` | 可选特权服务、固定传感器模块与任务管理器辅助程序 |
| `crates/argus-app` | 采样调度、设置、界面偏好、任务启动和安装辅助 |
| `crates/argus-view-logic` | 界面中不依赖 GPUI 的逻辑 |
| `src-gpui` | GPUI 视图、窗口生命周期、托盘、快捷键和更新 |
| `resources` | 应用元数据、图标、主题、动画参数与硬件指标定义 |
| `tools` | 独立窗口捕获探针和发布签名工具 |

`crates/argus-view-logic` 包含进程行与分组、进程列、显示筛选、界面偏好、区域格式、历史曲线的分桶与任务栏监控的排版。

## 数据流

采样线程按前台、最小化或托盘状态选择间隔。快照转换和进程分组在后台完成，界面接收最新结果，并保留当前排序和行选择。曲线使用采样时间戳，动画按显示节拍绘制。

## 系统操作与权限

文件占用查询和进程操作由宿主分配给工作线程。修改进程前核对 PID 和创建时间。需要内核权限的传感器读数经特权服务和固定的 PawnIO 模块获取，缺失值标为未知。

# 原生宿主

`src-gpui/src/lib.rs` 负责应用启动，先处理安装、任务启动、服务和任务管理器辅助模式，再加载设置、诊断日志、单实例通信、采样器与 GPUI 窗口。

窗口、托盘、全局快捷键和后台采样状态在原生平台适配层管理。隐藏和最小化时停止曲线绘制，采样按各自的设置继续。恢复时请求新快照，曲线仍使用源时间戳，不压缩后台采样间隔。

`window_motion.rs` 让窗口在显示、隐藏到托盘、最小化和还原时原地淡入淡出（显示 180 ms，离开 140 ms），关闭 DWM 的缩放动画；仅在淡入淡出期间给窗口加分层样式，跟随界面动画设置。其他线程的请求转到窗口线程执行；标题栏的最小化按钮发送 `SC_MINIMIZE`，任务栏还原和其他程序直接显示窗口时同样淡入。

`crates/argus-app/src/preferences.rs` 将界面偏好与窗口位置原子保存到配置目录的 `preferences.json`，同一配置目录下的启动入口共享偏好。文件中偏好保存在 `values`，窗口位置保存在 `window`，更新时保留已有偏好；早期原生版本把偏好写在顶层，读取时按偏好处理，下次保存时改写为上述格式。`src-gpui/src/window_state.rs` 保存 `WINDOWPLACEMENT` 的普通窗口矩形与最大化标记，移动或缩放结束后保存，关闭和退出前补写；隐藏启动延迟到首次显示时恢复最大化，不恢复最小化状态；测试实例不恢复窗口位置。

`admin.rs` 处理管理员启动策略与权限交接，在单实例及窗口创建前路由；设置中立即切换，引导中延后应用，详见[管理员启动](administrator-startup.md)。开机启动项（`commands/autostart.rs`）在已有管理员启动记录时使用受保护的稳定启动器。安装程序与卸载程序以 `argus.exe --argus-close-copies` 运行（不检查单实例、不创建窗口），由 `leftovers.rs` 结束任务管理器替换与管理员启动目录中正在运行的界面副本：Restart Manager 只关闭安装目录的 `argus.exe`，留下的副本会占着单实例并保留内存中的设置。

`native_runtime.rs` 提供进程内状态、通知合并和主线程调度；`commands.rs` 连接应用服务与现有系统能力。耗时命令在工作线程执行，界面通过有界通知更新。没有跨浏览器 IPC。

配置目录保存 settings.json 与 preferences.json，本地数据目录保存历史、更新文件和诊断日志。发布版标识来自 resources/app.json，开发版追加 .devbuild 与稳定的工作区指纹，不同工作区独立保存设置与单实例锁；测试也可显式指定独立标识。

`crates/argus-app/src/explorer.rs` 按桌面窗口、系统映像路径、会话、PID 与创建时间核对资源管理器。关闭前先创建主线程挂起的新 Explorer，以旧桌面进程为父进程继承原账户的普通令牌，并校验新进程的账户、会话与权限。进程和线程对象的访问控制与完整性级别也取自桌面令牌，避免管理员创建的对象阻止普通账户继续管理资源管理器。准备失败时保留原桌面并清理未启动的替代进程。

随后向任务栏发送 Explorer 自身的退出请求，先等待正常退出；五秒后仍未完成时，使用操作前取得的进程句柄结束已确认的旧实例，并等待最多五秒确认退出，避免退出清理或错误报告卡住后丢弃替代进程。结束权限在关闭桌面前检查，未确认旧进程退出时不启动替代进程；Windows 已恢复新桌面时复用该实例，避免重复启动。不发送 Restart Manager 的会话结束通知，也不依赖以普通权限重新运行 Argus 助手。新桌面与任务栏连续一秒能够响应消息后才报告完成。普通结束进程与结束进程树入口在调用特权服务前拦截当前桌面 Explorer，文件占用对话框对该进程提供重新启动操作。

更新保持原有下载、取消、版本状态转换和安装前再次验签。公钥在 resources/app.json，签名必须绑定清单版本；release-notes 同样验签。安装器沿用现有服务刷新、任务管理器恢复和文件占用处理；安装后钩子先退出运行中的界面副本并更新管理员启动记录，再刷新特权服务。更新安装类型按正在运行的文件判断：已安装的 `argus.exe` 及由它复制的管理员副本、任务管理器替换副本均为安装版，仍可应用内更新，不依赖副本目录中存在卸载程序；免安装下载在任何位置运行都是免安装版。只读助手 `--argus-updater-check` 在窗口、单实例和权限路由之前返回类型，供安装包检查使用。

平台职责与 macOS 边界见[GPUI 开发](../development/gpui.md)。

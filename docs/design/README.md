## 原则

- **安静的表格，响亮的脉搏**：只有顶部概况带使用大号数字和实时曲线，表格保持克制。
- **颜色只编码数据**：青色 = CPU（能效核为长春花蓝），紫色 = 内存，琥珀 = 磁盘与负载热度，绿色 = 网络，玫红 = GPU，黄绿 = 电池，珊瑚红 = 破坏性操作；选中和焦点使用系统强调色。
- **数字不抖动**：等宽数字，按显示精度排序，避免相近的行每秒互换位置。
- **同一个量只用一种单位**：容量和速率用二进制单位（1 KB = 1024 字节），写作 KB、MB、GB，与 Windows 一致；比特速率用十进制（Kbps、Mbps、Gbps）。磁盘与 I/O 用字节每秒；网络速率在设置里选字节或比特，全应用一致，只有性能页的网络视图同时显示两种；链路速度按规格写比特，并附上换算。同一个指标在不同位置用同一个名字和单位（例如分页缓冲池）。
- **首屏先给数字**：性能页的首屏由曲线、实时数字和常用规格填满，曲线占去数字以外的全部高度：窗口越大曲线越大，逻辑处理器与 GPU 引擎的小图按可用面积选择列数，让每格尽量大；窗口较矮时曲线压到最小高度、标注移入曲线框内，页面滚动。不常用的信息收进首屏之下的展开卡片，标题行保留一行摘要，收起时不渲染内容。
- **点哪儿就是哪儿**：指针在列表上、菜单或对话框打开时，刷新只更新数值，不重新排序。
- **原生优先**：Mica 背景、原生标题栏（保留贴靠布局）、Segoe UI Variable、系统强调色。
- **动效回应操作，曲线连续流动**：切换页面、打开菜单和对话框有过渡，选中标记在选项之间滑动；曲线按时间轴匀速流动，默认跟随屏幕刷新率，由合成器驱动，主线程不参与。
- **键盘可用**：Ctrl+1–7 切换页面；↑↓ 选择，←→ 折叠展开，Enter 详细信息，Delete 结束（Shift+Delete 跳过确认），Ctrl+F 搜索。
- **流畅是功能**：卡顿和性能回退按缺陷处理，每个界面改动都要量开销，见[性能基线与测量](../development/performance.md)。

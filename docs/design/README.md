## 原则

- **概况与详情**。概况带用大号数字显示整机负载。进程表使用等宽数字，按显示精度排序。性能页先分配实时读数与常用规格的位置，再用剩余空间绘制曲线。CPU 详情单独展示温度、功耗和传感器。
- **颜色**。CPU 用青色，能效核用长春花蓝，低功耗能效核用绿色（紫色系在红绿色觉异常下与能效核的蓝色几乎无法区分），内存用紫色，磁盘用琥珀色，网络用绿色，GPU 用玫红色，电池用黄绿色。选中和焦点使用系统强调色，破坏性操作使用珊瑚红。
- **单位**。容量与字节速率按 1024 进位，比特速率按 1000 进位。磁盘与 I/O 使用字节每秒，网络使用设置中的单位，网络性能页同时列出两种单位。
- **列表交互**。指针停在进程列表或打开菜单、确认框时保持行位置，数值继续刷新。恢复排序后按当前列和方向排列。
- **窗口与文字**。Windows 11 使用 Mica 和系统强调色，标题栏支持系统贴靠布局。界面使用 Segoe UI Variable 和微软雅黑 UI。
- **动效**。切换页面、打开对话框和重排图表网格时，元素从当前位置过渡到目标位置。实时曲线按采样时间滚动，复用缓存纹理。涉及绘制的改动按[性能测量方法](../development/performance.md)核对开销。
- **键盘**。Ctrl+1–8 切换页面，方向键选择或展开条目，Enter 查看详情，Ctrl+F 搜索。其他操作见[键盘操作](../guide/README.md#键盘操作)。

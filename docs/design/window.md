# 窗口外观

窗口采用 GPUI Kit TitleBar 和原生窗口管理；Windows 11 使用 Mica，其他支持的 Windows 系统采用不透明背景。色板、文本和原生窗口主题同步，颜色定义见 resources/theme.json。

Windows 启动参数 `--opaque-window` 选用绑定到 HWND 的不透明交换链，由 Argus 绘制主题底色。默认的 Windows 11 窗口保留云母材质。两种窗口均在显示前将曲线填充与底色混合。

启动窗口尺寸与最小尺寸来自 resources/app.json。隐藏启动不激活窗口；隐藏窗口的初始客户区尺寸在平台适配层按 DPI 校正，避免首次显示时使用默认桌面尺寸。拖动、缩放、系统按钮与命中测试由原生框架处理。

显示状态变化由原生窗口消息统一驱动采样节拍和曲线调度。最小化或托盘隐藏停止持续绘制，恢复时请求新快照。测试实例使用不激活显示和窗口捕获，不抢占正在使用的桌面。

主题、DPI、最大化与调整大小均通过窗口捕获验证实际合成画面。

菜单、下拉列表、悬浮提示与通知通过背景和边框区分层级，统一关闭投影；对话框使用遮罩和投影。部分 NVIDIA 显示环境在半透明页面上绘制浮层投影时会出现亮色光晕，关闭投影可避开该现象。普通及换行提示共用 `widgets::tooltip_text`，在此覆盖组件库的默认阴影。

## 按区域使用 ClearType（暂缓）

默认云母窗口保留阅读区原有的半透明底色，普通文字使用校准灰阶。整窗实色模式可按系统设置使用 RGB 子像素抗锯齿。当前实现见[原生界面](../architecture/frontend.md)。

备选方案在公共渲染器内为同一字形缓存 RGB 和灰阶覆盖率。绘字时，若同一绘制表面已有完全不透明的底色覆盖可见字形，且文字与设备像素对齐，则采用 RGB。透出云母、涉及圆角边缘、淡入或缩放的文字采用灰阶。重放缓存时根据当时的背景、裁剪和变换重新判断。

原型通过给进程表、性能详情、历史列表和设置卡片铺设主题实色来扩大 RGB 的覆盖范围。这些区域也随之遮住了云母，与当前保留材质层次的外观要求冲突，方案暂缓。以后若重新评估，优先从已有实色底的菜单和弹窗入手，保持主要阅读区的材质。

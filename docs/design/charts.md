# 曲线与时间轴

曲线使用 GPUI 原生路径与 tooltip。单调三次贝塞尔曲线保留采样峰值，不产生超调，统一使用主题线宽与渐变面积。数据值来自 Rust 快照，时间位置来自 Snapshot.timestamp；源时间映射到单调动画时钟，接收时间仅用于时钟校准，恢复时不会将排队数据压缩到一起。

resources/motion.json 定义时间窗口、显示延迟和绘制目标。流畅模式随实际显示节拍更新；均衡模式限制动画更新频率；节能模式按物理像素推进；关闭模式只在采样变化时更新。暂停保留最后的显示时间，隐藏或数据过期时停止绘制。

几何路径按数据序列、范围、颜色、语言与单位缓存，连续平移复用已有路径。页面布局记录图表位置和裁剪范围；独立的图表层与页面实体并列，曲线帧只更新图表，不沿父实体重建工具栏、表格和详情。页面过渡的透明度同步作用于图表层。缺失值断开曲线，设备以稳定标识索引；硬件变更不按旧数组位置拼接。

历史曲线支持时间选择与键盘定位，选中时刻对应独立查询结果。查询窗口随请求一起返回，过期响应不覆盖新的范围。

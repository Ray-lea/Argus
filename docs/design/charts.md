# 曲线与时间轴

曲线使用单调三次贝塞尔几何与 GPUI 原生 tooltip。悬停读数的节奏与原版相同：指针静止时，圆点每帧沿曲线移动，文字在流畅与均衡模式下每 100 ms 读取一次指针处的曲线，新采样到达或指针移动时立即读取；像素与关闭模式下曲线逐像素或逐采样移动，文字随每一步更新。曲线保留采样峰值，不产生超调，统一使用主题线宽。与原版一致，次要序列（内核时间、写入、发送等）用同色虚线（4/3），虚线沿弧长排列，陡峭处也保持长度。虚线像印在曲线上一样随曲线移动：每次重绘时，各采样点沿用上次绘制时在虚线图案中的位置（按周期取模），只要两采样点之间的线段为此伸缩不超过 25%；未变的线段重绘后完全相同，两端因新采样到达或最早采样移出而重新弯曲的线段只在自身范围内变化，上限变化后各段略微伸缩以保持各采样点处的相位，需伸缩更多的线段按自身长度排列、下一段重新对齐。若只固定最早一个采样点的相位、其后按长度续排，最早采样移出时第一段重新弯曲，其后所有虚线都会沿曲线移动，上限变化时整条重排。虚线按自己的细分（约每纹素一段）计算长度并切出各段，不交给 tiny-skia 分段：两者对弧长的估计相差零点几个像素，自行切分时上次测得的相位在重绘中精确重现。侧栏预览等无标题的紧凑图表中虚线断续难辨，次要序列改用 55% 不透明度的同色实线，不加填充。每条序列各自的面积从图表顶部向下渐隐。速率与功率图的上限取显示单位下的整数（十以上取十的倍数）并设下限；持续显示的同一序列上限变化时在 420 ms 内拉伸已缓存的纹理过渡，不额外重绘，首次显示、切换设备或返回页面时直接使用当前上限。数据值来自 Rust 快照，时间位置来自 Snapshot.timestamp；源时间映射到单调动画时钟，接收时间仅用于时钟校准，恢复时不会将排队数据压缩到一起。

resources/motion.json 定义时间窗口、显示延迟和绘制目标。流畅模式随实际显示节拍更新；均衡模式限制动画更新频率；节能模式按物理像素推进；关闭模式只在采样变化时更新。暂停保留最后的显示时间，隐藏或数据过期时停止绘制。进程页 CPU 卡片的核心条按原版尺寸绘制（4 px 宽、2 px 间隔、26 px 高、1.5 px 圆角，轨道为 14% 的 CPU 色），与原版的合成器动画相同，流畅与均衡模式下每收到一份采样，核心条从当前高度出发，在一个刷新间隔内线性滑向新值，下一份采样到达时恰好到位；高度不按采样时间戳插值，采样晚到或早到时既不停顿也不跳变。页面出现时核心条从底部升起，暂停及其他模式直接显示最新值。核心条的两侧与底边对齐设备像素，顶边保留亚像素位置，以一个设备像素高的覆盖渐变绘制，高度随显示节拍连续变化，不逐像素跳变；圆角从渐变起点开始，随顶边连续移动，不在顶边跨过像素行时整行跳动。

数据、范围、线宽、颜色或显示密度改变时，在后台以物理分辨率的两倍绘制曲线纹理；滚动帧仅以亚像素坐标平移缓存纹理，避免每帧重新细分路径和解析整窗多重采样纹理。Windows 渲染器对这类纹理按每个像素覆盖的纹素面积取样，纹素先预乘再平均：双线性取样在部分亚像素位置只取一个纹素，斜线出现随滚动变化的阶梯，还会把描边的直通颜色与周围的透明黑混合，使边缘发暗；按面积取样后，两倍纹理在任何位置都得到与直接绘制相同的抗锯齿。纹理左缘按时间轴对齐到整纹素，同一时刻在每次重绘中落在纹素内的同一位置：新采样到达后的重绘与已显示的部分逐纹素一致，曲线和虚线端点不会每个采样重新抗锯齿一次（时钟停住、新采样照常到达时，重绘前后可见部分至多 25 个像素相差至多 4 个色阶；1240×800 窗口，调试版，模拟数据）。网格、标签和交互标记独立绘制。面积渐隐用纯色填充加逐行遮罩，代价远低于渐变着色器；不透明度与原版的线性渐变相同，从图表顶部的序列不透明度（默认 30%）线性降到底边为零。纹理在预绘制阶段开始绘制，屏幕上的各图并行；一组序列首次显示（进入页面、切换设备或视图、打开详情窗格）时，绘制阶段等待它的纹理，曲线与页面同帧出现并随页面一起淡入，与原版在这一帧之前绘制画布相同。等待只为纹理迟迟不来的异常情况设 250 ms 上限。大窗口的纹理单线程绘制远超一帧（2500×1400 窗口中 CPU 曲线的纹理为 4735×1744，调试版单线程约 250–300 ms），因此较大的纹理分成横条交给多个线程：每 128K 像素一个线程，最多 8 个，每个线程隔条绘制两条，面积集中的下部不会落在同一个线程上；同一纹理调试版约 45 ms、发布版约 19 ms 完成。每个横条移动后单独裁剪绘制，跨过横条边界的曲线在边界处被切开、重新细分，个别纹素的覆盖率相差一个子采样（1/16），两倍纹理按面积缩小后不可见。每张图的同一组序列最多保留一个在途任务，换成其他序列时旧任务的结果作废；同一序列的较早纹理在新纹理完成前按自身的时间窗口和上限继续显示，其他序列（例如上一个设备）的纹理不显示，替换和卸载时释放旧纹理。减少动画、暂停和隐藏行为不变。

页面布局记录图表位置和裁剪范围；所有实时图表共用一个独立的动画实体，直接复用这些位置绘制，不在每帧重建图表的布局容器，也不带动工具栏、表格和详情重建。页面过渡的透明度与位移同步作用于图表层：图表层在预绘制阶段读取透明度，与页面在同一帧变化，位移随各图记录的位置一起移动。详情窗格打开或收起时只在绘制时移动，其中的曲线同样随窗格位移、淡入：曲线自身的裁剪范围（图表框）随窗格移动，再裁剪到窗格的绘制范围（布局位置，比布局宽时向左延伸），窗格出现时曲线随之完整出现。性能页切换设备时，详情视图从所选设备的方向移入 16 px 并淡入（250 ms），与原版的 transform 一样只作用于绘制：视图按最终位置布局，滚动范围不随位移变大，内容不超出时动画期间也不出现滚动条；曲线随视图位移、淡入，仍裁剪在滚动区域内。性能页的详情卡片内容高度不超过 640 px 时（原版对卡片的尺寸容器查询），图表名称、上限、时间跨度和零点移入曲线框内（距框外沿 7 px，字号为正文的 11/13），图表框占满腾出的高度；这些标注由图表层绘制在曲线之上、悬停读数之下，与曲线一同随页面位移、淡入和裁剪，只在图表层完整绘制时排版，曲线平移的帧沿用已绘制的文字。卡片高度取视口高度减去上次布局测得的卡片周边高度，调整窗口大小时当帧生效；CPU 详情页的温度与功耗曲线与原版一样取卡片高度的 22%（110–220 px）。未知读数断开曲线；采样间隔变大（最小化或在托盘中按后台间隔采样、暂停后恢复、漏采）时与原版一样连接前后的采样，窗口恢复后曲线不出现空段。设备以稳定标识索引；硬件变更不按旧数组位置拼接。时间轴从第一份快照起为每个进程和应用记录 CPU 与内存（保留图表时间窗口，进程退出即丢弃），详情面板选中时曲线已经完整。进入页面、切换设备或视图时，逻辑处理器与 GPU 引擎网格在测得实际尺寸后直接放到最终位置；此后的窗口尺寸变化与 GPU 引擎的布局变化按主题的过渡重排。CPU 的整体与多核视图切换为交叉淡入：新视图在 220 ms 内从 0.985 倍（以图表区域中心为原点）按减速曲线放大、淡入，旧视图留在原处叠在其上，在 83 ms 内线性淡出（加速曲线会让旧视图在大半段时间里仍盖在新视图上，两者重叠显得杂乱）。核心类型（全部、性能核、能效核）切换时，留下的核心卡片在 260 ms 内按移动曲线从原来的位置和尺寸滑到新位置，移除的卡片在原处 83 ms 内线性淡出并缩小到 0.96 倍，新卡片在 30 ms 后用 230 ms 从 0.96 倍放大、淡入（再晚，没有卡片留下的切换会在两者之间出现几帧几乎空白的网格）；窗口尺寸变化引起的重排同样如此，按主题的过渡（167 ms）。这些过渡都是 GPUI 补丁的实时变换（`Window::with_live_transform`，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）：页面在切换时按新的排列布局、绘制一次，此后各帧只更新变换的数值，重放页面已绘制的内容，不重新渲染和布局页面；图表层在每帧开始时推进这些变换，用同一组变换和锚点绘制其中的曲线，曲线与卡片在同一帧移动。分段控件的选中标记同样以实时变换滑动（平移并横向拉伸，边框与圆角不变），切换时不因标记滑动而逐帧重新渲染所在页面。滑动的卡片按目标位置布局：图表框（连同曲线与网格线）从原来的矩形平移、拉伸到目标矩形，边框与圆角保持原粗细，标题两端分别随卡片的左上角和右上角平移，文字不缩放变形；曲线纹理按卡片到位后的尺寸绘制，滑动期间只拉伸，不重新绘制。过渡从切换后绘制的第一帧开始计时：首次显示的曲线要在这一帧之前绘制纹理，计时若从切换时开始，较慢的第一帧会吞掉过渡的前段。本次运行中首次显示的逻辑处理器网格要在测得尺寸后的下一帧才放置卡片，切换也随之推迟到卡片画出之后开始。此后每帧至多推进一个 60 Hz 刷新间隔：个别较慢的帧（页面再次渲染、首次显示的曲线绘制纹理）只推迟过渡，不跳过其中一段。结束后页面按最终排列重新渲染一次，去掉已淡出的视图和卡片。减少动画时直接换为新的排列。与原版的差异：原版切换时旧视图立即消失、新视图从透明和 0.985 倍淡入（200 ms），核心卡片直接换位；原版的网格重排（平移加缩放）只用于列数变化，卡片文字随缩放变形，这里只拉伸图表框，标题文字保持原样。

纯平移与核心条高度更新直接复用已绘制场景中的图元，省去重复布局与绘制数据生成；图元不能超出预留区域。采样、交互、悬停、主题、窗口尺寸或显示密度改变后仍执行正常绘制，旧句柄不跨完整绘制复用。零值与未知读数的核心条保持不可见，不用非零值占位。

Windows 渲染器缓存首个动画图元之前的静态画面，以原始像素复制复用，后续图元仍按原顺序混合绘制。完整绘制、尺寸变化或设备重建会失效缓存，包含外部动态表面的场景使用完整绘制。这样可避免曲线滚动时反复绘制静止的文字与表格，同时保留抗锯齿、颜色和刷新节拍。

跨越静态与动画边界的绘制批次按原顺序拆分，动画帧仅恢复、重画并提交受影响区域。柱形收缩或曲线平移时仍覆盖完整裁剪范围，避免残影；采样和窗口变化继续完整提交。

分离的图表区域分别复制和提交，同一行或列的区域合并以控制 GPU 命令数量。未变化的字形、阴影、下划线实例及视口参数保留在 GPU 缓冲区中；新场景、窗口尺寸或设备变化会更新相应数据。

网格与柱状背景在动态曲线层之前绘制，随静态画面一起缓存。互不重叠的曲线区域可在一次绘制中读取静态背景并合成曲线，省去单独的背景复制；合成时颜色与覆盖率都按与常规混合相同的“覆盖”规则累积，浅色主题半透明卡片上的曲线与面积不会因透明度相加而遮住更多背景、显得发灰。后绘制的柱状图可复用下方曲线已恢复的区域；未覆盖的区域仍单独恢复。区域重叠、纹理不可用或其他绘制类型不满足条件时，继续使用原有复制与混合路径。两条路径保持相同的纹理密度、线宽和采样；着色器内的浮点合成与固定管线混合的舍入不同，像素对照中曲线合成帧允许 8 位颜色通道最多两个色阶的差异（深色与浅色主题实测多为一个色阶），其余重绘最多一个色阶。

Windows 的绘制请求在开始绘制前确认，避免清除绘制期间到达的下一次同步请求。交换链按一个显示周期提交，防止采样更新后的相邻提交互相替换；这沿用实际显示节拍，不改变曲线模式或采样间隔。[Present1 的同步间隔语义](https://learn.microsoft.com/en-us/windows/win32/api/dxgi1_2/nf-dxgi1_2-idxgiswapchain1-present1)区分了保留帧与允许新帧替换旧帧的行为。

历史曲线支持时间选择与键盘定位，选中时刻对应独立查询结果。每个范围总是显示截至当前的最新时间窗口：切换范围时立即查询新范围的最新窗口，此后无论是否选中时刻，窗口都按范围定期前移（1 小时每 10 秒，6 小时每分钟，24 小时每 4 分钟，7 天每 5 分钟）。选中的时刻只在窗口包含它时保留：切换范围或窗口前移后仍在窗口内的，保留标记与读数（读数取新窗口中离它最近的数据点），该时刻的进程列表不变，也不重新查询；不在窗口内的取消选中，读数与进程列表回到最新数据，与单击“回到最新”相同。单击与键盘（← →、Shift、Page Up / Page Down、Home、End）只在屏幕上窗口的数据点之间选择，不移动窗口；Esc 与“回到最新”只取消选中。时间轴不支持拖动或滚轮平移。工具栏的暂停只冻结实时数据，历史照常记录，历史页照常前移。原版选中时刻后窗口保持不动、不再前移，切换范围时以选中时刻为中心显示（可借此查看过去某一小时）；此处按用户要求改为始终显示最新窗口，查看更早的时段需切换到更长的范围。查询窗口随请求一起返回，过期响应不覆盖新的范围；序列与时刻查询各自同时只有一个在途，被丢弃的过期响应返回后立即补发当前范围或时刻的查询。新窗口的结果返回时再按它检查选中的时刻：查询期间在旧窗口上单击或按键选中、但不在新窗口内的时刻同样取消选中。每次查询结果视为不同的序列：切换范围、回到最新或定期刷新时，不把上一个时间窗口的纹理拉伸到新的时间轴上，各图与首次显示一样等待新纹理就绪（250 ms 仅为保险上限），在同一帧换成新曲线；与原版一样，新范围的时间网格在点击时即生效，曲线在查询返回后更新。

# 曲线与时间轴

曲线位图覆盖当前时间窗，两侧各预留八分之一个窗口用于滚动。采样间隔很长时，先在边界处裁切原曲线，再计算虚线和位图尺寸。窗口内延续原有斜率，未知读数仍会断开。纹理依据可见曲线段的端点、描边宽度、填充和滤波边缘分配行，填充渐变和悬停圆点仍按原图高度定位。

单张位图每边最多 16,384 个纹素，按 BGRA 像素和并行绘制所需的遮罩预留最多 128 MiB。超大视口逐档降低栅格密度。所有图表的在途构建和等待界面接收的结果共用 192 MiB 额度，空间释放后继续绘制。

曲线使用单调三次贝塞尔几何与 GPUI 原生 tooltip。悬停读数的节奏：指针静止时，圆点每帧沿曲线移动，文字在流畅与均衡模式下每 100 ms 读取一次指针处的曲线，新采样到达或指针移动时立即读取；像素与关闭模式下曲线逐像素或逐采样移动，文字随每一步更新。圆点位于指针竖线的中点，读取竖线中点处的曲线，高度按本帧纹理放置曲线的方式计算（包括上限过渡中的拉伸），并以小数像素位置绘制：布局和四边形都对齐整设备像素，按布局放置的圆点在平缓曲线上停住数十帧再跳一个像素，偏离曲线最多半个像素，看起来在抖；圆点因此以曲线纹理的密度预先绘制成图像，与曲线一样按面积取样，随曲线连续移动。

resources/motion.json 定义时间窗口、显示延迟和绘制目标。流畅模式随实际显示节拍更新；均衡模式限制动画更新频率；节能模式按物理像素推进；关闭模式只在采样变化时更新。暂停保留最后的显示时间，隐藏或数据过期时停止绘制。进程页 CPU 卡片的核心条按固定尺寸绘制（4 px 宽、2 px 间隔、26 px 高、1.5 px 圆角，轨道为 14% 的 CPU 色），流畅与均衡模式下每收到一份采样，核心条从当前高度出发，在一个刷新间隔内线性滑向新值，下一份采样到达时恰好到位；高度不按采样时间戳插值，采样晚到或早到时既不停顿也不跳变。页面出现时核心条从底部升起，暂停及其他模式直接显示最新值。核心条的两侧与底边对齐设备像素，顶边保留亚像素位置，以一个设备像素高的覆盖渐变绘制，高度随显示节拍连续变化，不逐像素跳变；圆角从渐变起点开始，随顶边连续移动，不在顶边跨过像素行时整行跳动。

数据、范围、线宽、颜色或显示密度改变时，在后台以物理分辨率的两倍绘制曲线纹理；滚动帧仅以亚像素坐标平移缓存纹理，避免每帧重新细分路径和解析整窗多重采样纹理。Windows 曲线纹理保留栅格器的预乘颜色。渲染器按目标像素覆盖的面积计算权重，将相邻纹素组合为四次硬件线性采样，完成二维面积过滤；有效采样范围保持每轴 1–3 个纹素，边界外按透明像素参与面积计算。纹理左缘按时间轴对齐到整纹素，同一时刻在每次重绘中落在纹素内的同一位置：新采样到达后的重绘与已显示的部分逐纹素一致，曲线和虚线端点不会每个采样重新抗锯齿一次（时钟停住、新采样照常到达时，重绘前后可见部分至多 25 个像素相差至多 4 个色阶；1240×800 窗口，调试版，模拟数据）。网格、标签和交互标记独立绘制。面积渐隐用纯色填充加逐行遮罩，代价远低于渐变着色器；不透明度从图表顶部的序列不透明度（默认 30%）线性降到底边为零。纹理在预绘制阶段开始绘制，屏幕上的各图并行；一组序列首次显示（进入页面、切换设备或视图、打开详情窗格）时，绘制阶段等待它的纹理，曲线与页面内容同帧出现。等待只为纹理迟迟不来的异常情况设 250 ms 上限。大窗口的纹理单线程绘制远超一帧（2500×1400 窗口中 CPU 曲线的纹理为 4735×1744，调试版单线程约 250–300 ms），因此较大的纹理分成横条交给多个线程：每 128K 像素一个线程，最多 8 个，每个线程隔条绘制两条，面积集中的下部不会落在同一个线程上；同一纹理调试版约 45 ms、发布版约 19 ms 完成。每个横条移动后单独裁剪绘制，跨过横条边界的曲线在边界处被切开、重新细分，个别纹素的覆盖率相差一个子采样（1/16），两倍纹理按面积缩小后不可见。每张图的同一组序列最多保留一个在途任务，换成其他序列时旧任务的结果作废；同一序列的较早纹理在新纹理完成前按自身的时间窗口和上限继续显示，其他序列（例如上一个设备）的纹理不显示，替换和卸载时释放旧纹理。减少动画、暂停和隐藏行为不变。

页面和设备切换时，旧内容在切换帧移除，新内容从首帧以正常亮度滑入。图表与内容使用同一段对齐物理像素的位移。性能图表的四条边由外框绘制，网格只绘制内部分隔线。缩放或重放缓存时，描边的位置与线宽分别对齐到设备像素。图表自身的裁剪随图框移动，滚动面板的视口保持在原位。

页面布局记录图表位置和裁剪范围；所有实时图表共用一个独立的动画实体，直接复用这些位置绘制，不在每帧重建图表的布局容器，也不带动工具栏、表格和详情重建。图表层在预绘制时读取页面位移，与页面在同一帧移动。详情窗格打开或收起时只在绘制时移动，其中的曲线同样随窗格位移、淡入：曲线自身的裁剪范围（图表框）随窗格移动，再裁剪到窗格的绘制范围（布局位置，比布局宽时向左延伸），窗格出现时曲线随之完整出现。性能页切换设备时，详情视图从所选设备的方向滑入 16 px（250 ms），过渡只作用于绘制：视图按最终位置布局，滚动范围不随位移变大，内容不超出时动画期间也不出现滚动条；曲线与视图同步移动，由滚动视口裁剪。性能页的详情卡片内容高度不超过 640 px 时，图表名称、上限、时间跨度和零点移入曲线框内（距框外沿 7 px，字号为正文的 11/13），图表框占满腾出的高度；这些标注由图表层绘制在曲线之上、悬停读数之下，与曲线一同随页面移动和裁剪，只在图表层完整绘制时排版，曲线平移的帧沿用已绘制的文字。卡片高度取视口高度减去上次布局测得的卡片周边高度，调整窗口大小时当帧生效；CPU 详情页的温度与功耗曲线取卡片高度的 22%（110–220 px）。未知读数断开曲线；采样间隔变大（最小化或在托盘中按后台间隔采样、暂停后恢复、漏采）时连接前后的采样，窗口恢复后曲线不出现空段。设备以稳定标识索引；硬件变更不按旧数组位置拼接。时间轴从第一份快照起为每个进程和应用记录 CPU 与内存（保留图表时间窗口，进程退出即丢弃），详情面板选中时曲线已经完整。首次显示逻辑处理器或 GPU 引擎网格时，先按视口测量卡片并排好图表，测量期间继续显示上一幅完整画面。首次按卡片高度计算图表尺寸、切换小窗口的图注布局时也沿用上一帧。图层从可呈现的布局开始生成曲线纹理，首帧直接使用实际尺寸。进入页面、切换设备或视图时，网格直接放到最终位置；此后的窗口尺寸变化与 GPU 引擎的布局变化按主题的过渡重排。CPU 的整体与多核视图切换为交叉淡入：新视图在 220 ms 内从 0.985 倍（以图表区域中心为原点）按减速曲线放大、淡入，旧视图留在原处叠在其上，在 83 ms 内线性淡出（加速曲线会让旧视图在大半段时间里仍盖在新视图上，两者重叠显得杂乱）。核心类型（全部、性能核、能效核）切换时，留下的核心卡片在 260 ms 内按移动曲线从原来的位置和尺寸滑到新位置，移除的卡片在原处 83 ms 内线性淡出并缩小到 0.96 倍，新卡片在 30 ms 后用 230 ms 从 0.96 倍放大、淡入（再晚，没有卡片留下的切换会在两者之间出现几帧几乎空白的网格）；窗口尺寸变化引起的重排同样如此，按主题的过渡（167 ms）。这些过渡都是 GPUI 补丁的实时变换（`Window::with_live_transform`，见 `vendor/gpui-pre/ARGUS-PATCHES.md`）：页面在切换时按新的排列布局、绘制一次，此后各帧只更新变换的数值，重放页面已绘制的内容，不重新渲染和布局页面；图表层在每帧开始时推进这些变换，用同一组变换和锚点绘制其中的曲线，曲线与卡片在同一帧移动。分段控件的选中标记同样以实时变换滑动（平移并横向拉伸，边框与圆角不变），切换时不因标记滑动而逐帧重新渲染所在页面。滑动的卡片按目标位置布局：图表框（连同曲线与网格线）从原来的矩形平移、拉伸到目标矩形，边框与圆角保持原粗细，标题两端分别随卡片的左上角和右上角平移，文字不缩放变形；曲线纹理按卡片到位后的尺寸绘制，滑动期间只拉伸，不重新绘制。过渡从切换后绘制的第一帧开始计时：首次显示的曲线要在这一帧之前绘制纹理，计时若从切换时开始，较慢的第一帧会吞掉过渡的前段。本次运行中首次显示的逻辑处理器网格要在测得尺寸后的下一帧才放置卡片，切换也随之推迟到卡片画出之后开始。此后每帧至多推进一个 60 Hz 刷新间隔：个别较慢的帧（页面再次渲染、首次显示的曲线绘制纹理）只推迟过渡，不跳过其中一段。结束后页面按最终排列重新渲染一次，去掉已淡出的视图和卡片。减少动画时直接换为新的排列。

纯平移与核心条高度更新直接复用已绘制场景中的图元，省去重复布局与绘制数据生成；图元不能超出预留区域。采样、交互、悬停、主题、窗口尺寸或显示密度改变后仍执行正常绘制，旧句柄不跨完整绘制复用。零值与未知读数的核心条保持不可见，不用非零值占位。

Windows 在支持且关闭硬件加速 GPU 计划的显卡上，会把符合条件的流动曲线和核心条交给 DirectComposition。带边框的图表使用主题卡片的实色底面，序列仍按原透明度渐隐。标准 SDR 输出下，静态背景和曲线分别缓存，移动时只提交位置变化。DirectComposition 在图表覆盖的矩形内将背景与动态图层合成为一幅图像，再与窗口材质混合。窗口圆角和其余静态区域直接显示原背景。核心条复用相同着色器绘制的高度缓存。改变页面、窗口或纹理会重新核对绘制顺序、裁剪和颜色空间，其他绘制仍由交换链完成。

包含已合成曲线的窗口在整帧重绘与图层滚动之间共用一个 DirectComposition 根节点和背景位图。收到新采样、等待缓存或显示悬停读数时，渲染器把当帧完成的画面写入该位图，在同一次提交中切换子图层。下一份曲线缓存就绪后，同一根节点恢复显示背景和移动曲线。这样可以避免滚动时短暂显示上一次交换链提交的曲线位置。

上传曲线纹理时记录首末非透明行。合成图层仅分配覆盖这些行和滤波边缘所需的显存，保留原图的采样坐标。位置相同的图层沿用上次提交的状态。最小化或隐藏窗口时释放活动图层和核心条缓存。所有窗口均已隐藏时，请求驱动回收临时缓冲。恢复后的首帧重建完整画面。

所有面积填充先与图表底色合成，包括 CPU 总体图、逻辑处理器网格、进程概览和详情、设备预览与各设备的性能曲线。进程概览整条卡片使用主题实色底面，悬停高亮与指标文字仍按原顺序绘制。历史页的静态曲线也在图框内绘制实色底面，读数标记叠在曲线上方。

Windows 渲染器让 GPU 逐列检查曲线覆盖范围内的背景。相邻列逐行相同且完全不透明时，共用一段底色。文字边缘等密集区合用一个裁剪范围，纹理为每个屏幕列按八分之一像素存放多个滚动位置的曲线颜色，每个位置都已与该列底色合成。滚动时通过位移在相邻采样之间插值，文字和网格保持原位。各区段并排存放在不透明的 BGRA8 表面。背景透出窗口材质、填充会覆盖先绘制的动态图元或缓存超出预算时，曲线回到窗口场景中绘制。默认云母窗口和 `--opaque-window` 都使用这项优化。

多核网格的裁剪区较多时，渲染器选取一列实际背景作为底图。GPU 逐行比较其余列，只为与参考列不同的网格线等像素写入虚拟表面。底图和这些修正列都存储已经混合好的颜色。滚动时每张符合条件的核心图只移动两层，同一列的修正始终显示在固定的屏幕位置。

Windows 渲染器缓存首个动画图元之前的静态画面，以原始像素复制复用，后续图元仍按原顺序混合绘制。完整绘制、尺寸变化或设备重建会失效缓存，包含外部动态表面的场景使用完整绘制。这样可避免曲线滚动时反复绘制静止的文字与表格，同时保留抗锯齿、颜色和刷新节拍。

两倍纹理密度的稳态区域使用四个等权重线性样本，省去逐像素计算通用面积权重；缩放过渡和纹理边缘继续按实际覆盖面积配权。两个分支共用预乘颜色与透明边界规则。

跨越静态与动画边界的绘制批次按原顺序拆分，动画帧仅恢复、重画并提交受影响区域。柱形收缩或曲线平移时仍覆盖完整裁剪范围，避免残影；采样和窗口变化继续完整提交。

分数缩放下，裁剪范围向外取整后可能比图像边界多出一个像素。背景合成着色器覆盖整个裁剪范围，图像外的像素从静态缓存恢复，因此保留该合成路径；区域重叠与不支持的图元仍按原条件回退。

分离的图表区域分别复制和提交，同一行或列的区域合并以控制 GPU 命令数量。未变化的字形、阴影、下划线实例及视口参数保留在 GPU 缓冲区中；新场景、窗口尺寸或设备变化会更新相应数据。

网格与柱状背景在动态曲线层之前绘制，随静态画面一起缓存。互不重叠的曲线区域可在一次绘制中读取静态背景并合成曲线，省去单独的背景复制；合成时颜色与覆盖率都按与常规混合相同的“覆盖”规则累积，浅色主题半透明卡片上的曲线与面积不会因透明度相加而遮住更多背景、显得发灰。核心条固定在曲线之后绘制，背景恢复范围限于各条预留的动画区域；与先绘制曲线相交的部分复用曲线已恢复的背景，其余部分单独恢复。区域重叠、纹理不可用或其他绘制类型不满足条件时，继续使用原有复制与混合路径。两条路径保持相同的纹理密度、线宽和采样；着色器内的浮点合成与固定管线混合的舍入不同，像素对照中曲线合成帧允许 8 位颜色通道最多两个色阶的差异（深色与浅色主题实测多为一个色阶），其余重绘最多一个色阶。

Windows 的绘制请求在开始绘制前确认，避免清除绘制期间到达的下一次同步请求。交换链按一个显示周期提交，防止采样更新后的相邻提交互相替换；这沿用实际显示节拍，不改变曲线模式或采样间隔。[Present1 的同步间隔语义](https://learn.microsoft.com/en-us/windows/win32/api/dxgi1_2/nf-dxgi1_2-idxgiswapchain1-present1)区分了保留帧与允许新帧替换旧帧的行为。

历史曲线支持时间选择与键盘定位，选中时刻对应独立查询结果。每个范围总是显示截至当前的最新时间窗口：切换范围时立即查询新范围的最新窗口，此后无论是否选中时刻，窗口都按范围定期前移（1 小时每 10 秒，6 小时每分钟，24 小时每 4 分钟，7 天每 5 分钟）。选中的时刻只在窗口包含它时保留：切换范围或窗口前移后仍在窗口内的，保留标记与读数（读数取新窗口中离它最近的数据点），该时刻的进程列表不变，也不重新查询；不在窗口内的取消选中，读数与进程列表回到最新数据，与单击“回到最新”相同。单击与键盘（← →、Shift、Page Up / Page Down、Home、End）只在屏幕上窗口的数据点之间选择，不移动窗口；Esc 与“回到最新”只取消选中。时间轴不支持拖动或滚轮平移。工具栏的暂停只冻结实时数据，历史照常记录，历史页照常前移。查询窗口随请求一起返回，过期响应不覆盖新的范围；序列与时刻查询各自同时只有一个在途，被丢弃的过期响应返回后立即补发当前范围或时刻的查询。新窗口的结果返回时再按它检查选中的时刻：查询期间在旧窗口上单击或按键选中、但不在新窗口内的时刻同样取消选中。每次查询结果视为不同的序列：切换范围、回到最新或定期刷新时，不把上一个时间窗口的纹理拉伸到新的时间轴上，各图与首次显示一样等待新纹理就绪（250 ms 仅为保险上限），在同一帧换成新曲线；新范围的时间网格在点击时即生效，曲线在查询返回后更新。

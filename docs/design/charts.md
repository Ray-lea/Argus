# 曲线与时间轴

本页说明实时曲线与历史曲线的设计：采样与显示节拍、纹理缓存、图表层与网格布局、Windows 合成、局部重绘、**历史**页的时间轴，以及磁盘与网络的速率量程。

## 采样与显示

图表使用快照的采样时间。相邻有效读数按单调三次贝塞尔曲线连接，明确缺失的读数形成断点。窗口最小化或隐藏期间若只延长了采样间隔，恢复时仍按实际时间连接前后样本。设备历史按稳定标识区分，进程与应用的 CPU、内存历史在首次采样时开始记录。

[动画参数](../../resources/motion.json)控制时间窗、显示延迟和绘制节拍。**曲线动画**设置的四档模式按以下节拍绘制：

| 模式 | 绘制节拍 |
| --- | --- |
| **流畅** | 跟随显示器 |
| **均衡** | 以 60 Hz 为目标，按整数个显示周期调度 |
| **省电** | 按物理像素推进 |
| **关闭** | 到达新采样时更新 |

暂停刷新会冻结显示时间，窗口隐藏或数据过期时停止持续绘制。

悬停圆点按曲线纹理和当前量程定位，随每一帧移动。指针静止时文字每 100 ms 刷新，收到新采样或移动指针时立即刷新。在省电与关闭模式下，文字随曲线更新。

## 可见范围与纹理缓存

栅格器先把线段裁到可见时间窗，两侧各留八分之一个窗口的滚动余量，再计算虚线、描边与位图尺寸。即使两次采样相隔数天，位图宽度仍由显示区域决定。只为可见曲线、填充和滤波边缘分配纹理行。侧栏预览被裁到视口外时保留其裁剪范围，重新进入视口后再绘制。

### 纹理尺寸与显存额度

单张位图每边最多 16,384 个纹素，按 BGRA 像素和并行绘制所需的遮罩预留最多 128 MiB。超大视口逐档降低栅格密度。所有图表的在途构建和等待界面接收的结果共用 192 MiB 额度，空间释放后继续绘制。

Windows 为超出常规图集页的彩色长条纹理按 64 个纹素对齐分配页面。移除最后一个图块后，页面退出活动图集。同一批上传里，物理尺寸相同的新图块可复用这张纹理及其着色器资源视图。最多暂存 8 页、合计 16 MiB，开始呈现时释放剩余空页。窗口隐藏、尺寸变化或图形设备重建时也会清空这些页。

Windows 仅在绘制矢量路径时建立全窗口的四倍多重采样纹理及其解析目标。场景移除路径、窗口隐藏或调整尺寸后释放这对资源，后续路径按当前视口重建。

### 栅格化

数据、量程、线宽、颜色或显示密度变化时，后台按两倍设备像素密度栅格化。纹理左缘对齐到时间轴的整纹素位置，同一时刻在后续采样中保持相同的采样相位。Windows 保留预乘颜色，按目标像素的覆盖面积做二维过滤，图外按透明像素处理。填充遮罩按整张图的高度，从顶部的序列不透明度（默认 30%）线性降到底部的零。

大纹理按横条并行绘制，每 128K 像素使用一个线程，最多八个。每张图的同一组序列最多有一个在途任务。首次显示时等待新纹理与页面同帧呈现，上限为 250 ms。关闭动画时，曲线、填充、悬停读数与时间轴在新纹理就绪后一起切换。切换序列后丢弃过期结果。

## 页面切换与网格布局

页面与图表按目标位置布局。`ChartLayer` 复用各图的位置和裁剪范围，与页面在同一帧更新平移；详情窗格使用同一位移和裁剪绘制内容与曲线。

### 概况卡片

图表层绘制在页面之上，因此**进程**页概况卡片的文字也由图表层绘制：曲线之后，依次绘制从卡片底色渐隐的遮罩、悬停与按下底色和文字。页面以透明文字排出同样的布局，承担悬停提示与命中区域。量程线与量程标注由页面绘制，位于曲线下方。

Windows 合成要求静止内容位于所有与其重叠的移动图元之上，且只接受纯色底色，因此遮罩以拉伸的图像绘制，遮罩完全不透明处不绘制曲线。概况带的渐隐遮罩是普通彩色图片：线性采样限制在当前图块最外侧纹素的中心之间，缩放时保持边缘颜色，避免混入同一纹理图集中相邻图标的像素。曲线的面积过滤仍将图外按透明像素处理。

曲线横向铺满卡片，底边比卡片高 8 px，避开圆角外透出的窗口材质。

曲线末端不加随曲线移动的圆点。开发构建在 1800×900 客户区、165 Hz 流畅模式下，五个这样的圆点使进程 CPU 时间约从 110 ms/s 升至 150–260 ms/s，GPU 最忙引擎从约 0.1% 升至约 1%。

### 图框与标注

**性能**页的外框负责四条边，网格只画内部分隔线，缩放时分别把线宽和位置对齐到设备像素。卡片空间较小时，量程和时间标注移入图框。

### 网格的首次显示与重排

首次显示逻辑处理器或 GPU 引擎网格时，先测量可用区域，再用实际尺寸绘制卡片和纹理。等待布局期间保留上一幅完整画面。

CPU 总览与多核布局交叉淡入，核心类型筛选和列数变化通过 `Window::with_live_transform` 重排。同一排列下调整窗口或设备列表宽度时，卡片按网格比例在同一帧伸缩，不播放过渡。卡片沿目标矩形移动，标题保持字号，边框保持线宽；过渡从第一幅可绘制的画面起算。关闭**界面动画**时直接使用新排列。

### 逻辑处理器网格的列数

逻辑处理器网格按曲线的可读程度选择列数（`model::core_grid_columns`）。曲线宽约为高的 1.4 倍时最易读，与原生任务管理器的小图相近；在页面滚动之前，曲线不扁于 2.8 : 1，高度达到 64 px 后不再受此限制。同样可读时，优先没有空位的整齐行列，末行空位越多越不取。

卡片可窄于完整标题：先省去频率，再隐藏整行标题，由曲线占用该行；省去的频率与占用率改在悬停提示中显示。标题仅在其行不使曲线过扁时显示；隐藏标题的排列须使曲线明显更大，才会取代显示标题的排列。

标题的变化与列数变化一同过渡：标题与频率淡入淡出，曲线框在同一实时变换中让出或占用标题行，过渡期间不重绘曲线纹理。

网格的可用高度是页面不滚动时它所得的空间（网格高度减去页面的溢出量），因此不随所选排列变化。该高度不足 300 px 时，网格取可见区域内至多 300 px，实时数字与规格移至其下方，页面滚动。

## 内核时间层

CPU 图表的内核时间与利用率曲线画在同一张纹理里，开启后不增加曲线图像与合成图层的数量。整体图为同色虚线加浅填充；多核视图的小图容不下虚线，用 60% 不透明度的实线加填充。

该层由**显示内核时间**控制，不计入图表的内容标识。勾选或取消后，屏幕上的纹理保留到新纹理就绪，曲线不出现空白帧，也不触发首次显示时的等待。图例里的“内核时间”随该层淡出并保留占位，图表高度不变。

淡入淡出沿用界面的 167 ms 过渡，匀速逐档改变该层的不透明度，每档重绘显示它的各张纹理；关闭**界面动画**时直接切换。档数随图表数量减少，全程重绘的纹理控制在约 40 张：整体图 6 档，12 个逻辑处理器 3 档，20 个 2 档，28 个及以上直接切换。档数按重绘的纹理总量限制，逻辑处理器很多时，一次切换不会重绘数百张纹理。

过渡期间逐帧绘制页面。测量条件为 i5-13500HX（20 个逻辑处理器）、发行构建、1240×800 客户区、165 Hz 流畅模式、刷新间隔 1 秒，整机另有约 50% 且持续波动的负载。各类过渡的刷新周期丢失如下：

- 多核视图一次淡入淡出比平稳滚动多丢失约 5 个刷新周期（2 档；4–6 档为 4–11 个）。
- 整体图的淡入淡出与设备列表的过渡，没有超出采样本身带来的丢失。
- 同法测得页面已有的过渡（核心筛选、视图切换、设备切换）每次约 2–6 个。

每档改由定时器单独绘制一次页面并不更省：夹在只平移纹理的帧之间的单次整页绘制各丢失一个周期（采样到达时同样如此），同样条件下每次约 8–15 个。

## 设备列表的过渡

设备列表隐藏某一项时，该项在 250 ms 内收起并淡出，其下各项与选中标记按同一曲线上移，恢复时反向进行；隐藏选中项时，标记留在原处，后一项移入。行的预览曲线由图表层按行的裁剪范围和不透明度绘制。过渡期间页面逐帧重新布局，结束后回到只平移曲线纹理的路径；关闭**界面动画**时直接切换。

## Windows 合成

Windows 在符合 SDR 输出、绘制顺序和显存预算条件时，将移动曲线交给 DirectComposition。具备 HAGS 能力的 Windows 11 显卡在两种调度模式下均可复用缓存。

CPU 总图、多核网格、进程概况与详情、设备预览、GPU 引擎和显存图都先将填充与图框底色合成，再与窗口材质混合。静态历史图同样在图框内绘制实色底面。窗口其余部分保留主题材质。

### 按列合成

Windows 渲染器让 GPU 逐列检查曲线覆盖范围内的背景。相邻列逐行相同且完全不透明时，共用一段底色。文字边缘等密集区合用一个裁剪范围，纹理为每个屏幕列按八分之一像素存放多个滚动位置的曲线颜色，每个位置都已与该列底色合成。

滚动时通过位移在相邻采样之间插值，文字和网格保持原位。各区段并排存放在不透明的 BGRA8 表面。默认云母窗口和 `--opaque-window` 都使用这项优化。

多核网格的裁剪区较多时，渲染器选取一列实际背景作为底图。GPU 逐行比较其余列，只为与参考列不同的网格线等像素写入虚拟表面。底图和这些修正列都存储已经混合好的颜色。滚动时，每张符合条件的核心图只移动两层，同一列的修正始终显示在固定的屏幕位置。

### 退回逐帧重绘的条件

以下情况下，曲线回到窗口场景中绘制：

- 背景透出窗口材质（诊断事件 `gpu-chart-backdrop-limit` 的 `translucent-prefix`）
- 填充会覆盖先绘制的动态图元
- 缓存超出预算

静止内容只在画在所有与其重叠的移动图元（曲线纹理、动画柱条）之后、且只用纯色底色或普通图像时，才留在合成树之外。渐变底色或夹在移动图元之间的静止内容，同样让曲线退回逐帧重绘。随曲线逐帧移动的小图像也会明显增加 CPU 与 GPU 开销。

窗口里只要有矢量路径（`window.paint_path`），渲染器就放弃静态画面缓存，曲线不再交给合成器，每帧整窗重绘。因此，有移动曲线的页面（包括用 `TimePlot::glide` 平移纹理的**历史**页）把小图用 tiny-skia 画成图片（`charts::sparkline_image`）。

### 静态前景

静态提示框与曲线共存时，渲染器按图元类型分离移动内容和静态前景，并检查相交区域的绘制顺序。前景只栅格化其可见边界，纹理按 16 个纹素对齐并复用同尺寸分配。普通底色、灰阶文字、下划线和图标使用此路径。

覆盖曲线的部分参与背景分段和相位像素合成。覆盖动画柱条，或分段数量、宽度与显存超出限制时，前景放入同一合成组。前景资源计入原有缓存预算，窗口隐藏、尺寸或设备变化时回收。

### 软件渲染时的合成

关闭**硬件加速**后，曲线表面由 WARP 在 CPU 上绘制，图层仍交给系统合成器，在连接窗口所在显示器的显卡上移动；能力与显存预算按该显卡判断。没有连接显示器的显卡时，仍由交换链逐帧绘制。

曲线表面位于系统内存，集成显卡报告的专用显存又很少，因此预算不低于未报告显存的显卡所用的 48 MiB。CPU 只在内容变化时（约每次采样一次）重绘这些表面，不再逐帧绘制图表区域。

曲线上方的文字与遮罩一律放入合成组上方的前景层。若按列合成，文字边缘拆出的窄列按八分之一像素存放，进程概况的曲线表面会因此增大约十倍，每次采样都要由 CPU 重绘。该前景层只覆盖曲线与柱条的裁剪区，其余部分的前景合成进背景，与完整重绘的像素一致；裁剪区外的静态变化仍只更新背景矩形。

### 根节点与背景位图

整帧重绘和图层滚动共用一个根节点与背景位图。采样更新、悬停或等待缓存时，渲染器在同一次提交中切换背景及子图层；恢复滚动后，波峰从当前帧的位置继续移动。最小化或隐藏时释放活动图层。设备或尺寸变化后重新检查缓存。

## 局部重绘与显示节拍

Windows 渲染器缓存首个动画图元之前的静态画面，以原始像素复制复用，后续图元仍按原顺序混合绘制。没有动画图元的页面同样与上一帧比较，只重绘变化的矩形。静态快照最多保留 20,000 个图元，隐藏窗口时释放。

### 静态图元的比较

新场景按图元种类比较静态图元的内容、顺序和裁剪范围。内容相同则继续复用；局部变化则清除其新旧边界，只上传并绘制触及该区域的图元，再更新对应缓存像素。移动或删除的内容同时恢复原位置，动态曲线的恢复范围包含上一帧的裁剪区。

图元相同、但所用图集贴图在上一帧之后重新上传时，也按变化处理：贴图回收后，下一张同尺寸图像会沿用原来的标识。

以下情况使用完整绘制：

- 窗口尺寸或设备变化
- 大范围变化
- 包含路径或外部表面的前缀
- 超过半个窗口的修补（整帧绘制的复制量更少）

投影按其模糊范围（边界外三倍模糊半径）参与比较，因此浅色主题的卡片投影不再使整帧重绘。连续的大范围变化（如滚动列表）期间，不再逐帧把整幅画面复制进缓存。

### 跨越动画边界的批次

跨越静态与动画边界的绘制批次按原顺序拆分。动画部分仅在其图元变化，或待恢复的区域与其相交时重画。悬停底色等只改静态内容的帧不再重画曲线：需要更新的区域直接用触及它的静态图元重绘，缓存只写入修补的矩形。

柱形收缩或曲线平移时，仍覆盖完整裁剪范围，避免残影；采样和窗口变化重新核对绘制顺序、边界和资源。

### 合成树的更新

首次完整绘制即标记曲线的动态范围。新场景的静态内容与图像资源均相同时，沿用合成树并更新位置；鼠标移动触发的通知由实际像素变化决定重绘范围。

合成树只在曲线近三秒内有过不经重绘的移动时建立。关闭动效时曲线静止；此前每次重绘都会离屏绘制前景并启动一次背景扫描，而下一次重绘又在扫描完成前重新开始，悬停和图标动效期间应用自身的 GPU 占用因此多出一倍以上。

悬停底色等变化落在所有动态图层范围之外时，仅更新合成树对应的背景矩形，同时提交当前曲线位置。与曲线相交的内容继续重建所需缓存，以保持遮挡关系。

由合成树显示曲线、只更新背景矩形的帧，渲染目标中的曲线不会呈现，因此跳过绘制，留待下一幅完整呈现的画面补齐。

### 量程过渡与相位缓存

量程过渡通过已有纹理的高度和位置表现。量程过渡或相位缓存超出预算时，符合条件的曲线可在各自的裁剪区内重绘，再更新同一合成组中的不透明表面；进程概览、详情和**性能**页共用这一路径。

底色经 GPU 检查后从静态缓存复制，曲线使用原有面积采样；其他图表保留各自的缓存。过渡结束后恢复位置更新；预算回退时，持续复用同尺寸的局部纹理和表面。两类缓存共用显存上限，替换时先释放无法复用的表面，隐藏、尺寸或设备变化时清理。具体的预算与像素覆盖边界见 [Windows 渲染器补丁](../../vendor/gpui-pre-windows/ARGUS-PATCHES.md)。

两倍纹理密度的稳态区域使用四个等权重线性样本，省去逐像素计算通用面积权重；缩放过渡和纹理边缘继续按实际覆盖面积配权。两个分支共用预乘颜色与透明边界规则。

### 交换链缓冲区

交换链有三个缓冲区，提交后取回的是三次提交前呈现的那一个，DWM 重新合成窗口时又会读取缓冲区的全部像素。因此每帧除本帧变化外，还补画该缓冲区上次绘制以来错过的变化，`Present1` 只报告相对上一次呈现的变化区域。提交未返回 `S_OK`、窗口尺寸变化、隐藏或设备丢失后，随后的几帧重建整个缓冲区。

### 滚动复制

滚轮滚动列表时，平滑滚动的每一帧都落在整设备像素上；切换页面时，滑入的页面同样按整设备像素移动，且全程不透明。滚动容器与滑入的页面在场景中登记显示范围和位移，渲染器在内容移动后的一秒内保留上一帧的画面及其图元。

新一帧只比上一帧整像素移动时，渲染器把上一帧在显示范围内的像素按位移复制过来，再逐一核对图元：

- 原样移动的图元由复制得到。
- 位置不变、圆角与边框都不在显示范围内、且位于所有移动内容之下的纯色底色，复制前后颜色相同。
- 其余位置不变的图元（包括位于新露出区域、旧像素会被复制进来的图元）、按屏幕位置抖动的渐变、新出现、消失或内容变化的图元，以及新露出的行，都要重绘。重绘按其现在的位置、复制范围外的原位置和复制后旧像素所在的位置进行，最多分八次带裁剪绘制。

需重绘的面积超过显示范围的四分之三时，改用常规方式绘制；表格横向滚动时各行分别移动，同样按常规方式绘制。

平滑滚动在最后一步之后再绘制一帧，渲染时读取滚动位置的内容（如固定在顶部的分组标题）随之到位。结果与完整重绘逐像素一致；WARP 绘制的字形在不同位置取样，边缘与原地重绘相比可能相差两个色阶。

测量条件为 i5-13500HX、发行构建、1240×800 客户区、固定快照，整机另有约一半负载。关闭**硬件加速**时，滚轮滚动进程列表的 CPU 占用约由 8.3–9.5 s/s 降至 2.7–3.6 s/s，每 0.7 秒切换一次页面约由 3.9 s/s 降至 2.4 s/s。开启**硬件加速**时 GPU 占用不变，滚动帧的 GPU 时间以每帧固定的提交与复制为主。

### 背景复制与区域合并

分数缩放下，裁剪范围向外取整后可能比图像边界多出一个像素。背景合成着色器覆盖整个裁剪范围，图像外的像素从静态缓存恢复，因此保留该合成路径；区域重叠与不支持的图元仍按原条件回退。

分离的图表区域分别复制和提交，同一行或列的区域合并，以控制 GPU 命令数量。未变化的字形、阴影、下划线实例及视口参数保留在 GPU 缓冲区中；新场景、窗口尺寸或设备变化会更新相应数据。

网格随静态背景缓存。独立的曲线区域可直接读取背景，并按相同的覆盖率混合；区域重叠或纹理暂不可用时，改用背景复制和常规混合。两条路径共用纹理密度、线宽和采样规则。

### 像素对照的容差

像素对照时，8 位通道允许的舍入差如下：

- **曲线合成帧**：最多两个色阶。
- **悬停的概况卡片**：三个色阶。
- **其他重绘**：最多一个色阶。

悬停的概况卡片在曲线上方依次叠有渐隐遮罩、悬停底色和文字。完整绘制每画一层都取整到 8 位；合成帧把这些静态层合为一张 8 位图像后只与曲线混合一次，再由合成器在相邻的滚动相位之间插值。因此，陡峭的曲线边缘与这些层重叠处，个别像素相差三个色阶。

### 合成器时钟

Windows 11 优先用合成器时钟驱动动画，Windows 10 使用 `DwmFlush`。显示器关闭或等待失败时，按刷新间隔调度。交换链按一个显示周期提交，绘制开始时确认当前请求，让绘制期间到达的下一次同步信号继续生效。见[合成器时钟](https://learn.microsoft.com/en-us/windows/win32/api/dcomp/nf-dcomp-dcompositionwaitforcompositorclock)和 [Present1 同步间隔](https://learn.microsoft.com/en-us/windows/win32/api/dxgi1_2/nf-dxgi1_2-idxgiswapchain1-present1)。

## 历史曲线

历史曲线按阶梯绘制，其他页面的实时曲线仍以单调三次贝塞尔曲线连接。

### 跟随最新

跟随最新时，6 小时以内的窗口在每次采样后查询新增的读数，更长的窗口每分钟查询一次。序列查询和时刻查询各自最多有一个在途请求：其间到达的采样在回复后立即补查，过期回复丢弃后补发当前查询。

窗口末端比当前时刻晚两个采样间隔加 250 ms，与实时曲线相同，最新读数在窗口边缘到达它的时刻之前已经绘制。按恰好 1 秒的节拍查询会跳过提前到达的采样；窗口末端只晚 1 秒时，曲线末端会间歇离开窗口边缘约一秒。

跟随最新时，合并的时间段只画到已结束的一段。正在累积的一段的平均值随每次读数变化，若绘制出来，最新一段会上下跳动。每结束一段，用 450 ms 从左向右画出，数值由前一段缓动到新值；窗口右端至多空出一段，约 3–4 px。

最新读数超过 10 秒未更新时（记录关闭或采样暂停），窗口末端按整秒移动。按毫秒移动时，曲线末端每次绘制都不同，纹理每落成一次就重绘一次，图表持续重绘。

### 随时钟移动

窗口不超过 15 分钟、**界面动画**开启且**曲线动画**不是**关闭**时，窗口随时钟连续移动。曲线纹理按最新读数所在的窗口绘制，随新读数每秒重绘一次。流畅与均衡模式下，各帧只把已绘制的纹理移到当前时刻（`Window::update_painted_bounds`），不重新排版。时间刻度线画进同一纹理，与曲线一起移动。

时间标签、无记录区间、选区和光标随图表卡片绘制：卡片按精确到毫秒以下的窗口单独重绘，页面其余部分重放。窗口移动较慢时，每四分之一个设备像素重绘一次（字形按四分之一像素定位）；较快时约每秒 30 次，每次至多一个设备像素。省电模式只按设备像素重绘卡片。

时间标签直接按时刻绘制文字，不经布局取整。选区、固定的游标与无记录区间先排在不超过其位置的设备像素上，再按剩余的小数像素平移绘制；边框、文字与图标仍落在整像素上。

开发构建、1240×800 客户区、165 Hz、5 分钟窗口时，呈现帧率由逐像素重绘的约 6 帧/秒升至约 150 帧/秒；卡片约每秒重绘 16 次，界面线程比逐像素重绘多约 5–15 ms/s。

移动的曲线由 Windows 合成器平移，标签移动时只更新合成树的背景矩形。为此，图表卡片使用不透明的图表底色，进程表的趋势小图按设备分辨率绘制成图片。曲线背后透出窗口材质时，渲染器不建立合成树；页面中的矢量路径又使它放弃静态画面缓存。两者都会让每一帧整窗重绘并复制给合成器。

同样条件下，GPU 最忙引擎占用由约 2.5% 降至约 0.3%（**性能**页约 0.1%），进程内存约少 15–20 MiB。

### 切换到历史页

切换到**历史**页时，窗口与轨道直接位于目标位置，不从上次离开时（首次为初始值）的位置缓动：缓动会让时间轴在滑入的 250 ms 里扫过其间的全部时间。

指针移到**历史**标签上时即开始查询，页面通常从第一帧起就带有曲线和读数。

滑入期间，查询结果和命令完成要等滑入结束才绘制整页；曲线纹理就绪时只重绘图表卡片，图表也暂停平移纹理，随页面移动。此前每次整页绘制（开发构建约 15 ms）都让滑入的前几帧停住。

### 时间范围与纵轴的过渡

切换时间范围时，窗口先停在原处，等新范围的读数到达后再缩放。等待至多 500 ms；打开下拉列表时预读的读数、切回时暂存的读数无需等待。

窗口宽度按相同倍率逐帧变化（缓进缓出，250–420 ms，倍率越大越长），以两个窗口的公共时刻（跟随时为最新读数）为不动点。原范围的曲线保持为原窗口绘制的纹理，新范围的曲线只为新窗口绘制一次，两者都按时刻随窗口移动、缩放并交叉淡化。窗口变窄时，新曲线只覆盖窗口末端，按覆盖的比例淡入。

纵轴刻度线与刻度值在新旧两组之间淡入淡出，导航条同样处理。

逐帧按缩放中的窗口重绘纹理时，后台绘制落后一到两帧，旧纹理不足以覆盖新窗口，左侧间歇空白；倍率大时，纹理还会被拉伸成色块。

纵轴上限因数据变化而改变时，上下限以 420 ms 缓动到新值，曲线按缓动中的范围重绘，刻度线与刻度值随之移动，旧刻度淡出、新刻度淡入。缓动按几何插值，与实时曲线的上限过渡相同，以两个范围在同一高度的值为不动点，通常为零。

### 阶梯与断开

每个点的值在其覆盖的时段内保持水平（一次采样到下一次采样，合并的时间段为其跨度），到下一个点开始处竖直变化。转角按不超过 2.5 px 的半径倒圆，短于两倍半径的边按其一半倒圆。

断开处，前一点的值延续到无记录区间的起点，恢复后的点从区间终点开始。悬停读取的点与绘制的阶梯一致（`Points::index_at`）：两点之间的空隙归前一点，无记录区间内没有点。

阶梯在无记录区间处的断开按区间起点排序，以各前缀的最晚终点二分查找（`Points::gaps_across`），不逐个比对。3 天范围、600 个点、300 个区间时，开发构建中每帧构建图表卡片由 40–55 ms 降至 2–4 ms。

### 悬停与选择

悬停竖线停在指针所在的设备像素上，不随曲线平移。卡片每次重绘都按指针位置重新换算时刻，圆点画在竖线上，取该时刻所在阶梯的值。跟随最新时，曲线从静止的指针下方移过，圆点、读数与提示随之变化，比纹理至多晚一次卡片重绘。

竖线与圆点按数据点定位时，它们随曲线平移，到下一个点又跳回指针处，看起来在抖动。

悬停提示宽度固定，过长的名称以省略号截断，列出该时刻占用最高的 5 个进程。进程较少时保留空行，新时刻的进程送达前保留上一时刻的列表，指针移动时提示框不改变大小。

单击与键盘导航选择屏内数据点，Esc 取消选择。实时刷新暂停期间仍记录历史。

## 速率量程

磁盘与网络的曲线纵轴选择覆盖当前时间窗峰值的最小档位。**进程**页概况、**性能**页大图及网络侧栏预览、历史曲线共用同一规则；磁盘侧栏的活动率图保持 0–100%。量程变化沿用**曲线动画**的过渡设置。

各类速率从最小档位起依次取以下档位：

- **磁盘传输速率**：100 KB/s、200 KB/s、500 KB/s、1 MB/s、10 MB/s、50 MB/s、100 MB/s、200 MB/s、500 MB/s、1 GB/s、10 GB/s……
- **网络吞吐量（比特）**：100 Kbps、500 Kbps、1 Mbps、5 Mbps、10 Mbps、50 Mbps、100 Mbps、500 Mbps、1 Gbps、5 Gbps……
- **网络吞吐量（字节）**：100 KB/s、500 KB/s、1 MB/s、5 MB/s、10 MB/s、50 MB/s、100 MB/s、500 MB/s、1 GB/s、5 GB/s……

磁盘从 MB/s 起，每级单位采用 1、10、50、100、200、500；网络从 Mbps 或 MB/s 起，每级单位采用 1、5、10、50、100、500，随后进入更大的单位。

网络切换单位时保留这组数字档位，按实际吞吐量重新选档；数据换算仍按每字节 8 比特计算。字节单位按**字节单位**设置进位（默认 1024，**十进制 SI** 为 1000），档位数字不变；比特单位始终按 1000 进位。功耗等其他动态量程继续使用整数或整十数上限。

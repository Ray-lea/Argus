# 曲线与时间轴

曲线使用单调三次贝塞尔几何与 GPUI 原生 tooltip。曲线保留采样峰值，不产生超调，统一使用主题线宽。与原版一致，次要序列（内核时间、写入、发送等）用同色虚线（4/3），虚线相位随时间轴固定，滚动时不游走；侧栏预览等无标题的紧凑图表中虚线断续难辨，次要序列改用 55% 不透明度的同色实线，不加填充。每条序列各自的面积从图表顶部向下渐隐。速率与功率图的上限取显示单位下的整数（十以上取十的倍数）并设下限；持续显示的同一序列上限变化时在 420 ms 内拉伸已缓存的纹理过渡，不额外重绘，首次显示、切换设备或返回页面时直接使用当前上限。数据值来自 Rust 快照，时间位置来自 Snapshot.timestamp；源时间映射到单调动画时钟，接收时间仅用于时钟校准，恢复时不会将排队数据压缩到一起。

resources/motion.json 定义时间窗口、显示延迟和绘制目标。流畅模式随实际显示节拍更新；均衡模式限制动画更新频率；节能模式按物理像素推进；关闭模式只在采样变化时更新。暂停保留最后的显示时间，隐藏或数据过期时停止绘制。进程页 CPU 卡片的核心条按原版尺寸绘制（4 px 宽、2 px 间隔、26 px 高、1.5 px 圆角，轨道为 14% 的 CPU 色），流畅与均衡模式下在每次采样后的一个间隔内滑向新值，其他模式直接显示最新值。

数据、范围、线宽、颜色或显示密度改变时，在后台以物理分辨率的两倍绘制曲线纹理；滚动帧仅以亚像素坐标平移缓存纹理，避免每帧重新细分路径和解析整窗多重采样纹理。网格、标签和交互标记独立绘制。面积渐隐用纯色填充加逐行遮罩，代价远低于渐变着色器。每张图最多保留一个在途任务；同一序列的较早纹理在新纹理完成前按自身的时间窗口和上限继续显示，其他序列（例如上一个设备）的纹理不显示，替换和卸载时释放旧纹理。减少动画、暂停和隐藏行为不变。

页面布局记录图表位置和裁剪范围；所有实时图表共用一个独立的动画实体，直接复用这些位置绘制，不在每帧重建图表的布局容器，也不带动工具栏、表格和详情重建。页面过渡的透明度同步作用于图表层。缺失值断开曲线，设备以稳定标识索引；硬件变更不按旧数组位置拼接。时间轴从第一份快照起为每个进程和应用记录 CPU 与内存（保留图表时间窗口，进程退出即丢弃），详情面板选中时曲线已经完整。进入页面、切换设备或视图时，逻辑处理器与 GPU 引擎网格在测得实际尺寸后直接放到最终位置；网格重排动画只用于此后的窗口尺寸与筛选变化。

纯平移与核心条高度更新直接复用已绘制场景中的图元，省去重复布局与绘制数据生成；图元不能超出预留区域。采样、交互、悬停、主题、窗口尺寸或显示密度改变后仍执行正常绘制，旧句柄不跨完整绘制复用。零值与未知读数的核心条保持不可见，不用非零值占位。

Windows 渲染器缓存首个动画图元之前的静态画面，以原始像素复制复用，后续图元仍按原顺序混合绘制。完整绘制、尺寸变化或设备重建会失效缓存，包含外部动态表面的场景使用完整绘制。这样可避免曲线滚动时反复绘制静止的文字与表格，同时保留抗锯齿、颜色和刷新节拍。

跨越静态与动画边界的绘制批次按原顺序拆分，动画帧仅恢复、重画并提交受影响区域。柱形收缩或曲线平移时仍覆盖完整裁剪范围，避免残影；采样和窗口变化继续完整提交。

分离的图表区域分别复制和提交，同一行或列的区域合并以控制 GPU 命令数量。未变化的字形、阴影、下划线实例及视口参数保留在 GPU 缓冲区中；新场景、窗口尺寸或设备变化会更新相应数据。

网格与柱状背景在动态曲线层之前绘制，随静态画面一起缓存。互不重叠的曲线区域可在一次绘制中读取静态背景并合成曲线，省去单独的背景复制。后绘制的柱状图可复用下方曲线已恢复的区域；未覆盖的区域仍单独恢复。区域重叠、纹理不可用或其他绘制类型不满足条件时，继续使用原有复制与混合路径。两条路径保持相同的纹理密度、线宽和采样；像素对照允许 8 位颜色通道最多一个色阶的舍入差异。

Windows 的绘制请求在开始绘制前确认，避免清除绘制期间到达的下一次同步请求。交换链按一个显示周期提交，防止采样更新后的相邻提交互相替换；这沿用实际显示节拍，不改变曲线模式或采样间隔。[Present1 的同步间隔语义](https://learn.microsoft.com/en-us/windows/win32/api/dxgi1_2/nf-dxgi1_2-idxgiswapchain1-present1)区分了保留帧与允许新帧替换旧帧的行为。

历史曲线支持时间选择与键盘定位，选中时刻对应独立查询结果。选中时刻后时间窗口保持不动，切换范围时以选中时刻为中心；仅在跟随最新时按范围定期刷新。查询窗口随请求一起返回，过期响应不覆盖新的范围。

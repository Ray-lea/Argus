# 曲线与时间轴

曲线使用单调三次贝塞尔几何与 GPUI 原生 tooltip。曲线保留采样峰值，不产生超调，统一使用主题线宽与渐变面积。数据值来自 Rust 快照，时间位置来自 Snapshot.timestamp；源时间映射到单调动画时钟，接收时间仅用于时钟校准，恢复时不会将排队数据压缩到一起。

resources/motion.json 定义时间窗口、显示延迟和绘制目标。流畅模式随实际显示节拍更新；均衡模式限制动画更新频率；节能模式按物理像素推进；关闭模式只在采样变化时更新。暂停保留最后的显示时间，隐藏或数据过期时停止绘制。

数据、范围、线宽、颜色或显示密度改变时，在后台以物理分辨率的两倍绘制曲线纹理；滚动帧仅以亚像素坐标平移缓存纹理，避免每帧重新细分路径和解析整窗多重采样纹理。网格、标签和交互标记独立绘制。每张图最多保留一个在途任务；过期任务不覆盖新请求，替换和卸载时释放旧纹理。减少动画、暂停和隐藏行为不变。

页面布局记录图表位置和裁剪范围；所有实时图表共用一个独立的动画实体，直接复用这些位置绘制，不在每帧重建图表的布局容器，也不带动工具栏、表格和详情重建。页面过渡的透明度同步作用于图表层。缺失值断开曲线，设备以稳定标识索引；硬件变更不按旧数组位置拼接。

纯平移与核心条高度更新直接复用已绘制场景中的图元，省去重复布局与绘制数据生成；图元不能超出预留区域。采样、交互、悬停、主题、窗口尺寸或显示密度改变后仍执行正常绘制，旧句柄不跨完整绘制复用。零值与未知读数的核心条保持不可见，不用非零值占位。

Windows 渲染器缓存首个动画图元之前的静态画面，以原始像素复制复用，后续图元仍按原顺序混合绘制。完整绘制、尺寸变化或设备重建会失效缓存，包含外部动态表面的场景使用完整绘制。这样可避免曲线滚动时反复绘制静止的文字与表格，同时保留抗锯齿、颜色和刷新节拍。

跨越静态与动画边界的绘制批次按原顺序拆分，动画帧仅恢复、重画并提交受影响区域。柱形收缩或曲线平移时仍覆盖完整裁剪范围，避免残影；采样和窗口变化继续完整提交。

历史曲线支持时间选择与键盘定位，选中时刻对应独立查询结果。查询窗口随请求一起返回，过期响应不覆盖新的范围。

# Argus

快速、现代、信息丰富的 Windows 任务管理器。

Argus 用 Rust 直接读取 Windows 的原生接口，用 Tauri 2 和 SolidJS 构建界面。进程、性能、服务、启动项、网络连接和最近 7 天的历史都在一个窗口里，曲线随屏幕刷新率连续流动；常驻托盘时约占单核 1%。名字取自希腊神话中的百眼巨人阿尔戈斯。

> 项目处于早期开发阶段，还没有发布安装包，需要从源码构建。

## 特性

- **进程**：按应用、进程树或列表查看，包括每个进程的 GPU 占用（启用特权服务或以管理员身份运行时还有网络流量）；排序与搜索；结束进程或整个进程树；详细信息面板显示命令行、用户、完整性级别等。
- **优先级与效率模式**：右键即可设置，也可以建立规则，让程序每次启动时自动套用。
- **性能**：CPU（每核、性能核 / 能效核、频率、温度、功耗）、内存、磁盘、网络、GPU 和电池。
- **服务与启动项**：启停服务、修改启动类型；启用或禁用启动项，与系统任务管理器使用同一个开关。
- **连接与端口**：TCP / UDP 端点及所属进程，按端口精确搜索，断开连接。
- **文件占用**：把文件或文件夹拖进窗口，结合 Restart Manager 与句柄枚举查找占用，包括进程的当前目录；可借助特权服务检查更多进程。
- **历史回溯**：最近 7 天的资源曲线，点任一时刻就能看到当时最忙的进程。
- **常驻托盘**：全局快捷键 Ctrl+Alt+Esc 随时呼出，隐藏时几乎不占资源。
- **原生外观**：Mica 背景、系统强调色，深浅色跟随系统。
- **无需管理员权限**：标准用户即可看到全部进程的路径与资源占用。
- **可选特权服务**：一次管理员授权后，以标准权限运行的界面也能管理系统进程、自动应用规则、统计每进程网络流量、控制服务和断开连接，可在设置中卸载。

## 系统要求

- Windows 11 x64
- WebView2 运行时（Windows 11 自带）

## 从源码构建

需要 Rust（stable，MSVC 工具链）、Node.js 22+、pnpm 和 Visual Studio Build Tools（“使用 C++ 的桌面开发”）。在仓库根目录运行：

```bash
start.bat           # 开发模式：前端即时热更新，Rust 改动后自动重新编译并重启
start.bat build     # 发布构建，生成 target\release\argus.exe
```

其他命令（浏览器预览、检查、打包安装程序、清理缓存）见[开发指南](docs/development/README.md)。

## 快捷键

| 操作 | 按键 |
|---|---|
| 切换页面 | Ctrl+1 … Ctrl+7 |
| 搜索进程 | Ctrl+F |
| 打开详细信息 | Enter |
| 结束进程 | Delete（Shift+Delete 跳过确认） |
| 显示 / 隐藏窗口（全局） | Ctrl+Alt+Esc |

完整的操作说明见[使用指南](docs/guide/README.md)。

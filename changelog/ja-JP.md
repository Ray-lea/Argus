# 更新履歴

Argus の各バージョンにおける、利用者向けの変更内容です。バージョン番号は[セマンティック バージョニング](https://semver.org/lang/ja/)に従います。このファイルは[簡体字中国語の更新履歴](zh-CN.md)を翻訳したもので、各項目が原文に対応しています。

## [0.7.0](https://github.com/Ray-lea/Argus/compare/v0.6.0...v0.7.0) - 2026-11-27

v0.7.0 では Windows ARM64 のインストーラー版とポータブル版の提供を開始し、本体、特権サービス、タスク マネージャーの置き換えが ARM64 上でネイティブに動作します。プロセス ページには 27 個の選択可能な列と、「メモリ ダンプ ファイルの作成」「デバッグ」の 2 つの操作を追加しました。バイトの単位の設定を追加し、タスク バー モニターは縦向きのタスク バーに対応し、新しいバージョンがあるときは Windows 通知を送信できます。このほか、画面が静止しているときの再描画を減らし、Ryzen 9000 のセンサー、タスク バー モニターがスタート ボタンを覆う問題、特権サービスの登録が削除されると再インストールできない問題などを修正しました。

このバージョンではドキュメント サイトを全面的に書き直しました。各機能の詳しい使い方は[ドキュメント サイト](https://argustask.com/docs/)（中国語）を参照してください。

### 互換性のない変更

- **列メニュー**：プロセス一覧の列見出しの右クリック メニューで、分類ごとに列を表示または非表示にする項目を廃止しました。メニューの「列の選択…」をクリックし、ダイアログで表示する列を選択します。

### 新機能

- **Windows ARM64**：ARM64 のインストーラー版とポータブル版を提供します。本体、特権サービス、管理者としての実行、タスク マネージャーの置き換えはネイティブに動作し、アプリ内更新は ARM64 版で行われます。パフォーマンス ページには ARM64 プロセッサのベンダー、モデル、命令セット、仮想化の状態を表示し、CPU 電力は Windows のエネルギー メーターから取得します。カーネル センサーは現時点では提供しません。（[#172](https://github.com/Ray-lea/Argus/issues/172)）
- **プロセスの列**：「列の選択」ダイアログに 27 個の列を追加しました。経過時間、カーネルとユーザーの CPU、コンテキスト スイッチ、共有ワーキング セット、ページ プールと非ページ プール、ハード フォールト、ディスクと I/O の読み書き回数と累計値などです。これらの列を選択していないときは、サンプリングの負荷は変わりません。
- **詳細ペイン**：プロセス一覧のすべての列の値を表示します。リソースと累計のセクションにコンテキスト スイッチ、ハード フォールト、1 秒あたりの要求回数を追加し、ワーキング セットやコミット サイズなどの値にはピーク値を併記します。「詳細をコピー」にもこれらの項目が含まれます。
- **メモリ ダンプとデバッグ**：単一プロセスの右クリック メニューに「メモリ ダンプ ファイルの作成」と「デバッグ」を追加しました。ダンプ ファイルは一時フォルダーに書き込まれ、完了すると通知にパスが表示されます。Just-In-Time デバッガーが登録されている場合、「デバッグ」でそのデバッガーを起動してプロセスにアタッチします。（[#169](https://github.com/Ray-lea/Argus/issues/169)、[#197](https://github.com/Ray-lea/Argus/issues/197)）
- **バイトの単位**：「設定 → データと履歴」に「バイトの単位」を追加し、従来の形式（既定）、2 進数 IEC、10 進数 SI から選べます。メモリ、ストレージ容量、転送速度、グラフの目盛り、各モニターの値が切り替わります。（[#156](https://github.com/Ray-lea/Argus/issues/156)）
- **縦向きのタスク バー**：タスク バーが画面の左端または右端にあるとき、タスク バー モニターは値をタスク バーに沿って縦に並べます。4 つのスタイルすべてに縦向きのレイアウトがあり、収まる項目だけを表示します。（[#177](https://github.com/Ray-lea/Argus/issues/177)）
- **新しいバージョンの通知**：ウィンドウが通知領域に隠れているときや前面にないとき、インストーラー版は新しいバージョンのダウンロードと検証が済んだ後に、ポータブル版は新しいバージョンを見つけたときに Windows 通知を送信します。通知をクリックすると更新ダイアログが開きます。「設定 → アップデート」で「新しいバージョンを通知する」をオフにすると、ウィンドウの表示時に右下で知らせます。
- **ページの切り替え**：Ctrl+Tab と Ctrl+Shift+Tab で次または前のページに切り替えます。端まで来ると反対側から続けます。（[#185](https://github.com/Ray-lea/Argus/issues/185)）
- **上部ナビゲーション**：ページ バーの幅が足りないときは、上部ナビゲーションのタブがまずアイコンに縮小し、ポインターを置くとページ名とショートカットを表示します。それでも収まらない場合にのみ、ページのコントロールが次の行に移ります。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **ドキュメント サイト**：すべてのドキュメントを書き直しました。新しい「入門」セクションには、クイック スタート、Argus とは、インストールと更新、Windows タスク マネージャーとの比較があります。使用ガイドは画面ごとにプロセス、パフォーマンス、サービスとスタートアップ、接続、履歴などのページに分かれ、説明をコードと照合して補完しています。

### パフォーマンス

- **再描画**：内容が変わらない表示中のウィンドウは、画面のリフレッシュごとに再描画しなくなりました。160 Hz のディスプレイでは、設定ページが静止しているときの 1 秒あたりの CPU サイクルがおよそ半分になり、アニメーションとスクロールの表示フレーム レートは変わりません。

### 修正

- **通知領域のアイコン**：既定のスタイルを「アプリのアイコン」に変更し、「推移」が濃色のタスク バー上で見分けにくい問題を避けます。「コンポーネント」ページでは、通知領域のアイコンのスタイルをドロップダウン リストで選ぶようになりました。（[#178](https://github.com/Ray-lea/Argus/issues/178)）
- **タスク バー モニター**：タスク バーのボタンが中央揃えのとき、値がスタート ボタンやタスク ボタンを覆わなくなり、収まる項目だけを表示します。グループ ポリシーでウィジェットが無効のときは、ウィジェット ボタンの分の空白を残さなくなりました。
- **デスクトップ モニター**：Windows の起動後や Argus の再起動後、オンにしてあるデスクトップ モニターがすぐに表示され、オンとオフを切り替え直す必要がなくなりました。
- **Ryzen 9000**：CCD 内に無効なコアがあるモデル（Ryzen 9 9900X3D など）で「未認識センサーテーブル」と表示されなくなり、PPT と TDC の現在値と上限を読み取れます。コアの対応付けの検証に通ると、コアごとの温度、電圧、C0／C1／CC6 の滞在率も表示します。（[#203](https://github.com/Ray-lea/Argus/issues/203)）
- **GPU と CPU の値**：ディスクリート GPU がスリープ中も、GPU ページは最後に読み取った「最大コアクロック」を保持します。カーネル センサーがオンでバックグラウンドの更新間隔が 30 秒のとき、CPU 電力と実効クロックが表示されたり消えたりしなくなり、バックグラウンド中の履歴にもこれらの値が記録されます。
- **特権サービスとカーネル センサー**：セキュリティ ソフトやクリーンアップ ツールがサービスの登録を削除した場合でも、Windows を再起動せずに Argus からそのまま再インストールできます。PawnIO がアンインストールされたり、デバイスが削除されたりした後は、インストール済みのドライバーが 2.2.0 以前であれば、カーネル センサーをオンにし直すとドライバーが自動的に再インストールされます。
- **管理者としての実行**：タスク スケジューラに同じ名前の登録が残っている場合でも、管理者としての実行をオンにできます。登録が拒否された場合は、360 などのセキュリティ ソフトによるブロックの可能性を案内します。エラー メッセージのエラー コードは 1 回だけ表示し、HRESULT は 16 進数で表示します。
- **タスク マネージャーの置き換え**：置き換えをオンにした状態で、管理者アカウントから「Windows タスク マネージャーを一時的に開く」をクリックしても反応しない問題を修正しました。Argus が応答しないときは、タスク マネージャーの起動操作が余分なタイムアウトを待たずに Windows タスク マネージャーを開きます。
- **右から左に書く文字**：プロセス名、説明、検索ボックスのアラビア語やヘブライ語など右から左に書く文字が、逆順に表示されなくなりました。（[#155](https://github.com/Ray-lea/Argus/issues/155)）
- **メニューとペイン**：ウィンドウ下部付近で開いた長いサブメニューの最後の項目が、ウィンドウの下端で切れなくなりました。詳細ペインは最も長い項目名に合わせて項目名の幅を決めるため、「専用 GPU メモリ」などの項目名が 2 行に折り返されなくなりました。Mica のウィンドウでダイアログを閉じるときに、カードが白く光らなくなりました。
- **更新後のアイコン**：インストールまたは更新の後、デスクトップのショートカットとタスク バーにピン留めした Argus がすぐに新しいアイコンになり、PC を再起動する必要がなくなりました。

### アップデート時の注意

- **特権サービス**：通信プロトコルは引き続き第 12 版です。Ryzen 9000 の値、バックグラウンドでのカーネル センサーの電力、タスク マネージャーの置き換えの修正、Windows 11 24H2 より前の Windows を標準の権限で実行しているときのディスクの読み書き回数は、サービスの更新後に有効になります。インストーラー版はアップグレード時にインストール済みのサービスを更新します。ポータブル版は「設定 → 権限 → 特権サービス」で「サービスを更新」をクリックしてください。
- **ARM64 PC 上のインストーラー版**：ARM64 PC 上の 0.6.0 は引き続き x64 のインストーラーをダウンロードし、x64 のインストーラーは ARM64 版を使うよう案内して終了します。公式サイトから `Argus_0.7.0_arm64-setup.exe` をダウンロードして元の場所に上書きインストールしてください。設定と履歴は保持され、以降のアプリ内更新は ARM64 版で行われます。
- **ARM64 PC 上のポータブル版**：Argus を終了し、元のプログラムを `Argus_0.7.0_arm64.exe` に置き換えてください。「管理者としての実行を許可する」がオンの場合は、先にオフにし、置き換えた後に新しいバージョンから再度オンにします。
- **通知領域のアイコン**：スタイルを変更したことのない通知領域のアイコンは、アップグレード後にアプリのアイコンを表示します。CPU 使用率をリアルタイムで表示するには、「コンポーネント」ページの「通知領域のアイコン」で「推移」「割合」「数値」のいずれかを選びます。

## [0.6.0](https://github.com/Ray-lea/Argus/compare/v0.5.0...v0.6.0) - 2026-11-23

v0.6.0 では新しいドット グラフのアプリアイコンを採用し、メイン ウィンドウのレイアウトを刷新してタイトル バーを整理、ページ バーとステータス バーを再配置するとともに「常に手前に表示」ボタンを追加しました。「コンポーネント」ページを新設して通知領域・デスクトップ・タスク バーでのリアルタイム表示に対応し、履歴ページも刷新して複数レーンのグラフ、リソース イベント、起動ごとのプロセス観測をサポートします。プロセス一覧にはリソース リーク通知と電源の使用率列を追加し、プロセス・サービス・スタートアップ・接続の各ページでセルのコピーと CSV 出力に対応、サービスとスタートアップ項目の削除、パフォーマンス ページでの NPU 監視、タッチ操作とハードウェア アクセラレーションの切り替えも追加しました。さらに一覧のスクロールや再描画の負荷を大幅に軽減し、一部の Intel RST VMD 環境でディスクの詳細を開くとブルー スクリーンが発生する問題を修正したほか、電源が切れたディスクリート GPU や回転停止中のハード ディスクを意図せず復帰させないようにしました。

### 互換性のない変更

- **履歴**：新しい保存形式を採用したため、履歴ページには 0.6.0 以降で記録されたデータのみが表示されます。更新後に当日の記録を初めて書き込むと、当日の旧形式ファイルは置き換えられ、旧バージョンの Argus では新しい記録を読み込めません。
- **特権サービスのプロトコル**：通信プロトコルが 11 から 12 へ更新されます。特権サービス経由でプロセスの終了や I/O・メモリ優先度の変更を行う前に、旧バージョンのサービスを更新する必要があります。

### 新機能

- **アプリのアイコン**：新しいドット パフォーマンス グラフのアイコンを採用し、サイズごとにドットを個別配置してタスク バー、タイトル バー、更新後のショートカットで鮮明に表示します。「バージョン情報」と「初回設定ガイド」ではドットでロゴを描いた後に直近 10 回の CPU 使用率の動的ドット グラフへ切り替わり、「画面のアニメーション」がオフのときは直接ドット グラフを表示します。
- **タイトル バー**：ロゴ、ウィンドウ幅に合わせて伸縮する検索ボックス、Windows 標準サイズのウィンドウ ボタンのみに整理し、残りの空白部分からウィンドウをドラッグできます。新たにピン ボタンを追加して「常に手前に表示」を切り替えられ、状態は再起動後も保持されます。（[#121](https://github.com/Ray-lea/Argus/issues/121)）
- **ページ バーとステータス バー**：ページの操作と「その他の操作」をナビゲーション タブの横へ移し、プロセス表示の切り替えボタンをアイコン化しました。「その他の操作」に「新しいタスクの実行…」（Ctrl+N）、「ファイルを使用しているプロセスを検索…」、ショートカット一覧をまとめ、サービス ページでは Windows のサービス管理も直接開けます。ステータス バーに更新の一時停止と更新間隔のボタンを備え、バージョン番号は更新の進行状況とインストール入口も兼ねます。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **コンポーネント ページ**：「コンポーネント」ページを新設し、通知領域とバックグラウンド動作の設定を一元管理するとともに、デスクトップ モニターとタスク バー モニター（いずれも既定ではオフ）を有効化できます。通知領域やモニターから設定を開くと、サイドバーで対応する項目が自動選択されます。
- **リアルタイムの通知領域アイコン**：既定では「推移」で CPU 使用率をリアルタイム表示し、「割合」「数値」「アプリのアイコン」にも切り替えられます。リアルタイム表示の 3 スタイルは使用率 80% 以上で琥珀色に変化します。ポインターを置くとリアルタイム読み取りカードを表示し、右クリックで開くクイック パネルには CPU 使用率上位 3 プロセスとよく使う操作が並びます。
- **トレイのカードとクイック パネル**：ホバー カードは言語と文字サイズに合わせて自動でレイアウトを調整し、無効時はシステムのヒントに切り替わります。クイック パネルの各読み取り値をクリックするとパフォーマンス ページの該当デバイスへ直接移動でき、隠れているアイコン領域から開いた場合もその領域は展開されたまま維持されます。（[@digital-bombyx](https://github.com/digital-bombyx) [#113](https://github.com/Ray-lea/Argus/pull/113) [#153](https://github.com/Ray-lea/Argus/pull/153)）
- **デスクトップ モニター**：デスクトップ上の小さなウィンドウでリアルタイム値を常駐表示し、「バー」と「パネル」の表示方法に対応します。パネルは「リスト」「曲線」「ゲージ」の 3 スタイルから選べます。ドラッグ時は現在のディスプレイの作業領域内に収まり、常に手前に表示、位置の固定、クリックの透過、不透明度の調整に対応します。
- **タスク バー モニター**：タスク バーにリアルタイム値を常駐表示し、「ラベル」「曲線」「カプセル」「大きな数字」の 4 スタイルを提供します。コンポーネント ページまたは右クリック パネルでプレビューしながら切り替えられ、右クリック パネルではディスプレイ選択、項目のチェック、ドラッグによる並べ替えも即座に反映されます。（[#28](https://github.com/Ray-lea/Argus/issues/28)、[#123](https://github.com/Ray-lea/Argus/issues/123)）
- **マルチディスプレイとウィンドウ切り替え**：選択中のディスプレイが切断されるとタスク バー モニターは一時的にメイン ディスプレイへ移動し、再接続時に自動で戻ります。タスク バー モニターまたは通知領域アイコンをクリックすると、前面に露出しているメイン ウィンドウを非表示にするか、非表示・最小化・背面のウィンドウを前面へ呼び出します。デスクトップ モニターをダブルクリックするとメイン ウィンドウが開きます。
- **モニターの読み取り値**：デスクトップ モニターとタスク バー モニターで温度、クロック、消費電力、ファン回転数を含む 18 種類の値に対応します。GPU、ディスク、ネットワーク アダプターごとに個別選択でき、カテゴリや項目単位のドラッグで順序を変更できます。タスク バー モニターはデバイス別の色で名称を区別し、同じ CPU や GPU の 2 項目目以降は項目名を表示します。
- **モニターの更新間隔**：デスクトップ モニターまたはタスク バー モニターが有効な間は、メイン ウィンドウ表示時と同じ更新間隔でサンプリングします。最小化時やバックグラウンド時の設定と異なる場合、設定ページに実際の間隔を示しつつ、両モニター終了後に適用する間隔設定も保持します。
- **履歴ページ**：複数レーンの階段状グラフへ全面刷新し、各レーンに 2 つ目の読み取り値を重ねて表示できます。名称やデバイスで項目を検索し、ドラッグでレーンの順序や高さを変更できるほか、表示領域を超えるレーンはグラフ内でスクロールできます。
- **履歴グラフの操作**：ホイールでポインター位置の時刻を中心に拡大・縮小でき、ズーム、曲線のクリック、範囲のドラッグで最新値への追従を一時停止します。「最新に戻る」、グラフの右クリック、End キーで追従を再開できます。未記録の区間は斜線で示し、直近 10 分間は実際のサンプリング間隔で表示します。（[#79](https://github.com/Ray-lea/Argus/issues/79)、[#129](https://github.com/Ray-lea/Argus/issues/129)）
- **履歴の曲線とカーソル**：最新値へ追従している間は階段曲線が時間とともに滑らかに進み、ポインターがあるレーンのカーソルが通過する値をリアルタイムに更新します。期間や縦軸の範囲変更も滑らかに切り替わり、重ねた曲線はフェード イン・アウトします。一度開いた長い期間は次回より速く読み込めます。
- **期間とイベント**：ドロップダウン リストから 5 分、3 時間、1 日、3 日、「カスタム…」を選べ、「期間を指定」ダイアログではカレンダーでの日付選択や正確な開始・終了時刻の入力が可能です。「30 日の概要とイベントを表示」をオンにすると、1 時間ごとのヒート マップと CPU 高負荷、メモリ不足、記録の空白といったイベント一覧を表示します。
- **履歴のプロセス表**：選択した時刻または期間のプロセスを検索でき、名前順にするとアプリ、バックグラウンド プロセス、Windows プロセスに分類されます。同名のグループを展開すると上位 4 インスタンスと残りの合計を確認でき、右クリック メニューからグラフへの曲線重ね合わせや名前と PID のコピーが行えます。
- **履歴グラフのヒント**：CPU などプロセス別に集計できるレーンにポインターを置くと、使用量上位 5 プロセスを表示します。プロセス数レーンではインスタンス数上位 5 プログラムと残りの合計を示し、温度やバッテリー残量などの項目ではデバイス値のみを表示します。
- **記録する履歴**：CPU のクロック・消費電力・温度、メモリの内訳、バッテリー値のほか、各ディスク・GPU・ネットワーク アダプターごとの値を新たに追加しました。「設定 → データと履歴」でカテゴリ別に記録項目を選び、1 フレームあたり約 20、約 40、またはすべてのアクティブなプロセスを記録する設定と 1 日あたりの推定容量を確認できます。
- **履歴の保存**：期間と容量の保持上限を個別に設定でき、先に達した上限を適用します。既定は 30 日・最大 2 GB で、7 日より古い記録は 1 分単位で平均値・ピーク値・上位プロセスへ自動統合します。保存先の変更時に既存の履歴と観測記録をまとめて移動するか選べ、指定フォルダーに他のファイルがある場合は自動的に「Argus History」サブフォルダーへ保存します。
- **プロセスの観測**：プロセスの右クリック メニューまたは詳細ペインから「プロセスを観測」を選ぶと、同じパスのプログラムを起動インスタンスごとに 14 項目（メモリ、CPU、GPU、ディスク、I/O、ネットワーク、スレッド、ハンドル）継続記録します（パスを取得できない場合は現在のインスタンスのみ）。開始後は「履歴」内の「プロセスの観測」が自動で開き、各インスタンスを切り替えながら複数レーンのグラフで値を比較できます。（[@hayxe1](https://github.com/hayxe1) [#82](https://github.com/Ray-lea/Argus/pull/82)）
- **観測記録**：直近 10 分間は実際のサンプリング間隔で表示し、それ以前はディスク上の記録を読み込みます。記録は最長 7 日間保持し、容量上限に達した場合は古いデータから優先的に削除します。「記録を停止」しても既存データは保持され、Argus の再起動後は観測を開始し直す必要があります。
- **プロセスのグループ**：「アプリ」「バックグラウンド プロセス」「Windows プロセス」および各ユーザー グループを色で区別します。一覧のスクロール中は現在のグループ見出しが上部に固定され、スクロール バー横には各グループの位置と現在のグループ名が表示されます。「システム プロセスを非表示」がオンのときは、プロセス統計に非表示のプロセス数も併記されます。（[#88](https://github.com/Ray-lea/Argus/issues/88)）
- **プロセスの電力使用量**：CPU、GPU、ディスクの動作から消費電力を推定する「電源の使用率」と「電源の使用率の傾向」列を追加しました（既定では非表示）。前者は現在の消費レベル、後者は直近約 2 分間の平均レベルを示します。（[#134](https://github.com/Ray-lea/Argus/issues/134)）
- **プロセスの優先度**：右クリック メニューから I/O 優先度とメモリ優先度を設定でき、詳細ペインと任意列にも表示されます。「基本優先度」はクラス名で表示しつつ特殊値は数値のまま保持し、並べ替えも数値順で行います。（[@digital-bombyx](https://github.com/digital-bombyx) [#80](https://github.com/Ray-lea/Argus/pull/80) [#116](https://github.com/Ray-lea/Argus/pull/116)）
- **ポインターを置いている間の並べ替えの一時停止**：プロセス一覧にポインターを置いて並べ替えが一時停止している間、並べ替え列の見出しに一時停止アイコン、ステータス バーに「並べ替えを一時停止中」を表示します。「設定 → 言語と外観」に「ポインターを置いている間は並べ替えを一時停止」スイッチを追加し、既定でオンにしました。（[#86](https://github.com/Ray-lea/Argus/issues/86)）
- **リソース リークの通知**：プロセス ページがハンドル リーク、子プロセスの蓄積、残留プロセスを自動検出し、見出しの琥珀色マークをクリックして素早く移動できます。詳細ペインで判断根拠、件数の推移、対処方法を確認でき、プロセス終了後の次回サンプルでマークが更新されます。プログラム単位の無視に対応し、「設定 → 言語と外観 → リソース リークの通知」で無視解除や機能の無効化が可能です。
- **表の内容のコピー**：プロセス、サービス、スタートアップ、接続の各ページで、右クリック メニューから現在のセル値、名前、詳細をコピーできます。プロセス ページでは Ctrl+C で名前、Ctrl+Shift+C で詳細をコピーし、テキスト選択中は Ctrl+C で選択文字列を優先してコピーします。（[@digital-bombyx](https://github.com/digital-bombyx) [#161](https://github.com/Ray-lea/Argus/pull/161)、[#91](https://github.com/Ray-lea/Argus/issues/91)、[#150](https://github.com/Ray-lea/Argus/issues/150)）
- **CSV 出力**：プロセス、サービス、スタートアップ、接続の各ページの「その他の操作」から「現在のページを CSV としてエクスポート…」を選ぶと、スクロール範囲外の行も含む一覧全体を、列順・フィルター・並べ替え・表示単位・グループ展開状態を保ったまま出力できます。（[#139](https://github.com/Ray-lea/Argus/issues/139)）
- **詳細ペイン**：「リソース」セクションにピーク ワーキング セット、仮想アドレス空間、I/O 速度、電源の使用率を追加し、新たに「累計」セクションでユーザー／カーネル モードの CPU 時間、種類別の I/O バイト数、ページ フォールト数を表示します。右上のコピー ボタンから値のある全項目をセクション単位でコピーできます。
- **接続ページ**：アプリ別の折りたたみグループ表示に対応し、検索時は一致するグループが自動で開きます。サービスと接続の状態フィルターを「状態」列の見出しへ移し、接続ページには状態フィルターと併用できる TCP、TCPv6、UDP、UDPv6 のフィルターを追加しました。（[@digital-bombyx](https://github.com/digital-bombyx) [#152](https://github.com/Ray-lea/Argus/pull/152)）
- **サービスとスタートアップ項目の削除**：右クリック メニューに「削除」を追加し、確認後にサービスまたはスタートアップ項目を削除できます。使用中のサービスは停止・解放後に Windows により削除され、スタートアップ フォルダーの項目はごみ箱へ移動します。パッケージ アプリの起動タスクは引き続き無効化のみ対応します。（[#114](https://github.com/Ray-lea/Argus/issues/114)、[#146](https://github.com/Ray-lea/Argus/issues/146)）
- **パッケージ アプリのサービス**：Windows がパッケージ アプリのサービスのスタートアップの種類変更を拒否した場合、確認後に設定をレジストリへ直接書き込み、再起動後に有効になる項目を一覧に示します。失敗時はサービス名と権限・保護に関する制限を案内します。（[@digital-bombyx](https://github.com/digital-bombyx) [#112](https://github.com/Ray-lea/Argus/pull/112)、[#168](https://github.com/Ray-lea/Argus/issues/168)）
- **メモリの読み取り値**：パフォーマンス ページのメモリ構成バーでは使用中の圧縮メモリを斜線で区別し、ポインターを置くと推定格納データ量と節約メモリを表示します。プロセス ページのヒントでもシステム全体、プロセスごとのプライベート ワーキング セット、グループ合計の集計範囲を説明しています。（[@digital-bombyx](https://github.com/digital-bombyx) [#81](https://github.com/Ray-lea/Argus/pull/81)、[#122](https://github.com/Ray-lea/Argus/issues/122)）
- **NPU**：パフォーマンス ページで Windows が識別した NPU ごとに名前、使用率、直近 60 秒のリアルタイム グラフを個別表示し、識別された NPU を GPU 一覧から分離しました。（[@SpookySandwich](https://github.com/SpookySandwich) [#140](https://github.com/Ray-lea/Argus/pull/140)、[#135](https://github.com/Ray-lea/Argus/issues/135)、[#148](https://github.com/Ray-lea/Argus/issues/148)）
- **CPU のグラフとディスクの詳細**：CPU の全体／マルチコア表示の切り替えとコア種類フィルターをグラフの右クリック メニューへ移しました。マルチコア表示の小グラフは読みやすい比率を保ち、領域が狭いときはクロック、見出しの順に省略します。ディスク詳細の SMART 生値は既定で 10 進数表示とし、16 進数への切り替えは全ディスクに適用され再起動後も保持されます。
- **ハードウェア アクセラレーション**：「設定 → アニメーション」に「ハードウェア アクセラレーション」スイッチを追加しました（既定はオン）。オフにすると即座に GPU を使わず CPU で画面を描画します。（[#127](https://github.com/Ray-lea/Argus/issues/127)）
- **タッチ操作**：Windows タッチ スクリーンでのタップ、ダブルタップ、スワイプ スクロール、長押しによるメニュー表示、スクロール バーのドラッグに対応しました。リモート経由で転送されたタップでもメイン ウィンドウ内のコントロールを操作でき、テキスト欄にフォーカスが移ると必要に応じてタッチ キーボードを呼び出します。（[#73](https://github.com/Ray-lea/Argus/issues/73)）
- **バージョン情報ページ**：「診断情報をコピー」ボタンを追加し、バージョン、実行状態、ハードウェア、ディスプレイ設定をワンクリックでコピーして問題報告に添付できます。公式サイトと GitHub のカード下部に、ダウンロード、使用ガイド、更新履歴、問題報告、ディスカッション、リリースの各ページへ直接アクセスできるボタンを追加しました。
- **管理者用プログラムの配置先**：特権サービス、タスク マネージャーの置き換え、管理者実行用のプログラムを固定ファイル名で `Program Files\Argus Privileged` に集約し、セキュリティ ソフトでパス指定した信頼設定を更新後も維持できるようにしました。Program Files 以外へインストールする場合は、インストール ページの情報アイコンでこれらの配置先を案内します。（[@digital-bombyx](https://github.com/digital-bombyx) [#154](https://github.com/Ray-lea/Argus/pull/154)、[#136](https://github.com/Ray-lea/Argus/issues/136)、[#159](https://github.com/Ray-lea/Argus/issues/159)）

### パフォーマンス

- **描画**：更新、ホバー、クリック時に変化した領域だけを再描画し、一覧上のポインター移動やアイコン アニメーションに伴う GPU 負荷を大きく低減しました。リリース ビルドの比較測定ではプロセス一覧のスクロール時に 1 フレームあたりの CPU 負荷が約 4 割減少しており、ハードウェア アクセラレーション無効時もスクロールやページ切り替えで描画済みの内容を再利用します。
- **最初の読み取り値**：起動後の初回収集待ち時間を短縮し、初期の読み取り値をより早く表示します。（[@hayxe1](https://github.com/hayxe1) [#119](https://github.com/Ray-lea/Argus/pull/119)）

### 修正

- **ディスクの詳細によるブルー スクリーン**：温度や NVMe 正常性を照会する前にコントローラー ドライバーを確認し、一部の Intel RST VMD 環境でディスク詳細を開いた際のブルー スクリーンを防ぎます。スキップされた項目は「不明」と表示されます。読み取り中またはその後 2 分以内に異常終了した場合は次回起動時の自動読み取りを一時停止し、手動で「それでも読み取る」を選べます。（[#48](https://github.com/Ray-lea/Argus/issues/48)、[#133](https://github.com/Ray-lea/Argus/issues/133)、[#160](https://github.com/Ray-lea/Argus/issues/160)）
- **デバイスのスリープ**：ハイブリッド グラフィックス搭載ノート PC で電源の切れたディスクリート GPU のセンサー照会を省いて不要な復帰を防ぎ、パフォーマンス ページに「スリープ中」と理由を表示します。アイドル中のハード ディスクは直前の温度を保持し、回転停止後は温度照会を省いてスリープを妨げないようにしました。（[#147](https://github.com/Ray-lea/Argus/issues/147)）
- **CPU の読み取り値**：CPU 使用率をアイドル サイクル基準で算出するよう改め、アイドル ループを負荷に含めて値が高く出ていた問題を修正しました。Windows 10 でハイブリッド構成プロセッサのクロックが表示されない問題や、一部の Intel プロセッサで P-コアと E-コアを区別できない問題も修正しています。（[#137](https://github.com/Ray-lea/Argus/issues/137)）
- **GPU の読み取り値**：内蔵 GPU 上のプロセスが共有 GPU メモリを専用 GPU メモリとして計上しないよう修正しました。ハードウェア GPU のない環境ではソフトウェア レンダリングをプロセスの GPU 使用率に含めず、プロセス ページの GPU 列を非表示にします。起動時にハードウェア GPU を検出していれば、ドライバー更新や GPU 追加後も再起動せずに値を復帰・表示できます。
- **ディスクの読み取り値**：USB 外付けハード ディスクで SMART 情報を取得できない、または正常性が「不明」になる問題と、Google Drive などの仮想ドライブ文字が誤ってディスク 0 の下に並ぶ問題を修正しました。
- **ファイルの使用状況**：システムのハンドル総数が非常に多い場合にファイル使用状況の検索が失敗する問題を修正しました。特権サービスとローカル検索が同じ原因で失敗した場合は通知を 1 回のみ表示し、特権サービスが既にインストール済みの場合は有効化を重複して勧めません。
- **プロセス終了保護**：対象がシステムの重要なプロセスか確認できない場合は終了操作を拒否します。単一プロセス、複数選択、プロセス ツリーのすべてに適用されます。（[@hayxe1](https://github.com/hayxe1) [#77](https://github.com/Ray-lea/Argus/pull/77)）
- **プロセス ページ**：検索やグループの開閉を行っても列幅を安定させ、ポインターによる並べ替え一時停止中に子プロセスを展開しても行順を保ちます。ユーザー グループ行で右クリック メニューが開かない問題、選択行をダブルクリックで展開すると詳細ペインが閉じる問題、一部プログラム名やバージョン情報に余分な文字が混じる問題も修正しました。
- **履歴からのプロセス移動**：履歴ページからプロセスへ移動する際に PID、名前、開始時刻を照合し、同じ PID を再利用した別プロセスを誤選択しないようにしました。（[@hayxe1](https://github.com/hayxe1) [#76](https://github.com/Ray-lea/Argus/pull/76)）
- **サービスとスタートアップの一覧**：列幅を内容に合わせて自動配分し、列境界のダブルクリックで自動幅に戻せるほか、手動調整した幅も再起動後に保持します。スタートアップ項目の状態を取得できない場合は「状態」列に簡潔に「利用不可」と表示します。
- **特権サービスと管理者として実行**：システム フォルダーの誤判定により管理者実行や特権サービスを有効化できない問題を修正しました。サービス ファイルが欠損している場合は「破損」と示して修復またはアンインストールを提供し、更新・アンインストール中の停電でも利用可能なサービス ファイルを保持します。Argus のアンインストール時には登録解除後の残存ファイルも整理します。（[#111](https://github.com/Ray-lea/Argus/issues/111)）
- **タスク マネージャーの置き換え**：セキュリティ ソフトなど外部プログラムによって置き換えが解除された際、設定ページと初回設定ガイドに「置き換えが解除されました」と明示します。メンテナンス ヘルパーが異常終了した場合はエラー通知に終了コードを付記します。
- **インストールと読み込みの安全性**：インストーラーは条件を満たすインストール先フォルダーを検査・保護し（管理者とシステムのみ書き込み可能）、対話式の新規インストールで保護できない場所が選ばれた場合は理由を説明して続行または変更を選べます。インポートするシステム DLL はシステム フォルダーからのみ読み込み、実行フォルダー内の同名ファイルは無視します。（[#136](https://github.com/Ray-lea/Argus/issues/136)）
- **ウィンドウ表示**：最大化・復元時にシステムのアニメーションが働かない問題、通知領域から開き直した際に最大化状態が維持されない問題、初回起動時やタスク マネージャー入口からの起動時に他ウィンドウの背面に隠れる問題を修正しました。（[#126](https://github.com/Ray-lea/Argus/issues/126)、[#142](https://github.com/Ray-lea/Argus/issues/142)）
- **拡大率とスクロール**：システムまたは画面の拡大率が 125% や 150% などのとき、一部ページで最下部までスクロールすると上に戻れない問題と、ダイアログをスクロールできない問題を修正しました。拡大率入力欄に 3 桁が収まり、列の選択肢やヒントで文字の下端が欠ける現象も解消しています。（[#164](https://github.com/Ray-lea/Argus/issues/164)）
- **メニューとダイアログ**：右クリック メニューとサブメニューは即座に閉じ、ドロップダウン リストは操作元の位置から開いて元の位置へ閉じます。ダイアログはウィンドウ中央から拡大フェード インして開き（表示中はウィンドウ ボタンの背景も暗転）、縮小フェード アウトで閉じます。ヒントが右クリック メニューを覆う問題や、無効なメニュー項目に警告色・ホバー強調が残る問題も修正しました。（[#141](https://github.com/Ray-lea/Argus/issues/141)）

- **ディスクの正常性と詳細**：ディスクのパフォーマンス ページに「概要／詳細」の切り替えを追加しました。NVMe、ATA/SATA、USB-SAT、SCSI/SAS のデバイス情報を必要に応じて 1 回読み取り、正常性、残り寿命、温度としきい値、通電時間と回数、読み書きの総量、メディアおよび読み書きのエラー統計、PCIe リンク、SMART 属性を表示します。手動での再読み取りも可能です。シリアル番号はプロトコルの識別情報に含まれるメーカーの番号を優先し、既定では非表示にします。
- **システム概要とパフォーマンス グラフ**：プロセス ページ上部の概要エリアを再設計しました。曲線はカードの端まで広がり、左側の数値の下で徐々に薄くなります。上部に目盛りの上限を表示し、ポインターを重ねるとカード全体を強調します。CPU 温度、CPU 消費電力、GPU 消費電力も追加しました。パフォーマンス ページの CPU 概要では、パッケージとコアの消費電力を「消費電力」に統合します（パッケージを優先し、ポインターを重ねると取得元を表示。詳細ページでは 2 本の曲線を維持）。ディスクとネットワークのグラフは一定の段階で目盛りを調整します。サイドバーのデバイス プレビューなど小型グラフの副系列は半透明の実線に変更し、小さい表示での識別性を高めました。
- **Intel 内蔵グラフィックスの測定値**：ドライバーが提供する温度、周波数、電圧、消費電力を拡充しました。カーネル センサー（IntelMCHBAR モジュール）と RAPL PP1 により、第 10 世代 Core（Comet Lake S/H）の内蔵グラフィックスについて、温度、周波数、共有メモリ周波数、コア VID、GT／メディア使用率、消費電力を補います。グラフィックス スライスのクロック停止状態を区別し、1 W 未満の消費電力を表示します。内蔵グラフィックスの消費電力は対応する GPU ページにまとめました。有効な RAPL の測定値を Windows の電力カウンターのゼロ値より優先し、ハードウェアやドライバーが提供しない項目は不明のままにします。
- **ウィンドウと画面レイアウト**：「設定 → 起動と通知領域」で起動時のページを選択できます。展開したサイド ナビゲーションは右端のドラッグで幅を調整でき、ダブルクリックで既定値に戻せます。詳細ペインに「プロセス選択時に表示」を追加し、選択時にスライド表示、選択解除時に自動収納します。履歴ページで時間範囲を切り替えると、常に現在までの最新期間を表示します。レイアウト全体を維持するため最小ウィンドウ サイズを 1240×800 に変更し、メイン ディスプレイの作業領域が小さい場合は自動的に縮小します。
- **バージョン情報、更新内容、公式ミラー**：「バージョン情報」を独立したナビゲーション ページにし（Ctrl+8）、Argus 公式サイトと GitHub リポジトリのリンク カードを追加しました。ステータス バー左端のバージョン バッジは、クリックで現在の更新内容を表示し、右クリックでバージョン番号をコピーできます。更新内容は分類別にまとめ、新機能は 2 列のカードで表示します。自動更新で GitHub に接続できない場合は Argus 公式ミラーを優先し、その後 GitHub プロキシを試します。インストーラーと更新説明の両方で署名を検証します。

### パフォーマンス

- **画面の応答性と高リフレッシュ レートのアニメーション**：サンプリング更新、文字サイズの測定、繰り返し描画によるメイン スレッドの負荷を減らしました。グラフの静的背景と合成レイヤーを再利用し、大きな曲線テクスチャは複数スレッドで並列描画します。ハードウェア アクセラレータによる GPU スケジューリング（HAGS）が無効な場合のグラフの GPU 使用率を大幅に削減しました。ページ切り替え、詳細ペイン、一覧のスクロール、列の並べ替えはディスプレイのリフレッシュ レートに合わせて滑らかに動きます。ウィンドウのサイズ変更時には、マルチコアのグリッドと GPU エンジンのグラフが同じフレーム内で即座に伸縮します。
- **ページ切り替えとバックグラウンド常駐**：起動後にサービス、スタートアップ、接続の一覧をバックグラウンドで先読みし、初回表示ですぐに内容を表示します。画面設定はバックグラウンドでまとめて非同期に保存し、ページ切り替え時の停止を解消しました。リアルタイム グラフのないページでは繰り返しの再構築を省き、CPU 使用率を下げます。最小化または通知領域への非表示時は描画を停止し、必要に応じてグラフ レイヤーのキャッシュ、期限切れのアイコン、テクスチャ アトラスを解放して、バックグラウンドのメモリと GPU メモリ使用量を減らします。
- **高負荷・低メモリ環境**：通知領域の更新を専用スレッドでまとめ、高負荷時やシェルが応答しない場合の操作とサンプリングの応答性を改善しました。メモリ不足時はグラフのバッファーとテクスチャ精度を自動的に下げてリアルタイム曲線を維持し、空きメモリが回復すると元の精度に戻します。広い範囲を覆う最前面ウィンドウがある場合の、ウィンドウのアクティブ化も改善しました。

### 修正

- **プロセス別ネットワーク通信量**：一部の PC で値がゼロのままになる問題と、更新間隔が 0.5 秒の場合に交互にゼロになったり更新が遅れたりする問題を修正しました。
- **特権サービス**：パイプ接続完了前にクライアントが異常切断するとサービスが終了する問題と、頻繁な読み取りでタイムアウトや誤ったデータなし判定が発生する問題を修正しました。
- **アプリ名とアイコン**：パッケージ アプリ（MSIX）でシステムのタスク マネージャーのアプリ名ではなく実行ファイルの説明が表示される問題を修正しました。デバイス パスの対応付けがない場合やプロセスのオープンが拒否された場合に、アイコンとファイルの説明が欠落する問題も修正しました。
- **プロセス別 GPU メモリ**：常駐メモリのカウンターを使用し、プロセスと物理アダプターごとに重複を除くことで、一部のシステムやドライバーで値が過大になる問題と重複加算を修正しました。測定値がない状態と使用量ゼロを区別します。
- **Intel 内蔵グラフィックスの消費電力表示**：CPU 概要で、アイドル中の内蔵グラフィックスの消費電力が繰り返し表示・非表示になる問題を修正しました。
- **CPU 仮想化の状態**：ハードウェア仮想化が有効な Hyper-V ホストで「無効」と表示される問題を修正しました。
- **管理者起動の承認**：ユーザー名とコンピューター名が同じ場合に SID の解決に失敗して承認できない問題を修正し、同一バージョンの再ビルドしたコピーの識別も改善しました。
- **長時間動作時のメモリ使用量**：プログラム アイコンを内容で重複排除し、終了済みプログラムのメタデータ キャッシュを定期的に削除します。解析処理が混雑した際の要求の蓄積を制限し、新しいパスのプログラムを頻繁に起動するとメモリが増え続ける問題を修正しました。
- **外部リンク**：公式サイト、リポジトリ、リリース ページなどのリンクは直接システム シェルに渡し、新しいエクスプローラー プロセスを経由することによる表示の遅れを解消しました。

- **特権サービス**：サービスの通信プロトコルをバージョン 10 に更新しました。インストール版をインストーラーまたはアプリ内更新で上書き更新すると、インストール済みサービスとタスク マネージャー置き換え用コピーも更新します。ポータブル版は実行ファイルの差し替え後、「設定 → 権限 → 特権サービス」で「サービスを更新」を選択し、管理者の確認を完了する必要があります。

## [0.2.0](https://github.com/Ray-lea/Argus/compare/v0.1.0...v0.2.0) - 2026-10-18

プロセス別のディスク読み書き速度を追加し、最小化時と通知領域への非表示時の更新間隔を個別に設定できるようにしました。アプリ内更新とショートカット設定を改善し、一部の PC で一定時間後にクラッシュする問題などを修正しました。特権サービスがインストールされている場合は、先に「互換性のない変更」の確認が必要です。

### 互換性のない変更

- **特権サービスの更新が必要**：Argus と特権サービスの通信方式を変更しました。0.1.0 のサービスは新バージョンでは使用できません。特権サービスが未インストールの場合は影響ありません。
- **インストーラー経由の更新**：アプリ内更新とインストーラーの直接実行が該当します。インストーラーは、タスク マネージャーの置き換えから起動して動作中の旧 Argus を先に終了し、同じ管理者承認で特権サービスも更新します。追加操作は不要です。「タスク マネージャーを置き換える」が有効な場合はその状態を維持し、更新成功後の Ctrl+Shift+Esc で新バージョンが開きます。
- **ポータブル版の更新**：特権サービスがインストールされている場合、本体の差し替え後にサービスを手動更新する必要があります。新版 Argus の案内または「設定 → 権限」で「サービスを更新」を選択して承認します。インストーラーによるサービス更新が失敗した場合も同じ手順です。サービス更新までは、それに依存するネットワーク、ディスク読み書き、CPU センサーのデータを取得できず、昇格が必要な管理操作が失敗する場合があります。「タスク マネージャーを置き換える」が有効な場合、Ctrl+Shift+Esc で旧版が開く場合がありますが、サービス更新時に置き換え用プログラムも更新し、有効状態を維持します。

### 新機能

- **プロセス別ディスク読み書き**：プロセス ページに「ディスク読み取り」「ディスク書き込み」の 2 列を追加しました。各プロセスが毎秒読み書きするデータ量を表示し、並べ替えに対応します。アプリ別表示ではグループの合計を表示し、詳細ペインでも確認できます。I/O 列はネットワークとデバイスの読み書きも含むため、この 2 列とは別に集計します。Windows 11 24H2 以降は追加権限が不要で、それ以前は特権サービスの有効化または管理者としての実行が必要です。サービスの承認説明にもこの項目を追加しました。一時的に値が取得できない場合は「—」を表示し、ポインターを重ねると理由が分かります。狭いウィンドウでも両列を維持し、名前列を左に固定して表を横スクロールできます。そのため、スレッド、ハンドル、PID、I/O 列は従来より早く非表示になります。
- **アプリ内更新**：このバージョンから、新版のダウンロードと署名検証が完了すると、タイトル バー右側に更新ボタン、通知領域のアイコンに丸印、右下にバージョンごとに一度だけ通知を表示します。ポータブル版は自動ダウンロードを行わず、新版を検出した時点で通知します。更新ダイアログは現在から新版までの各バージョンの変更を分類別に表示し、それぞれの変更件数を示します。更新内容もインストーラーと同様に署名を検証します。更新ボタンの右クリックで「このバージョンでは今後通知しない」を選択できます。ダウンロード済みの更新は Argus の再起動後も再ダウンロード不要です。
- **更新後の変更内容表示**：更新後に初めてウィンドウを開くと、新版の変更内容を表示します。「設定 → アップデート」の「更新後に変更内容を表示」で無効にでき、その後は右下に更新完了のみを通知します。同じページの「このバージョンの変更内容を表示」から随時開けます。
- **バックグラウンドの更新間隔**：最小化時と通知領域への非表示時を個別に設定できます。範囲は 0.5～30 秒、既定値は 5 秒で、「設定 → データと履歴」および初回設定ガイドから変更します。5 秒未満では CPU 使用率と消費電力が増える旨を事前に説明し、5 秒を超えると履歴の記録密度も下がります。前面に戻ると即座に更新します。バックグラウンドの間隔が前面より長い場合、右下に一度通知し、設定への直接移動または以後の通知停止を選べます。
- **ショートカット設定**：組み合わせを保存したまま無効化でき、再び有効にすると復元します。記録中は押しているキーをリアルタイムで表示し、使用できない組み合わせは理由を説明します。「デフォルトに戻す」も利用できます。Ctrl+文字キー、Alt+文字キーなど他のアプリと競合しやすい組み合わせは確認後に保存します。他のアプリが使用中の場合は直接再試行でき、そのアプリの終了後、ウィンドウを再表示した際にも自動で再試行します。

- **外観**：ツールバーはタイトル バーを兼ね、ナビゲーションはその下またはウィンドウ左側に配置します。Mica 背景とシステムのアクセント カラーを使用します。ライト・ダーク テーマは既定で Windows に従い、設定で指定することもできます。
- **インストールとアンインストール**：1 ページのインストーラーで、Windows のライト・ダーク モードに従います。旧版がインストール済みの場合は上書き更新し、アンインストール時には設定、履歴、ログの削除も選択できます。
- **多言語と初回設定ガイド**：画面、通知領域、インストーラーは簡体字中国語と英語に対応し、既定で Windows の表示言語に従います。初回起動時に、言語、表示と更新間隔、通知領域への常駐、アップデートなどを設定できます。任意の特権サービスのインストール、カーネル センサーの有効化、システムのタスク マネージャーの置き換えも直接実行できます。

### 既知の制限

- プログラムはまだコード署名されておらず、初回実行時に Windows SmartScreen が「不明な発行元」と警告する場合があります。
- CPU 内部センサーにはカーネル センサー（特権サービスと PawnIO ドライバー）の有効化が必要です。対応プロセッサとマザーボードは[ハードウェア データ](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)を参照してください。
- その他の制限は[既知の問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)を参照してください。

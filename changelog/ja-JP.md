## [0.4.0](https://github.com/Ray-lea/Argus/compare/v0.3.4...v0.4.0) - 2026-11-06

v0.4.0 では、アプリの画面を Tauri、SolidJS、WebView2 から Rust + GPUI Kit のネイティブ構成へ全面移行しました。ブラウザー エンジンの負荷を解消し、DirectX によるネイティブ描画と操作を再構築するとともに、高リフレッシュ レートのアニメーション、リアルタイム グラフの描画、一覧のサンプリング更新、バックグラウンド常駐時のリソース使用量を大幅に最適化しました。プロセス列のカスタマイズ、ディスクの正常性と SMART の詳細、Intel 内蔵グラフィックスの追加測定値、ウィンドウのレイアウト設定も追加しました。[Argus 公式サイト](https://argustask.com/ja/)を公開し、公式アップデート ミラーにも接続しました。

### 新機能

- **プロセス列のカスタマイズ**：基本情報、CPU、メモリ、ディスクと I/O、ネットワーク、GPU の 6 分類、計 40 列に対応しました。専用 GPU メモリ、共有 GPU メモリ、GPU エンジン、イメージ名、仮想アドレス空間、最大ワーキング セット、ページ フォールト、累積 I/O などを追加しています。仮想アドレス空間と最大ワーキング セットはプロセス単位で表示します。列見出しの右クリック メニューには分類別サブメニューを設け、連続して選択できます。「列の選択」ダイアログでは分類による絞り込み、検索、2 つのペインでの並べ替えが可能です。見出しや選択済みの列をドラッグすると、周囲の列が滑らかに移動し、その場で順序が変わります。自動列幅は数値書式に応じた余白を確保して幅の変動を防ぎ、手動調整にも対応します。一覧とプロセス ツリーの「名前」列はアプリ別表示と統一し、アプリ名またはファイルの説明を優先します。実行ファイル名は補助テキストまたは「イメージ名」列で確認できます。
- **ディスクの正常性と詳細**：ディスクのパフォーマンス ページに「概要／詳細」の切り替えを追加しました。NVMe、ATA/SATA、USB-SAT、SCSI/SAS のデバイス情報を必要に応じて 1 回読み取り、正常性、残り寿命、温度としきい値、通電時間と回数、読み書きの総量、メディアおよび読み書きのエラー統計、PCIe リンク、SMART 属性を表示します。手動での再読み取りも可能です。シリアル番号はプロトコルの識別情報に含まれるメーカーの番号を優先し、既定では非表示にします。
- **システム概要とパフォーマンス グラフ**：プロセス ページ上部の概要エリアを再設計しました。曲線はカードの端まで広がり、左側の数値の下で徐々に薄くなります。上部に目盛りの上限を表示し、ポインターを重ねるとカード全体を強調します。CPU 温度、CPU 消費電力、GPU 消費電力も追加しました。パフォーマンス ページの CPU 概要では、パッケージとコアの消費電力を「消費電力」に統合します（パッケージを優先し、ポインターを重ねると取得元を表示。詳細ページでは 2 本の曲線を維持）。ディスクとネットワークのグラフは一定の段階で目盛りを調整します。サイドバーのデバイス プレビューなど小型グラフの副系列は半透明の実線に変更し、小さい表示での識別性を高めました。
- **Intel 内蔵グラフィックスの測定値**：ドライバーが提供する温度、周波数、電圧、消費電力を拡充しました。カーネル センサー（IntelMCHBAR モジュール）と RAPL PP1 により、第 10 世代 Core（Comet Lake S/H）の内蔵グラフィックスについて、温度、周波数、共有メモリ周波数、コア VID、GT／メディア使用率、消費電力を補います。グラフィックス スライスのクロック停止状態を区別し、1 W 未満の消費電力を表示します。内蔵グラフィックスの消費電力は対応する GPU ページにまとめました。有効な RAPL の測定値を Windows の電力カウンターのゼロ値より優先し、ハードウェアやドライバーが提供しない項目は不明のままにします。
- **ウィンドウと画面レイアウト**：「設定 → 起動と通知領域」で起動時のページを選択できます。展開したサイド ナビゲーションは右端のドラッグで幅を調整でき、ダブルクリックで既定値に戻せます。詳細ペインに「プロセス選択時に表示」を追加し、選択時にスライド表示、選択解除時に自動収納します。履歴ページで時間範囲を切り替えると、常に現在までの最新期間を表示します。レイアウト全体を維持するため最小ウィンドウ サイズを 1240×800 に変更し、メイン ディスプレイの作業領域が小さい場合は自動的に縮小します。
- **バージョン情報、更新内容、公式ミラー**：「バージョン情報」を独立したナビゲーション ページにし（Ctrl+8）、Argus 公式サイトと GitHub リポジトリのリンク カードを追加しました。ステータス バー左端のバージョン バッジは、クリックで現在の更新内容を表示し、右クリックでバージョン番号をコピーできます。更新内容は分類別にまとめ、新機能は 2 列のカードで表示します。自動更新で GitHub に接続できない場合は Argus 公式ミラーを優先し、その後 GitHub プロキシを試します。インストーラーと更新説明の両方で署名を検証します。

### パフォーマンス

- **画面の応答性と高リフレッシュ レートのアニメーション**：サンプリング更新、文字サイズの測定、繰り返し描画によるメイン スレッドの負荷を減らしました。グラフの静的背景と合成レイヤーを再利用し、大きな曲線テクスチャは複数スレッドで並列描画します。ハードウェア アクセラレータによる GPU スケジューリング（HAGS）が無効な場合のグラフの GPU 使用率を大幅に削減しました。ページ切り替え、詳細ペイン、一覧のスクロール、列の並べ替えはディスプレイのリフレッシュ レートに合わせて滑らかに動きます。ウィンドウのサイズ変更時には、マルチコアのグリッドと GPU エンジンのグラフが同じフレーム内で即座に伸縮します。
- **ページ切り替えとバックグラウンド常駐**：起動後にサービス、スタートアップ、接続の一覧をバックグラウンドで先読みし、初回表示ですぐに内容を表示します。画面設定はバックグラウンドでまとめて非同期に保存し、ページ切り替え時の停止を解消しました。リアルタイム グラフのないページでは繰り返しの再構築を省き、CPU 使用率を下げます。最小化または通知領域への非表示時は描画を停止し、必要に応じてグラフ レイヤーのキャッシュ、期限切れのアイコン、テクスチャ アトラスを解放して、バックグラウンドのメモリと GPU メモリ使用量を減らします。
- **高負荷・低メモリ環境**：通知領域の更新を専用スレッドでまとめ、高負荷時やシェルが応答しない場合の操作とサンプリングの応答性を改善しました。メモリ不足時はグラフのバッファーとテクスチャ精度を自動的に下げてリアルタイム曲線を維持し、空きメモリが回復すると元の精度に戻します。広い範囲を覆う最前面ウィンドウがある場合の、ウィンドウのアクティブ化も改善しました。

### 修正

- **プロセス別ネットワーク通信量**：一部の PC で値がゼロのままになる問題と、更新間隔が 0.5 秒の場合に交互にゼロになったり更新が遅れたりする問題を修正しました。
- **特権サービス**：パイプ接続完了前にクライアントが異常切断するとサービスが終了する問題と、頻繁な読み取りでタイムアウトや誤ったデータなし判定が発生する問題を修正しました。
- **アプリ名とアイコン**：パッケージ アプリ（MSIX）でシステムのタスク マネージャーのアプリ名ではなく実行ファイルの説明が表示される問題を修正しました。デバイス パスの対応付けがない場合やプロセスのオープンが拒否された場合に、アイコンとファイルの説明が欠落する問題も修正しました。
- **プロセス別 GPU メモリ**：常駐メモリのカウンターを使用し、プロセスと物理アダプターごとに重複を除くことで、一部のシステムやドライバーで値が過大になる問題と重複加算を修正しました。測定値がない状態と使用量ゼロを区別します。
- **Intel 内蔵グラフィックスの消費電力表示**：CPU 概要で、アイドル中の内蔵グラフィックスの消費電力が繰り返し表示・非表示になる問題を修正しました。
- **CPU 仮想化の状態**：ハードウェア仮想化が有効な Hyper-V ホストで「無効」と表示される問題を修正しました。
- **管理者起動の承認**：ユーザー名とコンピューター名が同じ場合に SID の解決に失敗して承認できない問題を修正し、同一バージョンの再ビルドしたコピーの識別も改善しました。
- **長時間動作時のメモリ使用量**：プログラム アイコンを内容で重複排除し、終了済みプログラムのメタデータ キャッシュを定期的に削除します。解析処理が混雑した際の要求の蓄積を制限し、新しいパスのプログラムを頻繁に起動するとメモリが増え続ける問題を修正しました。
- **外部リンク**：公式サイト、リポジトリ、リリース ページなどのリンクは直接システム シェルに渡し、新しいエクスプローラー プロセスを経由することによる表示の遅れを解消しました。

### アップデート時の注意

- **動作環境**：Windows 10 22H2（ビルド 19045）以降、Windows 11 を含む、x64 のみ対応です。DirectX 11 に対応するグラフィックス デバイスとドライバーが必要です。アプリの画面は WebView2 ランタイムに依存しなくなりました。
- **設定と履歴**：アプリの設定と履歴ファイルは保持します。v0.3.3/v0.3.4 からの更新では、個別に保存した画面設定を引き継ぎます。v0.3.2 以前から直接更新する場合、旧 WebView2 キャッシュだけに保存されていた設定（レイアウト、行のメモ、固定表示の印など）は既定値に戻るため、再設定が必要です。新バージョンは Argus の古い WebView2 データをバックグラウンドで自動削除します。
- **特権サービス**：サービスの通信プロトコルをバージョン 10 に更新しました。インストーラー版をインストーラーまたはアプリ内更新で上書き更新すると、インストール済みサービスとタスク マネージャー置き換え用コピーも更新します。ポータブル版は実行ファイルの差し替え後、「設定 → 権限 → 特権サービス」で「サービスを更新」を選択し、管理者の確認を完了する必要があります。

## [0.3.4](https://github.com/Ray-lea/Argus/compare/v0.3.3...v0.3.4) - 2026-10-26

### 修正

- **エクスプローラーの再起動**：旧プロセスが終了処理やエラー報告中に停止すると、デスクトップとタスク バーが復元されない問題を修正しました。通常の終了がタイムアウトした場合、確認済みの旧インスタンスだけを終了し、その終了を確認してからデスクトップを復元します。Windows が既に復元している場合は既存のインスタンスを使用し、重複起動を防ぎます。([#20](https://github.com/Ray-lea/Argus/issues/20))

## [0.3.3](https://github.com/Ray-lea/Argus/compare/v0.3.2...v0.3.3) - 2026-10-26

画面の拡大率とフォント サイズの設定を追加し、ウィンドウと一覧の設定保存を改善するとともに、GPU 使用率の集計を調整しました。

### 新機能

- **画面の拡大率**：「設定 → 言語と外観」で 80%–150% に設定できます。既定値は 100% で、113% など整数の割合も入力できます。
- **フォント サイズ**：基本サイズを 11–20 px に調整できます。既定値は 13 px です。画面の拡大率と併用でき、即座に反映して自動保存します。各設定は個別に既定値へ戻せます。

### 修正

- **GPU 統計**：一部の計算負荷で全体の使用率が低くなる問題、サンプリング再開時の異常なピーク、複数 GPU やエンジンの集計が過大になる問題の修正を試みました。プロセスのエンジン カウンターと、取得可能な NVIDIA コア使用率を補い、集計元も表示します。([#19](https://github.com/Ray-lea/Argus/issues/19))
- **ウィンドウの復元**：終了後の再起動でサイズ、位置、最大化状態を復元します。最小化した状態で終了しても次回起動が最小化のままにならず、画面外のウィンドウは表示可能な領域へ戻します。
- **一覧の設定**：プロセス、サービス、スタートアップ、接続の各一覧で並べ替え列と昇順・降順を個別に保存します。サービスと接続のページでは選択済みフィルターも復元します。
- **設定の保存**：画面設定を個別に保存し、旧キャッシュからの移行にも対応しました。画面キャッシュを削除した後も保存済みの設定を復元できます。
- **レイアウトとウィンドウ ボタン**：フォントや拡大率が大きい場合もツールバーとナビゲーションが狭いウィンドウに収まるようにし、最大化ボタンの反応領域を修正しました。

### アップデート時の注意

- v0.3.x からの更新では既存の設定と履歴を保持します。旧画面設定は初回起動時に自動移行するため、手動での再設定は不要です。

## [0.3.2](https://github.com/Ray-lea/Argus/compare/v0.3.1...v0.3.2) - 2026-10-23

撤回済みの v0.3.1 を置き換えるバージョンです。インストーラー版を管理者として、またはタスク マネージャーの起動操作から開いた際、ポータブル版と誤判定されてアプリ内更新が利用できない問題を修正しました。

### アップデート時の注意

- インストーラー版で「ポータブル版は自動更新に対応していません」と表示される場合は、このバージョンのリリース ページからインストーラーをダウンロードして直接実行します。Argus の事前アンインストールは不要です。更新後は管理者としての起動やタスク マネージャーの起動操作でもアプリ内更新を利用できます。

### 修正

- **インストーラー版の更新**：管理者起動用とタスク マネージャー置き換え用のコピーを正しく識別し、更新の自動確認、ダウンロード、インストールを復旧しました。
- **ポータブル版の識別**：実行ファイルの隣にアンインストーラーがあってもインストーラー版と誤判定せず、引き続きリリース ページから手動で更新をダウンロードします。

### 含まれる変更

- v0.3.1 の一度の承認による管理者起動と、エクスプローラーの再起動、CPU 使用率の集計、ウィンドウ復元後の曲線、プロセス一覧のカーソル、更新インストールの修正を含みます。

## [0.3.1](https://github.com/Ray-lea/Argus/compare/v0.3.0...v0.3.1) - 2026-10-23

**このバージョンは撤回されました。機能と修正は v0.3.2 に含まれています。**

一度の承認による管理者起動を追加し、サインイン時、ショートカット、タスク マネージャーの起動操作での権限を統一しました。エクスプローラーの再起動、CPU 使用率、更新インストールの問題も修正しました。

### アップデート時の注意

- **管理者として実行**：既定では無効です。「設定 → 権限」または初回設定ガイドで有効にできます。管理者アカウントのみ対応し、有効化後は設定と履歴を保持して Argus が再起動します。特権サービス、カーネル センサー、タスク マネージャーの置き換えには、それぞれ個別の承認が必要です。
- **インストーラー版**：インストーラーまたはアプリ内更新で更新すると、インストール済みの特権サービスとタスク マネージャー置き換え用コピーも更新します。
- **ポータブル版**：旧バージョンを終了してから実行ファイルを差し替えます。特権サービスがインストールされている場合、新バージョンの「設定 → 権限」で「サービスを更新」を選択します。その後の手動更新では、管理者起動が有効な場合、事前に無効化して終了し、差し替え後に新しい実行ファイルから起動して再度有効にできます。

### 新機能

- **管理者起動**：一度承認すると、サインイン時、ショートカット、ピン留めしたアイコンから管理者権限で Argus を起動できます。タスク マネージャーの置き換えが有効な場合は Ctrl+Shift+Esc とタスク バーの右クリック メニューも対応します。設定とガイドに承認状態および現在の権限を表示し、承認の無効化と修復が可能です。([#13](https://github.com/Ray-lea/Argus/issues/13))

### 修正

- **エクスプローラー**：標準権限または管理者権限で再起動に失敗する問題、再起動後のデスクトップの異常、再度の再起動時に権限が不足する問題を修正しました。ファイルの使用状況の一覧で、現在のデスクトップのエクスプローラーに「再起動」を提供し、直接終了によるデスクトップとタスク バーの消失を防ぎます。([#14](https://github.com/Ray-lea/Argus/issues/14)、[#15](https://github.com/Ray-lea/Argus/issues/15))
- **CPU 統計**：一部のシステムでアイドル カウンターの更新が止まった際、CPU 使用率が 100% のままになる問題を修正しました。([#12](https://github.com/Ray-lea/Argus/issues/12))
- **曲線表示**：最小化状態や通知領域からウィンドウを復元した際、蓄積されたデータが密集したピークになる問題を修正しました。
- **プロセス一覧**：一覧をクリックすると点滅するテキスト カーソルが現れる問題を修正し、直接入力による検索と中国語入力メソッドへの対応は維持しました。([#16](https://github.com/Ray-lea/Argus/issues/16))
- **更新インストール**：実行ファイルを使用中のプロセスを表示して再試行に対応し、失敗した手順とエラー コードを補いました。別の管理者アカウントで承認した後、更新診断ログを読み取れない問題も修正しました。

### 既知の問題

- **コード署名**：公開プログラムにはまだ Windows のコード署名がなく、初回実行時に Windows SmartScreen が「不明な発行元」と警告する場合があります。アプリ内更新では引き続き更新署名を検証します。

## [0.3.0](https://github.com/Ray-lea/Argus/compare/v0.2.0...v0.3.0) - 2026-10-22

新しいタスクの実行、エクスプローラーの再起動、PC 構成のコピーを追加し、プロセスのグループ化とパフォーマンス表示を充実させ、Windows 10 との互換性を改善しました。

### 互換性のない変更

## [0.2.0](https://github.com/Ray-lea/Argus/compare/v0.1.0...v0.2.0) - 2026-10-18

プロセス別のディスク読み書き速度を追加し、最小化時と通知領域への非表示時の更新間隔を個別に設定できるようにしました。アプリ内更新とショートカット設定を改善し、一部の PC で一定時間後にクラッシュする問題などを修正しました。特権サービスがインストールされている場合は、先に「互換性のない変更」の確認が必要です。

### 互換性のない変更

- **特権サービスの更新が必要**：Argus と特権サービスの通信方式を変更しました。0.1.0 のサービスは新バージョンでは使用できません。特権サービスが未インストールの場合は影響ありません。
- **インストーラー経由の更新**：アプリ内更新とインストーラーの直接実行が該当します。インストーラーは、タスク マネージャーの置き換えから起動して動作中の旧 Argus を先に終了し、同じ管理者承認で特権サービスも更新します。追加操作は不要です。「タスク マネージャーを置き換える」が有効な場合はその状態を維持し、更新成功後の Ctrl+Shift+Esc で新バージョンが開きます。
- **ポータブル版の更新**：特権サービスがインストールされている場合、本体の差し替え後にサービスを手動更新する必要があります。新版 Argus の案内または「設定 → 権限」で「サービスを更新」を選択して承認します。インストーラーによるサービス更新が失敗した場合も同じ手順です。サービス更新までは、それに依存するネットワーク、ディスク読み書き、CPU センサーのデータを取得できず、昇格が必要な管理操作が失敗する場合があります。「タスク マネージャーを置き換える」が有効な場合、Ctrl+Shift+Esc で旧版が開く場合がありますが、サービス更新時に置き換え用プログラムも更新し、有効状態を維持します。

### 新機能

- **プロセス別ディスク読み書き**：プロセス ページに「ディスク読み取り」「ディスク書き込み」の 2 列を追加しました。各プロセスが毎秒読み書きするデータ量を表示し、並べ替えに対応します。アプリ別表示ではグループの合計を表示し、詳細ペインでも確認できます。I/O 列はネットワークとデバイスの読み書きも含むため、この 2 列とは別に集計します。Windows 11 24H2 以降は追加権限が不要で、それ以前は特権サービスの有効化または管理者としての実行が必要です。サービスの承認説明にもこの項目を追加しました。一時的に値が取得できない場合は「—」を表示し、ポインターを重ねると理由が分かります。狭いウィンドウでも両列を維持し、名前列を左に固定して表を横スクロールできます。そのため、スレッド、ハンドル、PID、I/O 列は従来より早く非表示になります。
- **アプリ内更新**：このバージョンから、新版のダウンロードと署名検証が完了すると、タイトル バー右側に更新ボタン、通知領域のアイコンに丸印、右下にバージョンごとに一度だけ通知を表示します。ポータブル版は自動ダウンロードを行わず、新版を検出した時点で通知します。更新ダイアログは現在から新版までの各バージョンの変更を分類別に表示し、それぞれの変更件数を示します。更新内容もインストーラーと同様に署名を検証します。更新ボタンの右クリックで「このバージョンでは今後通知しない」を選択できます。ダウンロード済みの更新は Argus の再起動後も再ダウンロード不要です。
- **更新後の変更内容表示**：更新後に初めてウィンドウを開くと、新版の変更内容を表示します。「設定 → アップデート」の「更新後に変更内容を表示」で無効にでき、その後は右下に更新完了のみを通知します。同じページの「このバージョンの変更内容を表示」から随時開けます。
- **バックグラウンドの更新間隔**：最小化時と通知領域への非表示時を個別に設定できます。範囲は 0.5～30 秒、既定値は 5 秒で、「設定 → データと履歴」および初回設定ガイドから変更します。5 秒未満では CPU 使用率と消費電力が増える旨を事前に説明し、5 秒を超えると履歴の記録密度も下がります。前面に戻ると即座に更新します。バックグラウンドの間隔が前面より長い場合、右下に一度通知し、設定への直接移動または以後の通知停止を選べます。
- **ショートカット設定**：組み合わせを保存したまま無効化でき、再び有効にすると復元します。記録中は押しているキーをリアルタイムで表示し、使用できない組み合わせは理由を説明します。「デフォルトに戻す」も利用できます。Ctrl+文字キー、Alt+文字キーなど他のアプリと競合しやすい組み合わせは確認後に保存します。他のアプリが使用中の場合は直接再試行でき、そのアプリの終了後、ウィンドウを再表示した際にも自動で再試行します。
- **CPU 稼働時間**：「5 日 14:03:07」のように秒単位で表示し、更新のたびに反映します。

## 0.1.0 - 2026-10-16

### 新機能

- **プロセス**：アプリ別、プロセス ツリー、一覧で表示でき、名前順では「アプリ」と「バックグラウンド プロセス」に分かれます。プロセス別に CPU、メモリ、I/O、GPU 使用量を表示し、特権サービスまたは管理者として実行する場合はネットワーク通信量も含みます。検索、プロセスまたはツリー全体の終了に対応します。詳細ペインにはコマンド ライン、ユーザー、整合性レベルなどを表示し、アプリ別ではアプリ全体の合計を表示します。

- **サービスとスタートアップ**：サービスの開始・停止とスタートアップの種類の変更、スタートアップ アプリの有効化・無効化に対応します。システムのタスク マネージャーと同じスイッチを使用します。
- **接続とポート**：TCP と UDP のエンドポイントおよび所属プロセスを表示し、ポート番号の完全一致検索と IPv4 TCP 接続の切断に対応します。
- **ファイルの使用状況**：ファイルやフォルダーをウィンドウにドロップすると、Restart Manager とハンドル列挙を組み合わせて使用中のプロセスを検索します。プロセスの現在のディレクトリも対象です。
- **履歴の確認**：過去 7 日間のリソース使用量を記録し、任意の時点をクリックすると当時の使用量が多いプロセスを確認できます。
- **通知領域への常駐**：グローバル ショートカット Ctrl+Alt+Esc でウィンドウを表示・非表示にできます。非表示時のリソース使用量はごくわずかです。
- **任意の特権サービス**：一度管理者の承認を受けると、標準権限の画面からシステム プロセスの管理、ルールの自動適用、プロセス別通信量の集計、サービスの制御、接続の切断が可能です。
- **システムのタスク マネージャーの置き換え**：Ctrl+Shift+Esc などの操作で Argus を開くようにできます。画面やサービスに依存しない独立した復元プログラムを付属しています。
- **アプリ内更新**：安定版とベータ版の 2 チャネルを提供し、任意で GitHub プロキシを使用できます。署名検証に成功したバージョンのみインストールします。
- **外観**：ツールバーはタイトル バーを兼ね、ナビゲーションはその下またはウィンドウ左側に配置します。Mica 背景とシステムのアクセント カラーを使用します。ライト・ダーク テーマは既定で Windows に従い、設定で指定することもできます。
- **インストールとアンインストール**：1 ページのインストーラーで、Windows のライト・ダーク モードに従います。旧版がインストール済みの場合は上書き更新し、アンインストール時には設定、履歴、ログの削除も選択できます。
- **多言語と初回設定ガイド**：画面、通知領域、インストーラーは簡体字中国語と英語に対応し、既定で Windows の表示言語に従います。初回起動時に、言語、表示と更新間隔、通知領域への常駐、アップデートなどを設定できます。任意の特権サービスのインストール、カーネル センサーの有効化、システムのタスク マネージャーの置き換えも直接実行できます。

### 既知の制限

- プログラムはまだコード署名されておらず、初回実行時に Windows SmartScreen が「不明な発行元」と警告する場合があります。
- CPU 内部センサーにはカーネル センサー（特権サービスと PawnIO ドライバー）の有効化が必要です。対応プロセッサとマザーボードは[ハードウェア データ](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)を参照してください。
- その他の制限は[既知の問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)を参照してください。

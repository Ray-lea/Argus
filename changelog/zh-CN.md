## [0.6.0](https://github.com/Ray-lea/Argus/compare/v0.5.0...v0.6.0) - 2026-11-22

v0.6.0 换用全新的点阵性能图应用图标，重新设计主窗口界面，精简标题栏、重排页面栏与状态栏，并新增置顶显示按钮。新增“组件”页，可在托盘、桌面与任务栏实时显示系统读数；重构历史页，支持多轨道曲线、资源事件与跨次运行的进程观察。进程页新增资源泄漏提示与电源使用情况列，进程、服务、启动与连接页均支持内容复制与 CSV 导出，服务与启动项支持删除；性能页新增 NPU 监控，同时加入触屏操作与硬件加速开关。本版还大幅降低列表滚动与界面重绘开销，修复部分 Intel RST VMD 系统打开磁盘详情时触发蓝屏的问题，并避免唤醒已断电的独立显卡与停转硬盘。

### 破坏性变更

- **历史记录**：本版改用新的存储格式，历史页仅显示 0.6.0 及之后记录的数据。升级后首次写入当日记录时，会替换当天的旧格式文件；旧版 Argus 也无法读取新版记录。
- **特权服务协议**：通信协议从第 11 版升至第 12 版。通过特权服务执行结束进程、调整 I/O 或内存优先级等操作前，须先更新旧版服务。

### 新功能

- **应用图标**：换用全新的点阵性能图图标，针对不同尺寸单独排布点阵，在任务栏、标题栏与更新后的快捷方式中均保持清晰。关于页与首次启动引导先由点阵拼出标志，再转为最近 10 次 CPU 占用的动态点阵图；关闭“界面动画”时直接显示点阵图。
- **标题栏**：精简为仅保留应用标识、宽度自适应的搜索框与 Windows 标准尺寸窗口按钮，其余空白处均可拖动窗口。新增图钉按钮以切换“置顶显示”，状态在重启后保留。（[#121](https://github.com/Ray-lea/Argus/issues/121)）
- **页面栏与状态栏**：页面控件与“更多操作”移至导航标签旁，进程视图切换按钮改用图标。“更多操作”收纳“运行新任务…”（Ctrl+N）、“查找占用文件的进程…”与快捷键说明，服务页还可直接打开 Windows 服务管理器。状态栏提供暂停刷新与刷新频率按钮，版本号兼作更新进度与安装入口。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **组件页**：新增“组件”页，集中管理托盘与后台常驻选项，并可开启桌面监控和任务栏监控（两者均默认关闭）。从托盘或监控打开设置时，侧栏自动定位到对应分组。
- **实时托盘图标**：托盘图标默认以“走势”实时显示 CPU 占用，也可切换为“占比”“数字”或“应用图标”；前三种实时样式在占用达到 80% 时以琥珀色提示。指针悬停时显示实时读数卡片，右键单击打开快捷面板，列出 CPU 占用最高的三个进程与常用操作。
- **托盘卡片与快捷面板**：悬停卡片按当前语言与字号自适应排版，关闭卡片后改用系统提示。单击快捷面板中的读数可直达性能页对应设备；从隐藏图标区打开面板时，该区域保持展开。（[@digital-bombyx](https://github.com/digital-bombyx) [#113](https://github.com/Ray-lea/Argus/pull/113) [#153](https://github.com/Ray-lea/Argus/pull/153)）
- **桌面监控**：以桌面小窗口常驻显示实时读数，支持“横条”与“面板”两种显示方式，其中面板提供“列表”“曲线”“仪表”三种样式。拖动时自动限制在当前显示器工作区内，支持置顶显示、锁定位置、鼠标穿透与不透明度调节。
- **任务栏监控**：在任务栏常驻显示实时读数，提供“标签”“曲线”“胶囊”与“大数字”四种样式。可在组件页或右键面板实时预览并切换样式；右键面板还支持选择显示器、勾选读数与拖动排序，调整立即生效。（[#28](https://github.com/Ray-lea/Argus/issues/28)、[#123](https://github.com/Ray-lea/Argus/issues/123)）
- **多显示器与窗口切换**：所选显示器断开时，任务栏监控暂移至主显示器，重连后自动移回。单击任务栏监控或托盘图标，可在窗口未被遮挡时隐藏主窗口，或在窗口隐藏、最小化、被遮挡时将其调至前台；双击桌面监控可打开主窗口。
- **监控读数**：桌面监控与任务栏监控共提供 18 种读数，涵盖温度、频率、功耗与风扇转速。支持为每块显卡、磁盘与网卡单独勾选，并可拖动类别或单项读数排序。任务栏监控以设备颜色区分名称，同一 CPU 或 GPU 的后续读数直接标注参数名称。
- **监控刷新间隔**：桌面监控或任务栏监控开启期间，Argus 沿用主窗口的刷新频率进行采样。当最小化或后台常驻间隔与该频率不同时，设置页会注明当前实际间隔，同时保留监控关闭后恢复使用的间隔选项。
- **历史页**：全面重构为多轨道阶梯曲线图表，每条轨道均可叠加第二项读数。支持按名称或设备搜索读数，拖动调整轨道顺序与高度；轨道超出可视区域时可在图表内滚动查看。
- **浏览历史曲线**：滚轮围绕指针所在时刻缩放；缩放、单击曲线或拖选时段会暂停跟随最新读数。单击“回到最新”、右键单击图表或按 End 可恢复跟随。无记录时段以斜纹标示，最近 10 分钟按实际采样间隔显示。（[#79](https://github.com/Ray-lea/Argus/issues/79)、[#129](https://github.com/Ray-lea/Argus/issues/129)）
- **历史曲线与游标**：跟随最新读数时，阶梯曲线随时间持续推进，指针所在轨道的游标随曲线经过实时更新读数。切换时段或纵轴量程时曲线平滑过渡，叠加曲线淡入淡出；再次查看已打开过的较长时段时加载更快。
- **时间范围与事件**：下拉列表提供 5 分钟、3 小时、1 天、3 天与“自定义…”；在“自定义时间范围”对话框中可通过日历选定日期，或输入精确的起止时间。勾选“显示 30 天概览与事件”可查看按小时分布的热力图，并列出 CPU 高负载、内存紧张与记录空档等事件。
- **历史进程表**：支持搜索所选时刻或区间内的进程，按名称排序时分为应用、后台进程与 Windows 进程。展开同名分组可查看前四个实例及其余实例的合计；右键菜单支持在图表中叠加该程序的曲线，或复制名称与 PID。
- **历史曲线提示**：悬停在 CPU 等可按进程统计的轨道上时，提示框列出占用最高的五个进程；进程数轨道列出实例最多的五个程序及其余程序合计。温度、电池电量等读数仅显示设备数据。
- **历史记录内容**：新增 CPU 频率、功耗与温度、内存细分、电池读数，以及每块磁盘、显卡与每个网络适配器的独立读数。在“设置 → 数据与历史”中可按类别勾选记录项，选择每帧记录约 20 个、约 40 个或全部活跃进程，并实时查看预计每日占用空间。
- **历史存储**：支持分别设置时间与空间保留上限，先达到者生效；默认保留 30 天、上限 2 GB，超过 7 天的记录自动按分钟合并，保留平均值、峰值与占用最高的进程。更改保存位置时可选择是否一并迁移现有历史与观察记录；若目标文件夹已有其他文件，则自动存入其中的“Argus History”子文件夹。
- **进程观察**：在进程右键菜单或详细信息面板中选择“观察进程”，即可按运行实例持续记录同一路径程序的 14 项读数（涵盖内存、CPU、GPU、磁盘、I/O、网络、线程与句柄）；无法读取路径时仅观察当前实例。开始后自动进入“历史”下的“进程观察”，可切换各次运行实例，并以多轨道图表对比读数。（[@hayxe1](https://github.com/hayxe1) [#82](https://github.com/Ray-lea/Argus/pull/82)）
- **观察记录**：最近 10 分钟按实际采样间隔显示，更早时段从磁盘读取。记录最多保留 7 天，达到容量上限时优先清理最早的数据；停止记录会保留已有数据，重启 Argus 后需重新开始观察。
- **进程分组**：“应用”“后台进程”“Windows 进程”与各用户分组以不同颜色区分。滚动列表时，当前分组标题固定在顶部，滚动条旁标出各组位置并显示当前组名。开启“隐藏系统进程”后，进程统计同时显示已隐藏的进程数。（[#88](https://github.com/Ray-lea/Argus/issues/88)）
- **进程电源使用情况**：新增“电源使用情况”与“电源使用情况趋势”两项可选列（默认隐藏），结合 CPU、GPU 与磁盘活动估算耗电水平。前者反映当前耗电等级，后者显示最近约两分钟的平均等级。（[#134](https://github.com/Ray-lea/Argus/issues/134)）
- **进程优先级**：右键菜单新增设置 I/O 优先级与内存优先级，详细信息面板及可选列同步显示。“基本优先级”改用类别名称展示，特殊值保留数字，排序仍按数值进行。（[@digital-bombyx](https://github.com/digital-bombyx) [#80](https://github.com/Ray-lea/Argus/pull/80) [#116](https://github.com/Ray-lea/Argus/pull/116)）
- **悬停暂停排序**：指针悬停在进程列表上暂停排序时，排序列的表头显示暂停图标，状态栏同步提示“排序已暂停”。“设置 → 语言与外观”新增“指针悬停时暂停排序”开关，默认开启。（[#86](https://github.com/Ray-lea/Argus/issues/86)）
- **资源泄漏提示**：进程页自动检测句柄泄漏、子进程累积与残留进程，单击表头的琥珀色标记即可快速定位。详细信息面板列出判断依据、数量走势与处理建议，进程退出后标记随下次采样更新。支持按程序忽略提示，并可在“设置 → 语言与外观 → 资源泄漏提示”中恢复已忽略的程序或关闭该功能。
- **复制表格内容**：进程、服务、启动与连接页均支持通过右键菜单复制当前单元格内容、名称或详细信息。在进程页按 Ctrl+C 可复制名称，按 Ctrl+Shift+C 可复制详细信息；已选中文本时，Ctrl+C 优先复制所选文字。（[@digital-bombyx](https://github.com/digital-bombyx) [#161](https://github.com/Ray-lea/Argus/pull/161)、[#91](https://github.com/Ray-lea/Argus/issues/91)、[#150](https://github.com/Ray-lea/Argus/issues/150)）
- **导出 CSV**：在进程、服务、启动或连接页的“更多操作”菜单中选择“导出当前页为 CSV…”，即可导出完整列表（包含滚动区域外的行），并保留当前的列顺序、筛选、排序、显示单位与分组展开状态。（[#139](https://github.com/Ray-lea/Argus/issues/139)）
- **详细信息面板**：“资源”小节新增工作集峰值、虚拟地址空间、I/O 速率与电源使用情况；新增“累计”小节，展示用户态与内核态 CPU 时间、各类 I/O 字节数和缺页次数。右上角的复制按钮可按小节复制全部有读数的项目。
- **连接页**：支持按应用折叠分组显示连接，搜索时自动展开匹配的分组。服务页与连接页的状态筛选移至“状态”列的表头；连接页还新增按 TCP、TCPv6、UDP 或 UDPv6 筛选，可与状态筛选组合使用。（[@digital-bombyx](https://github.com/digital-bombyx) [#152](https://github.com/Ray-lea/Argus/pull/152)）
- **删除服务与启动项**：右键菜单新增“删除”操作，经确认后即可删除服务或启动项。正在使用的服务会在停止且释放后由 Windows 移除；启动文件夹中的条目将移至回收站，应用包启动任务仍仅支持禁用。（[#114](https://github.com/Ray-lea/Argus/issues/114)、[#146](https://github.com/Ray-lea/Argus/issues/146)）
- **应用包服务**：当 Windows 拒绝修改应用包服务的启动类型时，经确认可直接写入注册表，并在列表中标出需重启后生效的启动类型。操作失败时，提示会写明服务名称以及权限或系统保护限制。（[@digital-bombyx](https://github.com/digital-bombyx) [#112](https://github.com/Ray-lea/Argus/pull/112)、[#168](https://github.com/Ray-lea/Argus/issues/168)）
- **内存读数**：性能页的内存组成条以斜纹标出使用中的已压缩内存，悬停可查看估计存储的数据量与节省的内存。进程页的内存提示也分别说明整机占用、进程专用工作集与分组总量的统计范围。（[@digital-bombyx](https://github.com/digital-bombyx) [#81](https://github.com/Ray-lea/Argus/pull/81)、[#122](https://github.com/Ray-lea/Argus/issues/122)）
- **NPU**：性能页为 Windows 识别到的每块 NPU 单独显示名称、利用率与最近 60 秒的实时曲线，并将已识别的 NPU 从 GPU 列表中移出。（[@SpookySandwich](https://github.com/SpookySandwich) [#140](https://github.com/Ray-lea/Argus/pull/140)、[#135](https://github.com/Ray-lea/Argus/issues/135)、[#148](https://github.com/Ray-lea/Argus/issues/148)）
- **CPU 图表与磁盘详情**：CPU 的整体／多核视图切换与核心类型筛选移入曲线图右键菜单；多核视图的小图保持可读比例，空间不足时依次省略频率与标题。磁盘详情的 SMART 原始值默认以十进制显示，切换为十六进制后对全部磁盘生效并在重启后保留。
- **硬件加速**：“设置 → 动画”新增“硬件加速”开关，默认开启。关闭后改由 CPU 绘制界面、不再占用 GPU，切换立即生效。（[#127](https://github.com/Ray-lea/Argus/issues/127)）
- **触屏操作**：支持 Windows 触屏点按、双击、滑动滚动、长按打开菜单与拖动滚动条。远程转发的触控轻点也可正常激活主窗口内的控件，文本框获得焦点时按需呼出触摸键盘。（[#73](https://github.com/Ray-lea/Argus/issues/73)）
- **关于页**：新增“复制诊断信息”按钮，可一键复制版本、运行状态、硬件与显示设置，便于附入问题报告。官网与 GitHub 卡片下方新增快捷入口，直达下载、使用指南、更新日志、问题反馈、讨论区与发行版页面。
- **管理员程序存放位置**：特权服务、任务管理器替换与管理员运行相关程序集中存放于 `Program Files\Argus Privileged` 并采用固定文件名，安全软件按路径添加的信任在版本更新后继续有效。若安装路径位于 Program Files 之外，安装程序会通过信息图标说明上述文件的存放位置。（[@digital-bombyx](https://github.com/digital-bombyx) [#154](https://github.com/Ray-lea/Argus/pull/154)、[#136](https://github.com/Ray-lea/Argus/issues/136)、[#159](https://github.com/Ray-lea/Argus/issues/159)）

### 性能

- **界面绘制**：刷新、悬停与单击仅重绘变化区域，指针移过列表或播放图标动画时的 GPU 开销明显降低。发布构建对照中，滚动进程列表的每帧 CPU 开销减少约四成；关闭硬件加速时，列表滚动与页面切换也会复用已绘制内容。
- **首份读数**：缩短启动后的首次采集等待时间，界面更早显示初始读数。（[@hayxe1](https://github.com/hayxe1) [#119](https://github.com/Ray-lea/Argus/pull/119)）

### 修复

- **磁盘详情导致蓝屏**：查询温度与 NVMe 健康信息前先检查控制器驱动，避免部分 Intel RST VMD 系统打开磁盘详情时触发蓝屏，被跳过的项目显示为“未知”。若读取期间或随后两分钟内异常退出，下次启动将暂停自动读取，仍可手动选择“仍要读取”。（[#48](https://github.com/Ray-lea/Argus/issues/48)、[#133](https://github.com/Ray-lea/Argus/issues/133)、[#160](https://github.com/Ray-lea/Argus/issues/160)）
- **设备休眠**：在混合显卡笔记本上跳过已断电独立显卡的传感器查询，避免反复唤醒，性能页同步显示“已休眠”及原因。机械硬盘空闲时保留上次温度读数，停转后跳过温度查询，不再妨碍硬盘休眠。（[#147](https://github.com/Ray-lea/Argus/issues/147)）
- **CPU 读数**：CPU 占用改按空闲周期计算，修正将空闲循环计入负载导致的读数偏高。修复 Windows 10 上混合架构处理器频率缺失，以及部分 Intel 处理器无法区分性能核与能效核的问题。（[#137](https://github.com/Ray-lea/Argus/issues/137)）
- **GPU 读数**：集成显卡上的进程不再将共享 GPU 内存计入专用 GPU 内存。无硬件 GPU 时，软件渲染不再计作进程 GPU 占用，进程页同步隐藏 GPU 列。若启动时已检测到硬件 GPU，更新驱动或接入新显卡后无需重启即可恢复或显示新读数。
- **磁盘读数**：修复 USB 外置硬盘无法读取 SMART 信息及健康状态显示为“未知”，以及 Google Drive 等虚拟驱动器盘符被错误列在磁盘 0 下的问题。
- **文件占用**：修复系统句柄总数过多时查询文件占用失败的问题。特权服务与本地查询因同一原因失败时仅提示一次；已安装特权服务时不再重复建议启用。
- **结束进程保护**：无法确认目标是否为系统关键进程时，拒绝执行结束操作，覆盖单个进程、批量操作与进程树。（[@hayxe1](https://github.com/hayxe1) [#77](https://github.com/Ray-lea/Argus/pull/77)）
- **进程页**：搜索或展开、折叠分组时保持列宽稳定；悬停暂停排序期间展开子进程也维持原有行序。修复用户分组行无法弹出右键菜单、双击展开已选行时详细信息面板意外收起，以及部分程序名称与版本信息混入多余字符的问题。

- **安装与加载安全**：安装程序会检查并保护符合条件的安装目录（仅允许管理员与系统写入）；交互式新安装若无法保护所选位置，会说明原因并提供继续安装或更改位置选项。程序仅从系统目录加载所导入的系统 DLL，忽略运行目录中的同名文件。（[#136](https://github.com/Ray-lea/Argus/issues/136)）

本版本新增每个进程的磁盘读写速率，可分别设置最小化和隐藏到托盘时的刷新间隔，改进了应用内更新与快捷键设置，并修复了部分电脑上运行一段时间后崩溃等问题。已安装特权服务时，请先阅读“破坏性变更”。

### 破坏性变更

- **特权服务需要更新**：本版本更改了 Argus 与特权服务之间的通信方式，0.1.0 的特权服务无法与新版配合使用。未安装特权服务时不受影响。
- **通过安装程序升级时**：应用内更新和直接运行安装程序都属于这种方式。安装程序会先关闭由任务管理器替换启动、仍在运行的旧版 Argus，并在同一次管理员授权中一并更新特权服务，无需另行操作。开启了“替换系统任务管理器”时，替换保持开启，更新成功后按 Ctrl+Shift+Esc 打开的即是新版。
- **免安装版升级须知**：已安装特权服务时，替换主程序后还需手动更新服务。在新版 Argus 的提示框或“设置 → 权限”中单击“更新服务”并授权即可。安装程序更新服务失败时，也按此方式处理。服务更新前，依赖服务的网络、磁盘读写和 CPU 传感器数据暂不可用，需提权的管理操作可能失败。已开启“替换系统任务管理器”时，Ctrl+Shift+Esc 仍可能打开旧版；更新服务会一并更新替换程序，并保持替换开启。

### 新功能

- **每个进程的磁盘读写**：进程页新增“磁盘读取”和“磁盘写入”两列，显示每个进程每秒读写磁盘的数据量，可以排序；按应用分组时显示组内合计，详细信息面板中也能看到。I/O 列还包含网络和设备的读写，与这两列分开统计。Windows 11 24H2 及以上无需额外权限；更早的系统需要启用特权服务或以管理员身份运行，特权服务的授权说明中已加入这一项。暂时没有读数时显示“—”，指针悬停可看到原因。窗口较窄时这两列始终保留，表格可左右滚动，名称列固定在左侧；为此，线程、句柄、PID 和 I/O 列会比以前更早隐藏。
- **应用内更新**：从本版本开始，新版本下载完成并通过签名校验后，标题栏右侧出现更新按钮，托盘图标上显示圆点，右下角也会提示一次，每个版本只提示一次。免安装版不自动下载，发现新版本时即提示。更新对话框按类别列出从当前版本到新版本之间各版本的更新内容，并注明每个版本的更改条数；更新内容与安装包一样经过签名校验。右键单击更新按钮可选择“此版本不再提醒”。已下载的更新在重启 Argus 后无需重新下载。
- **更新后显示更新内容**：更新完成后第一次打开窗口时，显示新版本的更新内容。如不需要，可在“设置 → 更新”中关闭“更新后显示更新内容”，之后只在右下角提示已更新。同一页的“查看本版本更新”可随时打开。
- **后台刷新间隔**：最小化时和隐藏到托盘时的刷新间隔可分别设置，可选 0.5 到 30 秒，默认 5 秒，在“设置 → 数据与历史”和首次启动引导中修改。设为短于 5 秒时，会先说明 CPU 占用和耗电将会增加；长于 5 秒时，历史记录也随之变稀。窗口回到前台时立即刷新；后台间隔比前台的刷新频率长时，右下角会提示一次，可直接转到设置调整，也可选择不再提醒。
- **快捷键设置**：可以只停用快捷键而保留组合，重新开启即恢复。录制时实时显示正按住的键，无法使用的组合会说明原因，也可单击“恢复默认”。Ctrl+字母、Alt+字母等容易与其他程序冲突的组合，确认后才会保存。组合被其他程序占用时可直接重试；占用它的程序退出后，再次显示窗口时也会自动重试。
- **CPU 正常运行时间**：精确到秒，例如“5天 14:03:07”，随每次刷新更新。

### 修复

- **崩溃**：部分没有可用 Intel 显卡的电脑上，Argus 运行一段时间后可能崩溃，现已修复。
- **设置丢失**：保存设置后不久遇到断电或强制重启，设置可能丢失，表现为首次启动引导再次出现、语言变回跟随系统，现已修复。
- **开机自启**：开机自启时不再抢走前台窗口。此前在单击其他位置之前，键盘输入都会进入看不见的 Argus 窗口。隐藏在托盘期间，界面不再在后台持续绘制，界面的 CPU 和 GPU 占用大幅降低，内存占用减少一半以上。
- **开机自启项**：在按 Ctrl+Shift+Esc 打开的 Argus 中开启“登录 Windows 时启动”，启动项会指向已安装的 Argus。已经指向任务管理器替换副本的启动项，在从开始菜单等处打开一次新版 Argus 后会自动改正。
- **后台刷新**：最小化或隐藏到托盘时，实际刷新间隔与设定一致。此前应每 5 秒刷新一次，实际常为 6 秒，有时达到 10 秒。以标准权限运行并使用特权服务时，从托盘或最小化恢复窗口后，进程页的网络列不再偶尔短暂消失。
- **窗口**：最大化时，右上角不再出现两组重叠的按钮；指针贴着屏幕顶边也能拖动窗口。
- **安装与卸载程序**：完成页的“关闭”、卸载确认页的“取消”以及复选框所在的一行居中显示，此前略偏左。
- **安装升级**：直接运行安装程序升级时，一并关闭由 Ctrl+Shift+Esc 或旧开机自启项打开、仍在运行的旧版 Argus，避免升级后的启动继续转交给旧版本，无需提前从托盘退出。
- **卸载**：卸载时一并关闭由 Ctrl+Shift+Esc 打开、仍在运行的 Argus。此前它会留在后台，勾选“同时删除设置、历史记录与日志”后重新安装，首次启动不显示引导，旧设置还会被写回。设置等数据未能全部删除时，卸载程序会列出剩下的文件夹。
- **首次启动引导**：按住 Ctrl+Shift+Esc 打开 Argus 时，按住的 Esc 不再直接关闭引导并记为已完成。
- **快捷键录制**：录制时按下当前的组合或按住按键稍久，不再意外隐藏窗口。使用非美式键盘布局时，录到的键与实际触发的键一致。按 Shift+Backspace 或 Win+Backspace 不再误清除快捷键。
- **快捷键的组合**：新设置的组合必须包含 Ctrl、Alt 或 Win，F13–F24 等少数按键除外；不再接受 Shift+字母这类会影响打字的组合，也不接受 Ctrl+C、Alt+F4 等常用的编辑和系统操作。已保存的组合不受影响。
- **快捷键**：部分小键盘按键不再被注册成别的键。更改快捷键时如果保存设置失败，不再多出一个无法取消的快捷键。注册失败的原因按界面语言显示。首次启动引导中，快捷键被占用或无法使用时，只显示原因并说明可在设置中更改。
- **替换系统任务管理器**：更新特权服务时替换保持开启，替换所用的 Argus 随之更新到新版本，不再先恢复 Windows 任务管理器、更新后再手动开启。开启失败时，会指出哪一步被拒绝以及可能的原因，例如安全软件拦截了注册表修改。状态显示“已有其他配置”时，会列出具体是哪些配置。关闭替换后，即使 Process Explorer 等其他工具接管了任务管理器，也不再妨碍更新或卸载特权服务。开启失败不再在服务目录中留下多余的 Argus 副本；以前留下的副本，会在升级、开启或关闭替换、更新或卸载特权服务时清理，正在运行的除外。
- **进程**：未选中任何项时单击“显示详细信息”，会提示先在列表中选择一项，此前单击没有反应。右键菜单或确认框打开时，状态栏不再显示“指针位于列表上，暂停重新排序”，列表也不会在确认框弹出的同时重新排序。指针停在列表上时用快捷键切换页面，这条提示不再留在其他页面的状态栏上。
- **曲线图**：指针停在曲线图右侧边缘附近时，读数圆点不再卡顿。
- **切换更新通道**：检查或下载更新的过程中切换稳定版或测试版，会按新的通道重新检查，不再给出原通道的版本。
- **诊断日志**：失败记录改为写明系统错误码，不再笼统地记为 operation failed，此前在非英文系统上几乎都是这样。启动时会记下特权服务无法连接的原因，例如版本不兼容或响应超时。

### 性能

- **进程页**：降低了系统概况中各逻辑处理器使用率小条的绘制开销。曲线流动时，界面每帧提交给显卡的数据减少约三分之一；I/O 列中 WebView2 的读写量主要来自这部分数据，因此也随之下降。

### 已知限制

- **磁盘读写**：Windows 11 24H2 及以上的读取方式只在内部版本 26300 上验证过；更早的系统改由特权服务或管理员权限读取，尚未在这些系统上验证。如果两列始终显示“—”，可附上诊断日志反馈，读取失败的原因会记在日志中。
- **代码签名**：程序尚未进行代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”。
- **其他**：其余限制见 GitHub 上的[已知问题](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)文档。

## 0.1.0 - 2026-10-16

Argus 的首个公开版本。

### 功能

- **进程**：按应用、进程树或列表查看，按名称排序时分为“应用”和“后台进程”两段；显示每个进程的 CPU、内存、I/O 与 GPU 占用，启用特权服务或以管理员身份运行时另含网络流量；支持搜索、结束进程或整个进程树，详细信息面板显示命令行、用户、完整性级别等，按应用分组时显示整个应用的合计。
- **优先级与效率模式**：通过右键菜单设置，也可建立规则，在程序每次启动时自动应用。
- **性能**：CPU（每核心、性能核与能效核、频率、温度、功耗、空闲状态）、内存、磁盘、网络、GPU（NVIDIA、AMD 与 Intel 显卡另有功耗瓦数）与电池；曲线随屏幕刷新率连续流动，随窗口大小伸缩，不常用的信息收在可展开的卡片中。
- **内核传感器（可选）**：在设置或首次启动引导中启用后，经特权服务与官方 PawnIO 驱动读取 CPU 内部传感器，包括每核温度与电压、功耗与限制状态、AMD SMU 数据，以及支持的主板的风扇转速、电压与温度。
- **服务与启动项**：启动、停止服务及修改启动类型；启用或禁用启动项，与系统任务管理器使用同一开关。
- **连接与端口**：TCP 与 UDP 端点及其所属进程，支持按端口精确搜索和断开 IPv4 TCP 连接。
- **文件占用**：将文件或文件夹拖放到窗口，结合 Restart Manager 与句柄枚举查找占用进程，包括进程的当前目录。
- **历史回溯**：记录最近 7 天的资源占用，单击任意时刻即可查看当时占用最高的进程。
- **常驻托盘**：通过全局快捷键 Ctrl+Alt+Esc 显示或隐藏窗口，隐藏时资源占用极低。
- **可选特权服务**：经一次管理员授权后，以标准权限运行的界面同样可以管理系统进程、自动应用规则、统计每进程网络流量、控制服务及断开连接。
- **系统任务管理器替换**：可让 Ctrl+Shift+Esc 等入口打开 Argus，并附带不依赖界面与服务的独立恢复程序。
- **应用内更新**：提供稳定版与测试版两个通道，可选 GitHub 加速代理；仅安装通过签名校验的版本。
- **外观**：工具栏兼作标题栏，导航栏位于工具栏下方或窗口左侧；Mica 背景与系统强调色，浅色、深色主题默认跟随 Windows，也可在设置中指定。
- **安装与卸载**：单页安装界面，跟随 Windows 的浅色或深色模式；已安装旧版本时原地升级，卸载时可选同时删除设置、历史记录与日志。
- **多语言与首次启动引导**：界面、托盘与安装程序支持简体中文和英文，默认跟随 Windows 显示语言；首次启动时引导完成语言、显示与刷新、托盘常驻、更新等常用设置，并可直接安装可选的特权服务、启用内核传感器或替换系统任务管理器。

### 已知限制

- 程序尚未进行代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”。
- CPU 内部传感器需要启用内核传感器（特权服务与 PawnIO 驱动）；支持的处理器与主板见[硬件数据](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)。
- 其他限制见[已知问题](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)。

## [0.5.0](https://github.com/Ray-lea/Argus/compare/v0.4.0...v0.5.0) - 2026-11-12

v0.5.0 新增进程暂停与恢复、按用户分组进程、四个进程信息列与按内容计算的列宽，性能页设备列表支持隐藏与排序，界面新增繁体中文、西班牙文、德文、日文、法文和俄文。本版还避免部分 Intel RST 系统在 Argus 启动后冻结，修复 USB 磁盘无法安全弹出等问题，并降低窗口隐藏后的内存与 CPU 占用。

### 新功能

- **暂停与恢复进程**：进程与应用组的右键菜单新增“暂停进程”和“恢复进程”。暂停前显示影响说明并请求确认；系统关键进程与 Argus 自身不可暂停。已暂停的进程在名称后显示“已暂停”标记。（[@digital-bombyx](https://github.com/digital-bombyx) [#65](https://github.com/Ray-lea/Argus/pull/65)）
- **进程信息列**：新增“文件版本”“架构”“已提升”和“命令行”四个可选列，默认隐藏，可在表头右键菜单或“选择列”中启用。（[@digital-bombyx](https://github.com/digital-bombyx) [#72](https://github.com/Ray-lea/Argus/pull/72)）
- **进程列宽**：自动列宽按内容计算，剩余空间留在表格右侧。拖动列边界可单独调整一列的宽度，双击列边界恢复自动宽度。表头菜单新增“全宽”，开启后名称列占用剩余宽度。
- **按用户分组进程**：“设置 → 语言与外观 → 按用户分组进程”提供自动、始终分组和不分组三种方式；自动方式仅在多个用户登录时分组。分组行的右键菜单提供“管理用户账户”和“注销”。
- **隐藏系统进程**：进程页与连接页新增“隐藏系统进程”开关，默认关闭，两页分别保存开关状态。始终显示与额外隐藏的程序名单可在设置页编辑。（[#32](https://github.com/Ray-lea/Argus/issues/32)）
- **进程树与概况带**：进程树默认折叠，表头右键菜单提供“展开所有”和“折叠所有”。“进程概况带”可设为自动、始终显示或隐藏；自动模式在窗口高度不足时收起概况带。
- **性能页设备列表**：右键单击设备可将其隐藏，也可在“显示的设备”子菜单中逐项选择。拖动设备可调整顺序；磁盘可按磁盘编号、盘符或自定义顺序排列。
- **CPU 多核视图**：各逻辑处理器的小图显示内核时间，可在 CPU 图表的右键菜单中关闭。识别 Intel 低功耗能效核（LP E 核），以独立颜色显示并支持单独筛选。小图优先排成没有空位的行列。
- **硬件信息**：GPU 页显示驱动版本、驱动日期与 DirectX 版本（含功能级别）。磁盘详情支持更多 SATA SSD 的剩余寿命与累计读写量，并新增机械硬盘的通电时间、启停次数、重映射与待映射扇区等统计。
- **界面语言**：新增繁体中文、西班牙文、德文、日文、法文和俄文。界面、托盘、系统提示与安装程序均提供译文，数字与日期采用 Windows 区域格式。（[@abc0922001](https://github.com/abc0922001) [#45](https://github.com/Ray-lea/Argus/pull/45)、[@Rimuwu](https://github.com/Rimuwu) [#51](https://github.com/Ray-lea/Argus/pull/51)、[@s0ftw4r8](https://github.com/s0ftw4r8) [#52](https://github.com/Ray-lea/Argus/pull/52)、[@khativari](https://github.com/khativari) [#55](https://github.com/Ray-lea/Argus/pull/55)、[@hayxe1](https://github.com/hayxe1) [#62](https://github.com/Ray-lea/Argus/pull/62)）
- **更新内容**：关于页与更新对话框按界面语言显示更新内容。“设置 → 更新”改为通过“查看更新内容”按钮打开更新对话框，对话框提供“展开所有”和“折叠所有”。打开、展开与悬停时的过渡遵循“界面动画”设置。
- **图标与动效**：界面图标改用 Lucide 图标库。指针移到按钮或导航项上时，图标播放一次短动效；关闭“界面动画”后不播放。
- **窗口与托盘**：新增独立的“窗口过渡动画”开关。“从托盘打开”可设为打开默认页面。默认窗口尺寸调整为 1000×680，最小尺寸降至 640×480。（[#27](https://github.com/Ray-lea/Argus/issues/27)、[#40](https://github.com/Ray-lea/Argus/issues/40)）
- **任务管理器替换**：“替换系统任务管理器”新增“临时打开系统任务管理器”，可打开 Windows 自带的任务管理器，替换设置保持不变。
- **提示与提醒**：免安装版在首次启动引导和窗口右下角说明与安装版的差异，并提供安装版的下载入口。新增“Star 提醒”，每天至多显示一次，可在“设置 → 更新”中关闭。“本机配置”上方的操作提示可收起。

### 性能

- **后台内存占用**：新增“隐藏时释放内存”设置。窗口最小化或隐藏到托盘达到设定时长（默认 10 分钟）后，Argus 释放图表图像，并将未使用的内存归还 Windows。全部窗口隐藏或最小化时减少界面相关的 CPU 开销，采样、历史记录与规则照常运行。（[@SpookySandwich](https://github.com/SpookySandwich) [#54](https://github.com/Ray-lea/Argus/pull/54)）

### 修复

- **系统冻结**：不再向 RAID 控制器（如 Intel RST）之后的磁盘查询温度，避免部分驱动版本无响应导致系统在 Argus 启动数秒后冻结。此类磁盘的温度显示为未知。（[#48](https://github.com/Ray-lea/Argus/issues/48)）
- **USB 磁盘安全弹出**：修复磁盘监控持续占用设备，导致 USB 磁盘无法安全弹出的问题。（[#57](https://github.com/Ray-lea/Argus/issues/57)）
- **磁盘列表与性能数据**：修复部分 NVMe 磁盘仅显示设备信息而没有性能数据，以及性能计数不可用时磁盘从列表消失的问题。
- **磁盘详情**：修复 SMART 属性表数值远离属性名、分组留出大片空白，以及窄窗口下原始值被裁切的问题。健康条正常状态统一使用绿色，温度与备用空间按阈值区分告警颜色。
- **进程数据**：系统查询缓慢时，进程名单仍会更新，资源读数保留最近一次有效值。修复已退出的进程持续留在列表，以及暂停刷新期间操作进程后状态不更新的问题。（[#66](https://github.com/Ray-lea/Argus/issues/66)）
- **进程表格**：效率模式与固定标记紧随名称显示，表头与数据列边界保持对齐。进程占用率补齐百分号。
- **连接页**：没有所属进程的连接现在显示为“无所属进程”。
- **CPU 读数**：修复混合架构处理器的速度显示异常、部分六核锐龙处理器的每核电压与温度读数错误，以及 Intel 内部传感器读数间断导致温度曲线中断的问题。（[#58](https://github.com/Ray-lea/Argus/issues/58)）
- **授权与卸载**：修复 Program Files 或运行目录的权限改变后无法撤销授权与卸载、已运行的 PawnIO 驱动无法用于内核传感器，以及卸载后残留 Argus Sensor Setup 文件夹与空的 Argus Runtime 文件夹的问题。（[#46](https://github.com/Ray-lea/Argus/issues/46)）
- **启动权限**：安装完成或应用内更新后，Argus 优先使用桌面账户的权限启动，与从快捷方式启动一致。以管理员身份运行的 Argus 可重启已经以管理员权限运行的资源管理器，并保留其原有权限。
- **窗口显示**：修复恢复窗口尺寸后界面仅显示在左上角、从任务管理器替换入口冷启动后最大化窗口显示不全、Windows 11 21H2 下窗口背景透明，以及切换应用后窗口仍遮挡其他窗口的问题。（[#44](https://github.com/Ray-lea/Argus/issues/44)、[#37](https://github.com/Ray-lea/Argus/issues/37)、[#35](https://github.com/Ray-lea/Argus/issues/35)）
- **托盘**：修复关闭窗口隐藏到托盘后 CPU 占用持续偏高，以及应用内更新后托盘图标移入溢出区的问题。（[#31](https://github.com/Ray-lea/Argus/issues/31)）
- **界面显示**：修复更新对话框加载时偏离居中、文件占用对话框在结果出现后抖动，以及关于页在较矮窗口中无法滚动到全部内容的问题。文本框右键菜单按界面语言显示。（[#39](https://github.com/Ray-lea/Argus/issues/39)）
- **数字与绘制**：修复动态数字刷新时横向跳动、深色主题下浅色文字的边缘显示异常，以及概况带底部出现细小彩色残影的问题。
- **运行稳定性**：修复显示时序异常或网卡地址枚举连续失败时程序退出，以及图形设备恢复与关闭窗口同时发生时界面卡死的问题。
- **大字号、进程规则与启动项**：修复大字号下性能页读数与规格信息重叠、程序名含非 ASCII 字母时从进程菜单重复添加规则，以及读取应用包启动任务时程序崩溃的问题。（[@hayxe1](https://github.com/hayxe1) [#59](https://github.com/Ray-lea/Argus/pull/59)）
- **版本类型**：设置页、关于页与状态栏按当前程序的实际构建显示“开发版”、“测试版”、“稳定版”，更新通道单独控制后续检查的版本来源。

### 升级提示

- **特权服务**：本版将服务通信协议升级至第 11 版。安装版通过安装程序或应用内更新升级时，同步更新已安装的服务与任务管理器替换副本；免安装版替换程序后，需在“设置 → 权限 → 特权服务”中单击“更新服务”并完成管理员确认。
- **设置与历史**：升级保留已有设置与历史记录。“窗口过渡动画”首次启动时沿用原“界面动画”对窗口过渡的设置。

## [0.4.0](https://github.com/Ray-lea/Argus/compare/v0.3.4...v0.4.0) - 2026-11-06

v0.4.0 将应用界面从 Tauri、SolidJS 与 WebView2 全面迁移至 Rust + GPUI Kit 原生技术栈，脱离浏览器内核开销，重做 DirectX 原生渲染与交互，并深度优化高刷新率动画、实时曲线绘制、列表采样刷新及后台常驻的资源占用。本版还新增自定义进程列、磁盘健康与 SMART 详情、更多 Intel 核显读数与窗口布局选项。[Argus 官网](https://argustask.com)现已上线并接入官方更新镜像。

### 新功能

- **自定义进程列**：涵盖基本信息、CPU、内存、磁盘与 I/O、网络、GPU 六大类共 40 列，新增专用与共享 GPU 内存、GPU 引擎、映像名称、虚拟地址空间、工作集峰值、缺页计数及累计 I/O 等参数。虚拟地址空间与工作集峰值按单进程展示。表头右键菜单提供分类子菜单并支持连续勾选，“选择列”对话框支持分类筛选、搜索与双栏排序；拖动表头或已选列时实时换位并平滑让位；自动列宽按数值格式预留宽度以防跳动，也支持手动调整列宽。平铺列表与进程树视图的“名称”列与按应用视图一致，优先显示应用名称或文件描述，可执行文件名作为次级文字或通过“映像名称”列查看。
- **磁盘健康与详情**：磁盘性能页新增“概览／详情”切换，按需单次读取 NVMe、ATA／SATA、USB-SAT 和 SCSI／SAS 设备信息，展示健康状况、剩余寿命、温度与阈值、通电时间与次数、读写总量、介质与读写错误统计、PCIe 链路及 SMART 属性，支持手动重新读取；序列号优先采用协议身份中的厂商序列号并默认隐藏。
- **系统概况与性能图表**：重做进程页顶部概况带，曲线贴边铺满卡片并在左侧数字下方渐隐，顶部标出量程上限，悬停时整张卡片高亮；卡片新增 CPU 温度、CPU 功耗与 GPU 功耗。性能页的 CPU 概览将封装功耗与核心功耗合并为单一项“功耗”（优先显示封装功耗，悬停说明来源，详情页仍保留双曲线）；磁盘与网络图表按固定档位调整量程；侧栏设备预览等紧凑小图表的次要序列改用半透明实线，提升小尺寸下的辨识度。
- **Intel 核显读数**：扩展驱动提供的温度、频率、电压与功耗信息，并通过内核传感器（IntelMCHBAR 模块）与 RAPL PP1 补充第 10 代酷睿（Comet Lake S/H）核显的温度、频率、共享内存频率、核心 VID、GT／媒体活动率与功耗。区分图形切片停钟状态，支持显示低于 1 W 的亚瓦级功耗，并将核显功耗归入对应的 GPU 页；有效的 RAPL 功耗读数优先于 Windows 功耗计数器的零值，硬件与驱动未提供的项目保持未知。
- **窗口与界面布局**：可在“设置 → 启动与后台”中选择启动时默认打开的页面；展开后的侧边导航栏支持拖动右边缘调整宽度（双击恢复默认）；详细信息面板新增“选中进程时显示”模式，选中进程即滑出、取消选中后自动收起；历史页切换时间范围后始终显示截至当前的最新时段；窗口最小尺寸调整为 1240×800 以保持完整布局，主屏幕可用区域不足时自动收缩适配。
- **关于页、更新内容与官方镜像**：“关于”独立为导航页面（快捷键 Ctrl+8），新增 Argus 官网与 GitHub 仓库双链接卡片；状态栏左端显示版本徽标，单击可查看本版本更新内容，右键可复制版本号；更新内容按类别分组展示，新功能以双列卡片列出；自动更新在连接 GitHub 失败时优先尝试 Argus 官方镜像，再回退至加速代理，安装包与更新说明同样校验签名。

### 性能

- **界面响应与高刷动画**：减少采样更新、文字测量与重复绘制的主线程开销，复用图表静态背景与合成图层，多线程并行绘制大尺寸曲线纹理，关闭硬件加速 GPU 计划（HAGS）时的图表 GPU 占用大幅下降；页面切换、详细信息面板、列表滚动与列重排动画按显示器刷新率流畅播放，窗口调整大小时多核网格与 GPU 引擎图同帧即时伸缩。
- **页面切换与后台常驻**：启动后在后台预读服务、启动项与连接列表，首次进入页面直接显示；界面偏好改为后台异步合并写盘，消除切换页面时的停顿；停留在无实时图表的页面时跳过重复构建以降低 CPU 占用；窗口最小化或隐藏到托盘后停止绘制，并按需回收曲线图层缓存、过期图标与纹理图集，减少后台内存与显存开销。
- **繁忙与低内存环境**：托盘更新由独立线程合并处理，优化高负载或外壳阻塞下的操作与采样响应；内存紧张时自动缩小图表缓冲、降低纹理精度以保留实时曲线，余量恢复后还原完整精度；增强激活窗口时应对大面积置顶遮挡的能力。

### 修复

- **进程网络流量**：修复部分机器读数持续为零，以及 0.5 秒刷新间隔下读数交替归零或更新延迟的问题。
- **特权服务**：修复客户端在管道接入前异常断开导致服务退出，以及高频读取时超时或误报无数据的问题。
- **应用名称与图标**：修复应用包（MSIX）程序显示可执行文件描述而非系统任务管理器应用名称，以及设备路径映射缺失或进程拒绝打开时图标与文件说明缺失的问题。
- **进程显存**：改用驻留计数并按进程与物理适配器去重，修正部分系统或驱动下显存读数偏高、重复累计的问题，并区分缺失读数与零用量。
- **Intel 核显功耗显示**：修复 CPU 概览中闲置核显功耗反复出现与消失的问题。
- **CPU 虚拟化状态**：修复已开启硬件虚拟化的 Hyper-V 宿主仍显示“未启用”的问题。
- **管理员启动授权**：修复用户名与计算机名相同时 SID 解析失败导致的授权失败，并改进同版本重建副本的识别。
- **长时间运行的内存占用**：对程序图标按内容去重并定期清理已退出程序的元数据缓存，限制解析器繁忙时的请求积压，修复频繁启动新路径程序后内存持续累积的问题。
- **外部链接**：单击打开官网、仓库与发布页等外部网页时直接交由系统外壳处理，消除经由新建资源管理器进程中转的打开延迟。

### 升级提示

- **系统要求**：Windows 10 22H2（内部版本 19045）及以上，含 Windows 11，仅支持 x64；需要支持 DirectX 11 的图形设备与驱动。应用界面不再依赖 WebView2 运行时。
- **设置与历史**：应用设置与历史文件保留。从 v0.3.3／v0.3.4 升级可继承独立保存的界面偏好；从 v0.3.2 及更早版本直接升级时，仅保存在旧 WebView2 缓存中的界面偏好（如布局、行备注与置顶标记）恢复默认值，需要重新设置。新版会在后台自动清理 Argus 遗留的 WebView2 数据。

## [0.2.0](https://github.com/Ray-lea/Argus/compare/v0.1.0...v0.2.0) - 2026-10-18

本版本新增每个进程的磁盘读写速率，可分别设置最小化和隐藏到托盘时的刷新间隔，改进了应用内更新与快捷键设置，并修复了部分电脑上运行一段时间后崩溃等问题。已安装特权服务时，请先阅读“破坏性变更”。

### 破坏性变更

- **特权服务需要更新**：本版本更改了 Argus 与特权服务之间的通信方式，0.1.0 的特权服务无法与新版配合使用。未安装特权服务时不受影响。
- **通过安装程序升级时**：应用内更新和直接运行安装程序都属于这种方式。安装程序会先关闭由任务管理器替换启动、仍在运行的旧版 Argus，并在同一次管理员授权中一并更新特权服务，无需另行操作。开启了“替换系统任务管理器”时，替换保持开启，更新成功后按 Ctrl+Shift+Esc 打开的即是新版。

### 新功能

- **每个进程的磁盘读写**：进程页新增“磁盘读取”和“磁盘写入”两列，显示每个进程每秒读写磁盘的数据量，可以排序；按应用分组时显示组内合计，详细信息面板中也能看到。I/O 列还包含网络和设备的读写，与这两列分开统计。Windows 11 24H2 及以上无需额外权限；更早的系统需要启用特权服务或以管理员身份运行，特权服务的授权说明中已加入这一项。暂时没有读数时显示“—”，指针悬停可看到原因。窗口较窄时这两列始终保留，表格可左右滚动，名称列固定在左侧；为此，线程、句柄、PID 和 I/O 列会比以前更早隐藏。
- **应用内更新**：从本版本开始，新版本下载完成并通过签名校验后，标题栏右侧出现更新按钮，托盘图标上显示圆点，右下角也会提示一次，每个版本只提示一次。免安装版不自动下载，发现新版本时即提示。更新对话框按类别列出从当前版本到新版本之间各版本的更新内容，并注明每个版本的更改条数；更新内容与安装包一样经过签名校验。右键单击更新按钮可选择“此版本不再提醒”。已下载的更新在重启 Argus 后无需重新下载。
- **更新后显示更新内容**：更新完成后第一次打开窗口时，显示新版本的更新内容。如不需要，可在“设置 → 更新”中关闭“更新后显示更新内容”，之后只在右下角提示已更新。同一页的“查看本版本更新”可随时打开。
- **后台刷新间隔**：最小化时和隐藏到托盘时的刷新间隔可分别设置，可选 0.5 到 30 秒，默认 5 秒，在“设置 → 数据与历史”和首次启动引导中修改。设为短于 5 秒时，会先说明 CPU 占用和耗电将会增加；长于 5 秒时，历史记录也随之变稀。窗口回到前台时立即刷新；后台间隔比前台的刷新频率长时，右下角会提示一次，可直接转到设置调整，也可选择不再提醒。
- **快捷键设置**：可以只停用快捷键而保留组合，重新开启即恢复。录制时实时显示正按住的键，无法使用的组合会说明原因，也可单击“恢复默认”。Ctrl+字母、Alt+字母等容易与其他程序冲突的组合，确认后才会保存。组合被其他程序占用时可直接重试；占用它的程序退出后，再次显示窗口时也会自动重试。
- **CPU 正常运行时间**：精确到秒，例如“5天 14:03:07”，随每次刷新更新。

### 修复

- **崩溃**：部分没有可用 Intel 显卡的电脑上，Argus 运行一段时间后可能崩溃，现已修复。
- **设置丢失**：保存设置后不久遇到断电或强制重启，设置可能丢失，表现为首次启动引导再次出现、语言变回跟随系统，现已修复。
- **开机自启**：开机自启时不再抢走前台窗口。此前在单击其他位置之前，键盘输入都会进入看不见的 Argus 窗口。隐藏在托盘期间，界面不再在后台持续绘制，界面的 CPU 和 GPU 占用大幅降低，内存占用减少一半以上。
- **开机自启项**：在按 Ctrl+Shift+Esc 打开的 Argus 中开启“登录 Windows 时启动”，启动项会指向已安装的 Argus。已经指向任务管理器替换副本的启动项，在从开始菜单等处打开一次新版 Argus 后会自动改正。
- **后台刷新**：最小化或隐藏到托盘时，实际刷新间隔与设定一致。此前应每 5 秒刷新一次，实际常为 6 秒，有时达到 10 秒。以标准权限运行并使用特权服务时，从托盘或最小化恢复窗口后，进程页的网络列不再偶尔短暂消失。
- **窗口**：最大化时，右上角不再出现两组重叠的按钮；指针贴着屏幕顶边也能拖动窗口。
- **安装与卸载程序**：完成页的“关闭”、卸载确认页的“取消”以及复选框所在的一行居中显示，此前略偏左。
- **安装升级**：直接运行安装程序升级时，一并关闭由 Ctrl+Shift+Esc 或旧开机自启项打开、仍在运行的旧版 Argus，避免升级后的启动继续转交给旧版本，无需提前从托盘退出。
- **卸载**：卸载时一并关闭由 Ctrl+Shift+Esc 打开、仍在运行的 Argus。此前它会留在后台，勾选“同时删除设置、历史记录与日志”后重新安装，首次启动不显示引导，旧设置还会被写回。设置等数据未能全部删除时，卸载程序会列出剩下的文件夹。
- **首次启动引导**：按住 Ctrl+Shift+Esc 打开 Argus 时，按住的 Esc 不再直接关闭引导并记为已完成。
- **快捷键录制**：录制时按下当前的组合或按住按键稍久，不再意外隐藏窗口。使用非美式键盘布局时，录到的键与实际触发的键一致。按 Shift+Backspace 或 Win+Backspace 不再误清除快捷键。
- **快捷键的组合**：新设置的组合必须包含 Ctrl、Alt 或 Win，F13–F24 等少数按键除外；不再接受 Shift+字母这类会影响打字的组合，也不接受 Ctrl+C、Alt+F4 等常用的编辑和系统操作。已保存的组合不受影响。
- **快捷键**：部分小键盘按键不再被注册成别的键。更改快捷键时如果保存设置失败，不再多出一个无法取消的快捷键。注册失败的原因按界面语言显示。首次启动引导中，快捷键被占用或无法使用时，只显示原因并说明可在设置中更改。
- **替换系统任务管理器**：更新特权服务时替换保持开启，替换所用的 Argus 随之更新到新版本，不再先恢复 Windows 任务管理器、更新后再手动开启。开启失败时，会指出哪一步被拒绝以及可能的原因，例如安全软件拦截了注册表修改。状态显示“已有其他配置”时，会列出具体是哪些配置。关闭替换后，即使 Process Explorer 等其他工具接管了任务管理器，也不再妨碍更新或卸载特权服务。开启失败不再在服务目录中留下多余的 Argus 副本；以前留下的副本，会在升级、开启或关闭替换、更新或卸载特权服务时清理，正在运行的除外。
- **进程**：未选中任何项时单击“显示详细信息”，会提示先在列表中选择一项，此前单击没有反应。右键菜单或确认框打开时，状态栏不再显示“指针位于列表上，暂停重新排序”，列表也不会在确认框弹出的同时重新排序。指针停在列表上时用快捷键切换页面，这条提示不再留在其他页面的状态栏上。
- **曲线图**：指针停在曲线图右侧边缘附近时，读数圆点不再卡顿。
- **切换更新通道**：检查或下载更新的过程中切换稳定版或测试版，会按新的通道重新检查，不再给出原通道的版本。
- **诊断日志**：失败记录改为写明系统错误码，不再笼统地记为 operation failed，此前在非英文系统上几乎都是这样。启动时会记下特权服务无法连接的原因，例如版本不兼容或响应超时。

### 性能

- **进程页**：降低了系统概况中各逻辑处理器使用率小条的绘制开销。曲线流动时，界面每帧提交给显卡的数据减少约三分之一；I/O 列中 WebView2 的读写量主要来自这部分数据，因此也随之下降。

### 已知限制

- **磁盘读写**：Windows 11 24H2 及以上的读取方式只在内部版本 26300 上验证过；更早的系统改由特权服务或管理员权限读取，尚未在这些系统上验证。如果两列始终显示“—”，可附上诊断日志反馈，读取失败的原因会记在日志中。
- **代码签名**：程序尚未进行代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”。
- **其他**：其余限制见 GitHub 上的[已知问题](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)文档。

## 0.1.0 - 2026-10-16

Argus 的首个公开版本。

### 功能

- **进程**：按应用、进程树或列表查看，按名称排序时分为“应用”和“后台进程”两段；显示每个进程的 CPU、内存、I/O 与 GPU 占用，启用特权服务或以管理员身份运行时另含网络流量；支持搜索、结束进程或整个进程树，详细信息面板显示命令行、用户、完整性级别等，按应用分组时显示整个应用的合计。
- **优先级与效率模式**：通过右键菜单设置，也可建立规则，在程序每次启动时自动应用。
- **性能**：CPU（每核心、性能核与能效核、频率、温度、功耗、空闲状态）、内存、磁盘、网络、GPU（NVIDIA、AMD 与 Intel 显卡另有功耗瓦数）与电池；曲线随屏幕刷新率连续流动，随窗口大小伸缩，不常用的信息收在可展开的卡片中。
- **内核传感器（可选）**：在设置或首次启动引导中启用后，经特权服务与官方 PawnIO 驱动读取 CPU 内部传感器，包括每核温度与电压、功耗与限制状态、AMD SMU 数据，以及支持的主板的风扇转速、电压与温度。
- **服务与启动项**：启动、停止服务及修改启动类型；启用或禁用启动项，与系统任务管理器使用同一开关。
- **连接与端口**：TCP 与 UDP 端点及其所属进程，支持按端口精确搜索和断开 IPv4 TCP 连接。
- **文件占用**：将文件或文件夹拖放到窗口，结合 Restart Manager 与句柄枚举查找占用进程，包括进程的当前目录。
- **历史回溯**：记录最近 7 天的资源占用，单击任意时刻即可查看当时占用最高的进程。
- **常驻托盘**：通过全局快捷键 Ctrl+Alt+Esc 显示或隐藏窗口，隐藏时资源占用极低。
- **可选特权服务**：经一次管理员授权后，以标准权限运行的界面同样可以管理系统进程、自动应用规则、统计每进程网络流量、控制服务及断开连接。
- **系统任务管理器替换**：可让 Ctrl+Shift+Esc 等入口打开 Argus，并附带不依赖界面与服务的独立恢复程序。
- **应用内更新**：提供稳定版与测试版两个通道，可选 GitHub 加速代理；仅安装通过签名校验的版本。
- **外观**：工具栏兼作标题栏，导航栏位于工具栏下方或窗口左侧；Mica 背景与系统强调色，浅色、深色主题默认跟随 Windows，也可在设置中指定。
- **安装与卸载**：单页安装界面，跟随 Windows 的浅色或深色模式；已安装旧版本时原地升级，卸载时可选同时删除设置、历史记录与日志。
- **多语言与首次启动引导**：界面、托盘与安装程序支持简体中文和英文，默认跟随 Windows 显示语言；首次启动时引导完成语言、显示与刷新、托盘常驻、更新等常用设置，并可直接安装可选的特权服务、启用内核传感器或替换系统任务管理器。

- 程序尚未进行代码签名，首次运行时 Windows SmartScreen 可能提示“未知发布者”。
- CPU 内部传感器需要启用内核传感器（特权服务与 PawnIO 驱动）；支持的处理器与主板见[硬件数据](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)。

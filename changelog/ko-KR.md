# 업데이트 기록

[简体中文](zh-CN.md) · [繁體中文](zh-TW.md) · [English](en-US.md) · [Español](es-ES.md) · [Deutsch](de-DE.md) · [日本語](ja-JP.md) · **한국어** · [Français](fr-FR.md) · [Русский](ru-RU.md)

Argus의 버전별 사용자 변경 사항입니다. 버전 번호는 [유의적 버전](https://semver.org/lang/ko/)을 따릅니다. 이 문서는 [중국어 간체 업데이트 기록](zh-CN.md)을 항목별로 번역한 것입니다.

## [0.7.0](https://github.com/Ray-lea/Argus/compare/v0.6.0...v0.7.0) - 2026-11-27

v0.7.0부터 Windows ARM64용 설치 버전과 포터블 버전을 제공하며, 기본 프로그램, 특권 서비스, 작업 관리자 대체 모두 ARM64에서 네이티브로 실행됩니다. 프로세스 페이지에는 선택 가능한 열 27개와 ‘메모리 덤프 파일 만들기’, ‘디버그’ 작업이 추가되었습니다. 바이트 단위 설정이 새로 생겼고, 작업 표시줄 모니터는 세로 작업 표시줄을 지원하며, 새 버전이 있을 때 Windows 알림을 보낼 수 있습니다. 또한 화면이 멈춰 있을 때의 다시 그리기를 줄였으며, Ryzen 9000 센서, 작업 표시줄 모니터가 시작 단추를 가리는 문제, 특권 서비스 등록이 삭제된 뒤 다시 설치할 수 없는 문제 등을 해결했습니다.

이번 버전에서는 문서 사이트를 전면 재작성했습니다. 각 기능의 자세한 사용법은 [문서 사이트](https://argustask.com/docs/)(중국어)에서 확인할 수 있습니다.

### 호환성이 깨지는 변경

- **열 메뉴**: 프로세스 목록의 열 머리글 바로 가기 메뉴에서 더 이상 범주별로 열을 표시하거나 숨기지 않습니다. 메뉴에서 ‘열 선택…’을 클릭한 뒤 대화 상자에서 표시할 열을 선택하세요.

### 새 기능

- **Windows ARM64**: ARM64용 설치 버전과 포터블 버전을 제공합니다. 기본 프로그램, 특권 서비스, 관리자 권한 실행, 작업 관리자 대체가 모두 네이티브로 실행되며, 앱 내 업데이트도 ARM64 버전으로 진행됩니다. 성능 페이지에 ARM64 프로세서의 제조사, 모델, 명령어 집합, 가상화 상태를 표시하고 CPU 소비 전력은 Windows 에너지 미터에서 가져옵니다. 커널 센서는 아직 지원하지 않습니다. ([#172](https://github.com/Ray-lea/Argus/issues/172))
- **프로세스 열**: ‘열 선택’ 대화 상자에 실행 시간, 커널 및 사용자 CPU, 컨텍스트 전환, 공유 작업 집합, 페이지 풀과 비페이지 풀, 하드 폴트, 디스크와 I/O의 읽기·쓰기 횟수 및 누적값 등 선택 가능한 열 27개를 추가했습니다. 이 열들을 선택하지 않으면 수집 부하는 그대로 유지됩니다.
- **세부 정보 창**: 프로세스 목록의 모든 선택 가능한 열 측정값을 표시합니다. 리소스와 누적 사용량 섹션에 컨텍스트 전환, 하드 폴트, 초당 요청 수를 추가했으며, 작업 집합과 커밋 크기 등의 값 뒤에는 최댓값을 함께 표시합니다. ‘세부 정보 복사’에도 이 항목들이 포함됩니다.
- **메모리 덤프 및 디버그**: 개별 프로세스의 바로 가기 메뉴에 ‘메모리 덤프 파일 만들기’와 ‘디버그’를 추가했습니다. 덤프 파일은 임시 폴더에 저장되며, 완료되면 알림에 경로가 표시됩니다. 시스템에 실시간(JIT) 디버거가 등록되어 있으면 ‘디버그’가 해당 디버거를 시작해 프로세스에 연결합니다. ([#169](https://github.com/Ray-lea/Argus/issues/169), [#197](https://github.com/Ray-lea/Argus/issues/197))
- **바이트 단위**: ‘설정 → 데이터 및 기록’에 ‘바이트 단위’를 추가해 기존 표기(기본값), 이진 IEC, 십진 SI 중에서 고를 수 있습니다. 메모리, 저장소 용량, 전송 속도, 그래프 눈금, 각 모니터의 측정값에 함께 적용됩니다. ([#156](https://github.com/Ray-lea/Argus/issues/156))
- **세로 작업 표시줄**: 작업 표시줄이 화면 왼쪽이나 오른쪽에 있을 때 작업 표시줄 모니터가 작업 표시줄을 따라 측정값을 세로로 배치합니다. 네 가지 스타일 모두 세로 레이아웃을 지원하며 공간에 들어가는 항목만 표시합니다. ([#177](https://github.com/Ray-lea/Argus/issues/177))
- **새 버전 알림**: 창이 시스템 트레이에 숨겨져 있거나 맨 앞에 있지 않을 때, 설치 버전은 새 버전 다운로드와 검증이 끝난 후, 포터블 버전은 새 버전을 찾았을 때 Windows 알림을 보냅니다. 알림을 클릭하면 업데이트 대화 상자가 열립니다. ‘설정 → 업데이트’에서 ‘새 버전이 있을 때 알림 보내기’를 끄면 창이 표시될 때 오른쪽 아래에 알립니다.
- **페이지 전환**: Ctrl+Tab과 Ctrl+Shift+Tab으로 다음 또는 이전 페이지로 전환하며, 끝에 도달하면 반대쪽 끝으로 이어집니다. ([#185](https://github.com/Ray-lea/Argus/issues/185))
- **상단 탐색**: 페이지 표시줄 공간이 부족하면 상단 탐색 탭이 먼저 아이콘으로 줄어들고, 포인터를 올리면 페이지 이름과 바로 가기 키를 표시합니다. 그래도 공간이 부족할 때만 페이지 컨트롤이 다음 줄로 내려갑니다. ([#87](https://github.com/Ray-lea/Argus/issues/87))
- **문서 사이트**: 모든 문서를 새로 작성했습니다. 빠른 시작, Argus 소개, 설치 및 업데이트, Windows 작업 관리자와의 비교를 담은 ‘시작하기’ 섹션을 추가했으며, 사용 가이드를 프로세스, 성능, 서비스 및 시작 프로그램, 연결, 기록 등 화면별 페이지로 나누고 코드에 맞춰 내용을 보완했습니다.

### 성능

- **화면 다시 그리기**: 내용이 바뀌지 않은 표시 중인 창을 화면 주사마다 다시 그리지 않습니다. 160 Hz 디스플레이에서 설정 페이지가 정지해 있을 때 초당 CPU 사이클이 약 절반으로 줄었으며, 애니메이션과 스크롤의 표시 프레임 속도는 그대로 유지됩니다.

### 수정

- **트레이 아이콘**: 어두운 작업 표시줄에서 ‘추세’가 잘 보이지 않는 문제를 피하도록 기본 스타일을 ‘앱 아이콘’으로 바꿨습니다. ‘구성 요소’ 페이지에서는 드롭다운 목록으로 트레이 아이콘 스타일을 선택합니다. ([#178](https://github.com/Ray-lea/Argus/issues/178))
- **작업 표시줄 모니터**: 작업 표시줄 단추가 가운데 정렬일 때 측정값이 시작 단추와 작업 단추를 가리지 않으며 공간에 들어가는 항목만 표시합니다. 그룹 정책으로 위젯이 비활성화되어 있으면 위젯 단추 자리의 여백을 남기지 않습니다.
- **데스크톱 모니터**: PC를 켜거나 Argus를 다시 시작한 뒤 켜 두었던 데스크톱 모니터가 바로 표시되어 다시 껐다 켤 필요가 없습니다.
- **Ryzen 9000**: CCD 안에 비활성화된 코어가 있는 모델(예: Ryzen 9 9900X3D)에서 ‘인식할 수 없는 센서 테이블’이 표시되지 않고 PPT와 TDC의 현재 값과 한도를 읽을 수 있습니다. 코어 매핑 검증을 통과하면 코어별 온도, 전압, C0/C1/CC6 상주 비율도 표시합니다. ([#203](https://github.com/Ray-lea/Argus/issues/203))
- **GPU 및 CPU 지표**: 외장 그래픽 카드가 절전 상태일 때도 GPU 페이지에서 마지막으로 읽은 ‘최대 코어 클럭’을 유지합니다. 커널 센서를 켜고 백그라운드 새로 고침 간격을 30초로 두었을 때 CPU 소비 전력과 유효 클럭이 간헐적으로 사라지지 않으며, 백그라운드 실행 중의 기록에도 이 항목들이 빠지지 않습니다.
- **특권 서비스와 커널 센서**: 보안 소프트웨어나 정리 도구가 서비스 등록을 삭제한 경우 Windows를 다시 시작하지 않고도 Argus에서 바로 다시 설치할 수 있습니다. PawnIO가 제거되었거나 장치가 삭제된 뒤에도 설치된 드라이버가 2.2.0 이하이면 커널 센서를 다시 켤 때 드라이버를 자동으로 재설치합니다.
- **관리자 권한으로 실행**: 작업 스케줄러에 같은 이름의 등록이 남아 있어도 관리자 권한 실행을 켤 수 있습니다. 등록이 거부되면 360 등 보안 소프트웨어에서 차단했을 가능성을 안내합니다. 오류 안내에서 오류 코드는 한 번만 표시하고 HRESULT는 16진수로 표시합니다.
- **작업 관리자 대체**: 대체를 켠 상태에서 관리자 계정으로 ‘Windows 작업 관리자 한 번 열기’를 클릭했을 때 반응하지 않던 문제를 해결했습니다. Argus가 응답하지 않을 때는 추가 시간 초과를 기다리지 않고 곧바로 Windows 작업 관리자를 엽니다.
- **오른쪽에서 왼쪽으로 쓰는 문자**: 프로세스 이름, 설명, 검색 상자에서 아랍어와 히브리어 등 오른쪽에서 왼쪽으로 쓰는 문자가 역순으로 표시되던 문제를 해결했습니다. ([#155](https://github.com/Ray-lea/Argus/issues/155))
- **메뉴와 창**: 창 아래쪽 가까이에서 펼쳐진 긴 하위 메뉴의 마지막 항목이 창 하단에 잘리지 않습니다. 세부 정보 창은 가장 긴 항목 이름에 맞춰 이름 열 너비를 조절하므로 ‘전용 GPU 메모리’ 같은 이름이 두 줄로 줄 바꿈되지 않습니다. Mica 창에서 대화 상자를 닫을 때 카드가 하얗게 깜빡이지 않습니다.
- **업데이트 후 아이콘**: 설치하거나 업데이트한 뒤 바탕 화면 바로 가기와 작업 표시줄에 고정한 Argus 아이콘이 PC를 다시 시작하지 않아도 즉시 새 아이콘으로 바뀝니다.

### 업데이트 안내

- **특권 서비스**: 통신 프로토콜은 계속 버전 12를 사용합니다. Ryzen 9000 측정값, 백그라운드 커널 센서 소비 전력, 작업 관리자 대체 수정 사항, 그리고 Windows 11 24H2 이전 버전에서 표준 사용자 권한으로 실행할 때의 디스크 읽기·쓰기 횟수는 서비스를 업데이트한 뒤 적용됩니다. 설치 버전은 업그레이드할 때 설치된 서비스를 함께 업데이트하며, 포터블 버전은 ‘설정 → 권한 → 특권 서비스’에서 ‘서비스 업데이트’를 클릭해야 합니다.
- **ARM64 PC의 설치 버전**: ARM64 PC에서 0.6.0은 x64 설치 패키지를 다운로드하며, x64 설치 프로그램은 ARM64 버전을 사용하라고 안내한 뒤 종료됩니다. 공식 웹 사이트에서 `Argus_0.7.0_arm64-setup.exe`를 다운로드해 기존 위치에 덮어써 설치하세요. 설정과 기록 데이터는 유지되며, 이후 앱 내 업데이트는 ARM64 버전으로 진행됩니다.
- **ARM64 PC의 포터블 버전**: Argus를 종료한 뒤 기존 실행 파일을 `Argus_0.7.0_arm64.exe`로 교체하세요. ‘관리자 권한으로 실행 허용’이 켜져 있다면 먼저 끄고 교체한 뒤 새 버전에서 다시 켜세요.
- **트레이 아이콘**: 이전에 스타일을 바꾼 적이 없는 트레이 아이콘은 업그레이드 후 앱 아이콘을 표시합니다. 실시간 CPU 사용률을 표시하려면 ‘구성 요소’ 페이지의 ‘트레이 아이콘’에서 ‘추세’, ‘비율’ 또는 ‘숫자’를 선택하세요.

## [0.6.0](https://github.com/Ray-lea/Argus/compare/v0.5.0...v0.6.0) - 2026-11-23

Argus v0.6.0에서는 점으로 그린 성능 그래프를 새 앱 아이콘으로 적용했습니다. 메인 창의 제목 표시줄을 간소화하고 페이지 표시줄과 상태 표시줄을 재배치했으며, 항상 위에 표시 버튼을 추가했습니다. 새 ‘구성 요소’ 페이지에서 시스템 지표를 시스템 트레이, 바탕 화면, 작업 표시줄에 실시간으로 표시할 수 있습니다. 새로 설계한 기록 페이지는 여러 트랙을 사용하는 그래프와 리소스 이벤트, 여러 실행에 걸친 프로세스 관찰을 지원합니다. 프로세스 페이지에는 리소스 누수 알림과 전력 사용량 열이 추가되었습니다. 프로세스, 서비스, 시작 프로그램, 연결 페이지에서 항목을 복사하거나 CSV로 내보낼 수 있으며, 서비스와 시작 항목을 삭제할 수 있습니다. 성능 페이지에서는 NPU를 모니터링할 수 있고, 터치 조작과 하드웨어 가속 설정도 추가되었습니다. 목록을 스크롤하거나 화면을 다시 그릴 때의 부하를 크게 줄였으며, 일부 Intel RST VMD 시스템에서 디스크 세부 정보를 열면 블루 스크린이 나타나는 문제와 전원이 꺼진 외장 GPU나 회전을 멈춘 하드 디스크가 깨어나는 문제도 해결했습니다.

### 호환성이 깨지는 변경

- **기록**: 저장 형식이 바뀌어 기록 페이지에는 0.6.0부터 기록한 데이터만 표시됩니다. 업데이트한 날의 기록을 처음 저장할 때 같은 날짜의 이전 형식 파일이 있으면 덮어씁니다. 이전 버전의 Argus에서도 새 형식의 기록을 읽을 수 없습니다.
- **특권 서비스 프로토콜**: 통신 프로토콜이 버전 11에서 12로 변경되었습니다. 특권 서비스로 작업을 끝내거나 I/O 또는 메모리 우선 순위를 변경하려면 기존 서비스를 먼저 업데이트해야 합니다.

### 새 기능

- **앱 아이콘**: 성능 그래프를 점으로 표현한 새 아이콘으로 바꿨습니다. 크기별로 점 배치를 조정해 작업 표시줄, 제목 표시줄과 업데이트된 바로 가기에서 선명하게 표시됩니다. 앱 정보 페이지와 첫 실행 안내에서는 점들이 로고를 이룬 뒤 최근 CPU 사용률 샘플 10개를 보여 주는 실시간 그래프로 바뀝니다. ‘UI 애니메이션’을 끄면 그래프가 바로 표시됩니다.
- **제목 표시줄**: 앱 로고, 창 너비에 맞춰 조절되는 검색 상자, Windows 표준 크기의 창 버튼만 남겼습니다. 나머지 빈 공간은 어디서든 드래그해 창을 옮길 수 있습니다. 새 핀 버튼으로 ‘항상 위에 표시’를 전환할 수 있으며 재시작해도 상태가 유지됩니다. ([#121](https://github.com/Ray-lea/Argus/issues/121))
- **페이지 표시줄과 상태 표시줄**: 페이지별 컨트롤과 ‘추가 작업’ 메뉴를 탐색 탭 옆으로 옮기고 프로세스 보기 전환 버튼을 아이콘으로 바꿨습니다. ‘추가 작업’에서 ‘새 작업 실행…’(Ctrl+N), ‘파일을 사용 중인 프로세스 찾기…’, 바로 가기 키 안내를 열 수 있습니다. 서비스 페이지에서는 Windows 서비스 관리 콘솔도 열 수 있습니다. 상태 표시줄에서 새로 고침을 일시 중지하거나 주기를 바꿀 수 있으며, 버전 번호에서 업데이트 진행률을 확인하거나 설치 창을 열 수 있습니다. ([#87](https://github.com/Ray-lea/Argus/issues/87))
- **구성 요소 페이지**: 새 ‘구성 요소’ 페이지에서 시스템 트레이와 백그라운드 옵션을 관리하고, 기본적으로 꺼져 있는 데스크톱 모니터와 작업 표시줄 모니터를 켤 수 있습니다. 시스템 트레이나 모니터에서 설정을 열면 사이드바에서 해당 항목이 선택됩니다.
- **실시간 시스템 트레이 아이콘**: 기본 스타일인 ‘추세’는 실시간 CPU 사용률을 표시하며, ‘비율’, ‘숫자’, ‘앱 아이콘’으로 바꿀 수 있습니다. 실시간 스타일 3종은 사용률이 80%에 도달하면 황색으로 바뀝니다. 포인터를 올리면 실시간 지표 카드가 표시되고, 마우스 오른쪽 버튼으로 클릭하면 CPU 사용률이 가장 높은 프로세스 3개와 자주 쓰는 작업이 빠른 패널에 나타납니다.
- **시스템 트레이 카드와 빠른 패널**: 포인터를 올렸을 때 뜨는 카드의 레이아웃이 언어와 글자 크기에 맞춰 조절됩니다. 카드를 끄면 시스템 도구 설명이 표시됩니다. 빠른 패널의 지표를 클릭하면 성능 페이지의 해당 장치로 이동합니다. 숨겨진 아이콘 영역에서 패널을 열면 그 영역이 펼쳐진 상태로 유지됩니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#113](https://github.com/Ray-lea/Argus/pull/113) [#153](https://github.com/Ray-lea/Argus/pull/153))
- **데스크톱 모니터**: 바탕 화면의 작은 창에 지표를 실시간으로 표시합니다. ‘가로 막대’와 ‘패널’ 레이아웃을 지원하며, 패널에는 ‘목록’, ‘선 그래프’, ‘계기판’ 스타일이 있습니다. 드래그해도 현재 디스플레이의 작업 영역을 벗어나지 않습니다. 항상 위에 표시, 위치 고정, 마우스 입력 통과, 불투명도 조절을 지원합니다.
- **작업 표시줄 모니터**: 작업 표시줄에 실시간 지표를 ‘레이블’, ‘선 그래프’, ‘캡슐형’, ‘큰 숫자’ 스타일로 표시합니다. 구성 요소 페이지나 마우스 오른쪽 버튼으로 여는 패널에서 스타일을 미리 보고 변경할 수 있습니다. 패널에서 디스플레이와 표시할 지표를 선택하거나 드래그로 순서를 바꾸면 즉시 적용됩니다. ([#28](https://github.com/Ray-lea/Argus/issues/28), [#123](https://github.com/Ray-lea/Argus/issues/123))
- **다중 디스플레이와 창 전환**: 선택한 디스플레이의 연결이 끊기면 작업 표시줄 모니터가 주 디스플레이로 옮겨 갔다가 다시 연결되면 돌아옵니다. 작업 표시줄 모니터 또는 시스템 트레이 아이콘을 클릭하면 메인 창이 가려지지 않은 상태에서는 숨겨지고, 이미 숨겨져 있거나 최소화되거나 다른 창에 가려져 있으면 맨 앞으로 나타납니다. 데스크톱 모니터를 두 번 클릭하면 메인 창이 열립니다.
- **모니터링 지표**: 두 모니터에서 온도, 클럭, 소비 전력, 팬 속도 등 18종의 지표를 표시할 수 있습니다. GPU, 디스크, 네트워크 어댑터마다 지표를 개별 선택하고, 범주나 개별 지표를 드래그해 순서를 바꿀 수 있습니다. 작업 표시줄 모니터는 장치 이름을 색으로 구분하고, 같은 CPU나 GPU의 후속 지표에는 지표 이름만 표시합니다.
- **모니터 새로 고침 간격**: 데스크톱 모니터나 작업 표시줄 모니터가 켜져 있으면 메인 창의 새로 고침 주기로 데이터를 수집합니다. 최소화 또는 백그라운드 상태의 간격 설정과 실제 간격이 다르면 설정 페이지에 현재 적용 중인 간격을 표시합니다. 두 모니터를 모두 끄면 기존 설정값이 다시 적용됩니다.
- **기록 페이지**: 여러 트랙으로 구성된 계단형 그래프로 새로 설계했습니다. 트랙마다 지표를 하나 더 겹쳐 볼 수 있습니다. 이름이나 장치로 지표를 검색하고, 드래그로 트랙의 순서와 높이를 조절할 수 있습니다. 트랙이 표시 영역을 넘으면 그래프 안에서 스크롤할 수 있습니다.
- **기록 그래프 탐색**: 마우스 휠을 굴리면 포인터가 가리키는 시점을 중심으로 확대하거나 축소합니다. 배율을 바꾸거나 그래프를 클릭하거나 드래그로 구간을 선택하면 최신 측정값의 자동 갱신이 일시 중지됩니다. ‘최신 기록으로 이동’을 클릭하거나 그래프를 마우스 오른쪽 버튼으로 클릭하거나 End 키를 누르면 자동 갱신이 재개됩니다. 기록이 없는 구간은 빗금으로 표시하고, 최근 10분은 실제 수집 간격대로 표시합니다. ([#79](https://github.com/Ray-lea/Argus/issues/79), [#129](https://github.com/Ray-lea/Argus/issues/129))
- **기록 그래프와 커서**: 최신 측정값을 자동 갱신하는 동안 계단형 그래프가 계속 진행되며, 포인터가 있는 트랙에서는 그래프가 커서를 지날 때마다 해당 지점의 값이 실시간으로 갱신됩니다. 시간 범위나 세로축 눈금이 바뀔 때는 그래프가 부드럽게 전환되고 겹쳐 표시한 그래프는 서서히 나타나거나 사라집니다. 이전에 열어 본 긴 시간 범위는 더 빠르게 다시 열립니다.
- **시간 범위와 이벤트**: 드롭다운에서 5분, 3시간, 1일, 3일, ‘사용자 지정…’을 선택할 수 있습니다. ‘시간 범위 지정’ 대화 상자에서 달력으로 날짜를 고르거나 정확한 시작 및 종료 시간을 입력할 수 있습니다. ‘30일 요약 및 이벤트 표시’를 켜면 시간대별 히트맵과 CPU 고부하, 메모리 부족, 기록 공백 등의 이벤트가 표시됩니다.
- **기록의 프로세스 표**: 선택한 시점이나 구간의 프로세스를 검색할 수 있습니다. 이름순으로 정렬하면 앱, 백그라운드 프로세스, Windows 프로세스로 나뉩니다. 이름이 같은 그룹을 펼치면 상위 인스턴스 4개와 나머지 인스턴스의 합계가 표시됩니다. 바로 가기 메뉴에서 해당 프로그램의 그래프를 겹쳐 보거나 이름과 PID를 복사할 수 있습니다.
- **기록 그래프 도구 설명**: CPU처럼 프로세스별로 집계할 수 있는 트랙에 포인터를 올리면 사용량이 가장 높은 프로세스 5개가 표시됩니다. 프로세스 수 트랙에는 인스턴스가 가장 많은 프로그램 5개와 나머지 프로그램의 합계가 표시됩니다. 온도와 배터리 잔량 등은 장치 데이터만 표시합니다.
- **기록 항목**: CPU 클럭, 소비 전력, 온도, 메모리 세부 정보, 배터리 지표와 디스크, GPU, 네트워크 어댑터별 지표를 추가했습니다. ‘설정 → 데이터 및 기록’에서 기록할 범주를 선택할 수 있습니다. 샘플마다 활성 프로세스를 약 20개, 약 40개 또는 모두 기록하도록 설정할 수 있으며, 하루 예상 저장 용량이 즉시 표시됩니다.
- **기록 저장소**: 보관 기간과 용량 한도를 각각 정할 수 있으며, 먼저 도달한 한도가 적용됩니다. 기본값은 30일 및 2 GB입니다. 7일이 지난 기록은 분 단위로 합쳐 평균, 최댓값, 사용량이 가장 높은 프로세스를 남깁니다. 저장 위치를 바꿀 때 기존 기록과 프로세스 관찰 기록을 함께 옮길지 선택할 수 있습니다. 대상 폴더에 다른 파일이 있으면 ‘Argus History’ 하위 폴더에 저장합니다.
- **프로세스 관찰**: 바로 가기 메뉴나 세부 정보 창에서 ‘프로세스 관찰’을 선택하면 경로가 같은 프로그램의 실행별 지표 14종을 기록합니다. 메모리, CPU, GPU, 디스크, I/O, 네트워크, 스레드, 핸들 관련 지표가 포함됩니다. 경로를 확인할 수 없으면 현재 인스턴스만 관찰합니다. 관찰을 시작하면 기록의 ‘프로세스 관찰’이 열리며, 실행 인스턴스를 전환하고 여러 트랙의 그래프로 지표를 비교할 수 있습니다. ([@hayxe1](https://github.com/hayxe1) [#82](https://github.com/Ray-lea/Argus/pull/82))
- **프로세스 관찰 기록**: 최근 10분은 실제 수집 간격대로 표시하며, 더 이전 기록은 디스크에서 읽습니다. 최대 7일간 보관하며 용량 한도에 도달하면 가장 오래된 데이터부터 삭제합니다. ‘관찰 중지’를 눌러도 기존 데이터는 남으며, Argus를 재시작한 후에는 관찰을 다시 시작해야 합니다.
- **프로세스 그룹**: ‘앱’, ‘백그라운드 프로세스’, ‘Windows 프로세스’와 사용자별 그룹을 서로 다른 색으로 구분합니다. 스크롤하는 동안 현재 그룹 제목이 맨 위에 고정되고, 스크롤 막대 옆에는 각 그룹의 위치와 현재 그룹 이름이 표시됩니다. ‘시스템 프로세스 숨기기’를 켜면 숨겨진 프로세스 수도 표시됩니다. ([#88](https://github.com/Ray-lea/Argus/issues/88))
- **프로세스 전력 사용량**: CPU, GPU, 디스크 활동을 바탕으로 전력 사용 수준을 추정하는 ‘전력 사용량’과 ‘전력 사용량 추세’ 열을 추가했습니다. 두 열 모두 기본적으로 숨겨져 있습니다. 첫 번째 열에는 현재 수준, 두 번째 열에는 최근 약 2분의 평균 수준이 표시됩니다. ([#134](https://github.com/Ray-lea/Argus/issues/134))
- **프로세스 우선 순위**: 바로 가기 메뉴에서 I/O 및 메모리 우선 순위를 설정할 수 있습니다. 설정값은 세부 정보 창과 선택한 열에 표시됩니다. ‘기본 우선 순위’에는 범주 이름을 표시하되 특수 값은 숫자로 표시하며, 정렬은 계속 숫자를 기준으로 합니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#80](https://github.com/Ray-lea/Argus/pull/80) [#116](https://github.com/Ray-lea/Argus/pull/116))
- **포인터를 올려 정렬 일시 중지**: 프로세스 목록에 포인터를 올려 정렬을 일시 중지하면 정렬 기준 열의 머리글에 일시 중지 아이콘이 나타나고 상태 표시줄에는 ‘정렬 일시 중지’가 표시됩니다. ‘설정 → 언어 및 모양’의 ‘마우스를 올려놓는 동안 정렬 일시 중지’는 기본적으로 켜져 있습니다. ([#86](https://github.com/Ray-lea/Argus/issues/86))
- **리소스 누수 알림**: 프로세스 페이지에서 핸들 누수, 계속 늘어나는 자식 프로세스, 남아 있는 프로세스를 자동으로 감지합니다. 머리글의 황색 표시를 클릭하면 해당 프로세스로 이동합니다. 세부 정보 창에는 감지 근거, 개수 추이, 권장 조치가 표시되며 프로세스 종료 후 다음 수집 주기에 갱신됩니다. 프로그램별로 알림을 무시할 수 있고, ‘설정 → 언어 및 모양 → 리소스 누수 알림’에서 무시한 프로그램의 알림을 다시 켜거나 기능 전체를 끌 수 있습니다.
- **표 내용 복사**: 프로세스, 서비스, 시작 프로그램, 연결 페이지의 바로 가기 메뉴에서 현재 셀의 내용, 이름, 세부 정보를 복사할 수 있습니다. 프로세스 페이지에서 Ctrl+C는 이름을, Ctrl+Shift+C는 세부 정보를 복사합니다. 선택한 텍스트가 있으면 Ctrl+C는 그 텍스트를 먼저 복사합니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#161](https://github.com/Ray-lea/Argus/pull/161), [#91](https://github.com/Ray-lea/Argus/issues/91), [#150](https://github.com/Ray-lea/Argus/issues/150))
- **CSV 내보내기**: 프로세스, 서비스, 시작 프로그램, 연결 페이지의 ‘추가 작업’ 메뉴에서 ‘현재 페이지를 CSV로 내보내기…’를 선택하면 화면 밖의 행까지 포함해 목록 전체를 내보냅니다. 현재 열 순서, 필터, 정렬, 표시 단위, 그룹 펼침 상태도 반영됩니다. ([#139](https://github.com/Ray-lea/Argus/issues/139))
- **세부 정보 창**: ‘리소스’에 최대 작업 집합, 가상 주소 공간, I/O 속도, 전력 사용량을 추가했습니다. 새 ‘누적 사용량’ 섹션에는 사용자 모드와 커널 모드의 CPU 시간, 유형별 I/O 바이트 수, 페이지 폴트 횟수가 표시됩니다. 오른쪽 위 복사 버튼을 누르면 값이 있는 모든 항목을 섹션별로 복사합니다.
- **연결 페이지**: 연결을 앱별로 묶어 접거나 펼칠 수 있습니다. 검색하면 일치하는 그룹이 자동으로 펼쳐집니다. 서비스와 연결 페이지의 상태 필터를 ‘상태’ 열 머리글로 옮겼습니다. 연결 페이지에는 TCP, TCPv6, UDP, UDPv6 필터도 추가되어 상태 필터와 함께 사용할 수 있습니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#152](https://github.com/Ray-lea/Argus/pull/152))
- **서비스 및 시작 항목 삭제**: 바로 가기 메뉴의 새 ‘삭제’ 항목을 선택하고 확인하면 서비스나 시작 항목을 삭제할 수 있습니다. 사용 중인 서비스는 중지되고 더 이상 참조되지 않을 때 Windows가 제거합니다. 시작 프로그램 폴더의 항목은 휴지통으로 이동하며, 패키지 앱의 시작 작업은 여전히 사용 안 함으로만 설정할 수 있습니다. ([#114](https://github.com/Ray-lea/Argus/issues/114), [#146](https://github.com/Ray-lea/Argus/issues/146))
- **패키지 앱의 서비스**: Windows가 패키지 앱 서비스의 시작 유형 변경을 거부하면 확인을 거쳐 레지스트리에 직접 저장할 수 있습니다. 재시작 후 적용되는 변경에는 목록에 표시가 붙습니다. 실패할 경우 오류 메시지에 서비스 이름과 권한 또는 시스템 보호 제한 사항이 표시됩니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#112](https://github.com/Ray-lea/Argus/pull/112), [#168](https://github.com/Ray-lea/Argus/issues/168))
- **메모리 지표**: 성능 페이지의 메모리 구성 막대에서 사용 중인 압축 메모리를 빗금으로 표시합니다. 포인터를 올리면 압축해 저장한 데이터의 추정 용량과 절약한 메모리 용량을 볼 수 있습니다. 프로세스 페이지의 메모리 도구 설명에는 시스템 전체 사용량, 프로세스별 개인 작업 집합, 그룹 합계에 포함되는 범위가 각각 표시됩니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#81](https://github.com/Ray-lea/Argus/pull/81), [#122](https://github.com/Ray-lea/Argus/issues/122))
- **NPU**: 성능 페이지에 Windows에서 인식한 NPU별 이름, 사용률, 최근 60초의 실시간 그래프가 표시됩니다. 인식된 NPU는 GPU 목록에서 제외됩니다. ([@SpookySandwich](https://github.com/SpookySandwich) [#140](https://github.com/Ray-lea/Argus/pull/140), [#135](https://github.com/Ray-lea/Argus/issues/135), [#148](https://github.com/Ray-lea/Argus/issues/148))
- **CPU 그래프와 디스크 세부 정보**: 전체 보기와 논리 프로세서별 보기 전환, 코어 유형 필터를 CPU 그래프의 바로 가기 메뉴로 옮겼습니다. 논리 프로세서별 그래프는 읽기 쉬운 비율을 유지하고, 공간이 부족하면 클럭과 제목을 차례로 생략합니다. 디스크 세부 정보에서는 SMART 원시 값을 기본적으로 10진수로 표시합니다. 16진수로 바꾸면 모든 디스크에 적용되며 재시작해도 유지됩니다.
- **하드웨어 가속**: ‘설정 → 애니메이션’에 기본적으로 켜져 있는 ‘하드웨어 가속’ 설정을 추가했습니다. 끄면 GPU 대신 CPU로 인터페이스를 그리며, 변경 사항이 즉시 적용됩니다. ([#127](https://github.com/Ray-lea/Argus/issues/127))
- **터치 조작**: Windows 터치 화면에서 탭, 두 번 탭, 밀어서 스크롤, 길게 눌러 메뉴 열기, 스크롤 막대 드래그를 지원합니다. 원격으로 전달된 탭도 메인 창 컨트롤에 정상적으로 적용됩니다. 텍스트 상자에 포커스가 가면 필요에 따라 터치 키보드가 나타납니다. ([#73](https://github.com/Ray-lea/Argus/issues/73))
- **앱 정보 페이지**: 새 ‘진단 정보 복사’ 버튼을 누르면 문제 보고에 필요한 버전, 실행 상태, 하드웨어 및 디스플레이 설정을 한 번에 복사할 수 있습니다. 공식 웹 사이트와 GitHub 카드 아래에 다운로드, 사용 안내서, 업데이트 기록, 이슈, 토론, 릴리스로 이동하는 바로 가기도 추가했습니다.
- **관리자 권한 프로그램 저장 위치**: 특권 서비스, 작업 관리자 대체, 관리자 권한 실행에 쓰이는 프로그램을 `Program Files\Argus Privileged`에 고정된 파일 이름으로 저장합니다. 보안 소프트웨어에서 경로를 기준으로 설정한 예외가 업데이트 후에도 유지됩니다. Program Files 외부에 설치할 때는 설치 프로그램의 정보 아이콘에서 이 파일들의 저장 위치를 확인할 수 있습니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#154](https://github.com/Ray-lea/Argus/pull/154), [#136](https://github.com/Ray-lea/Argus/issues/136), [#159](https://github.com/Ray-lea/Argus/issues/159))

### 성능

- **화면 그리기**: 새로 고침하거나 포인터를 올리거나 클릭하면 변경된 부분만 다시 그립니다. 목록 위에서 포인터를 움직이거나 아이콘 애니메이션을 재생할 때 GPU 부담이 크게 줄었습니다. 배포용 빌드에서 프로세스 목록을 스크롤할 때 프레임당 CPU 사이클이 약 40% 감소했습니다. 하드웨어 가속을 끈 상태에서도 스크롤하거나 페이지를 전환할 때 그려 둔 화면을 재사용합니다.
- **첫 지표 표시**: 시작 후 첫 데이터 수집까지의 대기 시간을 줄여 초깃값을 더 빠르게 표시합니다. ([@hayxe1](https://github.com/hayxe1) [#119](https://github.com/Ray-lea/Argus/pull/119))

### 수정

- **디스크 세부 정보의 블루 스크린**: 온도와 NVMe 상태를 조회하기 전에 컨트롤러 드라이버를 확인해 일부 Intel RST VMD 시스템에서 디스크 세부 정보를 열 때 블루 스크린이 나타나는 문제를 해결했습니다. 건너뛴 항목은 ‘알 수 없음’으로 표시됩니다. 읽는 중이거나 읽고 2분 안에 비정상 종료되면 다음 실행에서는 자동 읽기를 중지합니다. ‘그래도 읽기’로 수동 조회할 수 있습니다. ([#48](https://github.com/Ray-lea/Argus/issues/48), [#133](https://github.com/Ray-lea/Argus/issues/133), [#160](https://github.com/Ray-lea/Argus/issues/160))
- **장치 절전**: 하이브리드 그래픽 노트북에서 전원이 꺼진 외장 GPU의 센서를 조회하지 않아 반복해서 깨우지 않습니다. 성능 페이지에는 ‘절전 중’과 원인이 표시됩니다. 유휴 하드 디스크는 마지막 온도 값을 유지하며 회전이 멈추면 온도 조회를 건너뛰어 절전 상태를 유지합니다. ([#147](https://github.com/Ray-lea/Argus/issues/147))
- **CPU 지표**: 유휴 사이클을 바탕으로 CPU 사용률을 계산해 유휴 루프가 부하에 포함되면서 사용률이 과다하게 표시되던 문제를 해결했습니다. Windows 10에서 하이브리드 프로세서의 클럭이 표시되지 않거나 일부 Intel 프로세서에서 P 코어와 E 코어가 구분되지 않는 문제도 해결했습니다. ([#137](https://github.com/Ray-lea/Argus/issues/137))
- **GPU 지표**: 내장 GPU를 사용하는 프로세스의 공유 GPU 메모리가 전용 GPU 메모리에 합산되지 않습니다. 하드웨어 GPU가 없을 때는 소프트웨어 렌더링을 프로세스의 GPU 사용률로 집계하지 않으며 프로세스 페이지에서 GPU 열을 숨깁니다. 시작할 때 하드웨어 GPU를 감지했다면 드라이버를 업데이트하거나 새 GPU를 연결해도 재시작 없이 지표가 복구되거나 새로 표시됩니다.
- **디스크 지표**: USB 외장 하드 디스크의 SMART 정보를 읽지 못하거나 상태가 ‘알 수 없음’으로 표시되는 문제와 Google Drive 등 가상 드라이브의 드라이브 문자가 디스크 0 아래에 표시되는 문제를 해결했습니다.
- **파일 사용 여부 조회**: 시스템의 전체 핸들 수가 아주 많을 때 파일을 사용 중인 프로세스를 찾지 못하는 문제를 해결했습니다. 특권 서비스와 로컬 검색이 같은 원인으로 실패하면 오류를 한 번만 표시합니다. 특권 서비스가 이미 설치되어 있으면 사용 설정 안내를 다시 표시하지 않습니다.
- **작업 끝내기 보호**: 대상이 중요한 시스템 프로세스인지 확인할 수 없으면 작업을 끝내지 않습니다. 단일 프로세스, 일괄 작업, 프로세스 트리에 모두 적용됩니다. ([@hayxe1](https://github.com/hayxe1) [#77](https://github.com/Ray-lea/Argus/pull/77))
- **프로세스 페이지**: 검색하거나 그룹을 펼치거나 접어도 열 너비가 유지됩니다. 포인터를 올려 정렬이 일시 중지된 동안 자식 프로세스를 펼쳐도 행 순서는 바뀌지 않습니다. 사용자 그룹 행의 바로 가기 메뉴가 열리지 않는 문제, 선택한 행을 두 번 클릭해 펼칠 때 세부 정보 창이 갑자기 접히는 문제, 프로그램 이름과 버전 정보에 불필요한 문자가 섞이는 문제를 해결했습니다.
- **기록에서 프로세스로 이동**: 기록에서 프로세스로 이동할 때 PID, 이름, 시작 시간을 함께 확인해 같은 PID를 다시 할당받은 다른 프로세스를 잘못 선택하지 않도록 했습니다. ([@hayxe1](https://github.com/hayxe1) [#76](https://github.com/Ray-lea/Argus/pull/76))
- **서비스 및 시작 프로그램 목록**: 내용에 맞춰 열 너비를 자동으로 조절합니다. 열 경계를 두 번 클릭하면 자동 너비로 돌아가며, 수동으로 조절한 너비는 재시작해도 유지됩니다. 시작 항목의 상태를 확인할 수 없으면 ‘상태’ 열에 ‘읽을 수 없음’으로 표시합니다.
- **특권 서비스와 관리자 권한 실행**: 시스템 폴더를 잘못 감지해 관리자 권한 실행이나 특권 서비스를 사용하지 못하는 문제를 해결했습니다. 서비스 파일이 없으면 ‘손상됨’으로 표시하고 복구 또는 제거 옵션을 제공합니다. 업데이트나 제거 중에 전원이 끊겨도 사용할 수 있는 서비스 파일을 보존하며, Argus를 제거할 때 서비스 등록 해제 후 남은 파일도 정리합니다. ([#111](https://github.com/Ray-lea/Argus/issues/111))
- **작업 관리자 대체**: 보안 소프트웨어 등 다른 프로그램이 작업 관리자 대체 설정을 되돌리면 설정 페이지와 첫 실행 안내에 ‘대체 해제됨’을 표시합니다. 유지 관리 도우미가 비정상 종료되면 오류에 종료 코드를 표시합니다.
- **설치 및 로드 보안**: 설치 프로그램이 설치 폴더를 확인하고, 보호할 수 있는 경우 관리자와 시스템만 쓸 수 있도록 제한합니다. 대화형 신규 설치에서 선택한 위치를 보호할 수 없으면 이유를 설명하고 그대로 진행하거나 다른 위치를 선택할 수 있게 합니다. Argus는 가져오는 시스템 DLL을 시스템 폴더에서만 로드하며, 실행 폴더에 있는 같은 이름의 파일은 무시합니다. ([#136](https://github.com/Ray-lea/Argus/issues/136))
- **창 표시**: 최대화하거나 복원할 때 시스템 전환 애니메이션이 빠지던 문제, 시스템 트레이에서 다시 열 때 최대화 상태가 유지되지 않던 문제, 처음 실행하거나 작업 관리자를 여는 경로로 실행할 때 다른 창 뒤에 표시되던 문제를 해결했습니다. ([#126](https://github.com/Ray-lea/Argus/issues/126), [#142](https://github.com/Ray-lea/Argus/issues/142))
- **배율 및 스크롤**: 시스템이나 인터페이스 배율이 125%, 150% 등일 때 일부 페이지를 맨 아래까지 스크롤하면 다시 위로 이동할 수 없거나 대화 상자를 스크롤할 수 없던 문제를 해결했습니다. 배율 입력 상자에 세 자리 숫자가 온전히 표시되며, 열 옵션과 조작 안내 글자 하단이 잘리지 않습니다. ([#164](https://github.com/Ray-lea/Argus/issues/164))
- **메뉴와 대화 상자**: 바로 가기 메뉴와 하위 메뉴는 닫을 때 즉시 사라집니다. 드롭다운 목록은 컨트롤 위치에서 펼쳐지고 다시 그 위치로 접힙니다. 대화 상자는 창 중앙에서 커지며 서서히 나타나고, 작아지며 사라집니다. 열려 있는 동안은 창 버튼 배경도 함께 어두워집니다. 도구 설명이 바로 가기 메뉴를 가리거나 사용할 수 없는 메뉴 항목에 경고색 또는 포인터 강조 표시가 나타나던 문제를 해결했습니다. ([#141](https://github.com/Ray-lea/Argus/issues/141))
- **레이아웃**: 기본 창 크기에서 성능 개요가 잘리는 문제를 해결했습니다. 창을 넓히면 설정 페이지의 콘텐츠 영역도 적절히 넓어집니다. 내용이 모두 들어가는 대화 상자에서는 불필요한 스크롤 막대를 숨깁니다.

### 업데이트 안내

- **특권 서비스**: 설치 프로그램이나 앱 내 업데이트로 버전을 올리면 설치된 특권 서비스와 작업 관리자 대체용 사본이 함께 업데이트됩니다. 포터블 버전은 실행 파일을 교체한 뒤 ‘설정 → 권한 → 특권 서비스’에서 ‘서비스 업데이트’를 클릭하고 관리자 권한 요청을 승인해야 합니다.
- **관리자 권한 프로그램 저장 위치**: 설치 버전을 업데이트하거나 포터블 버전에서 서비스를 업데이트하면 기존 특권 서비스와 작업 관리자 대체 및 관리자 권한 실행용 사본이 `Program Files\Argus Privileged`로 자동 이동합니다. 보안 소프트웨어에서 이전 경로를 예외로 지정했다면 새 경로를 한 번 더 등록해야 합니다.
- **페이지 바로 가기 키**: ‘구성 요소’ 페이지가 추가되어 Ctrl+7은 구성 요소, Ctrl+8은 설정, Ctrl+9는 앱 정보를 엽니다.
- **설정 및 기록**: 업데이트한 뒤 시스템 기록을 처음 열면 기본적으로 최근 5분이 표시되며, 그 뒤에는 마지막으로 선택한 범위가 유지됩니다. 연결 페이지의 상태 필터가 ‘UDP’로 저장되어 있으면 ‘모두’로 초기화됩니다. ‘프로토콜’ 열에서 다시 필터링할 수 있습니다. 설정 파일에는 이제 기본값과 다른 항목만 저장하므로 변경하지 않은 항목은 이후 기본값이 바뀌면 자동으로 반영됩니다.

## [0.5.0](https://github.com/Ray-lea/Argus/compare/v0.4.0...v0.5.0) - 2026-11-12

v0.5.0에서는 프로세스를 일시 중단하거나 실행을 재개할 수 있고, 사용자별로 묶어 볼 수 있습니다. 프로세스 정보 열 4개를 추가했으며 열 너비는 내용에 맞춰 조절합니다. 성능 페이지의 장치 목록은 장치를 숨기거나 순서를 바꿀 수 있습니다. 인터페이스에 중국어 번체, 스페인어, 독일어, 일본어, 프랑스어, 러시아어를 추가했습니다. 일부 Intel RST 시스템에서 Argus를 시작한 뒤 시스템이 응답하지 않거나 USB 디스크를 안전하게 제거하지 못하는 문제를 해결했습니다. 창이 숨겨져 있을 때의 메모리 사용량과 CPU 사용률도 줄였습니다.

### 새 기능

- **프로세스 일시 중단 및 재개**: 프로세스와 앱 그룹의 바로 가기 메뉴에 ‘프로세스 일시 중단’과 ‘프로세스 실행 재개’를 추가했습니다. 중요한 시스템 프로세스와 바탕 화면 창 관리자, Argus 자체는 일시 중단할 수 없습니다. 그 밖의 프로세스는 일시 중단의 영향을 안내하고 확인을 받습니다. 일시 중단된 프로세스는 이름 옆에 ‘일시 중단됨’으로 표시합니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#65](https://github.com/Ray-lea/Argus/pull/65))
- **프로세스 정보 열**: 선택할 수 있는 열로 ‘파일 버전’, ‘아키텍처’, ‘권한 상승’, ‘명령줄’을 추가했습니다. 기본적으로 숨겨져 있으며 열 머리글의 바로 가기 메뉴나 ‘열 선택’에서 표시할 수 있습니다. ([@digital-bombyx](https://github.com/digital-bombyx) [#72](https://github.com/Ray-lea/Argus/pull/72))
- **프로세스 열 너비**: 자동 너비는 내용에 맞춰 열을 배치하고 남는 공간을 표 오른쪽에 둡니다. 열 경계를 드래그하면 너비를 조절하고 두 번 클릭하면 자동 너비로 돌아갑니다. 머리글 메뉴에서 새 ‘전체 너비’ 옵션을 켜면 남는 공간을 이름 열이 채웁니다.
- **사용자별 프로세스 그룹화**: ‘설정 → 언어 및 모양 → 사용자별로 프로세스 그룹화’에서 자동, 항상 그룹화, 그룹화하지 않음을 선택할 수 있습니다. 자동으로 설정하면 둘 이상의 사용자가 로그인했을 때만 그룹으로 묶습니다. 그룹 행의 바로 가기 메뉴에는 ‘사용자 계정 관리’와 ‘로그아웃’이 있습니다.
- **시스템 프로세스 숨기기**: 프로세스와 연결 페이지에 ‘시스템 프로세스 숨기기’를 추가했습니다. 기본적으로 꺼져 있으며 페이지별로 상태를 저장합니다. 항상 표시하거나 추가로 숨길 프로그램의 목록은 설정에서 편집할 수 있습니다. ([#32](https://github.com/Ray-lea/Argus/issues/32))
- **프로세스 트리와 요약 표시줄**: 프로세스 트리는 기본적으로 접혀 있습니다. 머리글의 바로 가기 메뉴에 ‘모두 펼치기’와 ‘모두 접기’를 추가했습니다. ‘프로세스 요약 표시줄’은 자동, 항상 표시, 숨기기로 설정할 수 있습니다. 자동으로 설정하면 창 높이가 낮을 때 요약 표시줄을 숨깁니다.
- **성능 페이지의 장치 목록**: 장치를 마우스 오른쪽 버튼으로 클릭해 숨기거나 ‘표시 중인 장치’ 하위 메뉴에서 표시할 장치를 개별 선택할 수 있습니다. 장치를 드래그해 순서를 변경할 수 있습니다. 디스크는 디스크 번호, 드라이브 문자 또는 사용자 지정 순서로 정렬할 수 있습니다.
- **CPU 멀티코어 보기**: 논리 프로세서별 그래프에 커널 시간이 표시되며, CPU 그래프의 바로 가기 메뉴에서 숨길 수 있습니다. Intel 저전력 효율 코어(LP E 코어)는 별도의 색으로 표시하고 개별 필터를 지원합니다. 가능한 한 빈 칸이 없도록 작은 그래프를 배치합니다.
- **하드웨어 정보**: GPU 페이지에 드라이버 버전 및 날짜, DirectX 버전과 기능 수준이 표시됩니다. 더 많은 SATA SSD의 남은 수명과 누적 읽기·쓰기 용량을 볼 수 있습니다. 하드 디스크의 전원 켜짐 시간, 시작·정지 횟수, 재할당된 섹터 및 재할당 대기 중인 섹터 등의 통계도 추가했습니다.

### 수정

- **시스템 응답 없음**: Intel RST 등 RAID 컨트롤러에 연결된 디스크의 온도를 조회하지 않습니다. 일부 드라이버에서 요청에 응답하지 않아 Argus 실행 후 몇 초 지나 시스템이 멈추던 문제를 방지합니다. 해당 디스크 온도는 ‘알 수 없음’으로 표시합니다. ([#48](https://github.com/Ray-lea/Argus/issues/48))
- **USB 디스크 안전 제거**: 디스크 모니터링이 장치를 계속 사용해 Windows에서 USB 디스크를 안전하게 제거할 수 없었던 문제를 해결했습니다. ([#57](https://github.com/Ray-lea/Argus/issues/57))
- **디스크 목록 및 성능 데이터**: 일부 NVMe 디스크에서 장치 정보만 표시되고 성능 데이터가 표시되지 않던 문제와 성능 카운터를 사용할 수 없을 때 디스크가 목록에서 사라지던 문제를 해결했습니다.
- **디스크 세부 정보**: SMART 속성 표에서 속성 이름과 값이 멀리 떨어지거나 그룹 사이가 지나치게 벌어지거나 좁은 창에서 원시 값이 잘리는 문제를 해결했습니다. 상태 표시줄은 정상일 때 녹색으로 표시하며 온도와 예비 공간이 임계값을 벗어나면 경고 색으로 표시합니다.
- **프로세스 데이터**: 시스템 조회가 느려도 프로세스 목록은 갱신하며 리소스 지표는 마지막으로 확인한 유효한 값을 유지합니다. 종료한 프로세스가 목록에 계속 남거나 새로 고침을 일시 중지했을 때 조작한 프로세스의 상태가 반영되지 않던 문제를 해결했습니다. ([#66](https://github.com/Ray-lea/Argus/issues/66))
- **프로세스 표**: 효율성 모드와 고정 아이콘을 프로세스 이름 바로 옆에 표시하고, 머리글과 데이터 열의 경계를 맞췄습니다. 프로세스 사용률에 백분율 기호를 표시합니다.
- **연결 페이지**: 소유 프로세스가 없는 연결은 ‘연결을 소유한 프로세스 없음’으로 표시합니다.
- **CPU 지표**: 하이브리드 CPU의 속도와 일부 6코어 Ryzen 프로세서의 코어별 전압 및 온도가 잘못 표시되던 문제를 해결했습니다. Intel 내부 센서 지표가 간헐적으로 중단되어 온도 그래프가 끊기는 문제도 해결했습니다. ([#58](https://github.com/Ray-lea/Argus/issues/58))
- **권한 승인과 제거**: Program Files 또는 실행 폴더의 권한이 바뀐 뒤 승인을 취소하거나 프로그램을 제거하지 못하는 문제를 해결했습니다. 커널 센서에서 이미 실행 중인 PawnIO 드라이버를 사용할 수 있습니다. 프로그램을 제거한 뒤 Argus Sensor Setup 폴더와 빈 Argus Runtime 폴더가 남지 않습니다. ([#46](https://github.com/Ray-lea/Argus/issues/46))
- **실행 권한**: 설치 또는 앱 내 업데이트 후에는 바로 가기에서 실행할 때처럼 먼저 바탕 화면에 로그인한 계정의 권한으로 실행을 시도합니다. 관리자 권한으로 실행 중인 Argus는 이미 관리자 권한으로 실행 중인 파일 탐색기를 같은 권한으로 다시 시작할 수 있습니다.
- **창 표시**: 창 크기를 복원했을 때 인터페이스가 왼쪽 위에만 표시되거나 작업 관리자 대체 경로에서 처음 실행할 때 최대화된 창이 일부만 표시되던 문제를 해결했습니다. Windows 11 21H2에서 창 배경이 투명하게 표시되거나 다른 앱으로 전환해도 Argus 창이 앞에 남아 있던 문제도 해결했습니다. ([#44](https://github.com/Ray-lea/Argus/issues/44), [#37](https://github.com/Ray-lea/Argus/issues/37), [#35](https://github.com/Ray-lea/Argus/issues/35))
- **시스템 트레이**: 창을 닫아 시스템 트레이에 숨겼는데도 CPU 사용률이 계속 높거나 앱 내 업데이트 후 아이콘이 숨겨진 영역으로 이동하던 문제를 해결했습니다. ([#31](https://github.com/Ray-lea/Argus/issues/31))
- **인터페이스 표시**: 업데이트 대화 상자가 로드 중에도 중앙에 유지되며, 파일을 사용하는 프로세스 목록이 표시될 때 대화 상자가 움직이지 않습니다. 높이가 낮은 창에서도 앱 정보 페이지 전체를 스크롤해 볼 수 있습니다. 텍스트 상자의 바로 가기 메뉴는 인터페이스 언어로 표시됩니다. ([#39](https://github.com/Ray-lea/Argus/issues/39))
- **숫자 및 화면 그리기**: 실시간 숫자가 갱신될 때 좌우로 움직이던 문제, 어두운 배경에서 밝은 글자의 테두리가 잘못 표시되던 문제, 요약 표시줄 아래에 작은 색 잔상이 남던 문제를 해결했습니다.
- **안정성**: 디스플레이 타이밍이 올바르지 않거나 네트워크 어댑터 주소 조회가 연달아 실패할 때 Argus가 종료되던 문제를 해결했습니다. 그래픽 장치가 복구되는 동시에 창을 닫을 때 인터페이스가 멈추는 문제도 해결했습니다.
- **큰 글자, 프로세스 규칙 및 시작 항목**: 글자 크기가 클 때 성능 지표가 사양 정보와 겹치지 않습니다. 프로그램 이름에 ASCII가 아닌 문자가 있어도 프로세스 메뉴에서 같은 규칙이 중복으로 추가되지 않습니다. 패키지 앱의 시작 작업을 읽을 때 Argus가 비정상 종료되는 문제를 해결했습니다. ([@hayxe1](https://github.com/hayxe1) [#59](https://github.com/Ray-lea/Argus/pull/59))
- **빌드 유형**: 설정과 앱 정보 페이지, 상태 표시줄은 실행 중인 빌드에 따라 ‘개발 빌드’, ‘베타 버전’, ‘안정 버전’을 표시합니다. 업데이트 채널은 이후에 업데이트를 확인할 때 사용할 소스를 별도로 지정합니다.

### 업데이트 안내

- **특권 서비스**: 통신 프로토콜이 버전 11로 업데이트됩니다. 설치 버전은 설치 프로그램이나 앱 내 업데이트로 업데이트하면 설치된 특권 서비스와 작업 관리자 대체용 사본도 함께 업데이트됩니다. 포터블 버전은 실행 파일을 교체한 뒤 ‘설정 → 권한 → 특권 서비스’에서 ‘서비스 업데이트’를 선택하고 관리자 권한 요청을 승인해야 합니다.
- **설정 및 기록**: 업데이트해도 기존 설정과 기록이 유지됩니다. 업데이트 후 처음 실행할 때는 ‘창 전환 애니메이션’에 이전 ‘UI 애니메이션’의 창 전환 설정이 적용됩니다.

## [0.4.0](https://github.com/Ray-lea/Argus/compare/v0.3.4...v0.4.0) - 2026-11-06

v0.4.0의 인터페이스는 Tauri, SolidJS, WebView2에서 Rust와 GPUI Kit 기반의 네이티브 인터페이스로 전환했습니다. 브라우저 엔진으로 인한 부하를 없애고 DirectX 렌더링과 조작 방식을 새로 구현했습니다. 고주사율 애니메이션, 실시간 그래프, 목록 갱신, 백그라운드 리소스 사용을 최적화했습니다. 사용자 지정 프로세스 열, 디스크 상태 및 SMART 세부 정보, 추가 Intel 내장 그래픽 지표와 새 레이아웃 옵션을 제공합니다. [Argus 공식 웹 사이트](https://argustask.com)와 공식 업데이트 미러도 공개했습니다.

### 새 기능

- **사용자 지정 프로세스 열**: 기본 정보, CPU, 메모리, 디스크 및 I/O, 네트워크, GPU 등 6개 범주의 열 40개 중에서 고를 수 있습니다. 전용 및 공유 GPU 메모리, GPU 엔진, 이미지 이름, 가상 주소 공간, 최대 작업 집합, 페이지 폴트 횟수, 누적 I/O 등을 추가했습니다. 가상 주소 공간과 최대 작업 집합은 프로세스별로 표시합니다. 머리글의 범주별 하위 메뉴에서 여러 열을 차례로 켜고 끌 수 있습니다. ‘열 선택’ 대화 상자는 범주별 필터, 검색, 두 열로 나눈 순서 조정을 지원합니다. 머리글이나 선택한 열을 드래그하면 열이 즉시 부드럽게 재배치됩니다. 자동 열 너비는 숫자 형식에 맞춰 공간을 확보해 값이 바뀔 때 움직이지 않으며, 수동 너비도 저장합니다. 기본 목록과 프로세스 트리의 ‘이름’ 열도 앱별 보기처럼 앱 이름이나 파일 설명을 우선 표시합니다. 실행 파일 이름은 보조 텍스트나 ‘이미지 이름’ 열에서 확인할 수 있습니다.
- **디스크 상태와 세부 정보**: 디스크 성능 화면에서 ‘개요’와 ‘세부 정보’를 전환할 수 있습니다. 필요할 때 NVMe, ATA/SATA, USB-SAT, SCSI/SAS 장치 정보를 한 번 읽습니다. 디스크 상태, 남은 수명, 온도와 임계값, 전원 켜짐 시간 및 횟수, 누적 읽기·쓰기 용량, 미디어 및 읽기·쓰기 오류, PCIe 링크, SMART 속성이 표시되며 수동으로 다시 읽을 수 있습니다. 일련 번호는 프로토콜에서 제공하는 제조사 일련 번호를 우선하며 기본적으로 숨겨져 있습니다.
- **시스템 개요와 성능 그래프**: 프로세스 페이지 상단의 개요 카드를 새로 구성했습니다. 그래프는 카드를 가득 채우고 왼쪽 숫자 아래에서 서서히 흐려집니다. 상단에는 눈금의 최댓값을 표시하며 포인터를 올리면 카드 전체가 강조됩니다. CPU 온도, CPU 소비 전력, GPU 소비 전력을 추가했습니다. CPU 개요는 패키지와 코어의 소비 전력을 ‘소비 전력’ 항목으로 합쳐 표시합니다. 패키지 소비 전력을 우선하며 포인터를 올리면 측정 출처를 볼 수 있고 세부 정보 페이지에서는 두 그래프가 모두 표시됩니다. 디스크와 네트워크 그래프의 눈금은 정해진 단계에 따라 조절됩니다. 사이드바의 장치 미리 보기 등 작은 그래프에서는 보조 지표를 반투명 실선으로 그려 쉽게 구분할 수 있습니다.
- **Intel 내장 그래픽 지표**: 드라이버가 제공하는 온도, 클럭, 전압, 소비 전력 지표를 확장했습니다. 커널 센서(IntelMCHBAR 모듈)와 RAPL PP1을 통해 10세대 Intel Core(Comet Lake S/H) 내장 그래픽의 온도, 클럭, 공유 메모리 클럭, 코어 VID, GT 및 미디어 활동률과 소비 전력을 확인할 수 있습니다. 그래픽 슬라이스의 클럭이 차단된 상태를 구분하고 1 W 미만의 소비 전력을 표시합니다. 내장 그래픽의 소비 전력은 해당 GPU 페이지에 표시합니다. Windows 전력 카운터의 0보다 유효한 RAPL 값을 우선하며, 하드웨어와 드라이버에서 제공하지 않는 값은 ‘알 수 없음’으로 남습니다.
- **창 및 레이아웃**: ‘설정 → 시작 및 시스템 트레이’에서 시작할 때 열 기본 페이지를 선택할 수 있습니다. 펼친 사이드바의 오른쪽 가장자리를 드래그하면 너비를 조절하며 두 번 클릭하면 기본 너비로 복원합니다. 세부 정보 창을 ‘프로세스를 선택하면 표시’로 설정하면 프로세스를 선택할 때 창이 옆에서 나타나고 선택을 해제하면 접힙니다. 기록 페이지에서 시간 범위를 바꾸면 현재 시점까지의 최신 구간이 표시됩니다. 레이아웃 전체를 유지하도록 최소 창 크기를 1240×800으로 조정했으며 주 디스플레이의 작업 영역이 부족하면 그에 맞춰 줄어듭니다.
- **앱 정보 페이지, 업데이트 내용 및 공식 미러**: ‘앱 정보’를 별도의 탐색 페이지(Ctrl+8)로 만들고 Argus 공식 웹 사이트와 GitHub 저장소 링크 카드를 추가했습니다. 상태 표시줄 왼쪽의 버전 표시를 클릭하면 현재 버전의 업데이트 내용을 볼 수 있으며 마우스 오른쪽 버튼으로 클릭하면 버전 번호를 복사할 수 있습니다. 업데이트 내용을 범주별로 묶고 새 기능은 두 열의 카드로 표시합니다. 자동 업데이트에서 GitHub에 연결하지 못하면 공식 Argus 미러를 먼저 시도한 뒤 GitHub 프록시를 사용합니다. 설치 프로그램과 릴리스 노트의 서명은 계속 검증합니다.

### 성능

- **인터페이스 응답 및 고주사율 애니메이션**: 데이터 갱신, 텍스트 크기 측정, 반복 그리기에 드는 메인 스레드 부하를 줄였습니다. 그래프의 고정 배경과 합성 레이어를 재사용하고 큰 그래프의 텍스처는 여러 스레드에서 나눠 그립니다. 하드웨어 가속 GPU 일정 예약(HAGS)이 꺼져 있을 때 그래프의 GPU 사용률을 크게 줄였습니다. 페이지 전환, 세부 정보 창, 목록 스크롤, 열 재배치 애니메이션은 디스플레이 주사율에 맞춰 움직입니다. 멀티코어 격자와 GPU 엔진 그래프는 창 크기가 바뀌는 프레임에 즉시 맞춰 조절됩니다.
- **페이지 전환 및 백그라운드 실행**: 시작 후 서비스, 시작 프로그램, 연결 목록을 백그라운드에서 미리 읽어 처음 페이지에 들어갔을 때 바로 표시합니다. 인터페이스 설정 변경은 모아 두었다가 백그라운드에서 비동기로 저장하므로 페이지 전환이 멈추지 않습니다. 실시간 그래프가 없는 페이지는 수집할 때마다 다시 구성하지 않아 CPU 사용률이 낮아집니다. 창을 최소화하거나 시스템 트레이로 숨기면 그리기를 중단하고, 필요에 따라 그래프 레이어 캐시, 만료된 아이콘과 텍스처 아틀라스를 해제해 메모리와 GPU 메모리 사용량을 줄입니다.
- **높은 부하 및 메모리 부족**: 시스템이나 셸이 바빠도 조작과 수집에 빠르게 응답하도록 시스템 트레이 업데이트를 전용 스레드에서 모아 처리합니다. 메모리가 부족하면 그래프 버퍼와 텍스처 해상도를 낮춰 실시간 그래프를 계속 표시하고, 여유가 생기면 원래 품질로 복구합니다. 다른 창이 항상 위에 표시되어 넓은 영역을 가릴 때도 Argus 창을 더 안정적으로 활성화합니다.

### 수정

- **프로세스별 네트워크 트래픽**: 일부 시스템에서 지표가 계속 0으로 표시되거나 새로 고침 간격을 0.5초로 설정했을 때 지표가 번갈아 0이 되거나 늦게 갱신되는 문제를 해결했습니다.
- **특권 서비스**: 클라이언트가 파이프에 연결되기 전에 끊겼을 때 서비스가 비정상 종료되거나 자주 읽을 때 시간이 초과되거나 데이터가 없다고 잘못 표시되는 문제를 해결했습니다.
- **앱 이름 및 아이콘**: 패키지 앱(MSIX)에 작업 관리자의 앱 이름 대신 실행 파일 설명이 표시되던 문제를 해결했습니다. 장치 경로 매핑을 찾을 수 없거나 프로세스에 접근할 수 없을 때도 아이콘과 파일 설명을 표시하도록 개선했습니다.
- **프로세스별 GPU 메모리**: GPU 상주 메모리 카운터를 사용하고 프로세스와 물리 어댑터별로 중복 집계를 없앴습니다. 일부 시스템이나 드라이버에서 사용량이 과도하거나 중복으로 집계되던 문제를 해결하고, 읽을 수 없는 값과 사용량이 0인 경우를 구분합니다.
- **Intel 내장 그래픽 소비 전력 표시**: 유휴 내장 그래픽의 소비 전력이 CPU 개요에서 반복해서 나타났다 사라지는 문제를 해결했습니다.
- **CPU 가상화 상태**: 하드웨어 가상화가 켜진 Hyper-V 호스트에서 ‘사용 안 함’으로 표시되던 문제를 해결했습니다.
- **관리자 권한 실행 승인**: 사용자 이름과 컴퓨터 이름이 같으면 SID를 찾지 못해 승인이 실패하는 문제를 해결했습니다. 같은 버전에서 다시 빌드한 사본의 인식도 개선했습니다.
- **장시간 실행 시 메모리 사용량**: 내용이 같은 프로그램 아이콘을 하나만 보관하고 종료된 프로그램의 경로별 메타데이터 캐시를 주기적으로 비웁니다. 메타데이터를 확인하는 동안 쌓이는 요청 수도 제한합니다. 새 경로에서 짧게 실행되는 프로그램이 많을 때 메모리 사용량이 계속 늘어나던 문제를 해결했습니다.
- **외부 링크**: 공식 웹 사이트, 저장소, 릴리스 페이지 등의 외부 링크를 열 때 새 탐색기 프로세스를 거치지 않고 URL을 시스템 셸에 바로 전달합니다. 브라우저가 열리기까지의 지연이 줄었습니다.

### 업데이트 안내

- **시스템 요구 사항**: Windows 10 22H2(빌드 19045) 이상 또는 Windows 11이 필요하며 x64만 지원합니다. 그래픽 장치와 드라이버는 DirectX 11을 지원해야 합니다. 인터페이스에 WebView2 런타임은 더 이상 필요하지 않습니다.
- **설정 및 기록**: 애플리케이션 설정과 기록 파일은 유지됩니다. v0.3.3 또는 v0.3.4에서 업데이트하면 별도로 저장된 인터페이스 설정도 유지됩니다. v0.3.2 이하에서 바로 업데이트하면 레이아웃, 행 메모, 고정 등 이전 WebView2 캐시에만 저장된 인터페이스 설정은 기본값으로 돌아가 다시 설정해야 합니다. Argus는 이전 WebView2 데이터를 백그라운드에서 자동으로 정리합니다.
- **특권 서비스**: 통신 프로토콜이 버전 10으로 업데이트됩니다. 설치 프로그램이나 앱 내 업데이트로 버전을 올리면 설치된 특권 서비스와 작업 관리자 대체용 사본도 함께 업데이트됩니다. 포터블 버전은 실행 파일을 교체한 뒤 ‘설정 → 권한 → 특권 서비스’에서 ‘서비스 업데이트’를 선택하고 관리자 권한 요청을 승인해야 합니다.

## [0.3.3](https://github.com/Ray-lea/Argus/compare/v0.3.2...v0.3.3) - 2026-10-26

인터페이스 배율과 글자 크기 설정을 추가했습니다. 창과 목록 설정이 유지되도록 개선하고 GPU 사용률 집계 방식을 조정했습니다.

### 새 기능

- **인터페이스 배율**: ‘설정 → 언어 및 모양’에서 80%~150% 사이의 배율을 직접 입력할 수 있습니다. 기본값은 100%이며 113%처럼 정수 단위로 지정할 수 있습니다.
- **글자 크기**: 기본 글자 크기를 11~20 px(기본값 13 px)로 조절할 수 있습니다. 인터페이스 배율과 함께 적용되며 바꾸면 즉시 적용되고 자동으로 저장됩니다. 두 설정은 각각 기본값으로 되돌릴 수 있습니다.

### 수정

- **GPU 통계**: 일부 연산 작업에서 전체 사용률이 낮게 표시되거나, 데이터 수집을 재개할 때 사용률이 급등하거나, 여러 GPU나 엔진의 값을 합산할 때 사용률이 과다하게 표시되는 문제에 대한 개선을 시도했습니다. 프로세스의 엔진 카운터와 사용 가능한 NVIDIA GPU 코어 사용률로 전체 지표를 보완하며, 인터페이스에 지표 출처를 표시합니다. ([#19](https://github.com/Ray-lea/Argus/issues/19))
- **창 복원**: 종료한 뒤 다시 열면 창 크기, 위치, 최대화 상태를 복원합니다. 최소화한 상태로 종료해도 다시 실행할 때 최소화된 상태로 남지 않으며, 화면 밖의 창은 사용 가능한 디스플레이 영역으로 돌아옵니다.
- **목록 설정**: 프로세스, 서비스, 시작 프로그램, 연결 목록에서 정렬 기준 열과 오름차순 또는 내림차순 설정을 저장합니다. 서비스와 연결 페이지는 선택한 필터도 복원합니다.
- **인터페이스 설정 저장**: 인터페이스 설정을 별도로 저장하며, 이전 캐시에서 자동으로 가져옵니다. 인터페이스 캐시를 지워도 저장한 설정이 유지됩니다.
- **레이아웃과 창 버튼**: 글자 크기나 배율이 높아도 도구 모음과 탐색 메뉴가 좁은 창에 맞게 배치됩니다. 최대화 버튼을 클릭할 수 있는 영역도 배율에 맞게 조정됩니다.

### 업데이트 안내

- v0.3.x에서 업데이트하면 기존 설정과 기록이 유지됩니다. 처음 실행할 때 이전 인터페이스 설정을 자동으로 가져오므로 다시 설정할 필요가 없습니다.

## [0.2.0](https://github.com/Ray-lea/Argus/compare/v0.1.0...v0.2.0) - 2026-10-18

이 버전에서는 프로세스별 디스크 읽기 및 쓰기 속도를 확인할 수 있습니다. 최소화 상태와 시스템 트레이에 숨긴 상태의 새로 고침 간격을 각각 설정할 수 있습니다. 앱 내 업데이트와 바로 가기 키 설정을 다듬었으며, 일부 PC에서 일정 시간이 지나면 비정상 종료되는 문제 등을 해결했습니다. 특권 서비스가 설치되어 있다면 ‘호환성이 깨지는 변경’을 먼저 읽어 주세요.

### 호환성이 깨지는 변경

- **특권 서비스 업데이트 필요**: Argus와 특권 서비스 사이의 통신 방식이 바뀌었습니다. 0.1.0의 특권 서비스는 새 Argus와 함께 사용할 수 없습니다. 특권 서비스를 설치하지 않았다면 영향이 없습니다.
- **설치 프로그램으로 업데이트**: 앱 내 업데이트와 설치 프로그램 직접 실행에 모두 적용됩니다. 설치 프로그램은 작업 관리자 대체로 시작해 아직 실행 중인 이전 버전의 Argus를 종료하고, 같은 관리자 승인으로 특권 서비스도 업데이트합니다. 별도로 조작할 필요는 없습니다. ‘작업 관리자 대체’가 켜져 있으면 설정이 유지되며, 업데이트 후 Ctrl+Shift+Esc를 누르면 새 버전이 열립니다.
- **포터블 버전 업데이트**: 특권 서비스가 설치되어 있으면 실행 파일 교체 후 서비스를 수동으로 업데이트해야 합니다. 새 Argus의 안내 창이나 ‘설정 → 권한’에서 ‘서비스 업데이트’를 클릭하고 승인하세요. 설치 프로그램에서 서비스 업데이트가 실패한 경우에도 같은 방식으로 진행합니다. 서비스가 업데이트되기 전에는 서비스에 의존하는 네트워크, 디스크 읽기 및 쓰기, CPU 센서 데이터를 사용할 수 없고 관리자 권한이 필요한 관리 작업이 실패할 수 있습니다. ‘작업 관리자 대체’가 켜져 있으면 Ctrl+Shift+Esc로 이전 버전이 열릴 수 있습니다. 서비스를 업데이트하면 대체용 프로그램도 함께 업데이트되며 설정은 유지됩니다.

### 새 기능

- **프로세스별 디스크 읽기 및 쓰기**: 프로세스 페이지에 ‘디스크 읽기’와 ‘디스크 쓰기’ 열을 추가했습니다. 각 프로세스가 디스크에서 초당 읽고 쓰는 데이터 양을 표시하며, 두 열 모두 정렬할 수 있습니다. 앱별로 묶으면 그룹 합계가 표시되며 세부 정보 창에서도 볼 수 있습니다. I/O 열에는 네트워크와 장치의 읽기 및 쓰기도 포함되므로 두 열과 별도로 집계합니다. Windows 11 24H2 이상에서는 추가 권한이 필요하지 않습니다. 이전 버전의 Windows에서는 특권 서비스를 켜거나 Argus를 관리자 권한으로 실행해야 하며, 이 내용은 특권 서비스의 승인 안내에도 표시합니다. 값이 없으면 ‘—’로 표시되고 포인터를 올리면 이유를 볼 수 있습니다. 창이 좁아도 두 열은 표시하며, 이름 열을 왼쪽에 고정한 상태에서 표를 가로로 스크롤할 수 있습니다. 이를 위해 스레드, 핸들, PID, I/O 열은 이전보다 먼저 숨깁니다.
- **앱 내 업데이트**: 새 버전을 내려받아 서명 검증을 마치면 제목 표시줄 오른쪽에 업데이트 버튼을, 시스템 트레이 아이콘에 점을 표시합니다. 창 오른쪽 아래에는 버전마다 한 번만 알림을 표시합니다. 포터블 버전은 자동 다운로드 없이 새 버전을 찾는 즉시 알립니다. 업데이트 대화 상자에는 현재 버전부터 새 버전까지 버전별로 변경 사항을 분류해 표시하고 각 버전의 변경 건수를 표시합니다. 설치 프로그램과 마찬가지로 업데이트 내용도 서명을 검증합니다. 업데이트 버튼을 마우스 오른쪽 버튼으로 클릭하면 ‘이 버전은 다시 알리지 않기’를 선택할 수 있습니다. Argus를 다시 시작해도 이미 내려받은 업데이트를 다시 받을 필요는 없습니다.
- **업데이트 후 변경 사항 표시**: 업데이트한 뒤 처음 창을 열 때 새 버전의 변경 사항을 표시합니다. ‘설정 → 업데이트’에서 ‘업데이트 후 변경 사항 표시’를 끄면 오른쪽 아래에 완료 알림만 표시됩니다. 같은 페이지의 ‘이 버전의 변경 사항 보기’로 언제든지 다시 열 수 있습니다.
- **백그라운드 새로 고침 간격**: ‘설정 → 데이터 및 기록’이나 첫 실행 안내에서 최소화 상태와 시스템 트레이에 숨긴 상태의 새로 고침 간격을 각각 0.5~30초 사이로 설정할 수 있습니다. 기본값은 5초입니다. 5초보다 짧게 설정하면 CPU 사용률과 전력 사용량이 증가한다고 미리 알립니다. 5초보다 길게 설정하면 기록을 남기는 간격도 길어집니다. 창을 맨 앞으로 가져오면 즉시 새로 고침합니다. 백그라운드 간격이 화면에 표시 중일 때보다 길면 오른쪽 아래에 한 번 알림을 표시하며, 알림에서 설정으로 이동하거나 다시 표시하지 않도록 할 수 있습니다.
- **바로 가기 키 설정**: 키 조합을 유지한 채 바로 가기 키를 끌 수 있으며 다시 켜면 이전 조합을 복원합니다. 키 조합을 입력할 때 누르고 있는 키를 실시간으로 표시하고 사용할 수 없는 조합은 이유를 안내합니다. ‘기본값 복원’도 사용할 수 있습니다. Ctrl+문자 키나 Alt+문자 키처럼 다른 프로그램과 충돌하기 쉬운 조합은 확인 후에만 저장합니다. 다른 프로그램이 조합을 사용 중이면 즉시 다시 시도할 수 있습니다. 해당 프로그램이 종료된 뒤 Argus 창을 다시 표시하면 자동으로 재시도합니다.
- **CPU 작동 시간**: ‘5일 14:03:07’처럼 초 단위로 표시하며 새로 고칠 때마다 갱신합니다.

### 수정

- **비정상 종료**: 사용할 수 있는 Intel 그래픽 어댑터가 없는 일부 PC에서 Argus를 일정 시간 실행하면 비정상 종료되던 문제를 해결했습니다.
- **설정 손실**: 설정 저장 직후 전원이 끊기거나 강제로 다시 시작하면 설정이 사라져 첫 실행 안내가 다시 표시되거나 언어가 시스템 기본값으로 돌아가던 문제를 해결했습니다.
- **Windows 시작 시 자동 실행**: Windows 시작과 함께 실행될 때 Argus 창이 더 이상 다른 창에 가 있던 포커스를 가로채지 않습니다. 이전에는 다른 곳을 클릭할 때까지 보이지 않는 Argus 창으로 키 입력이 전달되었습니다. 시스템 트레이에 숨겨져 있을 때 계속 화면을 그리지 않아 인터페이스의 CPU와 GPU 사용률이 크게 줄고 메모리 사용량도 절반 이상 줄었습니다.
- **자동 시작 항목**: Ctrl+Shift+Esc로 연 Argus에서 ‘Windows에 로그인할 때 시작’을 켜면 시작 항목이 설치된 Argus를 가리킵니다. 이미 작업 관리자 대체용 사본을 가리키면 시작 메뉴 등에서 새 버전을 한 번 열 때 자동으로 바로잡습니다.
- **백그라운드 새로 고침**: 최소화 상태나 시스템 트레이에 숨긴 상태의 실제 새로 고침 간격이 설정값과 일치합니다. 이전에는 5초로 설정해도 흔히 6초, 때로는 10초가 걸렸습니다. 표준 권한과 특권 서비스를 함께 사용할 때 시스템 트레이나 최소화 상태에서 창을 복원하면 프로세스 페이지의 네트워크 열이 잠깐 사라지던 문제도 해결했습니다.
- **창**: 최대화 상태에서 오른쪽 위에 창 버튼 두 세트가 겹쳐 표시되지 않습니다. 포인터가 화면 맨 위에 닿아 있어도 창을 드래그할 수 있습니다.
- **설치 및 제거 프로그램**: 이전에는 약간 왼쪽으로 치우쳐 있던 완료 페이지의 ‘닫기’ 버튼, 제거 확인 페이지의 ‘취소’ 버튼, 확인란이 있는 행을 가운데에 맞췄습니다.
- **설치 프로그램으로 업데이트**: 설치 프로그램을 직접 실행해 업데이트하면 Ctrl+Shift+Esc 또는 이전 자동 시작 항목으로 열려 아직 실행 중인 이전 버전의 Argus도 함께 종료합니다. 업데이트 후 실행 요청이 이전 버전으로 넘어가지 않으며, 미리 시스템 트레이에서 종료할 필요도 없습니다.
- **제거**: Ctrl+Shift+Esc로 열려 실행 중인 Argus도 제거 과정에서 종료합니다. 이전에는 백그라운드에 계속 남아, ‘설정, 기록 및 로그도 삭제’를 선택해 제거하고 다시 설치해도 첫 실행 안내가 표시되지 않고 이전 설정이 다시 저장되었습니다. 데이터를 모두 삭제하지 못하면 제거 프로그램에 남은 폴더를 표시합니다.
- **첫 실행 안내**: Ctrl+Shift+Esc를 누른 채 Argus를 열 때 누르고 있는 Esc 키로 안내가 닫히거나 완료 처리되지 않습니다.
- **바로 가기 키 입력**: 키 조합을 입력하는 동안 기존 조합을 누르거나 키를 조금 오래 눌러도 창이 의도치 않게 숨겨지지 않습니다. 미국식 이외의 키보드 레이아웃에서도 입력한 키와 실제로 동작하는 키가 일치합니다. Shift+Backspace나 Win+Backspace를 눌렀을 때 바로 가기 키가 잘못 지워지는 문제도 해결했습니다.
- **바로 가기 키 조합**: 새 키 조합에는 Ctrl, Alt, Win 중 하나가 포함되어야 합니다. F13~F24 등 일부 키는 예외입니다. 입력에 방해되는 Shift+문자 키나 Ctrl+C, Alt+F4 등 일반적인 편집·시스템 조합은 새 바로 가기 키로 지정할 수 없습니다. 이전에 저장한 조합은 그대로 유지됩니다.
- **바로 가기 키**: 숫자 키패드의 일부 키가 다른 키로 등록되던 문제를 해결했습니다. 바로 가기 키를 바꿀 때 설정 저장에 실패해도 삭제할 수 없는 바로 가기 키가 남지 않습니다. 등록 실패의 이유는 인터페이스 언어로 표시합니다. 첫 실행 안내에서 이미 사용 중이거나 지정할 수 없는 조합에는 이유와 설정에서 바꿀 수 있다는 안내만 표시합니다.
- **작업 관리자 대체**: 특권 서비스를 업데이트할 때 대체 설정은 유지되며, 대체용 Argus도 새 버전으로 바뀝니다. Windows 작업 관리자로 먼저 복원한 뒤 대체를 다시 켤 필요가 없습니다. 대체를 켜지 못하면 거부된 단계와 보안 소프트웨어의 레지스트리 변경 차단 등 가능한 원인을 표시합니다. ‘다른 프로그램에서 구성됨’이 표시될 때는 관련 설정을 구체적으로 보여 줍니다. 대체를 끈 뒤 Process Explorer 등 다른 도구가 작업 관리자를 대신해도 특권 서비스 업데이트나 제거를 막지 않습니다. 대체를 켜지 못했을 때 서비스 폴더에 불필요한 Argus 사본을 남기지 않습니다. 이전에 남은 사본은 Argus 버전을 올리거나, 대체를 켜거나 끄거나, 특권 서비스를 업데이트하거나 제거할 때 정리합니다. 현재 실행 중인 사본은 삭제하지 않습니다.
- **프로세스**: 선택한 항목이 없을 때 ‘세부 정보 표시’를 클릭하면 먼저 목록의 항목을 선택하라는 안내가 표시됩니다. 이전에는 클릭해도 아무 반응이 없었습니다. 바로 가기 메뉴나 확인 대화 상자가 열려 있을 때는 상태 표시줄에 ‘목록 위에 포인터가 있어 정렬이 일시 중지됨’을 표시하지 않으며, 확인 창이 열리는 순간 목록이 다시 정렬되지 않습니다. 목록에 포인터를 올린 채 바로 가기 키로 페이지를 바꿔도 이전 메시지가 다른 페이지에 남지 않습니다.
- **그래프**: 그래프 오른쪽 끝 근처에 포인터를 올렸을 때 값을 나타내는 점이 끊기던 문제를 해결했습니다.
- **업데이트 채널 전환**: 업데이트 확인 또는 다운로드 도중 안정 버전과 베타 사이에서 채널을 바꾸면 새 채널을 다시 확인하고 이전 채널의 버전은 표시하지 않습니다.
- **진단 로그**: 실패한 작업에는 일반 오류 메시지 대신 시스템 오류 코드가 기록됩니다. 이전에는 영어가 아닌 시스템에서 오류 대부분이 `operation failed`로만 기록되었습니다. 시작할 때 특권 서비스에 연결하지 못하면 버전 불일치, 응답 시간 초과 등 그 이유도 기록합니다.

### 성능

- **프로세스 페이지**: 시스템 개요에서 논리 프로세서별 사용률 막대를 그리는 데 드는 부하를 줄였습니다. 그래프가 움직이는 동안 프레임마다 GPU에 보내는 데이터를 약 3분의 1 줄였습니다. I/O 열에서 WebView2의 읽기 및 쓰기 대부분이 이 데이터에서 발생하므로 함께 줄었습니다.

### 알려진 제한 사항

- **디스크 읽기 및 쓰기**: Windows 11 24H2 이상에서 사용하는 조회 방식은 빌드 26300에서만 검증했습니다. 이전 버전의 Windows에서는 특권 서비스나 관리자 권한으로 값을 읽는데, 해당 시스템에서는 아직 검증하지 못했습니다. 두 열에 계속 ‘—’가 표시되면 조회 실패 이유가 담긴 진단 로그를 첨부해 보고해 주세요.
- **코드 서명**: 프로그램에 아직 코드 서명이 없어 처음 실행할 때 Windows SmartScreen에서 ‘알 수 없는 게시자’ 경고가 표시될 수 있습니다.
- **기타**: 다른 제한 사항은 GitHub의 [알려진 문제](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md) 문서를 참조하세요.

## 0.1.0 - 2026-10-16

Argus의 첫 공개 버전입니다.

### 새 기능

- **프로세스**: 앱별, 프로세스 트리, 목록으로 볼 수 있습니다. 목록에서 이름으로 정렬하면 ‘앱’과 ‘백그라운드 프로세스’로 나뉩니다. 프로세스별 CPU, 메모리, I/O, GPU 사용량을 볼 수 있으며, 특권 서비스를 사용하거나 관리자 권한으로 실행하면 네트워크 트래픽도 표시됩니다. 프로세스를 검색하고 개별 작업이나 프로세스 트리 전체를 끝낼 수 있습니다. 세부 정보 창에는 명령줄, 사용자, 무결성 수준 등이 표시되며, 앱별로 묶으면 앱 전체의 합계도 표시됩니다.
- **우선 순위와 효율성 모드**: 바로 가기 메뉴에서 설정하거나 프로그램을 시작할 때마다 자동으로 적용되는 규칙을 만들 수 있습니다.
- **성능**: CPU(코어별 정보, P 코어 및 E 코어, 클럭, 온도, 소비 전력, 유휴 상태), 메모리, 디스크, 네트워크, GPU(NVIDIA, AMD, Intel GPU의 와트 단위 소비 전력 포함), 배터리를 모니터링합니다. 그래프는 화면 주사율에 맞춰 움직이고 창 크기에 따라 조절됩니다. 자주 사용하지 않는 정보는 펼칠 수 있는 카드에 표시합니다.
- **커널 센서(선택 사항)**: 설정이나 첫 실행 안내에서 켜면 특권 서비스와 공식 PawnIO 드라이버로 CPU 내부 센서를 읽습니다. 코어별 온도와 전압, 소비 전력과 제한 상태, AMD SMU 데이터, 지원하는 메인보드의 팬 속도, 전압 및 온도를 확인할 수 있습니다.
- **서비스 및 시작 프로그램**: 서비스를 시작하거나 중지하고 시작 유형을 바꿀 수 있습니다. Windows 작업 관리자와 동일한 설정으로 시작 항목의 사용 여부를 바꿀 수 있습니다.
- **연결 및 포트**: TCP 및 UDP 엔드포인트와 소유 프로세스를 표시합니다. 포트 번호를 정확히 일치시켜 검색하거나 IPv4 TCP 연결을 끊을 수 있습니다.
- **파일 사용 여부 조회**: 파일이나 폴더를 창으로 끌어 놓으면 Restart Manager와 핸들 열거를 통해 해당 경로를 사용 중인 프로세스를 찾습니다. 프로세스가 현재 작업 폴더로 사용하는 경우도 찾을 수 있습니다.
- **이전 기록 조회**: 최근 7일의 리소스 사용량을 기록합니다. 원하는 시점을 클릭하면 그때 사용량이 가장 높았던 프로세스를 볼 수 있습니다.
- **시스템 트레이에서 실행**: 전역 바로 가기 키 Ctrl+Alt+Esc로 창을 표시하거나 숨길 수 있습니다. 창이 숨겨져 있으면 리소스를 거의 사용하지 않습니다.
- **특권 서비스(선택 사항)**: 한 번 관리자 권한을 승인하면 인터페이스를 표준 권한으로 실행해도 시스템 프로세스 관리, 규칙 자동 적용, 프로세스별 네트워크 트래픽 집계, 서비스 제어, 연결 끊기를 사용할 수 있습니다.
- **작업 관리자 대체**: Ctrl+Shift+Esc 등 작업 관리자를 여는 경로에서 Argus가 열리도록 설정할 수 있습니다. 인터페이스나 서비스 없이 사용할 수 있는 별도의 복원 프로그램도 제공합니다.
- **앱 내 업데이트**: 안정 버전과 베타 채널을 제공하며 GitHub 다운로드 프록시를 선택할 수 있습니다. 서명 검증을 통과한 버전만 설치합니다.
- **모양**: 도구 모음은 제목 표시줄을 겸하고 탐색 메뉴는 도구 모음 아래 또는 창 왼쪽에 표시됩니다. Mica 배경과 시스템 강조색을 사용합니다. 밝은 테마와 어두운 테마는 기본적으로 Windows 설정을 따르며 설정에서 직접 선택할 수 있습니다.
- **설치 및 제거**: 한 페이지로 구성된 설치 프로그램은 Windows의 밝은 모드와 어두운 모드를 따릅니다. 이전 버전이 설치되어 있으면 그 위치에 업데이트하며, 제거할 때 설정과 기록, 로그를 함께 삭제할 수 있습니다.
- **언어 및 첫 실행 안내**: 인터페이스, 시스템 트레이, 설치 프로그램은 중국어 간체와 영어를 지원하며 기본적으로 Windows 표시 언어를 따릅니다. 처음 실행할 때 안내에 따라 언어, 화면 표시와 새로 고침, 시스템 트레이 실행, 업데이트 등 자주 쓰는 옵션을 설정할 수 있습니다. 이때 특권 서비스 설치, 커널 센서 사용, 작업 관리자 대체도 바로 설정할 수 있습니다.

### 알려진 제한 사항

- 프로그램에 아직 코드 서명이 없어 처음 실행할 때 Windows SmartScreen에서 ‘알 수 없는 게시자’ 경고가 표시될 수 있습니다.
- CPU 내부 센서를 읽으려면 커널 센서(특권 서비스와 PawnIO 드라이버)를 켜야 합니다. 지원하는 프로세서와 메인보드는 [하드웨어 데이터](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围) 문서를 참조하세요.
- 다른 제한 사항은 [알려진 문제](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md) 문서를 참조하세요.

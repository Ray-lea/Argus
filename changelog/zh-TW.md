## [0.5.0](https://github.com/Ray-lea/Argus/compare/v0.4.0...v0.5.0) - 2026-11-12

v0.5.0 新增處理程序暫停與繼續、依使用者將處理程序分組、四個處理程序資訊欄與依內容計算的欄寬，效能頁的裝置清單支援隱藏與排序，介面新增繁體中文、西班牙文、德文、日文、法文和俄文。本版亦避免部分 Intel RST 系統在 Argus 啟動後凍結，修正 USB 磁碟無法安全移除等問題，並降低視窗隱藏後的記憶體與 CPU 使用量。

### 新功能

- **暫停與繼續處理程序**：處理程序與應用程式群組的快顯功能表新增「暫停處理程序」和「繼續處理程序」。暫停前會顯示影響說明並要求確認；系統關鍵處理程序、桌面視窗管理員與 Argus 本身無法暫停。已暫停的處理程序會在名稱後顯示「已暫停」標記。（[@digital-bombyx](https://github.com/digital-bombyx) [#65](https://github.com/Ray-lea/Argus/pull/65)）
- **處理程序資訊欄**：新增「檔案版本」、「架構」、「已提高權限」和「命令列」四個選用資料欄，預設隱藏，可在欄標題的快顯功能表或「選取資料欄」中啟用。（[@digital-bombyx](https://github.com/digital-bombyx) [#72](https://github.com/Ray-lea/Argus/pull/72)）
- **處理程序欄寬**：自動欄寬依內容計算，剩餘空間保留在表格右側。拖曳欄邊界可單獨調整一欄的寬度，按兩下欄邊界可還原自動寬度。欄標題功能表新增「全寬」，開啟後「名稱」欄會佔用剩餘寬度。
- **依使用者將處理程序分組**：「設定 → 語言與外觀 → 依使用者將處理程序分組」提供自動、一律分組和不分組三種方式；自動方式僅在多位使用者登入時分組。群組列的快顯功能表提供「管理使用者帳戶」和「登出」。
- **隱藏系統處理程序**：處理程序頁與連線頁新增「隱藏系統處理程序」開關，預設關閉，兩頁分別儲存開關狀態。一律顯示與額外隱藏的程式清單可在設定頁編輯。（[#32](https://github.com/Ray-lea/Argus/issues/32)）
- **處理程序樹與概況列**：處理程序樹預設收合，欄標題的快顯功能表提供「全部展開」和「全部收合」。「處理程序概況列」可設為自動、一律顯示或隱藏；設為自動時，若視窗高度不足，則收合概況列。
- **效能頁裝置清單**：在裝置上按一下滑鼠右鍵可將其隱藏，也可在「顯示的裝置」子功能表中逐項選取。拖曳裝置可調整順序；磁碟可依磁碟編號、磁碟機代號或自訂順序排列。
- **CPU 多核心檢視**：各邏輯處理器的小圖顯示核心時間，可在 CPU 圖表的快顯功能表中關閉。識別 Intel 低功耗效率核心（LP E 核心），以獨立色彩顯示，並支援單獨篩選。小圖優先排成沒有空位的列與欄。
- **硬體資訊**：GPU 頁顯示驅動程式版本、驅動程式日期與 DirectX 版本（含功能層級）。磁碟詳細資料支援更多 SATA SSD 的剩餘壽命與累計讀寫量，並新增傳統硬碟的通電時間、啟停次數、重映射與待映射磁區等統計。
- **介面語言**：新增繁體中文、西班牙文、德文、日文、法文和俄文。介面、系統匣、系統提示與安裝程式均提供譯文，數字與日期採用 Windows 地區格式。（[@abc0922001](https://github.com/abc0922001) [#45](https://github.com/Ray-lea/Argus/pull/45)、[@Rimuwu](https://github.com/Rimuwu) [#51](https://github.com/Ray-lea/Argus/pull/51)、[@s0ftw4r8](https://github.com/s0ftw4r8) [#52](https://github.com/Ray-lea/Argus/pull/52)、[@khativari](https://github.com/khativari) [#55](https://github.com/Ray-lea/Argus/pull/55)、[@hayxe1](https://github.com/hayxe1) [#62](https://github.com/Ray-lea/Argus/pull/62)）
- **更新內容**：關於頁與更新對話方塊依介面語言顯示更新內容。「設定 → 更新」改為透過「檢視更新內容」按鈕開啟更新對話方塊，對話方塊提供「全部展開」和「全部收合」。開啟、展開與游標停留時的轉場遵循「介面動畫」設定。
- **圖示與動態效果**：介面圖示改用 Lucide 圖示庫。指標移到按鈕或導覽項目上時，圖示會播放一次短暫的動態效果；關閉「介面動畫」後不播放。
- **視窗與系統匣**：新增獨立的「視窗轉場動畫」開關。「從系統匣開啟」可設為開啟預設頁面。預設視窗尺寸調整為 1000×680，最小尺寸降至 640×480。（[#27](https://github.com/Ray-lea/Argus/issues/27)、[#40](https://github.com/Ray-lea/Argus/issues/40)）
- **工作管理員取代**：「取代系統工作管理員」新增「暫時開啟系統工作管理員」，可開啟 Windows 內建的工作管理員，取代設定維持不變。
- **提示與提醒**：免安裝版會在首次啟動導覽和視窗右下角說明其與安裝版的差異，並提供安裝版的下載入口。新增「Star 提醒」，每天最多顯示一次，可在「設定 → 更新」中關閉。「本機規格」上方的操作提示可收合。
- **Telegram 頻道**：「關於 → 專案與支援」新增「Telegram 頻道」。按一下「加入頻道」開啟 [t.me/argustask](https://t.me/argustask)，按一下「複製連結」複製頻道連結。

### 效能

- **背景記憶體使用量**：新增「隱藏時釋放記憶體」設定。視窗最小化或隱藏至系統匣達到設定時間（預設 10 分鐘）後，Argus 會釋放圖表影像，並將未使用的記憶體歸還 Windows。所有視窗皆隱藏或最小化時，減少介面相關的 CPU 使用量；資料擷取、歷程記錄與規則照常運作。（[@SpookySandwich](https://github.com/SpookySandwich) [#54](https://github.com/Ray-lea/Argus/pull/54)）

### 修正

- **系統凍結**：不再向 RAID 控制器（如 Intel RST）後方的磁碟查詢溫度，以避免部分驅動程式版本沒有回應，導致系統在 Argus 啟動數秒後凍結。此類磁碟的溫度顯示為未知。（[#48](https://github.com/Ray-lea/Argus/issues/48)）
- **USB 磁碟安全移除**：修正磁碟監控持續佔用裝置，導致 USB 磁碟無法安全移除的問題。（[#57](https://github.com/Ray-lea/Argus/issues/57)）
- **磁碟清單與效能資料**：修正部分 NVMe 磁碟僅顯示裝置資訊而沒有效能資料，以及效能計數器無法使用時磁碟從清單中消失的問題。
- **磁碟詳細資料**：修正 SMART 屬性表數值遠離屬性名稱、分組留下大片空白，以及窄視窗中原始值遭裁切的問題。健康條的正常狀態統一使用綠色，溫度與備用空間依閾值區分警告色彩。
- **處理程序資料**：系統查詢緩慢時，處理程序清單仍會更新，資源讀值保留最近一次有效值。修正已結束的處理程序持續留在清單，以及暫停重新整理期間操作處理程序後狀態未更新的問題。（[#66](https://github.com/Ray-lea/Argus/issues/66)）
- **處理程序表格**：效率模式與釘選標記緊隨名稱顯示，欄標題與資料欄的邊界保持對齊。處理程序使用率補上百分號。
- **連線頁**：沒有所屬處理程序的連線現在顯示為「無所屬處理程序」。
- **CPU 讀值**：修正混合架構處理器的速度顯示異常、部分六核心 Ryzen 處理器的各核心電壓與溫度讀值錯誤，以及 Intel 內部感測器讀值間斷導致溫度折線中斷的問題。（[#58](https://github.com/Ray-lea/Argus/issues/58)）
- **授權與解除安裝**：修正 Program Files 或執行目錄的權限變更後無法撤銷授權與解除安裝、已在執行的 PawnIO 驅動程式無法用於核心感測器，以及解除安裝後殘留 Argus Sensor Setup 資料夾與空的 Argus Runtime 資料夾的問題。（[#46](https://github.com/Ray-lea/Argus/issues/46)）
- **啟動權限**：安裝完成或應用程式內更新後，Argus 優先使用桌面帳戶的權限啟動，與從捷徑啟動一致。以系統管理員身分執行的 Argus 可重新啟動已經以系統管理員權限執行的檔案總管，並保留其原有權限。
- **視窗顯示**：修正還原視窗尺寸後介面僅顯示在左上角、從工作管理員取代入口冷啟動後最大化視窗顯示不完整、Windows 11 21H2 下視窗背景透明，以及切換應用程式後視窗仍遮擋其他視窗的問題。（[#44](https://github.com/Ray-lea/Argus/issues/44)、[#37](https://github.com/Ray-lea/Argus/issues/37)、[#35](https://github.com/Ray-lea/Argus/issues/35)）
- **系統匣**：修正關閉視窗並隱藏至系統匣後 CPU 使用量持續偏高，以及應用程式內更新後系統匣圖示移入溢位區的問題。（[#31](https://github.com/Ray-lea/Argus/issues/31)）
- **介面顯示**：修正更新對話方塊載入時偏離置中、檔案使用狀況對話方塊在結果出現後抖動，以及關於頁在較矮視窗中無法捲動至全部內容的問題。文字方塊的快顯功能表依介面語言顯示。（[#39](https://github.com/Ray-lea/Argus/issues/39)）
- **數字與繪製**：修正動態數字重新整理時水平跳動、深色佈景主題下淺色文字的邊緣顯示異常，以及概況列底部出現細小彩色殘影的問題。
- **執行穩定性**：修正顯示時序異常或網路介面卡位址列舉連續失敗時程式結束，以及圖形裝置復原與關閉視窗同時發生時介面停止回應的問題。
- **大字級、處理程序規則與啟動項目**：修正大字級下效能頁讀值與規格資訊重疊、程式名稱含非 ASCII 字母時從處理程序功能表重複新增規則，以及讀取應用程式套件啟動工作時程式當機的問題。（[@hayxe1](https://github.com/hayxe1) [#59](https://github.com/Ray-lea/Argus/pull/59)）
- **版本類型**：設定頁、關於頁與狀態列依目前程式的實際組建顯示「開發版」、「測試版」、「穩定版」，更新通道獨立控制後續檢查的版本來源。

### 升級提示

- **特殊權限服務**：本版將服務通訊協定升級至第 11 版。安裝版透過安裝程式或應用程式內更新升級時，會同步更新已安裝的服務與工作管理員取代副本；免安裝版替換程式後，需在「設定 → 權限 → 特殊權限服務」按一下「更新服務」，並完成系統管理員確認。
- **設定與歷程記錄**：升級會保留現有的設定與歷程記錄。「視窗轉場動畫」首次啟動時沿用原「介面動畫」對視窗轉場的設定。

## [0.4.0](https://github.com/Ray-lea/Argus/compare/v0.3.4...v0.4.0) - 2026-11-06

v0.4.0 將應用程式介面從 Tauri、SolidJS 與 WebView2 全面遷移至 Rust + GPUI Kit 原生技術架構，省去瀏覽器引擎的資源負擔，重製 DirectX 原生繪製與互動，並深入最佳化高更新率動畫、即時折線繪製、清單取樣更新及背景常駐的資源使用量。本版亦新增自訂處理程序資料欄、磁碟健康狀態與 SMART 詳細資料、更多 Intel 內顯讀值及視窗版面配置選項。[Argus 官方網站](https://argustask.com/zh-TW/)現已上線，並接入官方更新鏡像。

### 新功能

- **自訂處理程序資料欄**：涵蓋基本資訊、CPU、記憶體、磁碟與 I/O、網路、GPU 六大類共 40 欄，新增專用與共用 GPU 記憶體、GPU 引擎、映像名稱、虛擬位址空間、工作集尖峰、分頁錯誤次數及累計 I/O 等參數。虛擬位址空間與工作集尖峰依個別處理程序顯示。欄標題的快顯功能表提供分類子功能表，支援連續勾選；「選取資料欄」對話方塊支援分類篩選、搜尋與雙欄排序。拖曳欄標題或已選資料欄時會即時換位並平滑讓位；自動欄寬依數值格式預留空間以避免跳動，亦支援手動調整欄寬。平面清單與處理程序樹檢視的「名稱」欄與依應用程式檢視一致，優先顯示應用程式名稱或檔案描述，執行檔名稱則以次要文字呈現，或透過「映像名稱」欄檢視。
- **磁碟健康狀態與詳細資料**：磁碟效能頁新增「概觀／詳細資料」切換，依需求單次讀取 NVMe、ATA／SATA、USB-SAT 和 SCSI／SAS 裝置資訊，顯示健康狀態、剩餘壽命、溫度與臨界值、通電時間與次數、讀寫總量、媒體與讀寫錯誤統計、PCIe 連結及 SMART 屬性，支援手動重新讀取；序號優先採用通訊協定識別資訊中的廠商序號，並預設隱藏。
- **系統概況與效能圖表**：重新設計處理程序頁頂端的概況列，折線貼齊邊緣鋪滿卡片，並在左側數字下方漸隱；頂端標示量程上限，游標停留時整張卡片會醒目顯示。卡片新增 CPU 溫度、CPU 功耗與 GPU 功耗。效能頁的 CPU 概觀將封裝功耗與核心功耗合併為單一「功耗」項目（優先顯示封裝功耗，游標停留時說明來源，詳細資料頁仍保留雙折線）；磁碟與網路圖表依固定級距調整量程；側欄裝置預覽等小型圖表的次要資料序列改用半透明實線，提升小尺寸下的辨識度。
- **Intel 內顯讀值**：擴充驅動程式提供的溫度、時脈、電壓與功耗資訊，並透過核心感測器（IntelMCHBAR 模組）與 RAPL PP1 補充第 10 代 Core（Comet Lake S/H）內顯的溫度、時脈、共用記憶體時脈、核心 VID、GT／媒體活動率與功耗。區分圖形切片的時脈閘控狀態，支援顯示低於 1 W 的功耗，並將內顯功耗歸入對應的 GPU 頁；有效的 RAPL 功耗讀值優先於 Windows 功耗計數器的零值，硬體與驅動程式未提供的項目維持未知。
- **視窗與介面配置**：可在「設定 → 啟動與背景」選擇啟動時預設開啟的頁面；展開的側邊導覽列支援拖曳右邊緣調整寬度（按兩下可還原預設值）；詳細資料窗格新增「選取處理程序時顯示」模式，選取處理程序即滑出，取消選取後自動收合；歷程記錄頁切換時間範圍後，一律顯示截至目前的最新時段；視窗最小尺寸調整為 1240×800，以維持完整配置，主螢幕可用區域不足時會自動縮小以配合。
- **關於頁、更新內容與官方鏡像**：「關於」獨立為導覽頁面（快速鍵 Ctrl+8），新增 Argus 官方網站與 GitHub 儲存庫的雙連結卡片；狀態列左端顯示版本徽章，按一下可檢視本版本更新內容，按右鍵可複製版本編號；更新內容依類別分組顯示，新功能以雙欄卡片列出；自動更新連線 GitHub 失敗時，會優先嘗試 Argus 官方鏡像，再改用加速 Proxy，安裝套件與更新說明同樣會驗證簽章。

### 效能

- **介面回應與高更新率動畫**：減少取樣更新、文字測量與重複繪製造成的主執行緒負擔，重複利用圖表靜態背景與合成圖層，透過多執行緒平行繪製大型折線紋理，大幅降低關閉硬體加速 GPU 排程（HAGS）時圖表的 GPU 使用量；頁面切換、詳細資料窗格、清單捲動與資料欄重排動畫依螢幕更新率流暢播放，調整視窗大小時，多核心網格與 GPU 引擎圖會在同一影格內即時縮放。
- **頁面切換與背景常駐**：啟動後在背景預先讀取服務、啟動項目與連線清單，首次進入頁面即可顯示；介面偏好改為在背景非同步合併寫入磁碟，消除切換頁面的停頓；停留在沒有即時圖表的頁面時，略過重複建構以降低 CPU 使用量；視窗最小化或隱藏至系統匣後停止繪製，並依需求回收折線圖層快取、過期圖示與紋理圖集，減少背景記憶體與顯示記憶體用量。

- **免安裝版升級須知**：已安裝特殊權限服務時，替換主程式後仍需手動更新服務。在新版 Argus 的提示方塊或「設定 → 權限」按一下「更新服務」並授權即可。安裝程式更新服務失敗時，亦依此方式處理。服務更新前，依賴服務的網路、磁碟讀寫與 CPU 感測器資料暫時無法取得，需要提高權限的管理操作可能失敗。已開啟「取代系統工作管理員」時，Ctrl+Shift+Esc 仍可能開啟舊版；更新服務會一併更新取代程式，並維持取代功能開啟。

### 新功能

- **各處理程序的磁碟讀寫**：處理程序頁新增「磁碟讀取」與「磁碟寫入」兩欄，顯示各處理程序每秒讀寫磁碟的資料量，並可排序；依應用程式分組時顯示群組合計，詳細資料窗格亦可檢視。I/O 欄也包含網路與裝置的讀寫，與這兩欄分開統計。Windows 11 24H2 及更新版本無需額外權限；更早的系統需啟用特殊權限服務或以系統管理員身分執行，特殊權限服務的授權說明已加入此項。暫時沒有讀值時顯示「—」，游標停留時可檢視原因。視窗較窄時仍保留這兩欄，表格可左右捲動，名稱欄固定於左側；因此，執行緒、控制代碼、PID 與 I/O 欄會比以往更早隱藏。
- **應用程式內更新**：從本版本開始，新版本下載完成並通過簽章驗證後，標題列右側會出現更新按鈕，系統匣圖示顯示圓點，右下角亦會提示一次，每個版本僅提示一次。免安裝版不會自動下載，發現新版本時即提示。更新對話方塊依類別列出目前版本至新版本之間各版本的更新內容，並註明各版本的變更項目數；更新內容與安裝套件一樣經過簽章驗證。以滑鼠右鍵按一下更新按鈕可選取「此版本不再提醒」。已下載的更新在重新啟動 Argus 後無需重新下載。
- **更新後顯示更新內容**：更新完成後首次開啟視窗時，顯示新版本的更新內容。如不需要，可在「設定 → 更新」關閉「更新後顯示更新內容」，之後僅在右下角提示已更新。同頁的「檢視本版本更新」可隨時開啟更新內容。
- **背景重新整理間隔**：最小化與隱藏至系統匣時的重新整理間隔可分別設定，可選 0.5 至 30 秒，預設為 5 秒，在「設定 → 資料與歷程」及首次啟動導覽中修改。設為短於 5 秒時，會先說明 CPU 使用量與耗電將增加；長於 5 秒時，歷程記錄的密度亦會降低。視窗回到前景時立即重新整理；背景間隔比前景的重新整理間隔長時，右下角會提示一次，可直接前往設定調整，亦可選擇不再提醒。
- **快速鍵設定**：可僅停用快速鍵並保留組合，重新啟用即恢復。錄製時即時顯示目前按住的按鍵，無法使用的組合會說明原因，亦可按一下「重設為預設值」。Ctrl+字母、Alt+字母等容易與其他程式衝突的組合，經確認後才會儲存。組合被其他程式占用時可直接重試；占用的程式結束後，再次顯示視窗時亦會自動重試。
- **CPU 運作時間**：精確至秒，例如「5 天 14:03:07」，隨每次重新整理更新。

### 修正

- **當機**：修正部分沒有可用 Intel 顯示卡的電腦上，Argus 執行一段時間後可能當機的問題。
- **設定遺失**：修正儲存設定後不久發生斷電或強制重新啟動時，設定可能遺失，導致首次啟動導覽再次出現、語言改回跟隨系統的問題。
- **自動啟動**：自動啟動時不再搶走前景視窗焦點。先前在按一下其他位置前，鍵盤輸入都會進入看不見的 Argus 視窗。隱藏至系統匣期間，介面停止在背景持續繪製，大幅降低介面的 CPU 與 GPU 使用量，記憶體用量減少一半以上。
- **自動啟動項目**：在透過 Ctrl+Shift+Esc 開啟的 Argus 中啟用「登入 Windows 時啟動」，啟動項目會指向已安裝的 Argus。已指向工作管理員取代副本的啟動項目，在從「開始」功能表等位置開啟一次新版 Argus 後會自動修正。
- **背景重新整理**：最小化或隱藏至系統匣時，實際重新整理間隔與設定一致。先前應每 5 秒重新整理一次，實際常為 6 秒，有時達到 10 秒。以標準權限執行並使用特殊權限服務時，從系統匣或最小化還原視窗後，處理程序頁的網路欄不再偶爾短暫消失。
- **視窗**：最大化時，右上角不再出現兩組重疊的按鈕；游標貼齊螢幕頂端邊緣亦可拖曳視窗。
- **安裝與解除安裝程式**：完成頁的「關閉」、解除安裝確認頁的「取消」及核取方塊所在列改為置中顯示，先前略為偏左。
- **安裝升級**：直接執行安裝程式升級時，一併關閉由 Ctrl+Shift+Esc 或舊自動啟動項目開啟、仍在執行的舊版 Argus，避免升級後啟動仍轉交舊版，無需事先從系統匣結束程式。
- **解除安裝**：解除安裝時一併關閉由 Ctrl+Shift+Esc 開啟、仍在執行的 Argus。先前該程式會留在背景，勾選「一併刪除設定、歷程記錄與記錄檔」後重新安裝，首次啟動仍不顯示導覽，且舊設定會被重新寫回。設定等資料未能全部刪除時，解除安裝程式會列出剩餘資料夾。
- **首次啟動導覽**：按住 Ctrl+Shift+Esc 開啟 Argus 時，持續按住的 Esc 不再直接關閉導覽並將其標示為已完成。
- **快速鍵錄製**：錄製時按下目前組合或較長時間按住按鍵，不再意外隱藏視窗。使用非美式鍵盤配置時，錄製的按鍵與實際觸發的按鍵一致。按 Shift+Backspace 或 Win+Backspace 不再誤清除快速鍵。
- **快速鍵組合**：新設定的組合必須包含 Ctrl、Alt 或 Win，F13–F24 等少數按鍵除外；不再接受 Shift+字母這類會影響輸入的組合，亦不接受 Ctrl+C、Alt+F4 等常用編輯與系統操作。已儲存的組合不受影響。
- **快速鍵**：修正部分數字鍵盤按鍵被註冊為其他按鍵的問題。變更快速鍵時，若儲存設定失敗，不再產生無法取消的額外快速鍵。註冊失敗的原因依介面語言顯示。首次啟動導覽中，快速鍵被占用或無法使用時，僅顯示原因並說明可在設定中變更。
- **取代系統工作管理員**：更新特殊權限服務時，取代功能維持開啟，所用的 Argus 會一併更新至新版，無需先還原 Windows 工作管理員再於更新後手動開啟。啟用失敗時會指出遭拒的步驟及可能原因，例如安全軟體攔截登錄修改。狀態顯示「已有其他設定」時，會列出具體設定。關閉取代功能後，即使 Process Explorer 等其他工具接管工作管理員，仍可更新或解除安裝特殊權限服務。啟用失敗不再於服務目錄留下多餘的 Argus 副本；先前遺留的副本會在升級、開啟或關閉取代功能、更新或解除安裝特殊權限服務時清理，正在執行的副本除外。
- **處理程序**：未選取任何項目時按一下「顯示詳細資料」，會提示先在清單中選取一項，先前按下時沒有回應。快顯功能表或確認方塊開啟時，狀態列不再顯示「游標位於清單上，暫停重新排序」，清單亦不會在確認方塊彈出時重新排序。游標停留在清單上時以快速鍵切換頁面，此提示不再殘留於其他頁面的狀態列。
- **折線圖**：游標停留於折線圖右側邊緣附近時，讀值圓點不再卡頓。
- **切換更新通道**：檢查或下載更新期間切換穩定版或測試版，會依新通道重新檢查，不再提供原通道的版本。
- **診斷記錄**：失敗記錄改為明確記載系統錯誤碼；先前在非英文系統上，幾乎一律記為 operation failed。啟動時會記錄特殊權限服務無法連線的原因，例如版本不相容或回應逾時。

### 效能

- **處理程序頁**：降低系統概況中各邏輯處理器使用率小條的繪製負擔。折線移動時，介面每影格提交至顯示卡的資料減少約三分之一；I/O 欄中 WebView2 的讀寫量主要來自這些資料，因此亦隨之下降。

### 已知限制

- **磁碟讀寫**：Windows 11 24H2 及更新版本的讀取方式僅在組建 26300 驗證過；更早的系統改由特殊權限服務或系統管理員權限讀取，尚未在這些系統上驗證。若兩欄持續顯示「—」，可附上診斷記錄回報，讀取失敗的原因會記錄其中。
- **程式碼簽章**：程式尚未進行程式碼簽章，首次執行時 Windows SmartScreen 可能提示「未知的發行者」。
- **其他**：其餘限制見 GitHub 上的[已知問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)文件。

## 0.1.0 - 2026-10-16

Argus 的首個公開版本。

### 功能

- **處理程序**：依應用程式、處理程序樹或清單檢視，依名稱排序時分為「應用程式」與「背景處理程序」兩段；顯示各處理程序的 CPU、記憶體、I/O 與 GPU 使用量，啟用特殊權限服務或以系統管理員身分執行時另含網路流量；支援搜尋、結束處理程序或整個處理程序樹，詳細資料窗格顯示命令列、使用者、完整性等級等，依應用程式分組時顯示整個應用程式的合計。
- **優先順序與效率模式**：透過快顯功能表設定，亦可建立規則，在程式每次啟動時自動套用。
- **效能**：CPU（各核心、效能核心與效率核心、時脈、溫度、功耗、閒置狀態）、記憶體、磁碟、網路、GPU（NVIDIA、AMD 與 Intel 顯示卡另有功耗瓦數）與電池；折線依螢幕更新率連續移動，隨視窗大小縮放，較少使用的資訊收納於可展開的卡片。
- **核心感測器（選用）**：在設定或首次啟動導覽中啟用後，經特殊權限服務與官方 PawnIO 驅動程式讀取 CPU 內部感測器，包括各核心溫度與電壓、功耗與限制狀態、AMD SMU 資料，以及支援主機板的風扇轉速、電壓與溫度。
- **服務與啟動項目**：啟動、停止服務及修改啟動類型；啟用或停用啟動項目，與系統工作管理員使用相同的開關。
- **連線與連接埠**：TCP 與 UDP 端點及其所屬處理程序，支援依連接埠精確搜尋及中斷 IPv4 TCP 連線。
- **檔案使用狀況**：將檔案或資料夾拖放至視窗，結合 Restart Manager 與控制代碼列舉尋找使用中的處理程序，涵蓋處理程序的目前目錄。
- **歷程回溯**：記錄最近 7 天的資源使用量，按一下任意時刻即可檢視當時使用量最高的處理程序。
- **常駐系統匣**：透過全域快速鍵 Ctrl+Alt+Esc 顯示或隱藏視窗，隱藏時資源使用量極低。
- **選用特殊權限服務**：經一次系統管理員授權後，以標準權限執行的介面亦可管理系統處理程序、自動套用規則、統計各處理程序網路流量、控制服務及中斷連線。
- **系統工作管理員取代**：可讓 Ctrl+Shift+Esc 等入口開啟 Argus，並附帶不依賴介面與服務的獨立還原程式。
- **應用程式內更新**：提供穩定版與測試版兩個通道，可選用 GitHub 加速 Proxy；僅安裝通過簽章驗證的版本。
- **外觀**：工具列兼作標題列，導覽列位於工具列下方或視窗左側；Mica 背景與系統強調色，淺色、深色佈景主題預設跟隨 Windows，亦可在設定中指定。
- **安裝與解除安裝**：單頁安裝介面，跟隨 Windows 的淺色或深色模式；已安裝舊版時原地升級，解除安裝時可選擇一併刪除設定、歷程記錄與記錄檔。
- **多語言與首次啟動導覽**：介面、系統匣與安裝程式支援簡體中文與英文，預設跟隨 Windows 顯示語言；首次啟動時引導完成語言、顯示與重新整理、系統匣常駐、更新等常用設定，並可直接安裝選用的特殊權限服務、啟用核心感測器或取代系統工作管理員。

### 已知限制

- 程式尚未進行程式碼簽章，首次執行時 Windows SmartScreen 可能提示「未知的發行者」。
- CPU 內部感測器需要啟用核心感測器（特殊權限服務與 PawnIO 驅動程式）；支援的處理器與主機板見[硬體資料](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)。
- 其他限制見[已知問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)。

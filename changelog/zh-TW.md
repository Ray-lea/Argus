Argus 各版本的使用者可見變更。版本編號遵循[語意化版本](https://semver.org/lang/zh-TW/)。本檔案譯自[簡體中文更新記錄](zh-CN.md)，與原文逐項對應。

## [0.6.0](https://github.com/Ray-lea/Argus/compare/v0.5.0...v0.6.0) - 2026-11-22

v0.6.0 可在系統匣、桌面和工作列顯示即時讀數。新版歷程頁支援多軌曲線、資源事件及跨次執行的處理程序觀察。處理程序頁新增資源洩漏提示，四個清單支援 CSV 匯出。本版也降低捲動清單的負擔，並修正部分 Intel RST VMD 系統開啟磁碟詳細資料時觸發藍色畫面的問題。

### 破壞性變更

- **歷程記錄**：歷程頁僅顯示 0.6.0 起記錄的資料。升級後首次寫入當天的記錄時，Argus 會取代當天的舊格式檔案。舊版 Argus 無法讀取新記錄。
- **特殊權限服務通訊協定**：特殊權限服務通訊協定從 11 升至 12。0.6.0 需連線至新版服務，才能透過服務結束處理程序或調整 I/O 和記憶體優先順序。

### 新功能

- **元件頁**：「元件」集中管理系統匣和背景執行選項，也可在此開啟桌面監控和工作列監控。兩種監控預設關閉。從系統匣或監控開啟設定時，側邊欄會選取對應群組。
- **即時系統匣圖示**：系統匣預設以「走勢」顯示 CPU 使用率，也可選擇「佔比」、「數字」或「應用程式圖示」。三種即時樣式在使用率達到 80% 時以琥珀色標示。暫留卡片顯示即時讀數，右鍵快速面板列出 CPU 使用率最高的三個處理程序和常用操作。
- **系統匣卡片與快速面板**：暫留卡片依目前語言與字型大小排列讀數，關閉卡片後改用系統提示。快速面板可直接開啟效能頁中的對應裝置。從隱藏圖示區開啟面板時，該區域維持展開。（[@digital-bombyx](https://github.com/digital-bombyx) [#113](https://github.com/Ray-lea/Argus/pull/113) [#153](https://github.com/Ray-lea/Argus/pull/153)）
- **桌面監控**：桌面監控可選「橫條」或「面板」，面板提供「清單」、「曲線」或「儀表」樣式。拖曳時小視窗會留在目前顯示器的工作區內。可設定置頂、鎖定位置、滑鼠穿透與不透明度。
- **工作列監控**：工作列監控提供「標籤」、「曲線」、「膠囊」和「大數字」四種樣式。可在元件頁或右鍵面板預覽並切換樣式。右鍵面板可選取顯示器，勾選或拖曳讀數時即時更新。（[#28](https://github.com/Ray-lea/Argus/issues/28)、[#123](https://github.com/Ray-lea/Argus/issues/123)）
- **顯示器與視窗**：所選顯示器中斷連線時，工作列監控暫時移至主顯示器，重新連線後移回。按一下工作列監控或系統匣圖示可隱藏未被遮住的主視窗，也可將已隱藏、最小化或被遮住的視窗移到最前方。按兩下桌面監控可開啟主視窗。
- **監控讀數**：兩種監控提供 18 類讀數，包括溫度、頻率、功耗和風扇轉速。可為每張顯示卡、每顆磁碟和每張網路卡選取讀數，拖曳類別或類別內的讀數即可調整順序。工作列以裝置顏色區分名稱，同一 CPU 或 GPU 的後續讀數顯示參數名稱。
- **監控重新整理間隔**：任一監控開啟時，Argus 依主視窗顯示時的頻率取樣。最小化或背景執行間隔與此頻率不同時，設定會顯示實際間隔，仍可選擇關閉監控後使用的間隔。
- **歷程記錄內容**：歷程記錄新增 CPU 頻率、功耗與溫度，記憶體細項，每個磁碟、每個網路介面卡與每張顯示卡的讀數，以及電池讀數。在「設定」的「資料與歷程」中，可依類別選取讀數，每筆記錄約 20 個、約 40 個或全部作用中的處理程序。設定也會顯示預估每日用量。
- **歷程儲存**：可分別設定時間與空間上限，以先達到者為準。預設保留 30 天、最多 2 GB，超過 7 天的記錄依分鐘合併，保留平均值、峰值與使用量最高的處理程序。變更儲存位置時，可選擇是否一併移動歷程與觀察記錄。
- **歷程記錄頁**：每條軌道以階梯曲線顯示讀數，可疊加第二項讀數。可依名稱或裝置搜尋讀數，拖曳軌道可調整順序與高度。軌道超出圖表高度時，可在圖表內捲動。
- **瀏覽歷程曲線**：滾輪以游標所在時刻為中心縮放，縮放、按一下曲線或拖曳選取範圍都會暫停跟隨。按一下「回到最新」、在圖表上按右鍵或按 End 可繼續跟隨。沒有記錄的時段以斜紋標示，最近 10 分鐘的讀數依實際取樣間隔顯示。（[#79](https://github.com/Ray-lea/Argus/issues/79)、[#129](https://github.com/Ray-lea/Argus/issues/129)）
- **歷程曲線與游標**：跟隨最新讀數時，階梯曲線隨時間移動，游標所在軌道顯示經過該處的讀數。切換時段或縱軸範圍時，曲線平滑過渡，疊加曲線淡入淡出。再次開啟已檢視的較長時段時，曲線載入更快。
- **時間範圍與事件**：時間範圍下拉式清單提供 5 分鐘、3 小時、1 天、3 天與「自訂…」。「自訂時間範圍」對話方塊可在日曆中選擇日期，或輸入精確的開始與結束時間。勾選「顯示 30 天概覽與事件」後，對話方塊顯示每小時的熱度圖，並列出 CPU 高負載、記憶體不足與記錄空檔等事件。
- **歷程處理程序表**：可搜尋所選時刻或區間的處理程序，依名稱排序時分為應用程式、背景處理程序與 Windows 處理程序。展開同名群組可查看前四個執行個體及其餘執行個體的合計。右鍵選單可疊加該程式的曲線，或複製名稱與 PID。
- **歷程曲線提示**：CPU 等可依處理程序統計的軌道列出使用量最高的五個處理程序。處理程序數量軌道列出執行個體最多的五個程式及其餘程式的合計。溫度、電池電量等讀數僅顯示裝置資料。
- **處理程序觀察**：在右鍵選單或詳細資料窗格選取「觀察處理程序」，即可依執行個體記錄同一路徑程式的 14 項讀數，包括記憶體、CPU、GPU、磁碟、I/O、網路、執行緒和控制代碼。無法讀取路徑時僅觀察目前的執行個體。開始觀察後會開啟「歷程記錄」下的「處理程序觀察」，可切換執行個體，並以系統歷程的多軌圖表比較讀數。（[@hayxe1](https://github.com/hayxe1) [#82](https://github.com/Ray-lea/Argus/pull/82)）
- **觀察記錄**：最近 10 分鐘依實際取樣間隔顯示，較早時段讀取磁碟記錄。觀察記錄最多保留 7 天，達到容量上限時優先清除最舊記錄。停止觀察會保留記錄，重新啟動 Argus 後需重新開始觀察。
- **標題列**：標題列保留標誌、依視窗寬度調整的搜尋框和標準尺寸的視窗按鈕。拖曳空白處可移動視窗。圖釘按鈕可切換「置頂顯示」，重新啟動後仍保留選擇。（[#121](https://github.com/Ray-lea/Argus/issues/121)）
- **頁面列與狀態列**：處理程序檢視切換按鈕改用圖示，頁面控制項與「更多動作」移至導覽標籤旁。選單提供「執行新工作…」（Ctrl+N）、「查詢使用檔案的處理程序…」和快速鍵說明，服務頁也可開啟 Windows 服務管理員。狀態列提供暫停重新整理與重新整理頻率按鈕，版本號碼兼作更新進度與安裝提示。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **處理程序分組**：「應用程式」「背景處理程序」「Windows 處理程序」與各使用者分組以顏色區分。捲動時目前分組的標題固定在頂端，捲軸旁標示各組的位置並顯示目前的組名。開啟「隱藏系統處理程序」時，處理程序統計會同時顯示被隱藏的處理程序數。（[#88](https://github.com/Ray-lea/Argus/issues/88)）
- **處理程序耗電情形**：選用欄「電源使用量」和「電源使用量趨勢」依 CPU、GPU 與磁碟活動估算耗電程度。前者顯示目前等級，後者顯示最近約兩分鐘的平均等級。兩欄預設隱藏。（[#134](https://github.com/Ray-lea/Argus/issues/134)）
- **處理程序優先順序**：右鍵選單可設定處理程序的 I/O 優先順序和記憶體優先順序，詳細資料與選用欄顯示兩者的值。「基本優先順序」顯示優先順序類別名稱，特殊值保留數字，排序仍依數值。（[@digital-bombyx](https://github.com/digital-bombyx) [#80](https://github.com/Ray-lea/Argus/pull/80) [#116](https://github.com/Ray-lea/Argus/pull/116)）
- **游標停留時暫停排序**：游標停留在處理程序清單上而暫停排序時，排序欄的標題顯示暫停圖示，狀態列顯示「排序已暫停」。「設定 → 語言與外觀」新增「游標停留時暫停排序」，預設開啟。（[#86](https://github.com/Ray-lea/Argus/issues/86)）
- **資源洩漏提示**：處理程序頁標示控制代碼洩漏、子處理程序累積與殘留處理程序，按一下欄標題的琥珀色標記可找到相關處理程序。詳細資料窗格列出依據、數量走勢與處理建議，處理程序結束後標記隨下次取樣更新。可依程式忽略提示，在「設定 → 語言與外觀 → 資源洩漏提示」還原已忽略的程式或關閉提示。
- **複製表格內容**：處理程序、服務、啟動與連線頁可透過右鍵選單複製目前儲存格的值、名稱或詳細資料。在處理程序頁按 Ctrl+C 複製名稱，按 Ctrl+Shift+C 複製詳細資料。已選取文字時，Ctrl+C 優先複製所選文字。（[@digital-bombyx](https://github.com/digital-bombyx) [#161](https://github.com/Ray-lea/Argus/pull/161)、[#91](https://github.com/Ray-lea/Argus/issues/91)、[#150](https://github.com/Ray-lea/Argus/issues/150)）
- **匯出 CSV**：在處理程序、服務、啟動或連線頁開啟「更多動作」，選取「將目前頁面匯出為 CSV…」。檔案包含捲動區域外的列，並保留欄位順序、篩選、排序、顯示單位和群組展開狀態。（[#139](https://github.com/Ray-lea/Argus/issues/139)）
- **詳細資料窗格**：資源區新增工作集峰值、虛擬位址空間、I/O 速率與耗電情形。「累計」列出使用者模式與核心模式的 CPU 時間、各類 I/O 位元組數和分頁錯誤次數。右上角的複製按鈕依小節複製有讀數的項目。
- **連線頁**：連線可依應用程式分組，搜尋時相符的群組會自動展開。服務和連線的狀態篩選移至「狀態」欄標題。連線也可依 TCP、TCPv6、UDP 或 UDPv6 篩選，可與狀態篩選同時使用。（[@digital-bombyx](https://github.com/digital-bombyx) [#152](https://github.com/Ray-lea/Argus/pull/152)）
- **服務與啟動項目**：在右鍵選單選取「刪除」並確認，可刪除服務或啟動項目。使用中的服務由 Windows 在停止且釋放後移除。啟動資料夾中的檔案移至資源回收筒，應用程式套件的啟動工作僅能停用。（[#114](https://github.com/Ray-lea/Argus/issues/114)、[#146](https://github.com/Ray-lea/Argus/issues/146)）
- **應用程式套件服務**：Windows 拒絕變更應用程式套件服務的啟動類型時，可確認將設定寫入登錄。清單會標示重新啟動後生效的啟動類型。操作失敗時會提示服務名稱、權限或保護狀態。（[@digital-bombyx](https://github.com/digital-bombyx) [#112](https://github.com/Ray-lea/Argus/pull/112)、[#168](https://github.com/Ray-lea/Argus/issues/168)）
- **記憶體讀數**：記憶體組成列以斜紋標示使用中的壓縮記憶體，游標停留時可查看預估儲存量與節省的記憶體。處理程序頁的提示分別說明全機用量、處理程序專用工作集與群組總計的統計範圍。（[@digital-bombyx](https://github.com/digital-bombyx) [#81](https://github.com/Ray-lea/Argus/pull/81)、[#122](https://github.com/Ray-lea/Argus/issues/122)）
- **NPU**：效能頁為 Windows 辨識的每個 NPU 分別顯示名稱、使用率和最近 60 秒的曲線。已辨識的 NPU 會從 GPU 清單移除。（[@SpookySandwich](https://github.com/SpookySandwich) [#140](https://github.com/Ray-lea/Argus/pull/140)、[#135](https://github.com/Ray-lea/Argus/issues/135)、[#148](https://github.com/Ray-lea/Argus/issues/148)）
- **CPU 圖表與磁碟詳細資料**：CPU 的整體／多核心檢視與核心類型篩選移入曲線圖的右鍵選單。多核心檢視的小圖保持易讀的比例，空間不足時依序省略頻率與標題。磁碟詳細資料的 SMART 原始值預設以十進位顯示，改用十六進位後套用至所有磁碟，重新啟動後仍會保留。
- **硬體加速**：「設定 → 動畫」新增「硬體加速」，預設開啟。關閉後由 CPU 繪製介面，切換立即生效。（[#127](https://github.com/Ray-lea/Argus/issues/127)）
- **觸控操作**：支援 Windows 觸控螢幕的點選、點兩下、滑動捲動、長按開啟選單與拖曳捲軸。遠端轉送的點選也可操作主視窗內的控制項，文字方塊取得焦點時會視需要顯示觸控式鍵盤。（[#73](https://github.com/Ray-lea/Argus/issues/73)）
- **應用程式圖示**：應用程式改用點陣效能圖圖示，工作列、標題列和更新後的捷徑採用對應尺寸的圖示。關於頁與首次啟動導覽先以點陣組成標誌，再顯示最近十次 CPU 使用率。關閉介面動畫時直接顯示讀數。
- **關於頁**：新增「複製診斷資訊」，複製版本、執行狀態、硬體與顯示設定，便於貼到問題回報中。官網與 GitHub 卡片下方新增按鈕，可直接開啟下載、使用指南、更新記錄、問題回報、討論區與發行版頁面。
- **系統管理員程式的位置**：特殊權限服務、工作管理員取代與以系統管理員身分執行的程式集中存放在 `Program Files\Argus Privileged`，並使用固定的檔名，安全軟體依路徑加入的信任在更新後依然有效。安裝位置不在 Program Files 時，安裝頁以資訊圖示說明這些檔案的存放位置。（[@digital-bombyx](https://github.com/digital-bombyx) [#154](https://github.com/Ray-lea/Argus/pull/154)、[#136](https://github.com/Ray-lea/Argus/issues/136)、[#159](https://github.com/Ray-lea/Argus/issues/159)）

### 效能

- **介面繪製**：重新整理、游標停留與點選只重繪變更的區域，滑過清單或播放圖示動畫時 GPU 負擔降低。發行組建的對照測量中，捲動處理程序清單時每幀 CPU 開銷降低約四成。關閉硬體加速時，捲動與切換頁面會重用已繪製的內容。
- **首份讀數**：啟動後更早顯示首份讀數。（[@hayxe1](https://github.com/hayxe1) [#119](https://github.com/Ray-lea/Argus/pull/119)）

### 修正

- **磁碟詳細資料導致藍色畫面**：Argus 依控制器驅動程式判斷是否查詢溫度和 NVMe 健康資訊，避免部分 Intel RST VMD 系統在開啟磁碟詳細資料時出現藍色畫面。略過查詢的項目顯示為未知。讀取期間或讀取後兩分鐘內異常結束時，下次啟動會暫停自動讀取，可選擇「仍要讀取」。（[#48](https://github.com/Ray-lea/Argus/issues/48)、[#133](https://github.com/Ray-lea/Argus/issues/133)、[#160](https://github.com/Ray-lea/Argus/issues/160)）
- **裝置休眠**：在混合顯示卡筆電上，Argus 會略過已斷電獨立顯示卡的感應器查詢，效能頁顯示「已休眠」並說明原因。機械硬碟閒置時保留上次溫度，停轉後略過溫度查詢。（[#147](https://github.com/Ray-lea/Argus/issues/147)）
- **CPU 讀數**：CPU 使用率依閒置週期計算，修正將閒置迴圈計入使用率而導致讀數偏高的問題。修正 Windows 10 上混合架構處理器的頻率缺失，以及部分 Intel 處理器無法區分效能核心與效率核心的問題。（[#137](https://github.com/Ray-lea/Argus/issues/137)）
- **GPU 讀數**：整合式顯示卡上的處理程序不再將共用 GPU 記憶體計為專用 GPU 記憶體。沒有顯示卡時，軟體轉譯不再計為處理程序的 GPU 使用率，處理程序頁會隱藏 GPU 欄。若啟動時已偵測到硬體 GPU，更新驅動程式或接上新顯示卡後，無須重新啟動即可恢復或新增讀數。
- **磁碟讀數**：修正 USB 外接硬碟無法讀取 SMART 資訊、健康狀態顯示為「未知」，以及 Google Drive 等虛擬磁碟機的磁碟機代號被列在磁碟 0 之下的問題。
- **檔案使用狀況**：系統控制代碼總數過多時，檔案使用狀況查詢不再失敗。特殊權限服務與本機查詢因同一原因失敗時只提示一次；已安裝特殊權限服務時，不再建議啟用特殊權限服務。
- **結束處理程序的保護**：無法確認處理程序是否為系統關鍵處理程序時，Argus 拒絕結束該處理程序，單一處理程序、批次與處理程序樹狀結構操作皆適用。（[@hayxe1](https://github.com/hayxe1) [#77](https://github.com/Ray-lea/Argus/pull/77)）
- **處理程序頁**：搜尋或摺疊群組時，處理程序欄寬保持穩定，游標停留而暫停排序時展開子處理程序也會保留列順序。使用者群組列可開啟右鍵選單，按兩下已選列展開時仍保留詳細資料。程式名稱與版本資訊中的多餘字元已清除。
- **歷程處理程序**：從歷程頁跳至處理程序時，Argus 會核對 PID、名稱和啟動時間，避免選到重複使用同一 PID 的其他處理程序。（[@hayxe1](https://github.com/hayxe1) [#76](https://github.com/Ray-lea/Argus/pull/76)）
- **服務與啟動清單**：服務與啟動清單依內容分配欄寬，按兩下欄界可還原自動寬度，手動調整的欄寬在重新啟動後保留。無法取得啟動項目狀態時，狀態欄顯示「無法讀取」。
- **特殊權限服務與以系統管理員身分執行**：修正系統目錄誤判導致無法啟用系統管理員執行和特殊權限服務的問題。服務檔案遺失時顯示「已損毀」並提供修復或解除安裝。更新或解除安裝期間斷電時保留可用的服務檔案，解除安裝 Argus 時會清理服務取消註冊後的殘留檔案。（[#111](https://github.com/Ray-lea/Argus/issues/111)）
- **工作管理員取代**：取代遭安全軟體等外部程式撤銷時，設定頁與首次啟動導覽會顯示取代已被撤銷。維護協助程式被終止時，提示會列出結束代碼。
- **安裝與載入的安全性**：在 Program Files 以外安裝時，安裝程式會保護符合條件的目錄，僅允許系統管理員及系統寫入。互動式全新安裝無法保護所選位置時，可查看原因後繼續或另選位置。程式只從系統資料夾載入所匯入的系統 DLL，忽略同一資料夾中的同名檔案。（[#136](https://github.com/Ray-lea/Argus/issues/136)）
- **視窗**：修正視窗最大化與還原時沒有系統轉場動畫、從系統匣重新開啟後不維持最大化，以及首次啟動或經工作管理員入口開啟時視窗被其他視窗遮擋的問題。（[#126](https://github.com/Ray-lea/Argus/issues/126)、[#142](https://github.com/Ray-lea/Argus/issues/142)）
- **捲動**：修正系統或介面縮放為 125%、150% 等比例時，部分頁面捲動到底部後無法向上捲動，以及對話方塊無法捲動的問題。縮放輸入框可完整顯示三位數，欄位選項和提示文字的底部也不再遭到裁切。（[#164](https://github.com/Ray-lea/Argus/issues/164)）
- **選單與對話方塊**：右鍵選單與子選單關閉時立即消失，下拉式清單從控制項展開並向原處收合。對話方塊從視窗中央放大淡入，視窗按鈕底色隨遮罩變暗，關閉時縮小淡出。游標提示不會遮住右鍵選單，停用的項目不再使用警示色或游標醒目提示。（[#141](https://github.com/Ray-lea/Argus/issues/141)）
- **介面配置**：預設視窗大小下，效能頁的概觀完整顯示。設定頁在較寬的視窗中適度加寬內容；內容放得下時，對話方塊不再顯示捲軸。
- **螢幕閱讀程式**：螢幕閱讀器可讀出頁面標題、說明、效能讀數與表格儲存格。切換頁面或重新整理讀數後仍可存取控制項。設定開關與數字輸入框使用對應設定的標題。（[#115](https://github.com/Ray-lea/Argus/issues/115)）
- **介面文字**：精簡重複的介面說明，統一各語言的 CPU、GPU、I/O 術語與硬體單位。俄文介面也修訂了錯誤提示、文法和單位間距。（[@Dimmitrius](https://github.com/Dimmitrius) [#93](https://github.com/Ray-lea/Argus/pull/93) [#95](https://github.com/Ray-lea/Argus/pull/95) [#96](https://github.com/Ray-lea/Argus/pull/96) [#98](https://github.com/Ray-lea/Argus/pull/98) [#100](https://github.com/Ray-lea/Argus/pull/100) [#101](https://github.com/Ray-lea/Argus/pull/101) [#102](https://github.com/Ray-lea/Argus/pull/102) [#103](https://github.com/Ray-lea/Argus/pull/103) [#104](https://github.com/Ray-lea/Argus/pull/104) [#105](https://github.com/Ray-lea/Argus/pull/105) [#106](https://github.com/Ray-lea/Argus/pull/106) [#108](https://github.com/Ray-lea/Argus/pull/108) [#109](https://github.com/Ray-lea/Argus/pull/109)）

### 升級提示

- **特殊權限服務**：透過安裝程式或應用程式內更新升級時，已安裝的特殊權限服務與工作管理員替代副本會一併更新。免安裝版替換程式後，在「設定 → 權限 → 特殊權限服務」選取「更新服務」並完成系統管理員確認。
- **系統管理員程式的位置**：安裝版升級後，或免安裝版更新服務後，現有的特殊權限服務、工作管理員取代與以系統管理員身分執行的副本會移至 `Program Files\Argus Privileged`。安全軟體中依舊路徑加入的信任，需依新路徑重新加入一次。
- **頁面快速鍵**：新增「元件」頁後，Ctrl+7 開啟元件頁，設定改為 Ctrl+8，關於改為 Ctrl+9。
- **設定與歷程記錄**：升級後首次開啟系統歷程時顯示最近 5 分鐘，此後會記住重新選取的範圍。舊版將 UDP 儲存為狀態篩選的連線檢視會還原為全部，可在通訊協定欄重新選取。設定檔只儲存與預設值不同的項目，沿用預設值的選項會隨後續版本更新。

## [0.5.0](https://github.com/Ray-lea/Argus/compare/v0.4.0...v0.5.0) - 2026-11-12

v0.5.0 新增處理程序暫停與繼續、依使用者將處理程序分組、四個處理程序資訊欄與依內容計算的欄寬，效能頁的裝置清單支援隱藏與排序，介面新增繁體中文、西班牙文、德文、日文、法文和俄文。本版亦避免部分 Intel RST 系統在 Argus 啟動後凍結，修正 USB 磁碟無法安全移除等問題，並降低視窗隱藏後的記憶體與 CPU 使用量。

### 新功能

- **暫停與繼續處理程序**：處理程序與應用程式群組的快顯功能表新增「暫停處理程序」和「繼續處理程序」。暫停前會顯示影響說明並要求確認；系統關鍵處理程序、桌面視窗管理員與 Argus 本身無法暫停。已暫停的處理程序會在名稱後顯示「已暫停」標記。（[@digital-bombyx](https://github.com/digital-bombyx) [#65](https://github.com/Ray-lea/Argus/pull/65)）
- **處理程序資訊欄**：新增「檔案版本」、「架構」、「已提高權限」和「命令列」四個選用資料欄，預設隱藏，可在欄標題的快顯功能表或「選取資料欄」中啟用。（[@digital-bombyx](https://github.com/digital-bombyx) [#72](https://github.com/Ray-lea/Argus/pull/72)）
- **處理程序欄寬**：自動欄寬依內容計算，剩餘空間保留在表格右側。拖曳欄邊界可單獨調整一欄的寬度，按兩下欄邊界可還原自動寬度。欄標題功能表新增「全寬」，開啟後「名稱」欄會佔用剩餘寬度。
- **依使用者將處理程序分組**：「設定 → 語言與外觀 → 依使用者將處理程序分組」提供自動、一律分組和不分組三種方式；自動方式僅在多位使用者登入時分組。群組列的快顯功能表提供「管理使用者帳戶」和「登出」。
- **隱藏系統處理程序**：處理程序頁與連線頁新增「隱藏系統處理程序」開關，預設關閉，兩頁分別儲存開關狀態。一律顯示與額外隱藏的程式清單可在設定頁編輯。（[#32](https://github.com/Ray-lea/Argus/issues/32)）
- **處理程序樹與概況列**：處理程序樹預設收合，欄標題的快顯功能表提供「全部展開」和「全部收合」。「處理程序概況列」可設為自動、一律顯示或隱藏；設為自動時，若視窗高度不足，則收合概況列。
- **效能頁裝置清單**：在裝置上按一下滑鼠右鍵可將其隱藏，也可在「顯示的裝置」子功能表中逐項選取。拖曳裝置可調整順序；磁碟可依磁碟編號、磁碟機代號或自訂順序排列。
- **CPU 多核心檢視**：各邏輯處理器的小圖顯示核心時間，可在 CPU 圖表的快顯功能表中關閉。識別 Intel 低功耗效率核心（LP E 核心），以獨立色彩顯示，並支援單獨篩選。小圖優先排成沒有空位的列與欄。
- **硬體資訊**：GPU 頁顯示驅動程式版本、驅動程式日期與 DirectX 版本（含功能層級）。磁碟詳細資料支援更多 SATA SSD 的剩餘壽命與累計讀寫量，並新增傳統硬碟的通電時間、啟停次數、重映射與待映射磁區等統計。
- **介面語言**：新增繁體中文、西班牙文、德文、日文、法文和俄文。介面、系統匣、系統提示與安裝程式均提供譯文，數字與日期採用 Windows 地區格式。（[@abc0922001](https://github.com/abc0922001) [#45](https://github.com/Ray-lea/Argus/pull/45)、[@Rimuwu](https://github.com/Rimuwu) [#51](https://github.com/Ray-lea/Argus/pull/51)、[@s0ftw4r8](https://github.com/s0ftw4r8) [#52](https://github.com/Ray-lea/Argus/pull/52)、[@khativari](https://github.com/khativari) [#55](https://github.com/Ray-lea/Argus/pull/55)、[@hayxe1](https://github.com/hayxe1) [#62](https://github.com/Ray-lea/Argus/pull/62)）

### 修正

- **系統凍結**：不再向 RAID 控制器（如 Intel RST）後方的磁碟查詢溫度，以避免部分驅動程式版本沒有回應，導致系統在 Argus 啟動數秒後凍結。此類磁碟的溫度顯示為未知。（[#48](https://github.com/Ray-lea/Argus/issues/48)）
- **USB 磁碟安全移除**：修正磁碟監控持續佔用裝置，導致 USB 磁碟無法安全移除的問題。（[#57](https://github.com/Ray-lea/Argus/issues/57)）
- **磁碟清單與效能資料**：修正部分 NVMe 磁碟僅顯示裝置資訊而沒有效能資料，以及效能計數器無法使用時磁碟從清單中消失的問題。
- **磁碟詳細資料**：修正 SMART 屬性表數值遠離屬性名稱、分組留下大片空白，以及窄視窗中原始值遭裁切的問題。健康條的正常狀態統一使用綠色，溫度與備用空間依閾值區分警告色彩。
- **處理程序資料**：系統查詢緩慢時，處理程序清單仍會更新，資源讀值保留最近一次有效值。修正已結束的處理程序持續留在清單，以及暫停重新整理期間操作處理程序後狀態未更新的問題。（[#66](https://github.com/Ray-lea/Argus/issues/66)）
- **處理程序表格**：效率模式與釘選標記緊隨名稱顯示，欄標題與資料欄的邊界保持對齊。處理程序使用率補上百分號。
- **連線頁**：沒有所屬處理程序的連線現在顯示為「無所屬處理程序」。
- **CPU 讀值**：修正混合架構處理器的速度顯示異常、部分六核心 Ryzen 處理器的各核心電壓與溫度讀值錯誤，以及 Intel 內部感測器讀值間斷導致溫度折線中斷的問題。（[#58](https://github.com/Ray-lea/Argus/issues/58)）
- **授權與解除安裝**：修正 Program Files 或執行目錄的權限變更後無法撤銷授權與解除安裝、已在執行的 PawnIO 驅動程式無法用於核心感測器，以及解除安裝後殘留 Argus Sensor Setup 資料夾與空的 Argus Runtime 資料夾的問題。（[#46](https://github.com/Ray-lea/Argus/issues/46)）

- **視窗顯示**：修正還原視窗尺寸後介面僅顯示在左上角、從工作管理員取代入口冷啟動後最大化視窗顯示不完整、Windows 11 21H2 下視窗背景透明，以及切換應用程式後視窗仍遮擋其他視窗的問題。（[#44](https://github.com/Ray-lea/Argus/issues/44)、[#37](https://github.com/Ray-lea/Argus/issues/37)、[#35](https://github.com/Ray-lea/Argus/issues/35)）
- **系統匣**：修正關閉視窗並隱藏至系統匣後 CPU 使用量持續偏高，以及應用程式內更新後系統匣圖示移入溢位區的問題。（[#31](https://github.com/Ray-lea/Argus/issues/31)）
- **介面顯示**：修正更新對話方塊載入時偏離置中、檔案使用狀況對話方塊在結果出現後抖動，以及關於頁在較矮視窗中無法捲動至全部內容的問題。文字方塊的快顯功能表依介面語言顯示。（[#39](https://github.com/Ray-lea/Argus/issues/39)）

## [0.2.0](https://github.com/Ray-lea/Argus/compare/v0.1.0...v0.2.0) - 2026-10-18

本版本新增各處理程序的磁碟讀寫速率，可分別設定最小化與隱藏至系統匣時的重新整理間隔，改善應用程式內更新與快速鍵設定，並修正部分電腦執行一段時間後當機等問題。已安裝特殊權限服務時，應先閱讀「破壞性變更」。

### 破壞性變更

- **特殊權限服務需要更新**：本版本變更了 Argus 與特殊權限服務之間的通訊方式，0.1.0 的特殊權限服務無法搭配新版使用。未安裝特殊權限服務時不受影響。
- **透過安裝程式升級時**：應用程式內更新與直接執行安裝程式均屬於此方式。安裝程式會先關閉由工作管理員取代功能啟動、仍在執行的舊版 Argus，並在同一次系統管理員授權中一併更新特殊權限服務，無需另行操作。已開啟「取代系統工作管理員」時，取代功能會維持開啟，更新成功後按 Ctrl+Shift+Esc 即會開啟新版。
- **免安裝版升級須知**：已安裝特殊權限服務時，替換主程式後仍需手動更新服務。在新版 Argus 的提示方塊或「設定 → 權限」按一下「更新服務」並授權即可。安裝程式更新服務失敗時，亦依此方式處理。服務更新前，依賴服務的網路、磁碟讀寫與 CPU 感測器資料暫時無法取得，需要提高權限的管理操作可能失敗。已開啟「取代系統工作管理員」時，Ctrl+Shift+Esc 仍可能開啟舊版；更新服務會一併更新取代程式，並維持取代功能開啟。

### 新功能

- **各處理程序的磁碟讀寫**：處理程序頁新增「磁碟讀取」與「磁碟寫入」兩欄，顯示各處理程序每秒讀寫磁碟的資料量，並可排序；依應用程式分組時顯示群組合計，詳細資料窗格亦可檢視。I/O 欄也包含網路與裝置的讀寫，與這兩欄分開統計。Windows 11 24H2 及更新版本無需額外權限；更早的系統需啟用特殊權限服務或以系統管理員身分執行，特殊權限服務的授權說明已加入此項。暫時沒有讀值時顯示「—」，游標停留時可檢視原因。視窗較窄時仍保留這兩欄，表格可左右捲動，名稱欄固定於左側；因此，執行緒、控制代碼、PID 與 I/O 欄會比以往更早隱藏。
- **應用程式內更新**：從本版本開始，新版本下載完成並通過簽章驗證後，標題列右側會出現更新按鈕，系統匣圖示顯示圓點，右下角亦會提示一次，每個版本僅提示一次。免安裝版不會自動下載，發現新版本時即提示。更新對話方塊依類別列出目前版本至新版本之間各版本的更新內容，並註明各版本的變更項目數；更新內容與安裝套件一樣經過簽章驗證。以滑鼠右鍵按一下更新按鈕可選取「此版本不再提醒」。已下載的更新在重新啟動 Argus 後無需重新下載。
- **更新後顯示更新內容**：更新完成後首次開啟視窗時，顯示新版本的更新內容。如不需要，可在「設定 → 更新」關閉「更新後顯示更新內容」，之後僅在右下角提示已更新。同頁的「檢視本版本更新」可隨時開啟更新內容。
- **背景重新整理間隔**：最小化與隱藏至系統匣時的重新整理間隔可分別設定，可選 0.5 至 30 秒，預設為 5 秒，在「設定 → 資料與歷程」及首次啟動導覽中修改。設為短於 5 秒時，會先說明 CPU 使用量與耗電將增加；長於 5 秒時，歷程記錄的密度亦會降低。視窗回到前景時立即重新整理；背景間隔比前景的重新整理間隔長時，右下角會提示一次，可直接前往設定調整，亦可選擇不再提醒。
- **快速鍵設定**：可僅停用快速鍵並保留組合，重新啟用即恢復。錄製時即時顯示目前按住的按鍵，無法使用的組合會說明原因，亦可按一下「重設為預設值」。Ctrl+字母、Alt+字母等容易與其他程式衝突的組合，經確認後才會儲存。組合被其他程式占用時可直接重試；占用的程式結束後，再次顯示視窗時亦會自動重試。

- **當機**：修正部分沒有可用 Intel 顯示卡的電腦上，Argus 執行一段時間後可能當機的問題。
- **設定遺失**：修正儲存設定後不久發生斷電或強制重新啟動時，設定可能遺失，導致首次啟動導覽再次出現、語言改回跟隨系統的問題。

- **自動啟動項目**：在透過 Ctrl+Shift+Esc 開啟的 Argus 中啟用「登入 Windows 時啟動」，啟動項目會指向已安裝的 Argus。已指向工作管理員取代副本的啟動項目，在從「開始」功能表等位置開啟一次新版 Argus 後會自動修正。
- **背景重新整理**：最小化或隱藏至系統匣時，實際重新整理間隔與設定一致。先前應每 5 秒重新整理一次，實際常為 6 秒，有時達到 10 秒。以標準權限執行並使用特殊權限服務時，從系統匣或最小化還原視窗後，處理程序頁的網路欄不再偶爾短暫消失。

- **解除安裝**：解除安裝時一併關閉由 Ctrl+Shift+Esc 開啟、仍在執行的 Argus。先前該程式會留在背景，勾選「一併刪除設定、歷程記錄與記錄檔」後重新安裝，首次啟動仍不顯示導覽，且舊設定會被重新寫回。設定等資料未能全部刪除時，解除安裝程式會列出剩餘資料夾。
- **首次啟動導覽**：按住 Ctrl+Shift+Esc 開啟 Argus 時，持續按住的 Esc 不再直接關閉導覽並將其標示為已完成。
- **快速鍵錄製**：錄製時按下目前組合或較長時間按住按鍵，不再意外隱藏視窗。使用非美式鍵盤配置時，錄製的按鍵與實際觸發的按鍵一致。按 Shift+Backspace 或 Win+Backspace 不再誤清除快速鍵。
- **快速鍵組合**：新設定的組合必須包含 Ctrl、Alt 或 Win，F13–F24 等少數按鍵除外；不再接受 Shift+字母這類會影響輸入的組合，亦不接受 Ctrl+C、Alt+F4 等常用編輯與系統操作。已儲存的組合不受影響。
- **快速鍵**：修正部分數字鍵盤按鍵被註冊為其他按鍵的問題。變更快速鍵時，若儲存設定失敗，不再產生無法取消的額外快速鍵。註冊失敗的原因依介面語言顯示。首次啟動導覽中，快速鍵被占用或無法使用時，僅顯示原因並說明可在設定中變更。
- **取代系統工作管理員**：更新特殊權限服務時，取代功能維持開啟，所用的 Argus 會一併更新至新版，無需先還原 Windows 工作管理員再於更新後手動開啟。啟用失敗時會指出遭拒的步驟及可能原因，例如安全軟體攔截登錄修改。狀態顯示「已有其他設定」時，會列出具體設定。關閉取代功能後，即使 Process Explorer 等其他工具接管工作管理員，仍可更新或解除安裝特殊權限服務。啟用失敗不再於服務目錄留下多餘的 Argus 副本；先前遺留的副本會在升級、開啟或關閉取代功能、更新或解除安裝特殊權限服務時清理，正在執行的副本除外。

- **歷程回溯**：記錄最近 7 天的資源使用量，按一下任意時刻即可檢視當時使用量最高的處理程序。
- **常駐系統匣**：透過全域快速鍵 Ctrl+Alt+Esc 顯示或隱藏視窗，隱藏時資源使用量極低。
- **選用特殊權限服務**：經一次系統管理員授權後，以標準權限執行的介面亦可管理系統處理程序、自動套用規則、統計各處理程序網路流量、控制服務及中斷連線。
- **系統工作管理員取代**：可讓 Ctrl+Shift+Esc 等入口開啟 Argus，並附帶不依賴介面與服務的獨立還原程式。
- **應用程式內更新**：提供穩定版與測試版兩個通道，可選用 GitHub 加速 Proxy；僅安裝通過簽章驗證的版本。
- **外觀**：工具列兼作標題列，導覽列位於工具列下方或視窗左側；Mica 背景與系統強調色，淺色、深色佈景主題預設跟隨 Windows，亦可在設定中指定。
- **安裝與解除安裝**：單頁安裝介面，跟隨 Windows 的淺色或深色模式；已安裝舊版時原地升級，解除安裝時可選擇一併刪除設定、歷程記錄與記錄檔。
- **多語言與首次啟動導覽**：介面、系統匣與安裝程式支援簡體中文與英文，預設跟隨 Windows 顯示語言；首次啟動時引導完成語言、顯示與重新整理、系統匣常駐、更新等常用設定，並可直接安裝選用的特殊權限服務、啟用核心感測器或取代系統工作管理員。

### 已知限制

- 程式尚未進行程式碼簽章，首次執行時 Windows SmartScreen 可能提示「未知的發行者」。
- CPU 內部感測器需要啟用核心感測器（特殊權限服務與 PawnIO 驅動程式）；支援的處理器與主機板見[硬體資料](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)。
- 其他限制見[已知問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)。

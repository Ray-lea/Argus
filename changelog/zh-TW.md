## [0.7.0](https://github.com/Ray-lea/Argus/compare/v0.6.0...v0.7.0) - 2026-11-27

v0.7.0 開始提供 Windows ARM64 安裝版與免安裝版，主程式、特殊權限服務與工作管理員取代均在 ARM64 上原生執行。處理程序頁新增 27 個可選資料欄與「建立記憶體傾印檔案」「偵錯」兩項操作；新增位元組單位設定，工作列監控支援垂直工作列，有新版本時可傳送 Windows 通知。本版還減少了介面靜止時的重繪，並修正 Ryzen 9000 感測器、工作列監控遮住開始按鈕、特殊權限服務登錄被刪除後無法重新安裝等問題。

本版完整重寫了文件網站，各項功能的詳細用法可前往[文件網站](https://argustask.com/docs/)（簡體中文）查看。

### 破壞性變更

- **資料欄選單**：處理程序清單的欄標題右鍵選單不再按分類顯示或隱藏資料欄。按一下選單中的「選取資料欄…」，在對話方塊中選擇要顯示的資料欄。

### 新功能

- **Windows ARM64**：提供 ARM64 安裝版與免安裝版，主程式、特殊權限服務、以系統管理員身分執行與工作管理員取代均原生執行，應用程式內更新按 ARM64 版進行。效能頁顯示 ARM64 處理器的廠商、型號、指令集與虛擬化狀態，CPU 功耗取自 Windows 能源計量；暫不提供核心感測器。（[#172](https://github.com/Ray-lea/Argus/issues/172)）
- **處理程序資料欄**：「選取資料欄」對話方塊新增 27 個可選資料欄，包括執行時長、核心與使用者 CPU、內容切換、共用工作集、分頁集區與非分頁集區、硬性分頁錯誤，以及磁碟與 I/O 的讀寫次數和累計值。未選取這些資料欄時，取樣負擔不變。
- **詳細資料窗格**：列出處理程序清單全部可選資料欄的讀數，資源與累計兩節增加內容切換、硬性分頁錯誤與每秒要求次數，工作集、認可大小等讀數後附峰值。「複製詳細資料」同樣包含這些項目。
- **記憶體傾印與偵錯**：單一處理程序的右鍵選單新增「建立記憶體傾印檔案」與「偵錯」。傾印檔案寫入暫存資料夾，完成後以通知提供路徑；系統登錄了 Just-In-Time 偵錯工具時，「偵錯」會啟動該偵錯工具並附加到處理程序。（[#169](https://github.com/Ray-lea/Argus/issues/169)、[#197](https://github.com/Ray-lea/Argus/issues/197)）
- **位元組單位**：「設定 → 資料與歷程」新增「位元組單位」，可選傳統風格（預設）、二進位 IEC 或十進位 SI。記憶體、儲存容量、傳輸速率、圖表刻度與各監控的讀數隨之切換。（[#156](https://github.com/Ray-lea/Argus/issues/156)）
- **垂直工作列**：工作列位於螢幕左側或右側時，工作列監控沿工作列直向排列讀數，四種樣式均有直向版面，只顯示放得下的幾項。（[#177](https://github.com/Ray-lea/Argus/issues/177)）
- **新版本通知**：視窗隱藏在系統匣或不在前景時，安裝版在新版本下載並通過驗證後、免安裝版在發現新版本時傳送 Windows 通知，按一下通知即開啟更新對話方塊。在「設定 → 更新」中關閉「有新版本時傳送通知」後，改為在視窗顯示時於右下角提示。
- **切換頁面**：Ctrl+Tab 與 Ctrl+Shift+Tab 切換到下一個或上一個頁面，到最後一頁後從另一端繼續。（[#185](https://github.com/Ray-lea/Argus/issues/185)）
- **頂部導覽**：頁面列空間不足時，頂部導覽的標籤先收合為圖示，指標停留時顯示頁面名稱與快速鍵；仍放不下時，頁面控制項才移到下一列。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **文件網站**：完整重寫全部文件。新增「入門」一節，包括快速入門、什麼是 Argus、安裝與更新，以及與系統工作管理員的比較；使用指南按介面拆分為處理程序、效能、服務與啟動項目、連線、歷程記錄等頁面，並依程式碼核對、補全了說明。

### 效能

- **介面重繪**：內容不變的可見視窗不再隨每次螢幕重新整理而重繪。在 160 Hz 顯示器上，Argus 設定頁靜止時每秒的 CPU 週期約減半；動畫與捲動的呈現影格速率不變。

### 修正

- **系統匣圖示**：預設樣式改為「應用程式圖示」，避免「走勢」在深色工作列上難以辨認；「元件」頁改用下拉式清單選擇系統匣圖示的樣式。（[#178](https://github.com/Ray-lea/Argus/issues/178)）
- **工作列監控**：工作列按鈕置中時，讀數不再遮住開始按鈕與工作按鈕，只顯示放得下的幾項。群組原則停用小工具時，不再為小工具按鈕預留空白。
- **桌面監控**：開機或重新啟動 Argus 後，已開啟的桌面監控直接顯示，無需重新開關。
- **Ryzen 9000**：CCD 內有停用核心的型號（如 Ryzen 9 9900X3D）不再顯示「未識別的感測器表」，可讀取 PPT、TDC 的目前值與上限。核心對應校驗通過後，還會顯示每核心溫度、電壓與 C0／C1／CC6 駐留比例。（[#203](https://github.com/Ray-lea/Argus/issues/203)）
- **GPU 與 CPU 讀數**：獨立顯示卡休眠時，GPU 頁保留最近讀到的「最高核心時脈」。開啟核心感測器、背景重新整理間隔為 30 秒時，CPU 功耗與有效時脈不再時有時無，背景期間的歷程記錄也不再缺少這幾項。
- **特殊權限服務與核心感測器**：服務的登錄被安全軟體或清理工具刪除後，可在 Argus 中直接重新安裝，無需先重新啟動 Windows。PawnIO 被解除安裝或裝置被刪除後，已安裝的驅動程式不高於 2.2.0 時，重新開啟核心感測器即可自動重裝驅動程式。
- **以系統管理員身分執行**：工作排程器殘留同名登錄時，仍可開啟以系統管理員身分執行；登錄被拒絕時，提示可能受到 360 等安全軟體的攔截。錯誤提示中的錯誤碼只顯示一次，HRESULT 以十六進位顯示。
- **工作管理員取代**：開啟取代後，系統管理員帳戶按一下「暫時開啟系統工作管理員」不再沒有反應。Argus 沒有回應時，工作管理員入口改開系統工作管理員，不再多等一輪逾時。
- **由右至左的文字**：處理程序名稱、描述與搜尋方塊中的阿拉伯文、希伯來文等由右至左書寫的文字不再倒序顯示。（[#155](https://github.com/Ray-lea/Argus/issues/155)）
- **選單與窗格**：靠近視窗底部展開的長子選單，最後一項不再被視窗底邊截去。詳細資料窗格按最長的名稱調整名稱欄寬度，「專用 GPU 記憶體」等名稱不再換成兩行。Mica 視窗關閉對話方塊時，卡片不再閃白。
- **更新後的圖示**：安裝或更新後，桌面捷徑與釘選到工作列的 Argus 立即顯示新圖示，無需重新啟動電腦。

### 升級提示

- **特殊權限服務**：通訊協定仍為第 12 版。Ryzen 9000 讀數、背景的核心感測器功耗、工作管理員取代的修正，以及 Windows 11 24H2 之前以標準權限執行時的磁碟讀寫次數，均在服務更新後生效。安裝版升級時會更新已安裝的服務；免安裝版須於「設定 → 權限 → 特殊權限服務」中按一下「更新服務」。
- **ARM64 電腦上的安裝版**：0.6.0 在 ARM64 電腦上仍下載 x64 安裝套件，x64 安裝程式會提示改用 ARM64 版並結束。須從官網下載 `Argus_0.7.0_arm64-setup.exe`，覆蓋安裝到原位置，設定與歷程資料保留；此後可在應用程式內更新 ARM64 版。
- **ARM64 電腦上的免安裝版**：結束 Argus，改用 `Argus_0.7.0_arm64.exe` 替換原程式。已開啟「允許以系統管理員身分執行」時，先關閉該選項，替換後從新版重新開啟。
- **系統匣圖示**：先前未變更樣式的系統匣圖示，升級後顯示應用程式圖示。需要即時顯示 CPU 使用率時，在「元件」頁的「系統匣圖示」中選擇「走勢」「佔比」或「數字」。

## [0.6.0](https://github.com/Ray-lea/Argus/compare/v0.5.0...v0.6.0) - 2026-11-23

v0.6.0 換用全新的點陣效能圖應用程式圖示，重新設計主視窗介面，精簡標題列、重排頁面列與狀態列，並新增置頂顯示按鈕。新增「元件」頁，可在系統匣、桌面與工作列即時顯示系統讀數；重構歷程記錄頁，支援多軌曲線、資源事件與跨次執行的處理程序觀察。處理程序頁新增資源洩漏提示與電源使用量欄，處理程序、服務、啟動與連線頁均支援內容複製與 CSV 匯出，服務與啟動項目支援刪除；效能頁新增 NPU 監控，同時加入觸控操作與硬體加速開關。本版也大幅降低清單捲動與介面重繪負擔，修正部分 Intel RST VMD 系統開啟磁碟詳細資料時觸發藍色畫面的問題，並避免喚醒已斷電的獨立顯示卡與停轉硬碟。

### 破壞性變更

- **歷程記錄**：本版改用新的儲存格式，歷程記錄頁僅顯示 0.6.0 及之後記錄的資料。升級後首次寫入當日記錄時，會取代當天的舊格式檔案；舊版 Argus 也無法讀取新版記錄。
- **特殊權限服務通訊協定**：通訊協定從第 11 版升至第 12 版。透過特殊權限服務執行結束處理程序、調整 I/O 或記憶體優先順序等操作前，須先更新舊版服務。

### 新功能

- **應用程式圖示**：換用全新的點陣效能圖圖示，針對不同尺寸單獨排布點陣，在工作列、標題列與更新後的捷徑中皆保持清晰。關於頁與首次啟動導覽先由點陣拼出標誌，再轉為最近 10 次 CPU 使用率的動態點陣圖；關閉「介面動畫」時直接顯示點陣圖。
- **標題列**：精簡為僅保留應用程式標誌、寬度自適應的搜尋框與 Windows 標準尺寸視窗按鈕，其餘空白處皆可拖曳視窗。新增圖釘按鈕以切換「置頂顯示」，狀態於重新啟動後保留。（[#121](https://github.com/Ray-lea/Argus/issues/121)）
- **頁面列與狀態列**：頁面控制項與「更多動作」移至導覽標籤旁，處理程序檢視切換按鈕改用圖示。「更多動作」收納「執行新工作…」（Ctrl+N）、「查詢使用檔案的處理程序…」與快速鍵說明，服務頁亦可直接開啟 Windows 服務管理員。狀態列提供暫停重新整理與重新整理頻率按鈕，版本號碼兼作更新進度與安裝入口。（[#87](https://github.com/Ray-lea/Argus/issues/87)）
- **元件頁**：新增「元件」頁，集中管理系統匣與背景執行選項，並可開啟桌面監控與工作列監控（兩者預設關閉）。從系統匣或監控開啟設定時，側邊欄自動定位到對應群組。
- **即時系統匣圖示**：系統匣圖示預設以「走勢」即時顯示 CPU 使用率，也可切換為「佔比」「數字」或「應用程式圖示」；前三種即時樣式於使用率達到 80% 時以琥珀色提示。游標停留時顯示即時讀數卡片，按右鍵開啟快速面板，列出 CPU 使用率最高的三個處理程序與常用操作。
- **系統匣卡片與快速面板**：暫留卡片依目前語言與字型大小自適應排版，關閉卡片後改用系統提示。按一下快速面板中的讀數可直達效能頁對應裝置；從隱藏圖示區開啟面板時，該區域維持展開。（[@digital-bombyx](https://github.com/digital-bombyx) [#113](https://github.com/Ray-lea/Argus/pull/113) [#153](https://github.com/Ray-lea/Argus/pull/153)）
- **桌面監控**：以桌面小視窗常駐顯示即時讀數，支援「橫條」與「面板」兩種顯示方式，其中面板提供「清單」「曲線」「儀表」三種樣式。拖曳時自動限制在目前顯示器工作區內，支援置頂顯示、鎖定位置、滑鼠穿透與不透明度調整。
- **工作列監控**：在工作列常駐顯示即時讀數，提供「標籤」「曲線」「膠囊」與「大數字」四種樣式。可在元件頁或右鍵面板即時預覽並切換樣式；右鍵面板亦支援選取顯示器、勾選讀數與拖曳排序，調整立即生效。（[#28](https://github.com/Ray-lea/Argus/issues/28)、[#123](https://github.com/Ray-lea/Argus/issues/123)）
- **多顯示器與視窗切換**：所選顯示器中斷連線時，工作列監控暫移至主顯示器，重新連線後自動移回。按一下工作列監控或系統匣圖示，可在視窗未被遮擋時隱藏主視窗，或在視窗隱藏、最小化、被遮擋時將其移至最前方；按兩下桌面監控可開啟主視窗。
- **監控讀數**：桌面監控與工作列監控共提供 18 種讀數，涵蓋溫度、頻率、功耗與風扇轉速。支援為每張顯示卡、每顆磁碟與每張網路卡單獨勾選，並可拖曳類別或單項讀數排序。工作列監控以裝置顏色區分名稱，同一 CPU 或 GPU 的後續讀數直接標註參數名稱。
- **監控重新整理間隔**：桌面監控或工作列監控開啟期間，Argus 沿用主視窗的重新整理頻率進行取樣。當最小化或背景執行間隔與此頻率不同時，設定頁會註明目前實際間隔，同時保留監控關閉後恢復使用的間隔選項。
- **歷程記錄頁**：全面重構為多軌階梯曲線圖表，每條軌道皆可疊加第二項讀數。支援依名稱或裝置搜尋讀數，拖曳調整軌道順序與高度；軌道超出可視區域時可在圖表內捲動檢視。
- **瀏覽歷程曲線**：滾輪圍繞游標所在時刻縮放；縮放、按一下曲線或拖曳選取時段會暫停跟隨最新讀數。按一下「回到最新」、在圖表上按右鍵或按 End 可恢復跟隨。無記錄時段以斜紋標示，最近 10 分鐘依實際取樣間隔顯示。（[#79](https://github.com/Ray-lea/Argus/issues/79)、[#129](https://github.com/Ray-lea/Argus/issues/129)）
- **歷程曲線與游標**：跟隨最新讀數時，階梯曲線隨時間持續推進，游標所在軌道隨曲線經過即時更新讀數。切換時段或縱軸量程時曲線平滑過渡，疊加曲線淡入淡出；再次檢視已開啟過的較長時段時載入更快。
- **時間範圍與事件**：下拉式清單提供 5 分鐘、3 小時、1 天、3 天與「自訂…」；在「自訂時間範圍」對話方塊中可透過日曆選定日期，或輸入精確的起訖時間。勾選「顯示 30 天概覽與事件」可檢視依小時分布的熱度圖，並列出 CPU 高負載、記憶體不足與記錄空檔等事件。
- **歷程處理程序表**：支援搜尋所選時刻或區間內的處理程序，依名稱排序時分為應用程式、背景處理程序與 Windows 處理程序。展開同名群組可檢視前四個執行個體及其餘執行個體的合計；右鍵選單支援在圖表中疊加該程式的曲線，或複製名稱與 PID。
- **歷程曲線提示**：游標停留在 CPU 等可依處理程序統計的軌道上時，提示框列出使用量最高的五個處理程序；處理程序數量軌道列出執行個體最多的五個程式及其餘程式合計。溫度、電池電量等讀數僅顯示裝置資料。
- **歷程記錄內容**：新增 CPU 頻率、功耗與溫度、記憶體細項、電池讀數，以及每顆磁碟、每張顯示卡與每個網路介面卡的獨立讀數。在「設定 → 資料與歷程」中可依類別勾選記錄項目，選擇每筆記錄約 20 個、約 40 個或全部作用中的處理程序，並即時顯示預估每日佔用空間。
- **歷程儲存**：支援分別設定時間與空間保留上限，以先達到者為準；預設保留 30 天、上限 2 GB，超過 7 天的記錄自動依分鐘合併，保留平均值、峰值與使用量最高的處理程序。變更儲存位置時可選擇是否一併遷移現有歷程與觀察記錄；若目標資料夾已有其他檔案，則自動存入其中的「Argus History」子資料夾。
- **處理程序觀察**：在處理程序右鍵選單或詳細資料窗格中選取「觀察處理程序」，即可依執行個體持續記錄同一路徑程式的 14 項讀數（涵蓋記憶體、CPU、GPU、磁碟、I/O、網路、執行緒與控制代碼）；無法讀取路徑時僅觀察目前的執行個體。開始後自動進入「歷程記錄」下的「處理程序觀察」，可切換各次執行個體，並以多軌圖表比較讀數。（[@hayxe1](https://github.com/hayxe1) [#82](https://github.com/Ray-lea/Argus/pull/82)）
- **觀察記錄**：最近 10 分鐘依實際取樣間隔顯示，較早時段自磁碟讀取。記錄最多保留 7 天，達到容量上限時優先清除最早的資料；停止記錄會保留已有資料，重新啟動 Argus 後須重新開始觀察。
- **處理程序分組**：「應用程式」「背景處理程序」「Windows 處理程序」與各使用者分組以不同顏色區分。捲動清單時，目前分組標題固定於頂端，捲軸旁標示各組位置並顯示目前組名。開啟「隱藏系統處理程序」後，處理程序統計同時顯示已隱藏的處理程序數。（[#88](https://github.com/Ray-lea/Argus/issues/88)）
- **處理程序耗電情形**：新增「電源使用量」與「電源使用量趨勢」兩項選用欄（預設隱藏），結合 CPU、GPU 與磁碟活動估算耗電程度。前者反映目前耗電等級，後者顯示最近約兩分鐘的平均等級。（[#134](https://github.com/Ray-lea/Argus/issues/134)）
- **處理程序優先順序**：右鍵選單新增設定 I/O 優先順序與記憶體優先順序，詳細資料窗格及選用欄同步顯示。「基本優先順序」改用類別名稱顯示，特殊值保留數字，排序仍依數值進行。（[@digital-bombyx](https://github.com/digital-bombyx) [#80](https://github.com/Ray-lea/Argus/pull/80) [#116](https://github.com/Ray-lea/Argus/pull/116)）
- **游標停留時暫停排序**：游標停留在處理程序清單上暫停排序時，排序欄的標題顯示暫停圖示，狀態列同步提示「排序已暫停」。「設定 → 語言與外觀」新增「游標停留時暫停排序」開關，預設開啟。（[#86](https://github.com/Ray-lea/Argus/issues/86)）
- **資源洩漏提示**：處理程序頁自動偵測控制代碼洩漏、子處理程序累積與殘留處理程序，按一下欄標題的琥珀色標記即可快速定位。詳細資料窗格列出判斷依據、數量走勢與處理建議，處理程序結束後標記隨下次取樣更新。支援依程式忽略提示，並可在「設定 → 語言與外觀 → 資源洩漏提示」中還原已忽略的程式或關閉該功能。
- **複製表格內容**：處理程序、服務、啟動與連線頁均支援透過右鍵選單複製目前儲存格內容、名稱或詳細資料。在處理程序頁按 Ctrl+C 可複製名稱，按 Ctrl+Shift+C 可複製詳細資料；已選取文字時，Ctrl+C 優先複製所選文字。（[@digital-bombyx](https://github.com/digital-bombyx) [#161](https://github.com/Ray-lea/Argus/pull/161)、[#91](https://github.com/Ray-lea/Argus/issues/91)、[#150](https://github.com/Ray-lea/Argus/issues/150)）
- **匯出 CSV**：在處理程序、服務、啟動或連線頁的「更多動作」選單中選取「將目前頁面匯出為 CSV…」，即可匯出完整清單（包含捲動區域外的列），並保留目前的欄位順序、篩選、排序、顯示單位與群組展開狀態。（[#139](https://github.com/Ray-lea/Argus/issues/139)）
- **詳細資料窗格**：「資源」小節新增工作集峰值、虛擬位址空間、I/O 速率與耗電情形；新增「累計」小節，顯示使用者模式與核心模式 CPU 時間、各類 I/O 位元組數及分頁錯誤次數。右上角的複製按鈕可依小節複製全部有讀數的項目。
- **連線頁**：支援依應用程式摺疊分組顯示連線，搜尋時自動展開相符的群組。服務頁與連線頁的狀態篩選移至「狀態」欄標題；連線頁另新增依 TCP、TCPv6、UDP 或 UDPv6 篩選，可與狀態篩選組合使用。（[@digital-bombyx](https://github.com/digital-bombyx) [#152](https://github.com/Ray-lea/Argus/pull/152)）
- **刪除服務與啟動項目**：右鍵選單新增「刪除」動作，經確認後即可刪除服務或啟動項目。使用中的服務會於停止且釋放後由 Windows 移除；啟動資料夾中的項目會移至資源回收筒，應用程式套件的啟動工作仍僅支援停用。（[#114](https://github.com/Ray-lea/Argus/issues/114)、[#146](https://github.com/Ray-lea/Argus/issues/146)）
- **應用程式套件服務**：當 Windows 拒絕變更應用程式套件服務的啟動類型時，經確認可直接寫入登錄，並於清單中標示須重新啟動後生效的啟動類型。操作失敗時，提示會載明服務名稱以及權限或系統保護限制。（[@digital-bombyx](https://github.com/digital-bombyx) [#112](https://github.com/Ray-lea/Argus/pull/112)、[#168](https://github.com/Ray-lea/Argus/issues/168)）
- **記憶體讀數**：效能頁的記憶體組成列以斜紋標示使用中的已壓縮記憶體，游標停留可檢視預估儲存的資料量與節省的記憶體。處理程序頁的記憶體提示也分別說明全機使用量、處理程序專用工作集與群組總計的統計範圍。（[@digital-bombyx](https://github.com/digital-bombyx) [#81](https://github.com/Ray-lea/Argus/pull/81)、[#122](https://github.com/Ray-lea/Argus/issues/122)）
- **NPU**：效能頁為 Windows 辨識到的每個 NPU 分別顯示名稱、使用率與最近 60 秒的即時曲線，並將已辨識的 NPU 自 GPU 清單中移除。（[@SpookySandwich](https://github.com/SpookySandwich) [#140](https://github.com/Ray-lea/Argus/pull/140)、[#135](https://github.com/Ray-lea/Argus/issues/135)、[#148](https://github.com/Ray-lea/Argus/issues/148)）
- **CPU 圖表與磁碟詳細資料**：CPU 的整體／多核心檢視切換與核心類型篩選移入曲線圖右鍵選單；多核心檢視的小圖維持易讀比例，空間不足時依序省略頻率與標題。磁碟詳細資料的 SMART 原始值預設以十進位顯示，改用十六進位後套用至全部磁碟並於重新啟動後保留。
- **硬體加速**：「設定 → 動畫」新增「硬體加速」開關，預設開啟。關閉後改由 CPU 繪製介面、不再佔用 GPU，切換立即生效。（[#127](https://github.com/Ray-lea/Argus/issues/127)）
- **觸控操作**：支援 Windows 觸控螢幕點選、點兩下、滑動捲動、長按開啟選單與拖曳捲軸。遠端轉送的觸控輕點亦可正常操作主視窗內的控制項，文字方塊取得焦點時視需要顯示觸控式鍵盤。（[#73](https://github.com/Ray-lea/Argus/issues/73)）
- **關於頁**：新增「複製診斷資訊」按鈕，可一次複製版本、執行狀態、硬體與顯示設定，便於附入問題回報。官網與 GitHub 卡片下方新增快捷入口，直達下載、使用指南、更新記錄、問題回報、討論區與發行版頁面。
- **系統管理員程式存放位置**：特殊權限服務、工作管理員取代與以系統管理員身分執行相關程式集中存放於 `Program Files\Argus Privileged` 並採用固定檔名，安全軟體依路徑加入的信任於版本更新後持續有效。若安裝路徑位於 Program Files 之外，安裝程式會透過資訊圖示說明上述檔案的存放位置。（[@digital-bombyx](https://github.com/digital-bombyx) [#154](https://github.com/Ray-lea/Argus/pull/154)、[#136](https://github.com/Ray-lea/Argus/issues/136)、[#159](https://github.com/Ray-lea/Argus/issues/159)）

### 修正

- **磁碟詳細資料導致藍色畫面**：查詢溫度與 NVMe 健康資訊前先檢查控制器驅動程式，避免部分 Intel RST VMD 系統開啟磁碟詳細資料時觸發藍色畫面，略過的項目顯示為「未知」。若讀取期間或隨後兩分鐘內異常結束，下次啟動將暫停自動讀取，仍可手動選取「仍要讀取」。（[#48](https://github.com/Ray-lea/Argus/issues/48)、[#133](https://github.com/Ray-lea/Argus/issues/133)、[#160](https://github.com/Ray-lea/Argus/issues/160)）
- **裝置休眠**：在混合顯示卡筆電上略過已斷電獨立顯示卡的感應器查詢，避免反覆喚醒，效能頁同步顯示「已休眠」及原因。機械硬碟閒置時保留上次溫度讀數，停轉後略過溫度查詢，不再妨礙硬碟休眠。（[#147](https://github.com/Ray-lea/Argus/issues/147)）
- **CPU 讀數**：CPU 使用率改依閒置週期計算，修正將閒置迴圈計入負載導致的讀數偏高。修正 Windows 10 上混合架構處理器頻率缺失，以及部分 Intel 處理器無法區分效能核心與效率核心的問題。（[#137](https://github.com/Ray-lea/Argus/issues/137)）
- **GPU 讀數**：整合式顯示卡上的處理程序不再將共用 GPU 記憶體計入專用 GPU 記憶體。無硬體 GPU 時，軟體轉譯不再計作處理程序 GPU 使用率，處理程序頁同步隱藏 GPU 欄。若啟動時已偵測到硬體 GPU，更新驅動程式或接上新顯示卡後無須重新啟動即可恢復或顯示新讀數。
- **磁碟讀數**：修正 USB 外接硬碟無法讀取 SMART 資訊及健康狀態顯示為「未知」，以及 Google Drive 等虛擬磁碟機代號被誤列於磁碟 0 下的問題。
- **檔案使用狀況**：修正系統控制代碼總數過多時查詢檔案使用狀況失敗的問題。特殊權限服務與本機查詢因同一原因失敗時僅提示一次；已安裝特殊權限服務時不再重複建議啟用。
- **結束處理程序保護**：無法確認目標是否為系統關鍵處理程序時，拒絕執行結束操作，涵蓋單一處理程序、批次操作與處理程序樹狀結構。（[@hayxe1](https://github.com/hayxe1) [#77](https://github.com/Ray-lea/Argus/pull/77)）
- **處理程序頁**：搜尋或展開、摺疊群組時維持欄寬穩定；游標停留暫停排序期間展開子處理程序也維持原有列序。修正使用者群組列無法開啟右鍵選單、按兩下展開已選列時詳細資料窗格意外收合，以及部分程式名稱與版本資訊混入多餘字元的問題。
- **歷程處理程序跳轉**：從歷程記錄頁跳至處理程序時同步核對 PID、名稱與啟動時間，避免誤選重複使用同一 PID 的其他處理程序。（[@hayxe1](https://github.com/hayxe1) [#76](https://github.com/Ray-lea/Argus/pull/76)）
- **服務與啟動清單**：欄寬改為依內容自動分配，按兩下欄界可恢復自動寬度，手動調整的寬度於重新啟動後保留。無法取得啟動項目狀態時，「狀態」欄簡明顯示為「無法讀取」。
- **特殊權限服務與以系統管理員身分執行**：修正系統目錄誤判導致系統管理員執行與特殊權限服務無法啟用的問題。服務檔案遺失時標示為「已損毀」並提供修復或解除安裝入口；更新或解除安裝期間意外斷電時保留可用服務檔案，解除安裝 Argus 時同步清理服務取消註冊後的殘留檔案。（[#111](https://github.com/Ray-lea/Argus/issues/111)）
- **工作管理員取代**：當取代設定遭安全軟體等外部程式撤銷時，設定頁與首次啟動導覽會明確顯示「取代已被撤銷」。維護協助程式遭異常終止時，錯誤提示會附帶結束代碼。
- **安裝與載入安全**：安裝程式會檢查並保護符合條件的安裝目錄（僅允許系統管理員與系統寫入）；互動式全新安裝若無法保護所選位置，會說明原因並提供繼續安裝或變更位置選項。程式僅從系統資料夾載入所匯入的系統 DLL，忽略執行資料夾中的同名檔案。（[#136](https://github.com/Ray-lea/Argus/issues/136)）
- **視窗顯示**：修正最大化與還原缺少系統轉場動畫、從系統匣重新開啟時未維持最大化狀態，以及首次啟動或經工作管理員入口開啟時被其他視窗遮擋的問題。（[#126](https://github.com/Ray-lea/Argus/issues/126)、[#142](https://github.com/Ray-lea/Argus/issues/142)）
- **縮放與捲動**：修正在 125%、150% 等系統或介面縮放比例下，部分頁面捲動到底部後無法向上捲動以及對話方塊無法捲動的問題。縮放輸入框現可完整顯示三位數，欄位選項與操作提示的文字底部也不再裁切。（[#164](https://github.com/Ray-lea/Argus/issues/164)）
- **選單與對話方塊**：右鍵選單與子選單關閉時立即消失，下拉式清單從控制項位置展開並向原處收合。對話方塊改為從視窗中央放大淡入、關閉時縮小淡出，開啟期間視窗按鈕底色隨遮罩一同變暗。修正游標提示遮擋右鍵選單，以及停用選單項目仍顯示警示色或游標醒目提示的問題。（[#141](https://github.com/Ray-lea/Argus/issues/141)）
- **介面配置**：修正預設視窗大小下效能頁概覽顯示不全的問題；設定頁在較寬視窗中適度放寬內容寬度，對話方塊內容放得下時不再顯示多餘捲軸。
- **螢幕閱讀程式**：支援朗讀頁面標題、說明、效能讀數與表格儲存格，切換頁面或重新整理讀數後控制項仍維持可存取。設定頁的開關與數字輸入框改以對應設定項目的標題命名。（[#115](https://github.com/Ray-lea/Argus/issues/115)）
- **介面文字**：精簡冗餘的介面說明文字，統一各語言的 CPU、GPU、I/O 術語與硬體單位；俄文介面同步修訂錯誤提示、文法與單位間距。（[@Dimmitrius](https://github.com/Dimmitrius) [#93](https://github.com/Ray-lea/Argus/pull/93) [#95](https://github.com/Ray-lea/Argus/pull/95) [#96](https://github.com/Ray-lea/Argus/pull/96) [#98](https://github.com/Ray-lea/Argus/pull/98) [#100](https://github.com/Ray-lea/Argus/pull/100) [#101](https://github.com/Ray-lea/Argus/pull/101) [#102](https://github.com/Ray-lea/Argus/pull/102) [#103](https://github.com/Ray-lea/Argus/pull/103) [#104](https://github.com/Ray-lea/Argus/pull/104) [#105](https://github.com/Ray-lea/Argus/pull/105) [#106](https://github.com/Ray-lea/Argus/pull/106) [#108](https://github.com/Ray-lea/Argus/pull/108) [#109](https://github.com/Ray-lea/Argus/pull/109)）

### 升級提示

- **特殊權限服務**：透過安裝程式或應用程式內更新升級時，已安裝的特殊權限服務與工作管理員取代副本會一併更新。免安裝版替換主程式後，須於「設定 → 權限 → 特殊權限服務」中按一下「更新服務」並完成系統管理員授權。

- **免安裝版升級須知**：已安裝特殊權限服務時，替換主程式後仍需手動更新服務。在新版 Argus 的提示方塊或「設定 → 權限」按一下「更新服務」並授權即可。安裝程式更新服務失敗時，亦依此方式處理。服務更新前，依賴服務的網路、磁碟讀寫與 CPU 感測器資料暫時無法取得，需要提高權限的管理操作可能失敗。已開啟「取代系統工作管理員」時，Ctrl+Shift+Esc 仍可能開啟舊版；更新服務會一併更新取代程式，並維持取代功能開啟。

### 新功能

- **各處理程序的磁碟讀寫**：處理程序頁新增「磁碟讀取」與「磁碟寫入」兩欄，顯示各處理程序每秒讀寫磁碟的資料量，並可排序；依應用程式分組時顯示群組合計，詳細資料窗格亦可檢視。I/O 欄也包含網路與裝置的讀寫，與這兩欄分開統計。Windows 11 24H2 及更新版本無需額外權限；更早的系統需啟用特殊權限服務或以系統管理員身分執行，特殊權限服務的授權說明已加入此項。暫時沒有讀值時顯示「—」，游標停留時可檢視原因。視窗較窄時仍保留這兩欄，表格可左右捲動，名稱欄固定於左側；因此，執行緒、控制代碼、PID 與 I/O 欄會比以往更早隱藏。
- **應用程式內更新**：從本版本開始，新版本下載完成並通過簽章驗證後，標題列右側會出現更新按鈕，系統匣圖示顯示圓點，右下角亦會提示一次，每個版本僅提示一次。免安裝版不會自動下載，發現新版本時即提示。更新對話方塊依類別列出目前版本至新版本之間各版本的更新內容，並註明各版本的變更項目數；更新內容與安裝套件一樣經過簽章驗證。以滑鼠右鍵按一下更新按鈕可選取「此版本不再提醒」。已下載的更新在重新啟動 Argus 後無需重新下載。
- **更新後顯示更新內容**：更新完成後首次開啟視窗時，顯示新版本的更新內容。如不需要，可在「設定 → 更新」關閉「更新後顯示更新內容」，之後僅在右下角提示已更新。同頁的「檢視本版本更新」可隨時開啟更新內容。
- **背景重新整理間隔**：最小化與隱藏至系統匣時的重新整理間隔可分別設定，可選 0.5 至 30 秒，預設為 5 秒，在「設定 → 資料與歷程」及首次啟動導覽中修改。設為短於 5 秒時，會先說明 CPU 使用量與耗電將增加；長於 5 秒時，歷程記錄的密度亦會降低。視窗回到前景時立即重新整理；背景間隔比前景的重新整理間隔長時，右下角會提示一次，可直接前往設定調整，亦可選擇不再提醒。
- **快速鍵設定**：可僅停用快速鍵並保留組合，重新啟用即恢復。錄製時即時顯示目前按住的按鍵，無法使用的組合會說明原因，亦可按一下「重設為預設值」。Ctrl+字母、Alt+字母等容易與其他程式衝突的組合，經確認後才會儲存。組合被其他程式占用時可直接重試；占用的程式結束後，再次顯示視窗時亦會自動重試。
- **CPU 運作時間**：精確至秒，例如「5 天 14:03:07」，隨每次重新整理更新。

### 修正

- **當機**：修正部分沒有可用 Intel 顯示卡的電腦上，Argus 執行一段時間後可能當機的問題。
- **設定遺失**：修正儲存設定後不久發生斷電或強制重新啟動時，設定可能遺失，導致首次啟動導覽再次出現、語言改回跟隨系統的問題。
- **自動啟動**：自動啟動時不再搶走前景視窗焦點。先前在按一下其他位置前，鍵盤輸入都會進入看不見的 Argus 視窗。隱藏至系統匣期間，介面停止在背景持續繪製，大幅降低介面的 CPU 與 GPU 使用量，記憶體用量減少一半以上。
- **自動啟動項目**：在透過 Ctrl+Shift+Esc 開啟的 Argus 中啟用「登入 Windows 時啟動」，啟動項目會指向已安裝的 Argus。已指向工作管理員取代副本的啟動項目，在從「開始」功能表等位置開啟一次新版 Argus 後會自動修正。
- **背景重新整理**：最小化或隱藏至系統匣時，實際重新整理間隔與設定一致。先前應每 5 秒重新整理一次，實際常為 6 秒，有時達到 10 秒。以標準權限執行並使用特殊權限服務時，從系統匣或最小化還原視窗後，處理程序頁的網路欄不再偶爾短暫消失。
- **視窗**：最大化時，右上角不再出現兩組重疊的按鈕；游標貼齊螢幕頂端邊緣亦可拖曳視窗。
- **安裝與解除安裝程式**：完成頁的「關閉」、解除安裝確認頁的「取消」及核取方塊所在列改為置中顯示，先前略為偏左。
- **安裝升級**：直接執行安裝程式升級時，一併關閉由 Ctrl+Shift+Esc 或舊自動啟動項目開啟、仍在執行的舊版 Argus，避免升級後啟動仍轉交舊版，無需事先從系統匣結束程式。
- **解除安裝**：解除安裝時一併關閉由 Ctrl+Shift+Esc 開啟、仍在執行的 Argus。先前該程式會留在背景，勾選「一併刪除設定、歷程記錄與記錄檔」後重新安裝，首次啟動仍不顯示導覽，且舊設定會被重新寫回。設定等資料未能全部刪除時，解除安裝程式會列出剩餘資料夾。
- **首次啟動導覽**：按住 Ctrl+Shift+Esc 開啟 Argus 時，持續按住的 Esc 不再直接關閉導覽並將其標示為已完成。
- **快速鍵錄製**：錄製時按下目前組合或較長時間按住按鍵，不再意外隱藏視窗。使用非美式鍵盤配置時，錄製的按鍵與實際觸發的按鍵一致。按 Shift+Backspace 或 Win+Backspace 不再誤清除快速鍵。
- **快速鍵組合**：新設定的組合必須包含 Ctrl、Alt 或 Win，F13–F24 等少數按鍵除外；不再接受 Shift+字母這類會影響輸入的組合，亦不接受 Ctrl+C、Alt+F4 等常用編輯與系統操作。已儲存的組合不受影響。
- **快速鍵**：修正部分數字鍵盤按鍵被註冊為其他按鍵的問題。變更快速鍵時，若儲存設定失敗，不再產生無法取消的額外快速鍵。註冊失敗的原因依介面語言顯示。首次啟動導覽中，快速鍵被占用或無法使用時，僅顯示原因並說明可在設定中變更。
- **取代系統工作管理員**：更新特殊權限服務時，取代功能維持開啟，所用的 Argus 會一併更新至新版，無需先還原 Windows 工作管理員再於更新後手動開啟。啟用失敗時會指出遭拒的步驟及可能原因，例如安全軟體攔截登錄修改。狀態顯示「已有其他設定」時，會列出具體設定。關閉取代功能後，即使 Process Explorer 等其他工具接管工作管理員，仍可更新或解除安裝特殊權限服務。啟用失敗不再於服務目錄留下多餘的 Argus 副本；先前遺留的副本會在升級、開啟或關閉取代功能、更新或解除安裝特殊權限服務時清理，正在執行的副本除外。
- **處理程序**：未選取任何項目時按一下「顯示詳細資料」，會提示先在清單中選取一項，先前按下時沒有回應。快顯功能表或確認方塊開啟時，狀態列不再顯示「游標位於清單上，暫停重新排序」，清單亦不會在確認方塊彈出時重新排序。游標停留在清單上時以快速鍵切換頁面，此提示不再殘留於其他頁面的狀態列。
- **折線圖**：游標停留於折線圖右側邊緣附近時，讀值圓點不再卡頓。
- **切換更新通道**：檢查或下載更新期間切換穩定版或測試版，會依新通道重新檢查，不再提供原通道的版本。
- **診斷記錄**：失敗記錄改為明確記載系統錯誤碼；先前在非英文系統上，幾乎一律記為 operation failed。啟動時會記錄特殊權限服務無法連線的原因，例如版本不相容或回應逾時。

### 效能

- **處理程序頁**：降低系統概況中各邏輯處理器使用率小條的繪製負擔。折線移動時，介面每影格提交至顯示卡的資料減少約三分之一；I/O 欄中 WebView2 的讀寫量主要來自這些資料，因此亦隨之下降。

### 已知限制

- **磁碟讀寫**：Windows 11 24H2 及更新版本的讀取方式僅在組建 26300 驗證過；更早的系統改由特殊權限服務或系統管理員權限讀取，尚未在這些系統上驗證。若兩欄持續顯示「—」，可附上診斷記錄回報，讀取失敗的原因會記錄其中。
- **程式碼簽章**：程式尚未進行程式碼簽章，首次執行時 Windows SmartScreen 可能提示「未知的發行者」。
- **其他**：其餘限制見 GitHub 上的[已知問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)文件。

## 0.1.0 - 2026-10-16

Argus 的首個公開版本。

### 功能

- **處理程序**：依應用程式、處理程序樹或清單檢視，依名稱排序時分為「應用程式」與「背景處理程序」兩段；顯示各處理程序的 CPU、記憶體、I/O 與 GPU 使用量，啟用特殊權限服務或以系統管理員身分執行時另含網路流量；支援搜尋、結束處理程序或整個處理程序樹，詳細資料窗格顯示命令列、使用者、完整性等級等，依應用程式分組時顯示整個應用程式的合計。
- **優先順序與效率模式**：透過快顯功能表設定，亦可建立規則，在程式每次啟動時自動套用。
- **效能**：CPU（各核心、效能核心與效率核心、時脈、溫度、功耗、閒置狀態）、記憶體、磁碟、網路、GPU（NVIDIA、AMD 與 Intel 顯示卡另有功耗瓦數）與電池；折線依螢幕更新率連續移動，隨視窗大小縮放，較少使用的資訊收納於可展開的卡片。
- **核心感測器（選用）**：在設定或首次啟動導覽中啟用後，經特殊權限服務與官方 PawnIO 驅動程式讀取 CPU 內部感測器，包括各核心溫度與電壓、功耗與限制狀態、AMD SMU 資料，以及支援主機板的風扇轉速、電壓與溫度。
- **服務與啟動項目**：啟動、停止服務及修改啟動類型；啟用或停用啟動項目，與系統工作管理員使用相同的開關。
- **連線與連接埠**：TCP 與 UDP 端點及其所屬處理程序，支援依連接埠精確搜尋及中斷 IPv4 TCP 連線。
- **檔案使用狀況**：將檔案或資料夾拖放至視窗，結合 Restart Manager 與控制代碼列舉尋找使用中的處理程序，涵蓋處理程序的目前目錄。
- **歷程回溯**：記錄最近 7 天的資源使用量，按一下任意時刻即可檢視當時使用量最高的處理程序。
- **常駐系統匣**：透過全域快速鍵 Ctrl+Alt+Esc 顯示或隱藏視窗，隱藏時資源使用量極低。
- **選用特殊權限服務**：經一次系統管理員授權後，以標準權限執行的介面亦可管理系統處理程序、自動套用規則、統計各處理程序網路流量、控制服務及中斷連線。
- **系統工作管理員取代**：可讓 Ctrl+Shift+Esc 等入口開啟 Argus，並附帶不依賴介面與服務的獨立還原程式。
- **應用程式內更新**：提供穩定版與測試版兩個通道，可選用 GitHub 加速 Proxy；僅安裝通過簽章驗證的版本。
- **外觀**：工具列兼作標題列，導覽列位於工具列下方或視窗左側；Mica 背景與系統強調色，淺色、深色佈景主題預設跟隨 Windows，亦可在設定中指定。
- **安裝與解除安裝**：單頁安裝介面，跟隨 Windows 的淺色或深色模式；已安裝舊版時原地升級，解除安裝時可選擇一併刪除設定、歷程記錄與記錄檔。
- **多語言與首次啟動導覽**：介面、系統匣與安裝程式支援簡體中文與英文，預設跟隨 Windows 顯示語言；首次啟動時引導完成語言、顯示與重新整理、系統匣常駐、更新等常用設定，並可直接安裝選用的特殊權限服務、啟用核心感測器或取代系統工作管理員。

### 已知限制

- 程式尚未進行程式碼簽章，首次執行時 Windows SmartScreen 可能提示「未知的發行者」。
- CPU 內部感測器需要啟用核心感測器（特殊權限服務與 PawnIO 驅動程式）；支援的處理器與主機板見[硬體資料](https://github.com/Ray-lea/Argus/blob/main/docs/guide/hardware-data.md#消费级硬件兼容范围)。
- 其他限制見[已知問題](https://github.com/Ray-lea/Argus/blob/main/docs/known-issues.md)。
